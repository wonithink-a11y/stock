# 비용 확인

규칙 9(사용자 지시 2026-11-07): **지금은 무료만.** 유료는 **제안은 해도 되지만** 사용자 확인 없이 설치·가입·결제하지 않고, 실행은 **수익이 생겼거나 무조건 필요할 때만**.
이 프로젝트에서 돈이 샌 곳: GCP e2-micro 는 VM 이 무료 등급인데도 **외부 IPv4 가 월 약 $3.6** 이었다(기억으로 "무료"라고 믿은 것). 그래서 아래 절차를 쓴다.

## 1. 고르는 순서

무료 → 이미 있는 것(이 PC · GitHub Actions · Cloudflare Workers 무료 · Tailscale 무료) → 유료. 유료뿐이면 멈추고 비용부터 말한다.
Actions cron 은 4~5시간(최대 12시간) 늦는다 — 분 단위 알림엔 부적합(Workers 가 대안).

## 2. 확인 (기억이 아니라 공식 페이지)

- 이 세션 도구에서 `WebSearch` 는 모델 오류로 죽어 있었다 → **브라우저 패널**(`mcp__Claude_Browser__navigate` → `javascript_tool` 로 `document.body.innerText` 에서 키워드 주변만 잘라 읽는다. 전체를 읽지 않는다).
- 확인할 것 4가지: ① 단가(시간·GB·요청 단위) ② 무료 한도(**무엇이 포함되고 무엇이 빠지는지** — "무료 등급"이라도 IP·디스크 유형·네트워크는 따로일 수 있다) ③ 한도 초과 시 동작(차단/과금) ④ 확인한 URL·날짜.
- 이미 확인한 페이지: `cloud.google.com/vpc/network-pricing`(외부 IP) · `cloud.google.com/compute/disks-image-pricing`(디스크) · `developers.cloudflare.com/workers/platform/limits/` · `developers.cloudflare.com/kv/platform/limits/`.

## 3. 답하는 형식 (매번, 한 번으로 끝내지 않는다)

첫 줄에 **"유료 / 무료 — 월 정확히 얼마(단위·무료 한도, 확인한 출처 또는 '미확인')"**, 이어서 무료 대안. 같은 선택지를 다시 말하거나 실행 단계로 넘어갈 때마다 비용을 다시 적는다(이미 한 말이라고 생략 금지). 모르면 "미확인"이라고 쓰고 지어내지 않는다.

## 4. 이미 확인된 값 (2026-11-07 기준 — 쓰기 전 날짜가 오래됐으면 다시 본다)

| 항목 | 결과 |
|---|---|
| GCP 외부 IPv4(고정·임시, 표준 VM) | 시간당 $0.005 ≈ 월 $3.6, 무료 사용량 월 1시간 — VM 중지 시 임시 IP 해제로 요금 멈춤 |
| GCP e2-micro VM | us-west1·us-central1·us-east1 월 1대 무료 |
| GCP 디스크 | 표준 PD 30GB 까지 무료, 그 외 유료(공식 예시 표준 PD GiB당 $0.04/월) — 이 VM 의 유형은 미확인 |
| Cloudflare Workers 무료 | 크론 5개/계정 · 요청 10만/일 · 실행당 외부 요청 50건 · CPU 10ms/요청 |
| Cloudflare KV 무료 | 읽기 10만/일 · 쓰기 1천/일 · 1GB |
| Tailscale | 무료(Personal) 요금제 사용 중 |
| OCI Always Free | 계정이 종량제로 업그레이드돼 있었는데도 정지됨 — 무료여도 계정 정지 위험이 있다 |
| 상시 무료 VPS | Oracle·구글 e2-micro 둘뿐, 나머지는 체험 크레딧(기간 뒤 정가) |

## 5. 실제 청구 확인

GCP 콘솔 → 결제 → 보고서(그룹 기준: 서비스 / SKU / 프로젝트). **반영이 하루쯤 늦는다.** 프로젝트가 여러 개면 결제 → 계정 관리 → 연결된 프로젝트로 어느 것이 이 결제 계정에 묶였는지 본다. 지금까지 청구: Compute Engine ₩118(11-06~07, 외부 IP 추정), 나머지는 무료로 차감.
