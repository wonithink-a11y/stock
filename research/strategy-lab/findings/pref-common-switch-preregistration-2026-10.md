# 보통주·우선주 괴리 스위칭 — 사전등록

## 1. 자료·정의 (동결)

- KRX Open API 일별 전종목: `data/krx-pbr-history/daily/`(2010-01 ~ 2016-01) + `data/krx-daily-ext/`(2016-02 ~, 이번 밤 수집). 우선주 = 종목코드 끝자리 ≠ 0, 짝 보통주 = 앞 5자리 + '0'.
- 각 종목의 수익 지수 = `FLUC_RT` 복리(기업행사 반영). 괴리 `s_t = log(우선주 지수 / 보통주 지수)`(수준은 임의, 변화만 쓴다). `z_t = (s_t − 직전 250거래일 s 평균) ÷ 표준편차`(유효 200일 이상).
- 적격(신호일): 우선주 20일 평균 거래대금 ≥ 3억 · 보통주 ≥ 10억 · 두 종목 모두 그날 거래 · 12월 1일 ~ 1월 10일 신호 제외(배당락 계절).
- **P-cheap**: `z_t ≤ −2`(직전 날 > −2 에서 처음 넘음) → 우선주로 갈아탐. 결과 = t+1 종가 → t+21 종가 **(우선주 수익 − 보통주 수익)**.
  **P-rich**: `z_t ≥ +2`(처음 넘음) → 보통주로 갈아탐. 결과 = (보통주 − 우선주).
- 에피소드: 같은 짝·같은 칸은 40거래일 안 새 사건 무시. 구간(진입 연도): **TRAIN 2010~2017 · VALID 2018~2021 · TEST 2022~2026**.
- 비용: 갈아타기 1회 = 한쪽 매도(세금 포함) + 다른 쪽 매수 ≈ **33.5bp**.

## 2. 판정

- 귀무: 사건마다 같은 짝의 적격 무작위 날짜(사건 ±20일 제외)를 뽑아 같은 결과를 잰 평균(1,000회) → 칸별 99백분위(두 칸 동시).
- **INFORMATION** = 전체 평균 > 귀무 99백분위 ∧ 세 구간 모두 양 ∧ 진입월 6개월 블록 95% 구간 하한 > 0. **ECONOMIC** = INFORMATION ∧ VALID·TEST 평균 > 33.5bp.
- 기록: z ±1.5·±2.5, 보유 5·60일, 짝별 기여(상위 10짝), 삼성전자 짝 단독, 짝 수·연도별 사건 수.

## 3. 재실행·사후 금지

- ±2·250일·20일·40일·제외 기간을 결과를 보고 바꾸지 않는다. 현실적 기대: 되돌림은 있으나 20일 안에 33.5bp 를 넘을지는 불확실.
