# 래리 윌리엄스 3박자 (돈치안20 + LWTI + 거래량MA20) — 기각 (2026-09-10)

사용자가 텔레그램에서 공유된 매매법을 가져왔다. TradingView 지표 셋을 걸고
"3가지가 동시에 일치하는 순간 즉시 매수", 손절은 돈치안 중간선, 익절은
손절폭의 정확히 2배.

**결론: 기각한다.** 세 조건 전부 음(-)일 뿐 아니라, **조건을 더할수록
단조롭게 나빠진다.** 거래량과 LWTI 의 한계기여가 둘 다 음수다.

**2026-09-11 종결.** 마지막 빈칸이던 변형 C(돈치안+LWTI, 거래량 없음)를
돌려 2x2 를 닫았다 — 두 필터가 **각각 독립적으로** 해롭고 상호작용은
+0.001%p 로 사실상 0 이다(아래 §결과). 판정은 그대로 REJECT 이고 이 연구
라인은 여기서 닫는다(§종결).

## 방법

같은 엔진·유니버스·비용·기간에서 **필터만 켜고 끈다.**

```
데이터    A2a 일봉 OHLCV (A4 는 수급 데이터셋이라 high/low 가 없다)
유니버스  A1A_A1B_MERGED (상장폐지분 포함 - 생존편향 회피)
기간      2016-01-01 ~ 2026-08-14
진입      T+1 시가 (원문의 "즉시 매수"는 일봉으로 재현 불가 - 이 전략에 불리한 쪽)
청산      STOP_FIRST · 갭이면 시가 체결 · 60거래일 시간청산
비용      진입 15bps + 청산 15bps, 슬리피지 0
```

기존 엔진을 그대로 썼다 — `engine/indicators/donchian.py`(이미 prior-channel
shift) · `engine/execution/executor.py` · `pbr_vs_ew_monthly_mtm.py` 의 월말
MTM. 신규는 `engine/indicators/lwti.py` 와 `strategies/lw3_donchian_v1/` 뿐.

### 본 지표는 포트폴리오 성과가 아니다

`maxPositions=10` 인데 신호가 149,279건이다. 포트폴리오 경로는 대부분을
버리고 `tie_break: ticker_ascending` 이 편입을 정한다 — **그 숫자로 필터를
비교하면 필터가 아니라 알파벳 순서를 재게 된다.** 그래서 슬롯 제약을 뺀
**체결 가능한 모든 신호를 1건씩 동일가중**한 것을 본 지표로 둔다.

(이 함정은 `5dc-riskoff-vix-refined-filter-rejection-2026-08.md` 에서
반대 방향으로 한 번 걸렸다 — 거기서는 거래단위 관측이 슬롯 경쟁을 놓쳐
필터 방향을 잘못 가리켰다. 두 관점을 함께 남기는 이유다.)

### LWTI 는 정본이 없다 — 지어내지 않았다

Loxx Pine 참조식 `(close - close[n]) / ATR(n) * 50 + 50` 만 옮겼다.
**"빨강 -> 녹색"의 수치 정의가 공개 정의에 없다.** 두 규칙 다 실제로 쓰인다:

```
slope     lwti[t] > lwti[t-1]      지표선이 돌아섰다
midline   lwti[t] > 50             기준선을 넘었다
```

둘 다 돌렸고, 원문 "동시에 일치하는 순간"을 **당일 전환**으로 읽는 해석도
별도 변형으로 돌렸다. Loxx 원본의 스무딩 선택지는 미검증으로 남긴다.

### 2x2 가 닫혔다 — 두 필터는 각각 독립적으로 해롭다 (2026-09-11 추가)

C(돈치안+LWTI, 거래량 없음)를 돌려 네 칸을 다 채웠다. 평균수익(net), %p.

|  | 거래량 없음 | 거래량 있음 | 거래량의 기여 |
|---|---|---|---|
| **LWTI 없음** | A -0.184% | B -0.232% | **-0.048%p** |
| **LWTI 있음** | C -0.204% | D -0.251% | **-0.047%p** |
| **LWTI 의 기여** | **-0.020%p** | **-0.019%p** | 상호작용 **+0.001%p** |

★ **상호작용이 +0.001%p 로 사실상 0 이다.** 두 필터의 해로움이 거의 완전히
가법적이고, 어느 쪽을 먼저 켜든 값이 같다 — 앞선 판정이 **필터를 얹은 순서의
아티팩트가 아니었음**을 뜻한다. LWTI 단독 기여도 -0.020%p 로 음수라
"거래량이 LWTI 를 망쳤다"는 방어도 성립하지 않는다.

C 는 신호를 A 대비 6.5%(149,279 -> 139,641)만 줄인다. 거래량 필터(-10.9%)보다
느슨한데도 평균은 내려간다 — **적게 거르면서 나쁜 쪽을 고른다.**

**PF 가 A 0.9734 -> C 0.9708 -> B 0.9668 -> D 0.9644 -> D' 0.9577 -> D" 0.9406
으로 단조 감소한다.**
이건 "필터가 효과 없다"가 아니라 "필터가 해롭다"다. 그리고 **gross 에서도
같은 방향이다** — 비용 아티팩트가 아니다.

D" (당일 전환 해석)는 신호를 64% 줄이는데 평균이 오히려 더 나쁘다. 즉
"더 엄격하게 읽으면 더 좋아진다"는 방어가 성립하지 않는다.

### 왜 승률 36%가 부족한가

원문의 손익비 2:1 이 실제로 2:1 로 실현되지 않는다.

```
평균이익  +18.7 ~ +19.1%      평균손실  -10.8 ~ -11.0%      실현 손익비 ~1.73
```

2.0 이 아니라 1.73 인 이유는 시간청산(60일)과 갭 관통 손절이다. 손익비
1.73 의 손익분기 승률은 36.6% 인데 관측은 35.6~36.0% 다 — **비용 이전에
이미 아슬아슬하게 밑이고, 왕복 30bps 가 확실하게 밀어 내린다.**

청산 구성(A): 손절 55,259(59.7%) · 익절 28,937(31.3%) · 시간 8,316(9.0%).

중앙값이 -5.75~-6.71% 인데 평균이 -0.18% 다. 소수의 큰 승리가 다수의 손실을
거의 상쇄하는 전형적 추세추종 분포이고, **거의**에서 멈춘다.

### E(익절 제거)가 말해주는 것

익절을 없애면 평균이익이 +18.99% -> +28.72% 로 커진다(승자가 달린다).
그런데 승률이 35.75% -> 23.72% 로 무너져 PF 는 오히려 0.964 -> 0.923 이
된다. **"승자를 더 달리게 하면 살아난다"도 성립하지 않는다.**

(E 는 체결이 84,225 -> 64,948 로 준다. 익절 도달이 없어 보유가 27.6일 ->
42.1일로 늘고, 데이터 구간 끝에서 청산이 안 끝난 건이 늘어난 탓이다.
방향을 바꾸지는 않는다.)

## 한계 — 정직하게

- **시간프레임을 원문이 밝히지 않았다.** 돈치안 20은 20**봉**이다. 일봉으로
  읽었지만 분봉 전략이었을 수 있고, 그러면 이 결과는 그 전략을 기각한 것이
  아니다. 다만 분봉이면 R(종가-중간선)이 0.3~0.5% 수준이라 왕복 30bps 의
  상대 부담이 훨씬 커진다 — 이 방향의 결과가 더 나빠질 것으로 본다(미검증)
- **LWTI 스무딩 변형 미검증.** 색상규칙 두 축은 덮었으나 Loxx 원본의
  MA 스무딩 선택지는 안 돌렸다
- **거래단위 t값은 부풀어 있다.** 같은 날 수십 종목이 동시에 돌파하면 그건
  시장이 오른 것이지 신호가 맞은 게 아닌데, t값은 독립 표본으로 센다.
  주별 EW 대비 초과로 재는 것이 옳다(CLAUDE.md 함정 4). **다만 이 한계는
  판정을 바꾸지 않는다** — 부풀림은 t 의 절댓값을 키우는 방향이고, 여기서는
  평균 자체가 음수이며 gross 에서도 필터의 한계기여가 음수다
- **연도별·KOSPI/KOSDAQ 분리 미측정.** 전 구간 평균이 명확히 음이라
  추가하지 않았다

## 종결 (2026-09-11)

**이 라인은 닫는다.** 남은 자유도(분봉 시간프레임 · LWTI 스무딩 변형)는
위 §한계에 적어 두었으나, 그것들을 돌릴 이유가 없다 — **기준선 A(돈치안

음수 위에서 음수를 고르게 된다.

재개 조건: **기준선 A 가 양(+)으로 나오는 새 근거**가 생길 때. 필터 쪽의
새 아이디어만으로는 재개하지 않는다.
