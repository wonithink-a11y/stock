# 극저가 소형주 회피 — 홀드아웃 사전등록 (2026-11-17)

> **동결.** 이 문서를 커밋한 뒤 회피 규칙(가격 1,000원·시총 하위 3분위)·유니버스·구간·순열·문턱·비용을 바꾸지 않는다. 코드 `kr_penny_avoid.py`.
> **기록 전용 — 점수·매매 불연결.** 통과해도 반영은 🔴 별도 GO.

## 0. 왜 홀드아웃인가

- kr-nominal-price(결과 59657ace·a3a57bd7)는 INFORMATION(저가 3분위가 월 −23.7bp, 순열 p 0.0165)이었고, 효과가 소형~중형·1,000원 미만에 몰렸다는 것은 **결과를 본 뒤의 관찰**이다. 같은 표본(2016~2026)으로 '회피 규칙'을 다시 시험하면 우연히 고른 경계를 확인하는 셈이다.
- 그래서 **발견 표본과 겹치지 않는 2010-01~2016-01 일별 자료**(`data/krx-pbr-history/daily`, 같은 KRX 일별 스키마, 상장폐지 종목 포함 PIT 스냅샷)로만 판정한다. 발견 표본의 결과는 기록 전용이다.
- 규칙·방향·문턱을 홀드아웃 자료를 열기 전에 여기서 고정한다. 홀드아웃 자료는 구조(종목 수·A 건수)만 확인했고 수익은 보지 않았다(월말 종목 수 중앙 약 900, A 월 중앙 약 45).

## 1. 자료·정의 (고정)

- 홀드아웃: `research/strategy-lab/data/krx-pbr-history/daily/*.parquet`(2010-01~2016-01). 컬럼 BAS_DD·ISU_CD·ISU_NM·TDD_CLSPRC(**분할 미조정 명목 종가**)·FLUC_RT·ACC_TRDVAL·MKTCAP. 보통주 = ISU_CD 끝 `0`, 이름에 `스팩|기업인수목적` 없음. (ETF 이름 패턴 점검: 해당 없음.)
- 수익·불연속·폐지 처리는 kr-nominal-price 와 같다: FLUC_RT 누적 지수, |일 등락률| > 30.5% 인 날을 낀 월은 그 종목 제외, 다음 월말 행이 없으면 마지막 종가로 청산(0%).
- 형성일 t = 매달 마지막 거래일, **2010-02-26 ~ 2015-12-30 (71개월)**, 보유 = 다음 월말 종가까지(수익 월 2010-03 ~ 2016-01).
- 유니버스 U_t: 보통주 ∧ t 에 행 있음 ∧ **20거래일 평균 거래대금 ≥ 5억원**(최소 15일 이력) ∧ 시총 > 0. 시총 5분위는 U_t 안에서 MKTCAP 순위로 균등 분할.
- **회피 대상 A_t = { 종가 < 1,000원 ∧ 시총 5분위 중 1~3분위 }** (명목 종가, 하위 60% 소형).
- 반분: 전반 형성 월 2010-02~2012-12(35) · 후반 2013-01~2015-12(36).

## 2. 지표·판정 (고정)

- **D_t = EW수익(A_t) − EW수익(U_t − A_t).** 방향은 **D < 0** 으로 사전 고정(단측). 월 부트스트랩 95% 구간(2,000회).
- **순열 바닥선**: 같은 달 U_t 의 시총 1~3분위 풀에서 |A_t| 개를 무작위로 뽑아 같은 D 를 계산하고, 71개월 평균이 관측 평균 이하인 비율 + 1 보정 = **단측 p**(2,000회, seed 20261117). (A 의 소형 성질만으로 생기는 열위를 걷어내고 '가격 < 1,000원'의 몫을 본다.)
- **신호 있음** = 평균 D < 0 ∧ p ≤ **0.0042**(=0.05/12) ∧ 전반·후반 평균 D 모두 < 0. **INFORMATION** = 평균 D < 0 ∧ 0.0042 < p ≤ 0.05(또는 반분 부호 갈림). **REJECT** = 평균 D ≥ 0 또는 p > 0.05.
- **경제성**(신호 있음 또는 INFORMATION 일 때): 회피 이득 G_t = EW수익(U_t − A_t) − EW수익(U_t), 추가 매매 비율 ΔTO_t = |A_t △ A_{t−1}| / |U_t|. net_t = G_t − 33.5bp × ΔTO_t. 홀드아웃 전 기간 평균 net > 0 이면 통과. gross·95% 구간·net·손익분기 비용(= 평균 G / 평균 ΔTO)을 낸다.
- 표준 열: 반도체 제외 한 줄(진단 전용, 테마 'AI·반도체' ∪ 업종 '반도체 제조업'), 시기 칸은 홀드아웃이 2010~2015 한 칸이라 전·후반으로 대신한다.

## 3. 기록 전용 (판정 불사용)

① 발견 표본(2016-03~2026-09 형성 127개월)에서의 같은 D·G·p(사후 관찰 규칙을 같은 표본에서 되짚는 것이라 판정에 쓰지 않음) ② 홀드아웃+발견 합친 198개월 ③ 가격 문턱 500원·2,000원 민감도(대체 정의, 판정 불사용) ④ A 의 월 평균 종목 수·유니버스 대비 비중.

## 4. 하지 않는 것
