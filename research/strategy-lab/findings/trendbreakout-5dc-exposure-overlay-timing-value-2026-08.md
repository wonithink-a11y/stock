# TREND-BREAKOUT-v1 · 5DC-v1A-P — 미국10Y 노출조절의 순수 타이밍가치 분리검증 (2026-08-24)

`pbr-exposure-overlay-vs-ranking-cut-2026-08.md`(같은 날 오전)가 PBR에서
확인한 방법론적 교훈 — "노출을 줄이는 방식(구성 변화 vs 순수 오버레이)에
따라 결론이 완전히 달라진다" — 을 이어받아, overnight macro regime 조사
(job3)가 찾은 "TREND-BREAKOUT-v1·5DC-v1A-P는 미국10Y 상승기에 손실
집중"이라는 상관관계가 실제 타이밍 가치로 이어지는지 검증한다.

**사용자 지시(2026-08-24 낮)**: 추가 macro filter를 더 만드는 것보다
이미 발견된 축이 실제 성과를 설명하는지 독립검증하는 게 우선이라는
판단에 따라 착수. 대조군(상수 노출) 비교는 Claude가 결과를 보고 나서
직접 추가한 것 — baseline 자체가 심하게 손실나는 전략이라 "평균노출을
줄이면 손실도 준다"는 자명한 디레버리징 효과와 "macro 타이밍이 추가
가치를 주는가"를 가르지 않으면 또 같은 혼동에 빠진다고 판단했다.

## 방법

`pbr_exposure_overlay_vs_baseline_mtm.py`(PBR용)와 완전히 같은 오버레이
공식을 재사용하되 두 가지를 추가했다:

1. **부호 반전**: PBR·LOWMOM60은 hiking에 유리해 `exposure_frac`이 클수록
   비중을 키웠다. TREND-BREAKOUT·5DC는 정반대(hiking에 불리)라는 게 이미
   job3 findings로 확정돼 있어 `1 - exposure_frac`을 썼다 — 새 임계값이
   아니라 이미 검증된 부호를 그대로 반영한 것뿐, 축·TRAIL_DAYS(126)·p10/p90
   정규화는 PBR과 완전히 동일(재최적화 없음).
2. **상수노출 대조군**(신규): macro 조건 없이 매달 동일한 상수 비중만
   적용한 버전을 같은 baseline 수익률에 대해 계산 — 상수값은 동적
   오버레이의 평균노출과 정확히 맞췄다(0.532). **"오버레이 − 대조군"이
   순수 타이밍가치**다: 이게 0에 가깝거나 음수면 macro 조건은 그냥
   "평균적으로 덜 투자한 것"에 불과하고, 뚜렷한 양수면 조건부 타이밍이
   실제로 추가 가치를 준다.

## 결과 — 두 전략이 갈린다

| | TREND-BREAKOUT-v1 | 5DC-v1A-P |
|---|---|---|
| baseline | CAGR -13.30%, MDD -77.92%, Sharpe -0.7279 | CAGR -10.88%, MDD -70.46%, Sharpe -0.6423 |
| macro 오버레이 | CAGR -7.46%, MDD -55.97%, Sharpe -0.7878 | CAGR -5.09%, MDD -42.50%, Sharpe -0.60 |
| 상수노출 대조군(0.532) | CAGR -6.91%, MDD -53.14%, Sharpe **-0.7279**(baseline과 동일) | CAGR -5.61%, MDD -45.74%, Sharpe **-0.6423**(baseline과 동일) |
| **순수 타이밍가치(오버레이−대조군)** | **CAGR -0.55%p, Sharpe -0.0599** | **CAGR +0.52%p, Sharpe +0.0423** |

상수노출 대조군의 Sharpe가 baseline과 소수점까지 정확히 같은 건 수학적으로
당연하다(월수익률을 상수배하면 평균·표준편차가 같은 비율로 줄어 mean/std
비율은 불변) — 계산이 올바르게 됐다는 검산이기도 하다.

**TREND-BREAKOUT-v1: 타이밍가치 없음, 오히려 소폭 마이너스.** baseline
대비 개선처럼 보였던 CAGR +5.84%p·MDD 개선은 **전부 평균노출 53%로
줄인 디레버리징 효과**였다 - macro 조건을 걷어내고 상수 53%만 적용해도
거의 같거나(CAGR -6.91% vs 오버레이 -7.46%) 오히려 더 나은 결과가
나온다. macro 조건은 그냥 노이즈를 더한 것에 가깝다.

**5DC-v1A-P: 작지만 진짜인 타이밍가치.** 디레버리징 대조군을 제하고도
CAGR +0.52%p·Sharpe +0.0423이 남는다 - 방향이 뚜렷하고 세 지표(CAGR·
MDD·Sharpe) 다 대조군보다 낫다. 다만 baseline·오버레이·대조군 셋 다
여전히 깊은 마이너스(-5%~-11%)라는 걸 놓치면 안 된다 - "손실을 줄이는
타이밍"이지 "수익을 내는 타이밍"이 아니다.

## 결론

이번 세션이 PBR에서 이미 확인한 교훈이 여기서도 그대로 재현됐다 —
**"상관관계가 있다"와 "타이밍 필터로 쓰면 이득이다"는 다른 질문이고,
디레버리징 효과와 타이밍 효과를 분리하지 않으면 항상 과대평가한다.**
TREND-BREAKOUT-v1은 이 축으로 타이밍할 근거가 없다(연구 방향 종료).
5DC-v1A-P는 작은 양의 신호가 남아있어 완전히 닫히진 않지만, 두 전략
다 baseline 자체가 채택 가능한 전략이 아니므로(연구 후보 상태) 이 결과가
당장 실전 적용으로 이어지진 않는다.
