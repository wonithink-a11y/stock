# 바이낸스 신규 상장 7일 숏 — 무기한 진입 시각 — 사전등록

## 1. 질문과 배경

2026-11-13 독립 감사(Fable 5.2 서브에이전트)의 지적: `futures/binance_listing_perp.py:96` 은 무기한 일봉 시가를 진입가 t0 로 쓴다. 무기한이 t0 당일 장중에 처음 열렸다면 그 시가는 00:00 가격이 아니라
**첫 체결가**이고, 같은 줄에서 BTC 는 00:00 가격이다. 첫 체결가는 상장 직후의 단발 체결이라 호가가 얇고 높게 찍히는 경향이 있어, 그 값에서 숏을 잡았다고 보면 수익이 부풀 수 있다.
원 결과 문서의 `perp_before_spot`(프리마켓 비율)은 이 구분을 하지 않았고, '무기한 첫 봉 = t0' 건수는 기록되지 않았다(감사 확인).

겹침 점검: INDEX 에서 binance-listing-perp(EXECUTABLE) 는 닫힌 것이 아니다(크기·손절은 새 사전등록 대상). 이 실험은 **같은 사건 표본의 진입가 정의 오류 점검**이며 새 신호 주장이 아니다.
원 판정을 소급 수정하지 않고(기록 수정 금지) 새 결과 파일로만 남긴다.

## 2. 고정 사항

- **사건 표본**: 원 실험과 동일 — `binance_listing.events_table`(7bba3b1 동결본)로 만든 상장 사건, 7일 보유, `t1 ≤ 2026-10-01`, 무기한 매칭(`{BASE}USDT` 또는 `1000{BASE}USDT`), TRAIN ≤2022 · VALID 2023 · TEST 2024~(`cp.split`).
- **t0** = 현물 첫 일봉일 L + 1일(00:00 UTC). 원 계산: 진입 = t0 일봉 시가, 청산 = t0+7일 일봉 시가, 펀딩은 (t0, t1] 정산 합, BTC 무기한 대비.
- **분류** (무기한 첫 일봉 날짜 f 로):
  - **C**: f < t0 — t0 00:00 에 무기한이 이미 거래 중. 원 계산이 유효. **변경 없음.**
  - **D**: f == t0 — t0 당일 장중에 개설. 원 시가는 첫 체결가. **교체 대상.**
  - **X**: f > t0 — 원 실험도 t0 가격이 없어 제외. 건수만 기록.
- **D 건의 실행 가능 진입가 (주 정의)**: 무기한 1시간봉의 첫 봉 시각을 F 라 하고 **진입 E = F + 1시간(그 봉의 시가), 청산 = E + 168시간 봉의 시가.** BTC 무기한도 같은 E, E+168시간 시가.
  펀딩은 (E, E+168h] 정산 합. 수식은 원과 같다: `obs = (−(r − b) + 펀딩합) × 1e4`. 필요한 봉이 없으면 그 건은 교정 표본에서 제외(건수 기록). `E+168h > 2026-10-01` 이면 제외.
- **스트레스 (기록 전용)**: 진입 지연 4시간(E = F + 4시간)으로 같은 계산.
- **비용**: 원과 같이 10bp, 스트레스 30bp. 결과를 보고 바꾸지 않는다. 시장: 바이낸스 USDⓈ-M 무기한 하나.
- **교정 표본** = C 건(원 값) + D 건(교체 값). 상장일(L) 단위로 같은 날 코인 평균 → 구간별 집계는 원 코드와 같다.

## 3. 판정 (원 판정 규칙 그대로)

OOS = TRAIN 이 아닌 상장일(VALID+TEST). 코드 8512abb 의 규칙을 교정 표본에 그대로 적용한다:

| 판정 | 조건 |
|---|---|
| NOT EXECUTABLE | OOS 상장일 < 30 또는 비용 10bp 뒤 평균 ≤ 0 |
| EXECUTABLE | 10bp 뒤 t ≥ 2 ∧ 30bp 뒤 평균 > 0 ∧ TEST 단독 10bp 뒤 평균 > 0 |
| PARTIAL | 그 밖 |

**진입 시각 라벨** (기록 전용, 운용 영향 없음):
- 진입가 문제 없음 — 교정 판정이 EXECUTABLE ∧ OOS 10bp 뒤 평균 감소 ≤ 100bp(원 약 +1,011bp 의 10% 안팎)
- 진입가 문제 있음(규모 한정) — 교정 판정이 EXECUTABLE ∧ 감소 > 100bp
- 진입가 문제로 약화 — PARTIAL, 또는 NOT EXECUTABLE

**기록 (판정 불사용):** 구간별 C·D·X 건수와 D 의 비중 · 원 시가 vs 교정 진입가 괴리(D 건 중앙, bp) · D 건의 원 obs 평균 vs 교정 obs 평균 · D 제외(C 만) 결과 · 스트레스 4시간 결과 · 시기 3칸(~2023 / 2024 / 2025~).
