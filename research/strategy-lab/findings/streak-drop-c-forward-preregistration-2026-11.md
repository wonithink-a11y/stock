# 연속 하락 셀 C — forward 사전등록 (2026-11-17)

> **동결.** 이 문서를 커밋한 뒤 사건 정의·지수·기준·wave 규칙·판정 시점·문턱을 바꾸지 않는다. 판정 시점 전 `--judge` 는 코드가 거부한다(건수만).
> **기록 전용 — 매매·알림 없음. CONFIRMED 여도 매매 반영은 🔴 별도 GO.** 코드: `run_drop_events_forward.py` (arm `streak`).

## 0. 왜 forward 인가·선택의 한계

- 과거 판정(streak-drop-events-results-2026-11)은 INCONCLUSIVE(21일 p ≤ 0.01 지수 2~3곳 < 6). 조건 격자 두 건(39칸·150칸)도 새로 통과한 칸이 없었다. 같은 표본 재절단은 금지다.
- **셀 C 만 forward 로 뽑은 것은 결과를 본 뒤의 선택이다.** 그래서 이 갈래는 과거 표본에서 얻은 어떤 숫자도 근거로 쓰지 않고, 아래 forward 사건만으로 판정한다. 셀 A·B 는 하지 않는다.
- 닛케이(5일 −11.2%)·대만(7일 −15.6%)은 11-08 기준 이미 조건 충족 상태였으므로 그 사건의 첫 날은 지났다. 관측은 2026-11-18 이후 **새로 생기는** 사건만 센다.

## 1. 자료·사건 (고정)

- yfinance 일봉 종가(`auto_adjust=True`): `SPY` `QQQ` `^SOX` `^N225` `^GDAXI` `^HSI` `^KS11` `^KQ11` `^TWII` `000001.SS` `^FTSE` `^FCHI`. 실행 때마다 전 기간을 받고, 실행 당일(KST) 봉은 버린다.
- 연속 하락 길이 L_t = 직전까지 매일 종가가 전일보다 낮았던 연속 일수(오늘 하락 포함), 누적폭 D_t = 연속 시작 전 종가 대비 오늘 종가 수익. 사건 = L ≥ 5 ∧ D ≤ −10% 를 처음 만족하는 날, 같은 연속 안에서 반복하지 않으며 직전 사건과 10거래일 간격(`streak_drop_events.py` 와 같은 루프). 관측 사건 = 사건일 ≥ **2026-11-18**.
- 사건은 처음 보일 때 `events.jsonl` 에 한 번만 쓰고 이후 고쳐 쓰지 않는다.

## 2. 평가·기준 (고정)

- 사건일 종가 → 1·5·21·63일 뒤 수익(%)을 성숙할 때 `outcomes.jsonl` 에 한 번만 쓴다. 판정에는 **21일**만 쓴다.
- 기준: 지수별 무조건 1·5·21·63일 평균 수익 = **2026-11-06 까지 전 표본**. 첫 실행 때 `baseline.json` 에 쓰고 다시 쓰지 않는다. 초과수익 = 사건의 21일 수익 − 그 지수의 무조건 21일 평균.
- 기록(판정 불사용): 사건 다음 날이 또 하락일인 비율(hazard), 1·5·63일 수익, 지수별 건수.

## 3. 판정 (사건 wave 단위)

- 사건을 날짜순으로 정렬해 첫 사건일부터 30일 안에 드는 사건(지수 무관)을 한 wave 로 묶는다. wave 값 = 그 wave 의 성숙한 21일 초과수익 평균, 성숙 wave 수 = k.
- **판정 시점**: k ≥ 7 ∧ 첫 관측 뒤 12개월(`--judge` 1회). INCONCLUSIVE 면 36개월에서 같은 규칙으로 최종 1회. 36개월에 k < 7 이면 INCONCLUSIVE(종결, 표본 부족).
- **CONFIRMED_UP**(반등) = wave 평균 > 0 ∧ 양 wave 수 w⁺ 의 단측 이항 p = P(X ≥ w⁺ | k, 0.5) ≤ **0.0125**. **CONFIRMED_DOWN**(추가 하락) = 평균 < 0 ∧ 음 wave 수로 같은 규칙. 그 밖 INCONCLUSIVE.
- α = 0.05 / 4 (오늘 등록한 forward 4갈래 공동). k=7 이면 7/7 이어야 통과.
- 현실적 기대: 위기 때 사건이 몰려 wave 는 연 몇 개에 그친다 — **INCONCLUSIVE(표본 부족)가 가장 흔한 결과**다.
