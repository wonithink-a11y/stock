# 약한 단기 신호 결합 순위 모델 — 사전등록 (2026-10-11)

결과(수익률)를 보기 전에 고정한다. 계산 스크립트 `combined_rank_model.py` 는 이 파일과 자기 자신이 커밋된 상태가 아니면 수익률을 계산하지 않는다.

## 1. 데이터·모집단

| 항목 | 값 |
|---|---|
| 가격 | `data/backfill/price/a2a`(현재 상장) + `a2b`(폐지, 품질 통과분) 일봉 OHLCV. 두 곳에 다 있는 4종목은 A2a 우선. **데이터 끝 = A2a 마지막 날**(그 뒤 날짜는 버린다) |
| 준비 구간 | 2014~2015 는 특징 계산용으로만. 학습 신호일은 2016-01-04 부터 |
| 적격(신호일 t) | 보통주(코드 끝 0) · t 종가 있음 · t 까지 20거래일 거래대금(종가×거래량) 중앙값 ≥ 10억(유효 15일 이상) |
| 업종 | **요구하지 않는다** — 폐지 종목은 업종 매핑이 없어 요구하면 생존편향이 다시 들어온다 |

알려진 구멍: A2b 품질 검사 제외 151종목(최악의 폐지 일부)은 빠져 있다(세션인수인계-2026-10-10-b §1). 성과를 위로 미는 쪽이다.

## 2. 특징 (t 종가까지의 정보만, 30개 고정)

가격은 거래정지일을 직전 종가로 채운(최대 20일) 수정종가 `Cf` 로 과거 구간을 잰다. 종목 특징은 **그날 적격 종목 안 순위 백분위**로 바꿔 넣는다(결측은 결측 그대로).

| 묶음 | 특징 |
|---|---|
| 수익(6) | r1 · r5 · r20 · r60 · r120 · r_12_1(=Cf[t−21]/Cf[t−252]−1) |
| 오늘 봉(6) | ovn(=O/Cf[t−1]−1) · intr(=C/O−1) · clv(=(C−L)/(H−L), H=L 이면 0.5) · hl(=(H−L)/Cf[t−1]) · upsh(윗꼬리) · losh(아랫꼬리) |
| 변동성(3) | vol20 · vol60(일 수익 표준편차) · max20(20일 최대 일 수익) |
| 위치(5) | d52h(=C/252일 최고가−1) · d52l(=C/252일 최저가−1) · ma5 · ma20 · ma60(=C/이동평균−1) |
| 거래량(3) | rvol(=V/직전 20일 평균 V) · rvol5_60(5일 평균 V/60일 평균 V) · tv20(log 20일 거래대금 중앙값) |
| 습관(3) | streak(연속 상승일 +, 연속 하락일 −) · intr20 · ovn20(20일 평균 장중·밤사이 수익) |
| 원값·시장(4, 순위 변환 안 함) | r1_raw(±30% 자름) · mkt_r1 · mkt_r5 · mkt_r20(그날 적격 등가중 평균) |

## 3. 매매·라벨

- **진입** t+1 시가 · **청산** t+h 종가, **h ∈ {1, 5}**.
- 미체결(매매 제외): t+1 시가 없음 · **t+1 시가 ≥ t 종가 × 1.29**(상한가 시가).
- 청산일 종가가 없으면 — 거래정지는 **재개 첫 종가**, 폐지(A2b)는 **마지막 종가**, 현재 상장 종목이 데이터 끝을 넘으면 **미결(제외)**.
- **시장** = 그날 적격 종목 중 시가가 있고 미결이 아닌 종목의 같은 창 수익 등가중(상한가 시가 제외 규칙은 시장에 적용 안 함).
- **초과** = 종목 수익 − 시장.
- **학습 라벨** = 그날 적격·유효 종목 안 수익 순위 백분위 − 0.5.

## 4. 모델 (고정, 튜닝 없음)

- LightGBM 회귀(L2): num_leaves 31 · learning_rate 0.05 · 300회 · min_data_in_leaf 2000 · feature_fraction 0.8 · bagging_fraction 0.7(freq 1) · lambda_l2 10 · max_bin 63 · seed 20261011 · deterministic · 스레드 2.
- **walk-forward**: 예측 연도 Y(2018 ~ 2026)마다 학습 신호일 = 2016-01-04 ~ (Y 첫 거래일 − h − 1 거래일). 학습은 **짝수 번째 거래일(날짜 색인 짝수)** 신호일만 쓴다(겹치는 라벨 중복 축소·시간 제한). 예측은 Y 의 모든 신호일.
- h 마다 따로 학습한다.

## 5. 포트폴리오·통계·판정

- 매일 예측 상위 **20종목**(동률은 종목코드 순) 동일가중. 일값 = 체결된 종목 초과 평균. **체결 10종목 미만인 날은 제외.**
- 구간(신호일 기준): **TRAIN-WF 2018-01 ~ 2020-12** · **VALID 2021-01 ~ 2022-12** · **TEST 2023-01 ~ 끝**. 모든 예측은 학습 뒤 기간이라 TRAIN-WF 도 표본 밖이다.
- **월 군집 t** = 월평균들의 평균 / (표준편차/√월수). 신뢰구간은 월 단위 부트스트랩 2,000회 90%.
- **바닥선** = 매일 적격 종목 중 무작위 20종목(같은 체결 규칙)으로 같은 계산 200회 → TRAIN-WF 2셀 최대 |t| 의 95백분위. **2.0 보다 작으면 2.0.**
- **INFORMATION(셀별)**: TRAIN-WF 평균 > 0 이고 t ≥ 바닥선 · VALID 평균 > 0 · TEST 평균 > 0.
- **ECONOMIC(INFORMATION 셀만)**: VALID·TEST 각각 **초과 − 23.54bp > 0**(시가·종가 둘 다 단일가 체결: 매도세 20 + 수수료 3.54). 33.5bp(연속 매매)는 스트레스로 기록.
- 그 밖은 **REJECT**. TRAIN-WF 에서 음(−)으로 유의하면 기록하되 반대 방향 채택은 새 사전등록으로만.
- 표준 열: gross 초과 평균(90% 구간) · 비용 후 net(23.54 / 33.5) · 손익분기 비용 · **시기 세 칸 2018~23 / 2024 / 2025~**.
