## 0. 배경 (왜 v2인가)

기존 `price_structure_sweep.py`는 치명적 버그로 **전략 결과가 전부 비어 있었다**:
`run_backtest(symbol, strategy_name, params)`가 두 번째 인자 `strategy_name`으로
전략명을 받으면서도 내부에서는 `params.get("strategy")`(항상 빈 dict → `None`)를
읽어 모든 전략이 `else` 분기(포지션 전부 0)로 떨어졌다. 그 결과 모든 심볼·전략에서
`sig=0`, `position sum=0`, `rets=[0]`이었다.

이를 고치기 위해 **신규 스크립트 `price_structure_sweep_v2.py`를 생성**했다
(기존 파일은 git revert로 원상 복구 — "기존 파일 수정 금지" 지시 준수).

v2에서 고친 것:
1. 전략 신호를 `strategy_name` 인자로 판정 (버그 수정 → 실제 백테스트 동작).
2. OOS를 Train/Valid/Test 3윈도우로 나눠 각 윈도우에서 실행. Train에서 파라미터 선택
   (가변 리스크 파라미터만), Valid 고정 검증, Test 최종 평가. Test peek 없음.
3. 비용 모델 명시: 왕복 10bp + 편도 슬리피지 5bp (왕복 합계 20bp, 진입/청산 각 10bp).
4. `turnover = 왕복 거래 수 / 윈도우 일수` (v1은 항상 1.0이던 무의미한 값).
5. Test 윈도우에 연도별 성과 포함.
6. 심볼별 왕복 거래를 윈도우별로 집계 (v1은 전 구간 거래를 모든 윈도우에 중복 반영).

## 3. 판단

### 🔴 승인 불가 (REJECT) — 표본 한계로 순위 신뢰 불가한 계열
- **MA_Align, High52w_Breakout, High52w_Pullback**: OOS 윈도우(~8~21개월)에서
  심볼당 왕복 거래가 극히 적어, ≥5회 필터를 통과한 심볼이 2~5개뿐이다.
  Test 리더보드의 MA_Align(1위)과 High52w(2~4위,10위) 순위는 **그 소수 심볼의
  소수 거래에 좌우된 표본 산물**이다. 예: MA_Align Test CAGR +130%는 2개 심볼
  (ZECUSDT 291% + INJUSDT -30%)의 10개 거래 평균이고, 커버 심볼 수가 전략마다
  달라 **전략 간 비교가 사과-오렌지**가 된다. Train에서 CAGR -42.9%(MA_Align)·
  -19%(MA_Cross)로 대패한 후 Test +130%로 급등하는 것을 "검증된 성과"로 읽으면 안 된다.

### 🟡 조건부 (CONDITIONAL) — 표본은 충분하되 구간 비일관/성과 보통
- **Donchian_20 / Donchian_55 (+Bull)**: 21~28개 심볼이 커버되고(정직한 심볼
  평균), Train/Valid/Test 전 구간 일관 양수 CAGR(+11~18%)에 Test Sharpe +0.10~0.23,
  MDD -12~-20%, PF 1.9~3.4로 **이번 스윕에서 가장 신뢰할 만한 후보**. 다만
  연별 변동(2025 vs 2026)과 Bull 필터 효과가 제한적이라, 생존 편향(완만한 상승
  장 환경 OOS)을 의심해 추가 강건성 검증(다중 장 기간, 파라미터 근접성) 전까지는
  조건부.
- **MA20_Breakout / MA20_Breakout_Bull**: 28개 심볼 커버로 표본은 충분하지만
  Train/Valid/Test CAGR 부호가 뒤집히고(-4.6 → +10.0 → -3.0) Sharpe가 마이너스
  반복이라 방식 자체는 재현력이 낮다. Bull 필터가 MDD를 개선(-27.6 → -20.1)하나
  성과 개선은 미미. **조건부/거절**.
- **DM_ATR2_Trail5 / EMA_SL5_Trail5**: Train에서 높은 성과(Sharpe 0.76/0.56)를
  보여 선택됐지만 **Valid 0.95/0.18 → Test -0.25/-0.33로 반전**, Test TO 8.6%/9.4%
  로 이번 계열 중 거래·비용 부담이 가장 크고 마이너스 성과를 냈다. **파라미터
  선택이 Train에 과적합** → 거절.

### 🟢 승인 (PASS)
이번 OOS 스윕만으로 **어떤 전략도 PASS할 만큼 강력한, 재현 가능한 우위**가
나타나지 않았다. 가장 유망한 Donchian_20 계열조차 Sharpe ~0.2 수준으로,
"율로 보험·전략 결정을 내릴 임계값"에는 미달이다.

## 4. 결론 (요약)

1. **스윕 자체는 이제 실제 백테스트로 동작**한다 (빈 결과 없음, 리더보드 생성).
2. **이번 실험의 가장 중요한 발견은 표본 한계다**: 장기 보유 성격의 가격구조
   전략(MA 정렬, 52주 신고가)은 짧은 OOS 윈도우에서 심볼당 거래가 너무 적어
   순위가 신뢰 불가능하다. 1위 MA_Align은 2개 심볼 단 10거래의 산물.
3. **Donchian 20/55 계열만이 28개 심볼에서 일관된 양수 성과**(Test CAGR ~9~12%,
   Sharpe ~0.1~0.23)로, 앞으로 시도할 만한 유일한 후보. 다만 Sharpe 수준으로는
   단독 PASS급 우위가 아니며, 추가 강건성 검증 필요.
4. 리스크관리 파라미터는 Train 선택 → Test 반전으로 **과적합** 확인 (정책 교훈:
   짧은 Train 윈도우에서의 파라미터 선택은 신뢰하지 않는다).
