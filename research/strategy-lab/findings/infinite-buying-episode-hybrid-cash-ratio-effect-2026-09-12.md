# 3C — "저점 시점 현금비중"이 Hybrid v1 효과의 방향을 가르는가 (2026-09-12)

`infinite-buying-drawdown-episode-detector-2026-09-12.md`(3A) 후속.

> **NOT SUPPORTED.** 저점 현금비중은 Hybrid v1의 효과 방향을 일반적으로 설명하지
> 못했다. 최초 관찰된 TQQQ 42% / SOXL 2% 사례는 전체 episode 표본에서 재현되지
> 않았으며, 극단적 drawdown에서의 가능성은 표본 부족으로 판단하지 않는다.
> **추가 탐색은 수행하지 않는다.**

## 가설과 설계 (사전 고정, 사후 조정 없음)

3B 에서 관찰: TQQQ 2021-11-19 episode(저점 현금비중 42%)에서 Hybrid v1 이 악화,
SOXL 2021-12-27 episode(저점 현금비중 2%)에서 Hybrid v1 이 개선. 가설 —
**"원래 전략이 저점에서 이미 얼마나 de-risk 됐는지가 Hybrid 효과의 방향을
가른다(현금비중 낮음 → Hybrid 도움, 높음 → Hybrid 방해)."**

고정 사항(재선정·재조정 없음):
- episode 목록 = 3A 확정 그대로(threshold 25%, TQQQ 16 · SOXL 12 = 28건)
- Hybrid 파라미터 = 기존 실험값 max_frac=0.75 그대로(재튜닝 안 함)
- 보조 분석 창 = trough 후 고정 252거래일(결과 보기 전에 정함)

## 주분석 결과 — 상관관계가 사실상 없다

전체 28건(episode 별로 "peak_date~recovery/end_date" 를 새 시드로 재실행,
V4.0 vs Hybrid 비교):

```
[pooled]  n=28  Pearson(현금,ΔCAGR)= 0.145  Spearman= 0.245
[TQQQ]    n=16  Pearson(현금,ΔCAGR)= 0.167  Spearman= 0.143
[SOXL]    n=12  Pearson(현금,ΔCAGR)=-0.054  Spearman= 0.363
```

**부호부터 가설과 반대다** — 가설은 현금비중이 높을수록 Hybrid 가 불리(음의 상관)
해야 하는데, pooled·TQQQ 는 오히려 약한 양의 상관이다.

7건은 episode 가 너무 얕아 T 가 20을 못 넘어 Hybrid 메커니즘 자체가 발동을
안 했다(ΔCAGR=ΔMDD=Δ자산=0.00 정확히) — 이건 가설의 반증이 아니라 그냥 무관한
잡음이라 제외하고 21건으로 다시 봐도:

```
[pooled, 발동분만]  n=21  Pearson(현금,ΔCAGR)=-0.012  Spearman= 0.023
[TQQQ, 발동분만]    n=14  Pearson(현금,ΔCAGR)= 0.047  Spearman= 0.020
[SOXL, 발동분만]     n=7  Pearson(현금,ΔCAGR)=-0.153  Spearman= 0.000
```

전부 0 근처다 — 상관이 없다고 봐야 한다.

## 저/고 현금비중 그룹 비교

```
pooled(중앙값 44.4%)   저군(n=14) ΔCAGR -1.80%p   고군(n=14) ΔCAGR -0.54%p
TQQQ(중앙값 40.3%)     저군(n=8)  ΔCAGR -2.00%p   고군(n=8)  ΔCAGR -1.73%p
SOXL(중앙값 62.3%)     저군(n=6)  ΔCAGR -0.68%p   고군(n=6)  ΔCAGR +0.18%p
발동분만(중앙값 35.7%)  저군(n=11) ΔCAGR -1.45%p   고군(n=10) ΔCAGR -1.70%p
```

**전부 가설과 반대 방향이거나 구분이 안 된다** — 저현금비중군이 오히려 더
나쁘거나(pooled·TQQQ·SOXL) 거의 같다(발동분만). 가설이 예측한 "저현금비중군이
더 유리하다"는 어느 잘라도 안 나온다.

## 반례 (표 전체, 낙폭순 — 가설에 맞는 것만 추리지 않음)

발동분 21건 전체(낙폭 큰 순):


**"2022 크래시 둘(TQQQ·SOXL, 낙폭 82%·91%로 표 전체에서 가장 깊다)만 가설에
맞고, 그보다 얕은 위기에서는 저현금비중이 오히려 더 나쁜 사례가 여럿이다."**
이게 가장 중요한 관찰이다 — 원 가설은 **표본 2개(가장 극단적인 두 사례)에서
귀납한 것**이었고, 나머지 19건으로 넓히니 방향성이 사라진다.

**표본 한계를 명시한다** — episode 는 28건(발동분 21건)뿐이고 그중 낙폭 70%를
넘는 "진짜 위기"급은 3~4건뿐이다(SOXL 91%·80%, TQQQ 82%·70%). 원 가설이 관찰된
두 사례가 바로 이 극단 그룹에 속한다. **이 좁은 가설("최극단 크래시에서만
성립")은 이 표본으로 검증 자체가 불가능하다(n=3~4) — 확정도 기각도 안 하고,
추가로 추적하지도 않는다.** 문턱을 70%→65%→75% 식으로 옮겨가며 맞는 자리를
찾는 건 이 프로젝트가 이미 여러 번 REJECT 한 "사후 문턱 탐색"과 같은 함정이라
여기서 의도적으로 멈춘다.

## 결론 — 이 연구라인 종료

**Hybrid v1 의 효과를 "저점 현금비중"으로 설명하려던 시도는 기각한다.** 2022
크래시 둘에서 나온 설명은 일반화되지 않는다 — "가설이 틀렸다"보다 "현재 데이터
에서 설명변수로 쓸 만한 일반적 관계를 발견하지 못했다"가 정확한 표현이다.

이걸로 하이브리드 v1 라인의 "채택 안 함" 결론(§ hybrid-v1-quarterfrac-sweep)이
더 굳어졌다. 회복 runway 가설(§ crisis-path-decomposition)도 저현금비중 가설도
전체 표본에서 설명력이 없었다 — **무한매수법 파라미터 탐색(max_frac·분할수·
리버스 공식 등)은 여기서 중단한다.** 새 가설을 만들어 3D·3E 로 계속 쫓지 않는다
— 이미 반증이 충분히 쌓였고, 여기서 멈추는 게 연구 품질상 맞다.

다음에 이 종목군을 다시 볼 때는 파라미터 최적화가 아니라 **"이 전략이 어떤
가격 경로(추세장·급락·V자반등·장기횡보·장기하락)에서 구조적으로 유리·불리한가"**
· **B&H 대비 성과를 cash drag/averaging benefit/recovery capture 로 분해하는 것**
· **일봉 LOC 체결 가정(종가≤지정가 → 체결)이 실제 Nasdaq Closing Cross 체결과
얼마나 다른가** 세 방향이 후보다 — 파라미터가 아니라 별도의 새 연구라인
(`Infinite Buying V4.0 — Path Dependence / Execution Reality`)으로 다룬다.
