# OKX 신규 상장 7일 — BL7 재현 — 사전등록

## 1. 질문과 배경

BL7(`binance-listing`, ROBUST)은 바이낸스 신규 상장 코인이 상장 다음 날부터 7일 동안 BTC 대비 평균 약 9~12% 덜 올랐다는 결과다. 업비트 가격으로도 같은 방향(CONSISTENT)이었으나 그 표본은 바이낸스 상장 코인의 부분집합이다.
이 실험은 **바이낸스와 무관한 새 표본**에서 같은 방향이 나오는지 본다. OKX 가 바이낸스보다 먼저 상장했거나 바이낸스에 아예 없는 코인이 대상이다.
겹침 점검: 새 표본 재현이므로 같은 표본 재판정이 아니다. 매매 규칙 주장이 아니다(비용·실행성 판정 안 함).

## 2. 고정 사항

- **자료(공개 API, 키 없음)**: OKX `GET /api/v5/public/instruments?instType=SPOT`(상장 시각 `listTime`, `state=live` 만 반환) · `GET /api/v5/market/history-candles`(`bar=1Dutc`, 첫 봉 이후 일봉). BTC 대조 = OKX `BTC-USDT` 일봉.
- **사건**: `quoteCcy=USDT` 인 현물, `bl.eligible(base)`(스테이블·레버리지 토큰 제외, 바이낸스 BL7 과 같은 함수), 첫 일봉 일자 L(UTC) ≥ 2018-01-01, `t0 = L + 1일`, 청산 `t1 = t0 + 7일`, `t1 ≤ 2026-10-01`.
  **바이낸스 오염 제외**: 바이낸스 어떤 마켓이든 그 코인의 첫 상장 월(`data/crypto/listing/months.json` 의 첫 월)이 `t0 + 8일`이 속한 월 이하이면 제외한다(바이낸스 상장 이벤트가 7일 창 안이거나 이전). 바이낸스 자료 범위는 2026-09 까지이며 그 뒤 월은 창 밖이다.
  제외 후 두 갈래를 기록한다(판정은 합친 표본): **A** = 바이낸스에 나중에 상장된 코인 · **B** = 바이낸스에 한 번도 없는 코인.
- **관측**: `rel = (OKX 코인 t1 시가 / t0 시가 − 1) − (BTC t1 시가 / t0 시가 − 1)`. 같은 L 의 코인은 평균해 상장일 하나로 센다(BL7 과 같다).
- **구간**: 상장일 L 기준 TRAIN ≤2022 · VALID 2023 · TEST 2024~ (`cp.split`), OOS = VALID+TEST.
- **생존편향(한계, 사전 고지)**: `instruments` 는 현재 `live` 인 상품만 준다 — 상장 후 폐지된 코인이 빠진다. 폐지 코인은 보통 이후 약했으므로 숏 쪽 효과를 **보수적으로** 만든다(표본이 살아남은 코인으로 편향).

## 3. 판정 (재현 여부)

| 라벨 | 조건 |
|---|---|
| 재현 | OOS 상장일 ≥ 40 ∧ OOS 평균 rel < 0 ∧ OOS 상장일 평균의 t ≤ −1.65(한쪽 5%) ∧ TRAIN 평균 rel < 0 |
| 부분 재현 | OOS 평균 rel < 0 이나 t > −1.65, 또는 OOS 는 맞으나 TRAIN 평균 ≥ 0 |
| 재현 실패 | OOS 평균 rel ≥ 0 |
| 정보 부족 | OOS 상장일 < 40 |

**기록(판정 불사용):** A·B 갈래별 평균·t · 시기 3칸(~2023 / 2024 / 2025~) · 코인 단위 분포(백분위 5/25/50/75/95) · 7일 경로 중 BTC 대비 최악 상승(꼬리) · 바이낸스 BL7 원 값(OOS 약 −1,000bp대)과의 크기 비교 · 사건 수·제외 사유별 건수.
**강건성 점검(기록):** 상장일 평균 대신 코인 단위 평균의 군집 부트스트랩(상장 월 블록 10,000회, seed 20261114) 95% 구간.

## 4. 현실적 기대

OKX 신규 상장도 약세 방향일 가능성이 높다(일반적 신규 상장 약세). 다만 OKX 는 유동성이 작은 코인이 많아 분산이 커 t 가 −1.65 를 못 넘길 수 있고, 생존편향이 보수적으로 작용해 "부분 재현"이 가장 그럴듯하다.
숏 실행(OKX 무기한 등)은 판정하지 않는다.

## 5. 범위 밖

비용·숏 실행성·크기·손절 · 다른 거래소(Bybit·Bitget·Gate) · 상장 직후 시간 단위 경로 · 바이낸스 BL7 재판정. 어떤 결과여도 운용·모의 슬리브·정책은 바뀌지 않는다.

## 6. 하지 않는 것

결과를 보고 오염 제외 기준(월)·보유 7일·문턱(−1.65·40일)·자료 소스를 바꾸지 않는다. 같은 표본 재절단 금지. 남은 길: 다른 거래소 새 사전등록.
