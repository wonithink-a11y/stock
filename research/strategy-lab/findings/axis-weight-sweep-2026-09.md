# 축 가중치 재조정(A층) — 수급 축이 점수를 깎고 있다

현재 KR-2.3 의 축 배점(fundamental .35 / valuation .30 / technical .15 /
supplyDemand .20)은 프로젝트 초기에 데이터 없이 정해졌고 측정으로 확인된 적이
없다. 사용자가 "초반에 아무 데이터 없이 설계한 부분이 문제 아닌가"라고 제기해
착수했다.

## 방법 — 재백필 없이 잰다

A5 패널이 축별 기여도 `c` 를 저장하는데 **이미 재정규화된 값**이다(축이 둘만
있는 행의 기여합이 그 축들의 가중합 상한을 넘는 것으로 확인). 정확한 역산:

```
축 원점수 = c[축] x (존재 축 가중치 합) / W[축]
새 점수   = Σ 새W[축] x 축 원점수 / Σ 새W[존재 축]
```

복원값이 0~100.1 에 들어가고 오차는 소수 1자리 반올림뿐(|기여합 - raw| 최대
0.2, 0.25 초과 0건). **처음에 `c / W` 로 역산했다가 틀렸다** - 재정규화를 안
되돌리면 결측 축이 있는 행에서 조용히 어긋난다.

측정은 날짜별 횡단면 Spearman IC + **Newey-West(lag=4)** - d20 이 주간 스냅샷
4개와 겹치므로 naive t 는 부풀려진다. 패널 1,201,741행 · 553일 · d20.
판정 기준은 착수 전에 고정했다(TRAIN 에서만 선택, 난수 바닥선 통과, 부호 반전 0).

## 결과 — 상위 10개가 전부 supplyDemand = 0

격자 286개(0.1 단위, 축 하나가 0 인 경우 포함) TRAIN IC 상위:

| 가중치 F/V/T/S | TRAIN | VALID | TEST |
|---|---|---|---|
| **0/100/0/0** | +0.0548 | +0.0591 | +0.0919 |
| 20/70/10/0 | +0.0469 | +0.0531 | +0.0831 |
| 30/60/10/0 | +0.0469 | +0.0546 | +0.0846 |
| **30/50/20/0** | +0.0469 | +0.0547 | +0.0845 |
| 20/60/20/0 | +0.0468 | +0.0526 | +0.0820 |
| 40/50/10/0 | +0.0456 | +0.0555 | +0.0853 |
| *(현행) 35/30/15/20* | *+0.0351* | *+0.0491* | *+0.0793* |

**상위 10개 전부 supplyDemand 가중치가 0 이다.** 난수 가중치 200개(Dirichlet)
바닥선은 중앙 +0.0284 · **p95 +0.0452** · 최대 +0.0475 - 상위권이 이를 넘는다.

이는 2026-08-19 slot-marginal 발견("수급 5일 추세를 얹으면 IC 가 오히려 감소")의
독립적 재확인이다. 수급 축은 커버리지 94.4% 로 대부분의 행에 존재하므로,
결측 때문이 아니라 **있는 값이 점수를 희석하고 있다.**

## ★ 커버리지 교란을 통제했다

TRAIN 최선인 `0/100/0/0`(valuation 단독)은 **전체 행의 53.6% 에만 점수를 낸다** -
valuation 축이 그만큼만 존재하기 때문이다. 나머지 후보는 99.8~100% 다. 서로 다른
유니버스를 비교하는 것은 같은 날 lowmom60 에서 결론을 한 번 뒤집었던 실수라
(`lowmom60-test-negative-regime-diagnosis-2026-09.md` §0), valuation 이 있는
행만으로 다시 쟀다.

| 표본 | 구간 | 현행 35/30/15/20 | valuation 단독 | **30/50/20/0** | 수급만 0 (44/38/19/0) |
|---|---|---|---|---|---|
| 전체 1,201,741행 | TRAIN | +0.0351 (t6.5) | +0.0548 (t5.3) | **+0.0469** (t7.5) | +0.0437 (t7.2) |
| | VALID | +0.0491 (t5.0) | +0.0591 (t4.1) | **+0.0547** (t5.8) | +0.0558 (t5.8) |
| | TEST | +0.0793 (t8.2) | +0.0919 (t5.5) | **+0.0845** (t7.8) | +0.0847 (t8.3) |
| 공통 643,547행 | TRAIN | +0.0390 (t4.9) | +0.0545 (t5.3) | **+0.0517** (t5.7) | +0.0443 (t5.4) |
| | VALID | +0.0553 (t4.6) | +0.0581 (t4.1) | **+0.0616** (t4.8) | +0.0596 (t4.9) |
| | TEST | +0.0896 (t6.0) | +0.0905 (t5.4) | **+0.0949** (t5.9) | +0.0927 (t6.0) |

**교란이 결과를 뒤집지 않았고 오히려 정리해줬다.**

- `valuation 단독`은 TRAIN 최고지만 **커버리지 53.6% 라 실용성이 없고**, 공통
  표본의 VALID·TEST 에서는 `30/50/20/0` 에 진다. 채택 대상이 아니다.
- **`30/50/20/0` 이 두 표본 x 세 구간 = 6개 셀 전부에서 현행을 이긴다.**
  커버리지는 99.8% 로 사실상 유지된다.
- 가중치 비율은 그대로 두고 **수급만 뺀** 변형(44/38/19/0)도 6개 셀 전부 개선 -
  개선의 원천이 "수급 제거"임을 보여준다.

## 판정

**PASS.** `30/50/20/0`(fundamental .30 / valuation .50 / technical .20 /
supplyDemand 0)을 KR-2.4 후보로 올린다. 부호 반전 0건, 난수 바닥선 통과,
커버리지 유지, 두 표본 세 구간 전부 개선.

사용자 가설 셋 중 둘이 실측으로 확인됐다 - **재무 비중이 과하다**(35% -> 30%,
그리고 valuation 이 30% -> 50%), **초기 설계가 측정 없이 정해진 것이 실제
문제였다.**

## 한계

1. **이건 A층(축 배점)이다.** "재무를 여러 지표로 세분화한다"는 축 내부 문제라
   여기서 답이 안 나온다 - A5 재백필이 필요한 B층이다.
2. **`supplyDemand`를 삭제하라는 뜻이 아닐 수 있다.** 2026-08-19 발견은 5일 창
   정의가 역방향일 가능성을 지목했고 A4 연구의 20일 누적은 양(+) IC 였다.
   **정의를 고치는 것(5d->20d)이 축을 버리는 것보다 나을 수 있다** - 그것도 B층.
3. `30/50/20/0` 의 TRAIN IC(0.0469)가 난수 p95(0.0452)를 간신히 넘는다. 난수
   벡터 대부분이 수급에 가중치를 주므로 바닥선 자체가 낮게 잡혔을 수 있다 -
   "특별한 가중치를 찾았다"가 아니라 **"해로운 축을 뺐다"**로 읽는 것이 정확하다.
4. 지평은 d20 하나, 유동성 필터 없음(패널 전체 3,001종목). IC 이지 백테스트가
   아니다 - 실제 엔진에서 슬롯·비용·MTM 을 넣으면 달라질 수 있다(오늘만 세 번
   확인했다).
5. criteria 승격은 🔴 - `config/criteria/KR-2.4.json` 신설 + registry 승격 +
   A5 재백필은 별도 GO 다.
