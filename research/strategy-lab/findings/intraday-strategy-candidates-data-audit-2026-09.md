## 2. 후보별 판정

### ST-1 ORB (Opening Range Breakout) — 데이터 O · **이미 부분 연구됨**

| | |
|---|---|
| 필요 데이터 | 장 초반 1~30분봉 |
| 보유 | **O** (252일) |
| 구현 | **가능** |
| 기존 연구 | `open30-event-study`(09:00~09:29 형성 → 09:30 as-of 판정, 5패턴 분류) · `minute-opening-fade` 계열 **7건** · `intraday-timeofday` · `archive/opening-fade/` |

**빈 영역이 아니다.** 다만 우리가 본 것은 **페이드(반전)** 쪽이고, "OR High
상향돌파 매수"라는 ORB **본래 방향은 정면으로 검증한 적이 없다.** 그런데
`intraday-timeofday` 가 이미 09:00~09:30 창수익률 5분위 → 잔여 당일 초과수익
**Q5-Q1 -0.281%, IC -0.0589 (t=-10.38)** 를 측정했다. 즉 **초반에 오른 종목이
이후 진다** — ORB 돌파매수와 반대 방향의 사전 증거가 이미 있다.

### ST-2 VWAP Mean Reversion — 데이터 △ · **유일한 미검증 축**

| | |
|---|---|
| 필요 데이터 | 1~5분봉 + 세션 시작점 (+ 정확한 VWAP 은 거래대금) |
| 보유 | **△** — 분봉은 있으나 **거래대금 필드가 없다** |
| 구현 | **가능(근사)** — `cumsum(close×volume)/cumsum(volume)`. 정확한 체결가중이 아니라 분봉 종가 가중이다 |
| 기존 연구 | **없음.** `v6_extract_buy_vwap.py` 는 A4 기반 **일별** 외국인/기관 매수단가지 장중 VWAP 이 아니다 |

**5개 중 진짜로 비어 있는 유일한 축이다.** 근사의 한계는 명시해야 한다 —
1분 안의 체결 분포를 모르므로 변동성이 큰 분에서 오차가 커진다.

### ST-3 Gap Reversal — 데이터 O · **이미 연구했고 결과가 있다**

`kr-gap-overnight-effect-2026-08.md` (2026-08-28, **WEAK / FOLLOW-UP**)

```
gap[t] -> intraday[t]  IC(Spearman)
  TRAIN  -0.206  t=-19.38      CAGR +7.0%  Sharpe 1.76  MDD -2.5%
  VALID  -0.164  t= -9.05
  TEST   -0.142  t= -7.68      CAGR -1.3%   <- 최근 실질 소멸
```

효과의 **부호는 세 구간 모두 유지**되는데 **수익이 사라졌다.** 일봉
(open/close)으로 잰 것이라 **장중 경로는 안 봤다** — 분봉으로 "언제 되돌리는가"
를 다시 보는 것은 새 정보를 준다. 단 새 가설이 아니라 **기존 WEAK 판정의 후속**
으로 다뤄야 한다.

### ST-4 Intraday Momentum + Volatility Filter — 데이터 O · **부분 연구됨, 부호가 반대**

| | |
|---|---|
| 보유·구현 | **O / 가능** |
| 기존 연구 | `intraday-timeofday`(창별 수익률 → 잔여 당일), `minute-volume-profile`, 오늘의 `dma-stoch50` 이벤트 스터디 |

우리 실측은 **장중 모멘텀이 아니라 반전**을 가리킨다.

```
intraday-timeofday   창수익률 5분위 -> 잔여 당일 초과수익  IC -0.0589 (t=-10.38)
dma-stoch50 이벤트   진입 후 1~120분 상대수익 126/126 셀 음수 (-0.67 ~ -2.55bp)
minute-opening-fade  초반 5분 수익률 -> 잔여 구간 음의 단조 (Q5-Q1 -34.6bp)
```

**변동성 threshold 축만 미검증**이다. 다만 위 세 결과를 뒤집으려면 그 필터가
부호 자체를 바꿔야 하는데, 그건 사전 확률이 낮다.

### ST-5 Order Flow / Tick — 데이터 **X · 구현 불가**

| | |
|---|---|
| 필요 데이터 | 체결 스트림(시각·방향) 또는 L1+ 호가 스냅샷 |
| 보유 | **0건** |
| 구현 | **불가능** — 파생으로도 못 만든다 |

★ 제안문의 *"우리도 이미 KIS 실시간 체결/호가 데이터를 연구하고 있었죠"* 는
**사실이 아니다.**

- 저장소의 order-flow findings 2건(`order-flow-imbalance-audit`·`-predictive`)은
  **`track: crypto`** 다. 데이터는 Binance `activity/` 의 `taker_buy_quote_asset_volume`
  이고 KR 과 무관하다. 그중 predictive 는 **FAIL**(스프레드가 10bp 비용 대비 너무 작음).
- KR 체결·호가는 수집 스크립트·정책·프로브가 **전무**하다.
- A4 로 대체 불가: ① 최소 해상도가 '일'(장중 사용 시 PIT 위반) ② 체결시각·방향
  부재 ③ 투자자구분 집계지 주문흐름이 아님 ④ 장 마감 후 확정치.

**이 축을 열려면 데이터 수집 결정이 선행한다** — 새 외부 데이터 소스 통합이므로
CLAUDE.md 실행 기준상 **확인 대상**이고, 보존기간·저장량·PIT 계약을 새로 써야 하므로
사실상 🔴 이다.

## 3. 이 시간축의 구조적 사실 — 신호는 이미 여러 번 찾았다, 전부 비용에서 죽었다

이게 후보 목록보다 중요하다.

| 연구 | gross | 비용 | net |
|---|---|---|---|
| 오프닝 페이드 롱숏 (`minute-fade-net-costs`) | **+34.6bp/일** | 최소 드래그 **60bp**(하루 4체결) | **-25.4bp** |
| 오프닝 페이드 호라이즌 확장 (`minute-opening-fade-cost`) | 당일 3구간 전부 음 | RT 20/30/40bp | T+5 +9.2bp·T+10 +3.1bp 만 손익분기 근방 |
| DMA+Stoch50 분봉 (2026-09-09) | 코어 36/36 **음** | 왕복 30bp | 전부 -97% 이하 |
| DMA+Stoch50 이벤트 스터디 | 진입 후 -0.67~-2.55bp | 문턱 30bp | 부호부터 반대 |

**분봉 시간축에서 우리가 찾은 우위의 크기는 일관되게 1~35bp 이고, 왕복 비용은
30~60bp 다.** 새 후보를 열 때 이 숫자를 먼저 놓고 시작해야 한다 — "신호가
있는가"가 아니라 "**30bp 를 넘는 신호인가**"가 질문이다.

## 4. 권고 (하나만 고른다)

후보 5개 트랙을 새로 여는 것은 권고하지 않는다. 순서는 이렇다.

1. **`intraday-data-inventory-2026-08` 갱신** — 그 문서는 "분봉 0건"이라고
   적혀 있고 지금은 252일이 있다. 낡은 재고 문서는 다음 사람이 같은 감사를
   반복하게 만든다. (🟡, 30분)
2. **ST-2 VWAP 이격 이벤트 스터디 1회** — 5개 중 유일한 미검증 축이고,
   오늘 만든 `dma_stoch_kr_event_study.py` 를 그대로 재사용한다(신호 정의만 교체).
   판정선은 같다: 30bp. 넘는 horizon 이 없으면 닫는다.
3. **ST-1 ORB 는 2번 결과를 보고 결정** — 사전 증거(IC -0.0589)가 반대 방향이라
   우선순위가 낮다. 열더라도 "돌파매수"가 아니라 **돌파 실패 후 되돌림** 쪽이다.
4. **ST-5 체결/호가는 데이터 결정 먼저.** 전략 설계가 아니라 수집 계약 문제다.
   분봉과 달리 **소급이 아예 없고**(오늘부터만), 저장량이 분봉의 수십 배다.

ST-3(Gap)·ST-4(Momentum)는 기존 판정이 이미 있으므로 **새 트랙으로 열지 않는다** —
필요하면 기존 finding 의 후속으로 붙인다.
