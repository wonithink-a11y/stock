## 1. 연구 목적

KRX 선물의 단기 가격변화가 한국 개별주식의 미래 수익률에 **추가적인** 정보를
제공하는지 검증한다. **처음부터 거래전략을 만드는 것을 목적으로 하지 않는다.**

판정은 셋으로 분리한다.

1. 통계적 정보 존재 여부
2. OOS 재현 여부
3. 거래비용을 고려한 경제적 유용성

**"정보는 존재하지만 거래할 수 없다"도 유효한 연구 결과로 기록한다.**

## 3. 유니버스

기본 분석 유니버스는 유동성 상위 종목이며 **최대 500종목**이다.

★ **유니버스 선정에 미래정보를 쓰지 않는다.** 특정 시점의 포함 여부는 그 시점
이후의 거래대금이 아니라 **전일 또는 그 이전에 확정된 lagged liquidity**로 정한다.

미래수익률은 stale price에서 재는 것이 되고 추세를 가진 어떤 신호와도
**기계적으로 양의 관계**를 만든다. 반면 거래대금 상위 300은 커버리지가
380/381로 사실상 완전하다.

## 4. S0 — 경제성 사전 점검

Top-decile 롱의 기대초과수익 근사:

```
Expected return  ≈  IC × σ × 1.755
IC_break-even    =  cost / (σ × 1.755)
```

**측정한 σ** (유동성 상위 300종목, 3일 표본, 09:00~15:20):

| horizon | 수익률 sd | \|수익률\| 중앙값 |
|---|---:|---:|
| 1분 | 34~45bp | 12~16bp |
| 5분 | 70~91bp | 20~35bp |
| 30분 | 155~203bp | 43~88bp |

**왕복 40bp 기준 손익분기 IC:**

| horizon | σ | IC_break-even |
|---|---:|---:|
| 1분 | 35bp | 0.65 |
| 5분 | 80bp | 0.28 |
| 30분 | 160bp | 0.14 |

사전 예상되는 단기 IC 수준(0.01~0.05)에서는 1~30분 horizon이 거래비용을
넘기 어려울 것으로 예상한다.

★ **S0는 실제 IC 결과를 선제적으로 REJECT하는 게이트가 아니다.**
실제 IC가 사전 예상보다 크게 나타나면 그 결과를 그대로 기록한다.

```
경제성 사전검토   ≠   정보 존재 여부의 사전기각
```

## 5. S1 — 분석 패널

- 선물 30초 → **1분 집계**

  미래 선물을 쓰지 않는다. 미래 주식 수익률은 t 이후 관측치로 정의한다.

**기본 horizon: 1 · 3 · 5 · 10 · 30분.**
**30초 → 30초 실험은 수행하지 않는다.**

## 6. S2 — 핵심 Lead-Lag 검증

원자료 관계와 시장방향 제거 잔차 관계를 구분한다.
**주 분석은 잔차다.**

시장수익률은 KOSPI200 지수 분봉 대신 **분석 유니버스의 횡단면 평균 수익률**을
쓴다(지수 분봉은 `inquire-time-indexchartprice`가 날짜를 무시하고 일별을
돌려주므로 취득 불가 — 교훈81).

```
Stock residual(t) = Stock return(t) − Market return(t)
```

원자료 결과는 **계산 검산용으로만** 보관한다. KOSPI200 선물 ≈ 시장 자체이므로
원자료 관계가 유의하게 나오는 것은 측정 전에 이미 참이고 정보를 주지 않는다.

## 7. 양방향 검증

**두 방향을 모두, 동일 패널에서 측정한다.**

```
방향 A   Futures(t) → Stock residual(t+h)
방향 B   Stock(t)   → Futures(t+h)
```

방향 B는 별도의 경제적 의미를 가진다 — **선물은 거래세가 없고 스프레드가
1틱**이라 집행 비용 구조가 주식과 완전히 다르다. 방향 B가 살아 있다면 그것이
비용을 통과할 수 있는 형태다.

## 8. S3 — 통계 검증

★ **종목 × 분 관측치를 그대로 독립표본으로 취급하지 않는다.**
2,448종목 × 241일 × 380분 ≈ 2억 관측치지만, 한 시점에 모든 종목이 같은 시장
충격을 공유하므로 유효 독립표본은 그보다 몇 자릿수 작다.

```
1단계   각 시점에서 횡단면 IC 계산  →  IC 시계열
2단계   IC 시계열에 Newey-West 시계열 검정
```

수억 개 관측치를 수억 개 독립표본으로 간주하는 순간 naive t가 수백으로 나오고,
시간축 NW만으로는 횡단면 상관을 전혀 못 잡는다.

## 9. Random Baseline

**단순 timestamp permutation은 사용하지 않는다.** 선물과 주식은 개장·마감 등
동일한 장중 계절성을 공유하므로, 무작위 치환은 그 공통 구조까지 파괴해
귀무분포를 실제보다 약하게 만든다 — 통과가 정보를 주지 않는다(교훈72).

**기본 귀무분포: 거래일 단위 circular shift.**

```
1. 선물 거래일 시계열을 통째로 k일 이동
2. 장중 시간 구조는 유지
3. 주식과의 실제 날짜 정렬만 파괴
4. 반복 200회
```

단순 p-value뿐 아니라 **실제 통계량이 난수 분포의 상위 분위수를 충분히
넘는지**를 확인한다.

## 14. 최종 판정 체계

| 판정 | 조건 |
|---|---|
| **INFORMATION PASS** | 통계적으로 유의한 선행관계 + random baseline 초과 |
| **ROBUST PASS** | INFORMATION PASS가 OOS에서도 재현 |
| **ECONOMIC PASS** | 거래비용·체결조건 적용 후에도 경제적 가치 잔존 |
| **REJECT** | 정보관계가 OOS 또는 random baseline에서 재현 안 됨 |
| **INFORMATION-ONLY** | 정보관계는 재현되나 비용 반영 시 경제적 가치 없음 |
| **EXECUTION PASS** | §18-6 — 어차피 낼 주문의 체결 시각만 바꿔 대조군(즉시 체결) 대비 평균 체결가가 개선됨. **비용 허들 0** |

**INFORMATION-ONLY를 실패로 취급하지 않는다.**

★ `EXECUTION PASS`는 `ECONOMIC PASS`와 **판정 기준이 다르다.** ECONOMIC은
왕복 거래비용을 넘어야 하지만, EXECUTION은 그 거래를 어차피 하므로 넘어야
할 것이 **0**이다. 둘을 같은 표에 섞어 읽지 않는다.

섞지 않는다.**

### A. S3 통과 기준 (S4 진입 조건) — 확정

```

```

**두 조건을 모두 요구한다.** `NW t ≥ 2.0`만 쓰면 반복적인 장중 구조 때문에
과대평가될 수 있고, circular-shift p95만 쓰면 시간적 안정성을 보장하지 못한다.

근거: 이 프로젝트 실측으로 난수 팩터 4,845조합에서 최고 t=3.21이 나왔다 —
바닥선 없이 t≥2는 근거가 못 된다.

### B. Futures shock 정의 — 확정

```
shock(t) = |1분 수익률(t)| / σ(같은 시각대, 직전 20거래일)     → 5분위
```

★ **σ 계산에 당일 데이터를 넣지 않는다.** 직전 20거래일만 쓴다. 그래야 shock
정의 자체에서 PIT가 깨지지 않는다.

★ 시각대별로 정규화하는 이유: 절대 `|return|`을 쓰면 09:05의 +0.05%와 13:05의
+0.05%가 같은 shock이 된다. 실제로는 09:05 평소 σ=0.02%면 2.5σ, 13:05 평소
σ=0.01%면 5.0σ다. 정규화하지 않으면 개장 직후가 상위 분위를 독점해
**shock 효과와 §10 시간대 효과가 완전히 뒤엉킨다.**

### C. 야간 귀속 판정 규칙 — 확정

★ **매일 귀속을 고르는 것이 아니다.** 야간 세션 **전체**에 동일한 사전 정의
규칙을 한 번 적용해 D 또는 D+1 귀속을 결정한다.

```
표본: kospi200 야간 전 거래일
비교: median |야간 D 18:00 시가 − 주간 D 15:45 종가|
      median |야간 D 18:00 시가 − 주간 D+1 09:00 시가|
판정: 전자가 작으면 "야간 D는 주간 D의 뒤"
동률: D+1 귀속 (deterministic tie-break)
```

### D. 결측·stale 처리 — 확정

**ffill 금지. 관측 제외.**

선물 마지막 체결이 10:01이고 다음이 10:04라면 10:02·10:03을 10:01 가격으로
채우지 않는다. 그 구간은 **관측 없음**이다.

대신 `time_since_last_trade`(직전 체결로부터 경과 초)를 패널에 보존한다.
사후에 "이 신호는 실제 거래가 활발할 때만 존재했는가"를 확인하기 위해서다.

근거: ffill은 인공적인 0 수익률을 만들고, 그것이 §3이 막으려던 stale-price
인공물 자체다. 상위 500 유니버스는 커버리지가 380/381이라 제외로 인한 손실이
거의 없다.

### E. 비용 민감도 격자 — 확정

```
왕복 0 / 20 / 40 / 60 bp
```

0bp = 정보 상한 · 20bp = 세금·수수료 하한 · 40bp = 프로젝트 규약 ·
60bp = 보수적.

## 18. 추가 사전등록 — 구현 검토 중 발견 (2026-09-05, 결과 관측 전)

아래 여섯은 §1~§16을 코드로 옮기는 과정에서 나온 것이다. **결과를 보기 전에**
적으므로 확증적(confirmatory) 가설로 취급한다. 결과를 본 뒤 떠오른 것은
§15대로 탐색적(exploratory)으로 분리한다.

★ 이 여섯이 셀 수를 늘리므로 §9 난수 바닥선은 **추가된 축까지 포함해** 다시
계산한다. 바닥선을 안 늘리고 축만 늘리면 다중검정이 그만큼 새는 것이다.

### 18-1. 잔차 검정에서 상품 우선순위가 뒤집힌다 (예측)

KOSPI200 선물은 사실상 **시장 그 자체**다. §6 잔차화는 정확히 그것을 제거한다.
따라서 잔차 lead-lag에서 **KOSPI200이 가장 살아남기 어렵다.**

반대로 USD·KTB는 한국주식 시장요인과 상대적으로 직교하므로, 시장방향을 빼도
**횡단면**(수출주 vs 내수주, 금리민감 vs 둔감)을 설명할 여지가 남는다.

```
원자료 기준 우선순위   KOSPI200 > KOSDAQ150 > USD > KTB      (계획안)
잔차 기준 우선순위     USD ≈ KTB > KOSDAQ150 > KOSPI200      (이 예측)
```

계획안의 Priority 1/3 배치는 **원자료 기준**이다. 잔차가 주 분석이므로
실행 순서를 바꾸지는 않되, **이 역전 예측을 사전에 기록**한다.

### 18-2. 횡단면 예측변수를 라벨이 아니라 노출도(beta)로

§10의 업종 20그룹은 그대로 두되, **축을 하나 추가**한다.

| 선물 | 라벨 방식(계획안) | 추가 축 |
|---|---|---|
| USD | "수출주" | 종목별 **USD/KRW 베타** |
| KTB3 · KTB10 | "금리 민감주" | 종목별 **금리 베타** |
| KOSPI200 | 대형/중소형 | **지수 편입비중** (18-3) |

★ 베타는 **TRAIN 145일에서만 추정**하고 VALID·TEST에 그대로 적용한다.
전 구간에서 추정하면 look-ahead다.

근거: 업종 라벨은 사람이 만든 분류이고 베타는 데이터가 말하는 실제 노출도다.
"수출주"로 묶으면 같은 업종 안의 환헤지 정도 차이가 통째로 사라진다.

### 18-3. ★ 차익거래 채널 가설 — 가장 falsifiable한 검정

선물 → 현물 전달에는 통계적 우연이 아닌 **물리적 경로**가 있다. 베이시스가
벌어지면 프로그램 차익거래가 지수 바스켓을 **편입비중에 비례해** 사고판다.

```
사전 예측:
  시장방향을 제거한 뒤에도 남는 KOSPI200 선물 → 주식 신호가 있다면,
  그것은 지수 편입비중이 높은 종목에 단조적으로 집중되어야 한다.

  비중과 무관하게 평평하다면 → 차익거래 채널이 아니다.
                              잔차화가 덜 된 시장 베타로 읽는다.
```

이 검정은 §6 잔차화의 **품질검사도 겸한다.** 통과/실패 어느 쪽이든 정보를 준다
(교훈61 — 통과가 정보를 주는지 먼저 묻는다).

**필요한 것: 합성 현물(시총가중).** 새 수집 0으로 만들 수 있다 —
`data/backfill/fundamentals/a3c/`(발행주식총수, 커밋됨) × 우리 분봉 가격.
지수 구성종목 명단이 없어도 시총 상위로 근사한다.

### 18-4. 공매도 비대칭 — 방향을 나눠서 본다

차익거래는 방향이 대칭이 아니다.

```
선물 고평가 → 주식 매수 + 선물 매도        쉽다
선물 저평가 → 주식 공매도 + 선물 매수      제약이 있다
```

```
사전 예측: 선물 → 주식 전달이 상승 방향에서 더 강하다.
```

★ 이익 관점에서도 중요하다 — 이 프로젝트는 **LONG_ONLY**(최상단 규칙, 엔진에
숏 개념 없음)라 하락 방향 신호는 애초에 쓸 수 없다. 상승 방향만 봐도 잃는 것이
없다.

조건부 축: `.cache/v9_shortselling/`(A8)로 종목별 공매도 활성도 분해 가능.

### 18-5. 만기·롤오버 — 정확성 함정 하나 + 이벤트 축 하나

**실측(수집분 kospi200 주간 107일):** 계약 교체 2회(2025-09-12 `101W9000`→
`101WC000`, 2025-12-12 `101WC000`→`A0163000`). **하루 안에서 계약이 섞인
경우는 0건.**

| | 영향 |
|---|---|
| 장중 lead-lag (S2~S5) | **안전** — 일 내부 수익률은 계약을 넘지 않는다 |
| 야간 → 익일 갭 (S6) | ★ **위험** — 야간 D와 주간 D+1의 계약이 다르면 가격 수준 자체가 다르다 |

```
S6 규칙: 야간 D의 krxCode ≠ 주간 D+1의 krxCode 인 날은 갭 관측을 제외한다.
```

별도로 **동시만기일**(3·6·9·12월 두 번째 목요일, 이 창에 4회)은 프로그램
매매가 폭발하는 날이므로 §10 조건부의 이벤트 축으로 분리한다. 4회뿐이라
확증적 판정에는 쓰지 않고 관측으로만 남긴다.

### 18-6. ★★ 집행 타이밍 — 비용 허들이 0인 유일한 경로

§4의 산수는 **독립 전략**에만 적용된다. 왕복 40bp를 넘으려면 손익분기 IC가
0.14~0.65여서 사실상 닫힌다.

그런데 **어차피 낼 주문의 체결 시각만 고르는 것**은 추가 비용이 0이다.
넘어야 할 것이 40bp가 아니라 **0**이다.

**실측으로 확인한 현재 상태:**

```
deploy/paper-trading-poll.timer   OnCalendar=Mon..Fri *-*-* 9..15:00/10:00
paperEngine.py:25                 신호는 D일(scan_signals)
                                  체결은 D+1일(poll_once)
```

D+1에 **09:00~15:00 · 10분 간격으로 37번** 폴링하는데, **첫 폴에서 그대로
체결한다.** 하루치 선택지가 있는데 타이밍 판단이 0이다. 이미
`pbr_value_v1_combined` · `factor_earnings_yield_v1` 두 전략이 이 경로로 실제
체결 중이다.

```
규칙 형태:  선물 shock이 역방향이면 체결을 한 폴(10분) 미룬다.
대조군:     현행 그대로 — 첫 폴 즉시 체결.
판정:       평균 체결가 개선 > 0  (EXECUTION PASS, §14)
```

★ **이 실험은 S3를 통과해야 의미가 있다.** 선행관계가 없으면 타이밍 규칙도
없다. 그러므로 S3 PASS 뒤에 붙는 **S7**로 두고, S3가 FAIL이면 수행하지 않는다.

★ 실주문 경로(`enable_live_orders`)는 **건드리지 않는다.** 최상단 규칙상 주문
실행 코드 변경은 사람 확인이 먼저다. S7은 과거 데이터 위의 반사실
(counterfactual) 측정까지만 한다.
