# TQQQ 단일종목 V2.1 vs V3.0 vs V4.0 최종 비교 (2026-09-12)

사용자 요청 — 종목 정책 선택(최고성과/중간/최저손실) 전 마지막 검증. **TQQQ 하나로
고정**해 종목 효과와 버전 효과를 분리했다. 3A 확정 episode(재선정 없음) 16건에
V2.1·V3.0·V4.0 을 그대로 적용했다(`infinite_buying_tqqq_version_episode_compare.py`,
selftest 3/3). 레거시 엔진(`infinite_buying_legacy_versions.py`)에 V4.0 과 같은 trace
기능을 추가했다(27/27 회귀 확인, trace 유무로 결과 안 바뀜).

## 1. 5개 지표 — 고정 기간 비교 (전부 재확인·신규 채움)

| | 전체기간 | 2022위기(2021-11-01~2022-12-30) | 2023회복(2023-01-01~) | 최근1년 |
|---|---|---|---|---|
| **V2.1** | 5.00% / 16.0% | **+9.87%** / 12.7% | 9.66% / 8.1% | 2.08% / 14.6% |
| **V3.0** | 10.67% / 31.4% | -20.78% / 26.9% | 20.46% / 12.5% | 13.95% / 6.8% |
| **V4.0** | 19.17% / 48.7% | -25.23% / 51.1% | 25.90% / 33.3% | 15.70% / 17.5% |

여기까지는 이전 findings(버전별 백테스트·최근장 재백테스트)에서 이미 확인된 그대로다.

## 2. ★★ episode 전체 재실행 — 앞선 결론을 뒤집는 발견

3A 의 16개 episode(peak→**실제 회복일**, 예: 2021-11-19 episode 는 2022-12-30 이
아니라 **2024-12-11**까지) 로 다시 돌리면 그림이 달라진다.

```
             episode평균CAGR   최악episode CAGR   최악episode MDD   전략 회복실패*
V2.1         +12.95%p          -12.47%(2012-04)    37.0%            2/16
V3.0         +12.84%p          -12.53%(2012-04)    35.7%            3/16
V4.0         +24.20%p          +4.21%(2026-06)     50.8%            0/16
```
\* 전략 회복실패 = 가격은 예전 고점까지 회복했는데(3A 정의) 전략 자체의 최종
평가금은 아직 시드보다 적은 episode(즉 "가격은 복구됐지만 내 계좌는 아직 손실"
인 경우).

**핵심 발견**:

1. **V4.0 은 16개 episode 중 단 한 번도 "가격은 회복했는데 전략은 손실"인 적이
   없다(0/16).** V2.1 은 2번(2012-04-03·2012-09-19), V3.0 은 3번(같은 둘 + 2018-08-29)
   그런 episode 가 있다 — 즉 이 두 사례에서 가격이 옛 고점을 다시 찍었는데도
   V2.1/V3.0 계좌는 여전히 마이너스였다.
2. **2021-11-19 episode(TQQQ 82% 폭락, 2024-12-11 회복)** 를 전체 기간으로 다시
   보면 V4.0 CAGR 은 **-25.23%(2022-12-30 까지만 잘랐을 때) 가 아니라 +9.80%
   (실제 회복일까지)** 다. 이전 findings(`crisis-path-decomposition`)의 "TQQQ 는
   회복할 시간이 없었다"는 이미 3B 에서 한 번 정정했는데, 여기서 다시 확인된다 —
   **2022년만 잘라서 보면 V4.0 이 최악이지만, 실제 전체 사이클(회복까지)로 보면
   V4.0 이 이 episode 에서 이긴다.**
3. 반대로 **MDD(경로 중 최대낙폭)는 V4.0 이 여전히 가장 나쁘다** — 최악 MDD
   50.8%(V4.0) vs 37.0%(V2.1)/35.7%(V3.0). 즉 V4.0 은 **"버티면 결국 회복하지만
   버티는 동안 훨씬 크게 흔들린다."**

## 3. 두 그림을 어떻게 같이 봐야 하나

이건 서로 다른 질문에 답한다 — 모순이 아니다.

```
"고정 시점(예: 2022년 말)에 계좌를 열어보면 어떤가"   → 5개 지표 비교(§1)가 답
                                                    → 이 기준으로는 V2.1 이 압도적으로 안전
"이 하락을 끝까지(회복될 때까지) 들고 있으면 결국 어떻게 되나" → episode 전체 비교(§2)가 답
                                                    → 이 기준으로는 V4.0 이 한 번도 실패한 적 없다
```

실제 투자자 입장에서 중요한 건 **"버틸 수 있는가"**다 — V4.0 이 결국 회복한다는
게 맞더라도, 그 사이 자산이 50%+ 빠지는 걸 실제로 버틸 수 있어야 그 회복을 누릴
수 있다. 그리고 회복까지 걸린 기간(714일, 약 2년)도 짧지 않다. **"결국 회복한다"와
"고정 시점 평가에서 안 좋아 보인다"가 동시에 참일 수 있다.**

## 4. V2.1/V3.0 의 새로운 약점 — 2012년 두 episode

2012-04-03·2012-09-19(둘 다 낙폭 32% 안팎, 중간 정도 조정) 에서 V2.1·V3.0 은
전략 자체 손실로 끝났는데 V4.0 은 이 두 episode 에서 각각 +12.81%·+11.30% 로
수익을 냈다. **중간 정도 조정에서는 오히려 보수적 버전이 반등 참여를 충분히
못 해서 손실로 끝날 수 있다** — "V2.1/V3.0 이 항상 더 안전하다"는 단정도 틀렸다.
이유는 확인 안 함(추가 조사 안 함 — 스코프 유지).

## 결론 — 판단 기준을 명확히 해야 한다

| 판단 기준 | 유리한 정책 |
|---|---|
| 특정 시점에 평가했을 때 손실 폭을 줄이고 싶다 | V2.1 |
| 하락 중 겪는 최대 흔들림(심리적 버티기 난이도)을 줄이고 싶다 | V2.1 (MDD 최저) |
| 하락을 끝까지 들고 있을 자신이 있고, "결국 회복하느냐"가 중요하다 | V4.0(16/16 회복) |
| 중간 정도 조정(30% 안팎)에서도 안정적으로 수익을 내고 싶다 | V4.0 (2012년 사례) |

**판정은 안 낸다** — 이건 산수가 아니라 사용자의 위험 감내 방식(고정 시점 평가
vs 완주 능력)에 달렸다. 다음 결정은 사용자 몫이다.
