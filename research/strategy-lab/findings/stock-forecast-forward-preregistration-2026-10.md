# 종목 종합 분석 예측 고정 forward — 사전등록 (2026-10-19)

## 1. 질문

1. Claude 가 매달 종합 분석으로 고른 10종목은 12개월 동안 유동 종목 등가중보다 더 오르는가. (판정)
2. 그 선택은 같은 달 저PBR 결합 규칙(`pbr_value_v1_combined`) 바구니보다 나은가. (기록)
3. 지금 적자·재무 약함이지만 미래 수익성을 근거로 고른 갈래 B 는 흑자 갈래 A 와 어떻게 다른가. (기록)

### 이미 아는 것 (그래서 forward 로만 묻는다)

- 숫자 특징을 많이 섞어도(54축 조합·급등 확률 모델·51특징 부상 공통점) '크게 오를 한 종목' 고르기는 매수 수익이 음이었다 —
  부상 직전 공통점이 고변동·저이익(복권형)이고 같은 모양이 붕괴도 2배 잦다(findings/individual-rise-profile-results-2026-10.md · 야간연구-보고-2026-10-13 §1).
- 빠진 것은 **질적 분석**(사업 모델·해자·경영·제품 주기)과 **긴 보유 기간**이다. 둘 다 10년 자료로는 통계 검증이 안 된다(언어 모델은 결과를 안다 · 겹치지 않는 5년 창 2개).
- 갈래 B 는 위 '복권형' 과 겹친다. 그래서 B 에는 **흑자 전환 경로**(수주잔고·적자 축소 추세·매출 성장·자금 여력)를 근거로 적게 하고, 판정과 별개로 A 와 갈라 기록한다.

## 2. 고정 정의 (결과 전)

| 항목 | 값 |
|---|---|
| 예측자 | Claude(모델 id 기록). 사람이 고른 것을 Claude 이름으로 적지 않는다 |
| 주기 | 달마다 1회. 2026-11 부터는 그 달 1~7일(월간 점검 때). 첫 회 2026-10 만 10-19 |
| 빠진 달 | 빈칸. **소급 작성 금지**(등록일 = 오늘 KST 만, 코드가 거부) |
| 대상 | 국내 상장 보통주(A2a 수정주가 있음). 진입 직전 20거래일 평균 거래대금 ≥ 10억원 — 미달 종목은 코호트에서 빠진다(예측자도 이 조건 안에서 고른다) |
| 개수 | 서로 다른 10종목. 갈래 B 는 0~5개 |
| 갈래 B 조건 | 등록일 기준 가장 최근 연간 재무(A3)에서 영업이익 ≤ 0 ∨ 순이익 ≤ 0 ∨ 부채/자본 ≥ 2 ∨ 자본 ≤ 0. 갈래 A 는 넷 다 아님. 코드가 A3 로 대조해 어긋나면 등록 거부(A3 에 없으면 선언 그대로) |
| 종목마다 적을 것 | ① 사업·해자 ② 촉매(앞으로 12개월) ③ 재무 판단 ④ 밸류에이션 판단 ⑤ 위험 ⑥ 틀렸다고 볼 조건 ⑦ 근거 2개 이상(출처·날짜·URL, 등록일 이전) · 갈래 B 는 ⑧ 흑자 전환 경로 |
| 쓸 수 있는 정보 | 등록일 이전 공개 정보 전부(공시·AI 해독·뉴스·대시보드). **이 forward 의 중간 성과는 보지 않는다**(코드가 출력하지 않음) |
| 진입 · 청산 | 등록일 **다음** 거래일 종가 → 252거래일 뒤 종가. 그 전에 가격이 끊기면 마지막 종가(폐지·정지 포함) |
| 기준 | 같은 창의 적격 종목 전체 등가중 |
| 코호트 값 | X = 고른 종목 평균 수익 − 기준. 비용 33.5bp(코호트당 왕복 1회)를 뺀 net 도 같이 |
| 귀무 | **종목 이름 재배치** 10,000회(seed 20261019): 고른 종목 하나하나를 그 첫 코호트의 적격 종목 중 무작위 하나로 바꾸고, 이후 코호트에도 같은 대응을 쓴다(같은 종목을 여러 달 고르는 지속성 보존). 대응 종목이 그 코호트에 적격이 아니면 그 코호트에서만 새로 뽑는다. p = 귀무 평균 X ≥ 실제 평균 X 비율 |

## 3. 판정 (단계당 1회, 그 전엔 코드가 거부)

| 단계 | 조건 | 규칙 |
|---|---|---|
| 1차 | 오늘 ≥ 2029-10-20 ∧ 성숙 코호트 ≥ 24 | 평균 X ≤ 0 → **REJECT** · net 평균 > 0 ∧ p < 0.05 → **SUPPORTED** · 그 밖 **INCONCLUSIVE** |
| 최종 | 1차 INCONCLUSIVE 일 때만, 오늘 ≥ 2030-10-20 ∧ 성숙 ≥ 36 | 같은 규칙 |

SUPPORTED 라도 매매·점수 채택이 아니다 — 새 사전등록 + 🔴 별도 GO.

### 기록 전용 (판정 불사용)

- 같은 달 `pbr_value_v1_combined` 선정 바구니(등록일 이전 마지막 선정일 종목)를 같은 창 12개월 보유한 X, '예측 − PBR' 차이
- 갈래 A · B 각각의 X, 그리고 B 종목의 12개월 낙폭 −50% 이하 비율(붕괴율) vs 적격 종목 전체 비율
- 6개월(126거래일) X · 적중률(기준을 이긴 종목 비율)
- 반도체 제외 X(종목 업종명에 '반도체' — 진단 전용, 시기 분리 규칙 2)

## 4. 현실적 기대와 한계

- 검출력이 매우 낮다: 12개월 창이 매달 겹쳐 24 코호트 ≈ 독립 창 2개. 현실적 기대 INCONCLUSIVE, 실질 가치는 '종합 분석이 단순 저PBR 보다 못하다'를 싸게 확인하는 것.
- 예측자 하나(Claude)의 판단만 잰다 — 종합 분석 일반에 대한 결론이 아니다.
- 갈래 B 는 표본이 더 작다(달마다 최대 5).
