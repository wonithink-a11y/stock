## 3. Lifecycle 검증 — **전 종목 통과**

- `first_trade ≤ date ≤ last_trade` 강제 필터 적용, 벗어난 행 **0건**(selftest --real 실측).
- 발행일과 첫 거래일의 간격도 관측됨(예: 500077 발행 03-23 vs 첫 봉 03-30) — 공식 상장일과
  데이터 시작일을 별도 컬럼으로 보관.
- 500077·570088은 **완결 lifecycle 검증 샘플**: 상장→거래→만기/폐지까지 데이터가 끊김 없이
  존재하며, 마지막 봉이 각각 만기 직전(03-18)·마지막 거래일과 일치.

## 4. 가격 백필 & 품질 (`daily_prices.parquet`, 2,703행)

품질 검사(validate + 추가 검사) **전 항목 결함 0**: duplicate date 0 · 날짜 역순 0 ·

## 5. PIT 3규칙 구현

- **A. VIXCLS**: 기존 연구 규칙 유지 — KR 거래일 D 신호에는 `FRED date < D`(vix_daily_kr
  재사용, provenance 컬럼 `vixLevelAsOfDate` 동봉).
- **B. ETN 종가**: D 종가는 D 마감 후 확정 → 실행 D+1부터. 이벤트 수익률 primary는 기존 연구와
  동일한 **D 종가 진입**, robustness로 **D+1 시가 진입** 변형을 별도 컬럼(`etn_ret_nextopenT*`)
  저장 — 두 값의 차이가 overnight gap 민감도다.
- **C. ETN IV**: IV(D)는 **D+1 오전 고시**(투자설명서 문구 확인분) → signal D의 정보가 아니므로
  **전략 입력에서 제외**하고 manifest에 PIT-unresolved로 기록. 본 축은 가격만 사용.
- 셀프테스트가 세 규칙을 fixture로 검증: strict `<D` 매칭, NaN 스킵, D종가→익일 실행 변환,
  중복 제거, 수익률 산식. **offline 13/13 PASS + 실데이터 재적용 PASS**.

## 8. 수익률 구조 분석 — 전달률(실증)과 갭(미실증)의 분리

- **T+1 전달률 ≈ 100%(인버스)**: VIX(asOf) −1.82% × −0.5x = 이론 +0.91% vs 실제 +0.90%
  — 단기 전달은 배수표기대로 작동한다.
- **h가 길어질수록 감쇠**: T+5 이론 +8.93% vs 실제 +4.46%(≈50%), T+10 이론 +13.95% vs
  실제 +6.81%(≈49%), T+20 이론 +7.95% vs 실제 +3.16%(≈40%). 감쇠 요인은 구조적으로
  ①선물지수 vs 현물 괴리(contango 롤 드래그) ②운용보수(연 0.45~1.2%) ③일간 재조정
  경로효과가 있다. **단 선물커브 데이터가 없어 contango 기여를 정량 분리하지 못한다 —
  "구조상 가능성"으로만 기록한다.**
- overnight gap: close 진입 vs 익일 시가 진입 차이 소폭(500077 T+20 3.16% vs 2.94%) —
  진입 시점 선택이 결론을 바꾸지 않는다.
- 예외 관측: 570088 T+20(n=12)은 VIX 중앙값 −8% 구간에서 −19% 손실 — 폐지 전 구간의
  전달 붕괴 가능성. 표본이 작아 원인 단정 보류(UNKNOWN).

SURGE 185일 중: 현재 LIVE 3종만으로 커버되는 날 **24일**, 폐지/만기 포함 전 수집 상품으로

## 11. 최종 판정

**A. VIX 현물 → 국내 VIX ETN 전략 연구 가능** — 단 "전략 성과 확정"이 아니라
"연구 인프라 완비"의 의미다.

1. **500077을 기준 상품으로 정식 연구할 수 있는가?** — **예.** 완결 lifecycle 721행 +
   이벤트 34건(full horizon) + 무료 재현 경로 확정. 단 −0.5x 비헤지(추정) 단일 상품이라
   일반화는 530131 등과 교차검증 필요.
2. **폐지/만기 포함 survivorship 통제가 가능한가?** — **예(수집 7종 범위).** 폐지 3종의
   전 생애 가격을 실제 확보했다. 다만 2018~2022년 세대는 코드 미확보 — 완전 통제는
   KRX 로그인 또는 공시 기반 코드 마스터 선행.
3. **VIX surge → ETN 수익률 방향성이 실제로 존재하는가?** — **예.** 이벤트 평균에서
   롱 4종 전부 음수·인버스 3종 전부 양수, 일별 베타 부호도 7/7 일치. 크기는 명목 배수의
   35~50%로 감쇠(roll·보수·경로효과 추정 — 커브 데이터 부재로 분리 불가).
4. **현물 VIX 연구보다 ETN에서 alpha가 유지되는가?** — **직접 비교 불가(아직)**. 현물
   VIX median −28%에 비해 최선 인버스 ETN +3~+10% — 전달 감쇠가 크고, 이벤트 겹침·실행
   구조를 반영한 대응 비교는 다음 단계 과제다. "유지된다"고 말할 근거는 없다.
5. **거래비용을 적용하면 결과가 유지되는가?** — **이벤트 평균 기준으로는 유지**
   (500077 T+20: +3.16% → RT 30bp에서 +2.86%; 520063 +10.27% → +9.97%). 단 왕복 고정비용
   선형 차감 근사이며 슬리피지·유동성은 미반영.

## 결론 (요구 8항목)

1. **데이터축 구축 가능 여부**: 가능 — 실제로 구축했고(7종 2,703행 + 이벤트 129행),
   품질 결함 0, selftest offline/real 모두 PASS.
2. **500077 lifecycle 검증**: 통과 — 발행 2023-03-23 / 첫 거래 2023-03-30 / 최종 거래
   2026-03-18 / 만기 2026-03-20, 경계 밖 데이터 0건.
3. **폐지상품 survivorship 통제**: 수집 7종 범위에서 가능(폐지 3종 전 생애 확보).
   2018~2022 세대는 코드 미확보 — 완전 통제는 별도 과제.
4. **PIT 처리**: 3규칙(A VIXCLS date<D / B ETN D종가→D+1 실행 / C IV 제외) 구현·테스트 완료.
5. **VIX surge → ETN 실제 수익률**: 방향 존재(롱 −, 인버스 +, 7/7 일치). 500077 기준
   T+10 평균 +6.81%(승률 82%), 크기는 명목의 절반 이하로 감쇠.
6. **비용 반영 후**: 이벤트 평균 기준 유지(RT 30bp에서도 부호·수준 유지). 실행 미세구조 미반영.
7. **VIX ETN 정식 전략 후보 여부**: **아직 아니다** — 이벤트 클러스터링(105 에피소드/11년),
   세대 누락, IV/유동성 정보 부재를 남긴 채로는 "구조 전달 검증" 단계다.
8. **다음 실험**: ①500077+530131 인버스 2종 풀기간 결합 재측정(에피소드 독립 보정)
   ②거래대금 근사 기반 유동성 필터 민감도 ③IV·괴리율 축 확보 후 전달 감쇠 분해

## 전체 ETF/ETN 데이터축으로 확장하기 전에 VIX ETN 데이터축에서 추가로 해결해야 하는 문제

1. **폐지 포함 ETN 코드 마스터** — KRX 로그인 세션(pykrx 목록 함수) 또는 DART+발행사
   공시 스윕으로 2018~2022 세대 코드 복원. 없으면 survivorship이 "부분 통제"에 머문다.
2. **ETN IV·괴리율 일별 축** — PIT 규칙(D+1 오전 고시)은 확정됐으니 수집 경로만 결정
   (KIS API 또는 발행사 자료실 — 둘 다 미검증).
3. **실제 거래대금** — close×volume 근사의 한계 고정. KRX 로그인 경로의
   `get_etf_trading_volume_and_value` 검증이 최단 경로.
4. **VIX 선물지수/커브 데이터** — 전달 감쇠를 roll·contango·basis로 분해하려면 필수.
   무료 공식 원천 존재 여부부터 확인(CBOE 지연값 등 — 미검증).
5. **헤지 여부 메타데이터 확정** — 500095(E형)·530130/530131(B형)의 환헤지 구조 확인.
   인버스 상품에서 환율 항은 수익률 분해의 독립 변수다.
6. **라이프사이클 종료일 공식화** — 520063(조기상환 추정)·570088(폐지일 UNKNOWN)의
   정확한 상장폐지일을 공시로 확정해 metadata를 갱신해야 PIT universe 경계가 완전해진다.
