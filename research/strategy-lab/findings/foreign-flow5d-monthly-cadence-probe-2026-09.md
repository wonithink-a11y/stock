# 라이브가 실제로 돌리던 조합을 재다 — 월 1회 선택 + 5세션 보유 (2026-09-11)

## 0. 왜 쟀나

`foreign_flow5d_v1` 은 **일별 리밸런싱 + 5세션 고정보유**로 설계됐고 그 형태는
REJECT 다(CAGR -4.26%, `kr-foreign-flow5d-v1-engine-smoke-2026-08.md`).

그런데 라이브 배선은 그렇게 돌지 않는다. `refresh-selections` 의 트리거가
`backfill-price-a2a`(월 1회) 하나뿐이라 selection 이 월 1회만 갱신되고,
`run_paper_trading_daily.py` 가 `--as-of latest` 로 그 최신 리밸런싱일을 잡아
5세션 고정보유한다. 결과는

```
월 1회 top-30 선택 → 5세션 보유 → 나머지 약 15거래일 현금
```

**연구된 일별판도 아니고 설계된 월간판(다른 4슬리브)도 아닌 제3의 것**이고,
findings 어디에도 이 조합의 수치가 없었다. A2a 증분화 GO/STOP 을 판단하려면
이게 필요했다.

## 1. 방법 — 엔진도 정책도 안 건드린다

새 팩터도 새 파라미터도 만들지 않았다. `selection.json` 에서 **리밸런싱일만
걸러** 파생 전략 둘을 만들고 같은 러너(`run_foreign_flow5d_v1.py --strategy`)에
태웠다.

```
foreign_flow5d_monthlylast_probe    월별 마지막 리밸런싱일만   ← 라이브 모델
foreign_flow5d_monthlyfirst_probe   월별 첫 리밸런싱일만       ← 월중 위치 민감도
```

**왜 last 가 라이브 모델인가**: A2a 는 매월 1~5일에 돌고, 그때 재생성된
selection 의 최신 리밸런싱일은 사실상 **전월 말**이다. 진입이
`next_tradable_session_open` 이므로 그 다음 달 초에 산다 — 라이브 그대로다.
first 변형은 "월중 어느 날에 사는가"가 결과를 끄는지 보려고 같이 돌렸다.

```
리밸런싱일   2,598 → 129 (월 1회)
신호         77,940 → 3,870 (129개월 × 30종목)
```

정책·비용·슬롯경쟁·유니버스·기간 전부 원본과 동일하다.

## 2. 결과

```
변형                         CAGR      MDD    Sharpe    승률    거래수    총수익
일별 (원본, REJECT)         -4.26%   -37.2%   -0.313   45.2%   19,289   -37.0%
월간-last (라이브 모델)     -1.20%   -37.3%   -0.058   45.5%    3,780   -12.0%
월간-first (민감도)         -0.81%   -31.7%   -0.027   46.9%    3,779    -8.2%

같은 창의 벤치마크 (market-benchmark-comparison-2026-09.md, 2016-01~2026-08)
KOSPI              +12.98%
KOSDAQ              +2.23%
유니버스 EW(정본)    +2.30%
유니버스 EW(편향보정) +4.37%
```

**세 가지가 한 번에 보인다.**

1. **라이브 조합은 여전히 음수다.** 배선 사고가 숨은 알파를 만들고 있지 않다.
2. **일별 대비 개선분은 alpha 가 아니라 회전율이다.** 거래가 5.1배 줄었고
   (19,289 → 3,780) 손실이 3.5배 줄었다. 신호에 edge 가 있어서가 아니라
   **비용을 덜 내서** 덜 잃는다. edge 가 있었다면 거래를 줄일 때 수익도 줄어야 한다.
3. **월중 위치는 결과를 끌지 않는다.** last(-1.20%)와 first(-0.81%)가 같은 부호·
   같은 자릿수다. 즉 "우연히 나쁜 날을 잡았다"는 설명은 안 된다.

## 3. 정직하게 — 이 수치의 한계

- **0과 구분되지 않는다.** Sharpe -0.058 을 10.6년으로 환산하면 t≈-0.19 다
  (일별판도 -1.02 로 유의하지 않다). 즉 "유의하게 손해"가 아니라
  **"유의한 edge 가 없다"**가 정확한 진술이다.
- **그래서 벤치마크 t 검정은 안 돌렸다.** 절대수익이 음수이고 모든 벤치마크에
  한참 못 미치므로 초과수익 유의성을 잴 필요가 없다 — 양수로 보였다면 필요했다.
  (필요해지면 `market_comparison_kr_2026_09.py` 에 태우면 된다.)
- **위험이 줄지 않는다.** MDD 가 -37.3% 로 일별판과 거의 같다. 한 달에 5일만
  시장에 있는데 낙폭은 그대로다 — 보유 구간이 짧아도 30종목 동시 노출이라
  개별 하락장을 그대로 맞는다. **0에 가까운 수익을 -37% 낙폭으로 산다.**
- 파생 selection 은 원본 리밸런싱일의 부분집합이라 **새 룩어헤드는 없다**
  (날짜를 고르기만 했고 팩터값을 다시 계산하지 않았다).

## 4. 판정과 쓸 곳

**REJECT.** 이 조합을 production 후보로 올릴 근거가 없다.

다만 **슬리브를 회수하라는 뜻은 아니다.** 모의계좌 슬리브는 REJECT 여도 존치가
원칙이고(2026-09-04 결정), `run_paper_trading_daily.py` 주석이 적은 존치 근거
("실손실 0, 기각한 전략이 어떻게 가는지 공짜로 쌓인다")는 그대로 유효하다.
이 측정이 바꾸는 것은 **그 슬리브에 인프라를 투자할 이유가 없다**는 점이다 —
`docs/A2a-증분화-결정브리프.md` §8 의 STOP 판정을 지지한다.

★ 부수로 하나 확인됐다: 라이브 배선이 "틀린" 상태로 돌고 있었지만 **설계대로
돌렸을 때보다 덜 나쁘다**(-1.20% vs -4.26%). 고쳤으면 더 잃었을 것이다.
배선을 고치는 일이 언제나 개선은 아니라는 사례로 남긴다.
