# 연속 하락 사건 — 사전등록 (2026-11-08)

## 1. 질문과 배경
`one-day-drop-5pct`·`foreign-drop-events` 는 하루 −5% 날을 보았다. 이번엔 **연속 하락 구간의 누적 하락폭**으로 사건을 정의한다. 이미 닫힌 인접: 20일 −20%·고점 −30%(crash-rebound), 10일 −5%(post-drop-asset-selection), 연속 상승 7일(forward #10). 연속 하락 일수 자체의 통계는 처음이다.
현실적 기대: 평균 반등은 양이나 위기 시기에 사건이 몰려 독립이 아니고, 일부 셀은 INCONCLUSIVE.

## 2. 자료·사건 (고정)
- yfinance 종가: `SPY` `QQQ` `^SOX` `^N225` `^GDAXI` `^HSI` `^KS11` `^KQ11` `^TWII` `000001.SS` `^FTSE` `^FCHI`. 평가 끝 2026-11-06.
- 연속 하락 길이 L_t = 직전까지 매일 종가가 전일보다 낮았던 연속 일수(오늘 하락 포함). 누적 하락폭 D_t = 연속 시작 전 종가 대비 오늘 종가 수익.
- 셀: A (L ≥ 3 ∧ D ≤ −5%) · B (L ≥ 4 ∧ D ≤ −7%) · C (L ≥ 5 ∧ D ≤ −10%). 조건을 처음 만족하는 날이 사건, 같은 연속 안에서 반복하지 않으며 직전 사건과 10거래일 간격.

## 3. 지표 (고정)
1. 사건일 종가 → 1·5·21·63일 수익: 건수·평균·중앙·이익·최악, 무조건 평균과의 차, 양측 순열 p(같은 건수 시작일 순환 이동 2,000회, seed 20261108).
2. **연속 지속(hazard)**: 사건일 다음 거래일이 또 하락일 비율 vs 그 지수의 무조건 하락일 비율. 사건일 이후 하락이 몇 일 더 이어졌는지(연속 길이 분포)와 이어진 추가 하락폭 평균.
3. 기록 전용: 구간(1990~2009 / 2010~19 / 2020~) 평균, 현재(2026-11-06) 각 지수의 연속 하락 일수·누적폭.

## 4. 판정
셀별로 21일 평균 차이 p ≤ 0.01 이고 같은 부호인 지수 ≥ 6/12 → 방향 신호(부호로 반등/추가 하락). 2~5곳 → INCONCLUSIVE, 0~1곳 → 신호 없음. hazard 와 구간별은 기록 전용.
