# EV 가치 계열(EBIT/EV · FCF/EV · GP/EV) — 사전등록 (2026-09-21)

## 0. 이 문서를 쓰는 시점의 지식 (블라인드가 아니다)

- **A3e 값으로 본 것**: 계정 커버리지·부호·중복·차입금 모호도(`docs/control/A3e-계정매핑감사-2026-09-21.md`). **수익률·IC·순위는 한 번도 계산하지 않았다.**
- **선행 결과(불리한 것)**: EY 는 세 경로(단독·raw 50:50·잔차화 50:50) 전부 막혔다. 잔차화 결합은 TEST 구간이 "실질 동등"이었으나 2018·2022·2024 하락장 3개 해에서 전부 PBR 단독보다 나빴고 2022 는 격차 −8.98%p(최대)였다.
  PBR 슬리브의 초과수익 74% 가 2022+2024 두 해(금리 상승기 가치 노출)에서 나왔다 — 이 조건부 성격을 안고 시작한다.
- **왜 그래도 하는가**: EV 는 자본구조를 중립화한다(차입 많은 기업의 PER·PBR 왜곡 제거). FCF/EV 는 발생액 왜곡을 걷어내고, GP/EV 는 회계 조작 여지가 작다. PBR·EY 가 못 본 축이라 **잔차 정보가 있을 수 있다** — 없다는 것을 싸게 확인하는 것이 값이다.
- **기대치**: 낮다. 현실적 결과는 REJECT 이거나 INCONCLUSIVE. TEST 31개월·독립 하락장 3개로 ROBUST 는 검출력 한계가 있다.

## 1. 정의 (결과 전 고정)

**매핑**: `research/strategy-lab/a3e_account_map.py` **a3e-map-1.1** 그대로. 바꾸면 새 사전등록.

| 항목 | 정의 |
|---|---|
| 재무 선택 | 월별 패널 날짜 d 마다 **`availableFrom ≤ d` 인 A3e 레코드 중 접수일이 가장 늦은 것**(기존 `select_as_of` 와 같은 PIT). `fsDiv` 는 수집기가 CFS 우선·없으면 OFS 로 이미 고른 값. **접수일이 d 로부터 500일보다 오래되면 미정의**(상장 유지하나 공시가 끊긴 종목 방지) |
| 시가총액 | **그 달 패널 `pbr` × 같은 레코드의 A3e `equity`**. 주식수·수정주가·기업행위 보정을 여기서 재현하지 않는다 — PBR 은 A5 리졸버가 보정 주식수로 이미 계산했으므로 같은 시총 기준을 물려받는다. (PBR ≤ 0 이거나 equity ≤ 0 이면 미정의) |
| EV | 시가총액 + `debt_eff` − `cash`. **EV ≤ 0 이면 미정의.** `debt_ambiguous` 레코드는 **주 분석에서 제외**(매핑 감사의 결정) |
| 셀 EBIT/EV | `op_income` / EV |
| 셀 FCF/EV | (`cfo` − `capex_ppe`) / EV. **무형자산 취득은 빼지 않는다**(사전 단순화 — 개발비 자산화 기업은 FCF 가 과대. 한계로 기록). `capex_ppe` 결측이면 미정의 |
| 셀 GP/EV | `gross_profit` / EV |
| 제외 | **금융업**: 패널 `sector` 라벨이 정규식 `금융|보험|은행|저축|신탁|집합투자|증권|상품 중개` 에 걸리면 **세 셀 모두에서 제외**(EV·매출총이익이 의미 없음). 이 라벨에는 지주회사가 포함된 `기타 금융업`이 함께 빠진다 — 한계로 기록. **제외된 라벨 목록을 결과 문서 맨 위에 싣는다** |
| 방향 | 셋 다 **높을수록 좋음**(수익률 형태). 분자가 음수여도 정의(적자면 낮은 순위) |
| 유니버스 | 기존 패널 `liquid` 참 ∩ `pbr` 존재 ∩ 위 조건을 통과 — **PBR 단독 기준선과 셀들이 정확히 같은 (종목, 월) 표본**을 쓴다(셀마다 표본이 달라 비교가 깨지는 것을 막는다) |
| 잔차화 | 07·10 의 **TRAIN-고정 직교화 그대로**: 셀 신호의 월별 단면 순위를 PBR 순위에 OLS 하되 **계수는 TRAIN 월별 계수의 중앙값으로 고정**해 VALID·TEST 에 적용(lookahead 없음). 07·10 코드를 복사하고 신호 열만 바꾼다 |
| 결합 | **composite = 0.5·(1 − PBR 순위 백분위) + 0.5·잔차 순위 백분위.** 50:50 고정, 가중치 스윕 없음 |
| 포트폴리오 | 월 리밸런스, composite(또는 PBR 단독) 상위 10분위, 동일가중, 롱온리, 타깃 `fwd1m`. 비용 30bp(본문)·50·65 — 10 하네스의 비용 모델 그대로 |

**시총 역산의 알려진 한계**(정의는 그대로 두고 결과 문서에 함께 적는다): (a) A3e `equity` 는 비지배지분을 포함한 자본총계이고 A5 PBR 의 분모와 같은 계정·같은 레코드(연결/별도)라는 확인을 이 문서에서 하지 않았다 — 어긋나면 시총이 비지배지분 비중만큼 왜곡되고, 지배구조가 복잡한 기업에서 커진다. (b) 시총이 연 1회 자본에 묶여 있어 그 사이 유상증자·자사주 소각이 반영되지 않는다(PBR 과 같은 한계를 물려받는다). 이 한계를 보려고 §4-5 의 저부채·규모 쏠림과 §4-2 의 연결 표본 결과를 함께 낸다.

**정합 게이트(수행 후 결과 전에 확인, 실패면 UNTESTABLE)**: (1) EV > 0 비율 ≥ 90%, (2) 셀별 단면 종목 수 ≥ 30 인 월이 TRAIN·VALID·TEST 각각 12개월 이상, (3) 잔차와 PBR 의 순위 상관 평균 < 0.3(10 과 같은 selftest). 게이트 실패는 REJECT 가 아니라 "이 정의로는 검정 불가"다.

## 2. 판정 (셀별, 결과 전 고정)

**대조**: 같은 표본의 PBR 단독 상위 10분위. 지표는 월별 net(30bp) 수익률로 계산한 CAGR·Sharpe.

- **INFORMATION**: ΔSharpe(composite − PBR 단독)의 **TRAIN 값이 가족 난수 바닥선 이상** ∧ **VALID·TEST 의 ΔSharpe 부호가 모두 양(+)**.
  - **가족 난수 바닥선**: 무작위 신호(순위를 섞은 것)를 같은 잔차화·결합 절차에 넣어 **세 셀 중 최대 ΔSharpe(TRAIN)** 의 95번째 백분위(1,000회). 셀 세 개를 고른 것 자체가 다중검정이라 최대값 분포를 쓴다.
- **ECONOMIC**: INFORMATION ∧ **VALID+TEST 를 이은 구간에서** composite net30 CAGR > PBR 단독 net30 CAGR ∧ net50 에서도 같은 방향.
- **ROBUST**: ECONOMIC ∧ **하락장 조건**: 벤치마크(같은 유니버스 EW)가 음수인 달력연도(2018·2022·2024)에서 composite 연수익이 PBR 단독보다 좋은 해가 **3개 중 2개 이상** ∧ OOS(VALID+TEST) 월별 초과수익(composite − PBR 단독)의 t ≥ 2.
- 구간 표본이 30개월 미만이거나 게이트 실패면 판정불가. 어느 것도 아니면 REJECT.
- 세 셀을 **각각** 판정하되 통과 셀이 여럿이면 다중검정 보정 없이 "통과"라 하지 않고 **가족 바닥선을 넘은 것만** 인정한다(바닥선이 이미 최대값 분포다).
- **채택 아님**: ROBUST 도 "그림자 관측 후보"까지다. production(`portfolio.v1.json`)·점수 반영은 🔴 별도 GO — 규칙 1(추정치·재무 확장을 점수에 임의 반영 금지)과의 관계도 그때 다룬다.

## 3. 결과 표 (CLAUDE.md 기록 규칙)

셀별: 표본 월수·평균 종목수, composite 와 PBR 단독의 TRAIN/VALID/TEST **CAGR·Sharpe·MDD**, ΔSharpe, **손익분기 비용**(composite 가 PBR 단독과 같아지는 왕복 bp), net30/50/65, 연도별 표(벤치 EW·PBR·composite·차이 — 하락장 3개 해 굵게), 상위 1개 연도의 초과수익 집중도.
머리말 `reason` 은 **"신호: 있음/없음 · 경제성: 통과/미달"** 로 시작한다.

## 4. 기록 전용 (판정에 쓰지 않는다 — 결과를 보고 고르면 다중검정)

1. **필수 민감도**: 매핑 감사가 요구한 대로 `debt_zero_assumed`(무차입 가정 17.3%)를 **뺀** 표본에서 같은 세 셀을 한 번 더. 주 결과와 방향이 갈리면 결과 문서 첫 줄에 적는다(교훈57).
2. `fsDiv` 통제: 연결만(CFS) 표본.
3. 잔차화 없는 원본 신호 단독 상위 10분위(EBIT/EV 등)와 그 PBR 순위상관.
4. 셀 세 개의 잔차끼리의 순위 상관(세 개가 사실상 하나인지).
5. 상위 10분위 종목의 평균 EV/시총·부채비율 — 저부채 쏠림인지.

## 5. 하지 않는 것

- 가중치(60:40 등)·분위수(5·20분위)·보유기간·유니버스 임계를 결과를 보고 바꾸는 것. 바꾸려면 새 사전등록.
- 감가상각을 쓰는 EV/EBITDA(커버리지 19%로 전면 불가), 무형자산 취득을 빼는 FCF 변형, 리스부채를 넣는 EV — 매핑에서 뺐다.
- 통과 셀의 정의를 같은 날 다듬는 것(과최적화).
- 품질 계열(gross profitability·발생액·자산성장)은 **별도 사전등록** — 가치 결과에 끌려 합치지 않는다.
