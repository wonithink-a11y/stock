## 0. 먼저 확정된 시장 구조 사실

- **국내 VIX 상품의 시작은 2018-05-09**다(매일경제 2018-05-04: "한국거래소는 삼성증권·신한금융투자·
  NH투자증권·미래에셋대우 등 4개 증권사가 동시에 발행하는 VIX 선물 ETN 4종목이 이날 상장").
  따라서 **"2016~현재" 전 구간은 애초에 상품이 존재하지 않는다** — 연구 가능 창은 2018-05~현재.
- 확인된 상품은 전부 **ETN**이며 기초자산은 **VIX 현물이 아니라 S&P 500 VIX Short-Term Futures
  Index(선물 지수)** 계열이다. VIX 현물에 직접 연동된 국내 상품은 이번 조사 범위에서 관측되지 않았다.
- 국내 상장 VIX **ETF**는 네이버·발행사·언어 소스 어디에서도 관측되지 않았다(부재 단정은 아니고
  "관측된 바 없음"). 한국투자 "TIGER VIX"류 ETF도 관측 실패.

## 3. 생존편향 (핵심 검증 — 실증됨)

- **폐지 상품의 과거 가격이 무료로 남아 있다**: 500077(만기 상환)은 2026-03-18(만기 직전
  거래일)까지, 570088(상장폐지)은 2025-03-19까지, 520063(조기상환 추정)도 2025-03-19까지
  **전부 pykrx/네이버 경로로 조회됐다**. 네이버가 상장폐지 종목 이력을 유지한다는 것을
  샘플 3건으로 실증.
- **KRX에서 과거 상장폐지 상품 목록**: KIND 상장폐지목록은 프로젝트 기존 문서에서
  "경로 없음" 확정. 대안: ①DART 공시(list.json — A1b가 폐지 사유 복원에 이미 사용) +
  발행사 공시(만기/조기상환 통지) ②KRX 로그인 세션(pykrx `get_etf_ticker_list(date)` /
  `get_etn_ticker_list(date)`가 **date 인자를 받는 시그니처**로 확인 — 과거 시점 유니버스
  재구성 가능성. 단 로그인 필요, 미검증).
- **종목코드 재사용**: 확인 안 됨(**UNKNOWN**) — ETN은 코드 체계가 발행사별 블록(500xxx 신한,
  57xxxx 한투, 52xxxx 미래에셋)으로 보이나 재사용 사례 검증 없음. 백필 시 코드별 연속성
  점검 로직 필요.
- **PIT universe 구성**: 상장일(첫 데이터일과 발행일이 일치함을 3종에서 실측 — 예:
  500077 발행 2023-03-23 vs 첫 가격 2023-03-30, 상장 지연 존재) + 폐지일(마지막 가격일)로
  `[listing, delisting]` 구간 필터면 당시 투자 가능 상품만 남는다. **가능**.

## 4. PIT 판정

| 정보 | D일 장 종료 시점에 알 수 있는가 | 규칙 |
|---|---|---|
| 상품 OHLCV(D) | ○ (장 마감 확정) | **D 종가 → D+1 거래 가능** |
| 거래량(D) | ○ | 동일 |
| **ETN 지표가치 IV(D)** | **✗ — D+1 오전 고시** | 발행사 투자설명서 문구 직접 확인: *"지표가치(T) : 한국거래소 영업일 T일에 한국예탁결제원이 산출한 지표가치로서 한국거래소영업일 (T+1)일 오전에 고시"* → **IV(D)는 D+1부터 사용** |
| 실시간 지표가치 | ○(장중 제공) | 역사 축적 불요 |
| 괴리율(D) | 종가 기준 산출물 — 게시 시각 소스별 상이 | 미확인(UNKNOWN), 사용하려면 소스별 확인 필요 |
| 기초지수(VIX 선물지수) D일 종가 | 미국 새벽 산출 → 한국 D일 아침부터 알 수 있음(발행사 문구: "기초지수종가(T): T일 오전에 확인되는 가장 최근 기초지수 종가") | D일 오전 이후 의사결정에 usable |
| VIXCLS(FRED, 현물) | 미국 D−1 세션 종가가 한국 D일 아침 확정 | 기존 프로젝트 asOf 원칙 그대로(별개 규칙) — 상품 가격과 **혼합하지 말 것** |

두 축의 분리(요구사항대로): "상품 D종가 → D+1 매매" / "기초·VIX 정보 → 각각의 고시 시점
이후 사용". IV는 상품 가격보다 하루 늦게 확정된다는 점이 ETN 특유의 PIT 함정이다.

"롤비용/환율/보수/괴리"로 **분해**하려면 선물지수·IV·괴리율 데이터가 추가로 필요하며,
특히 VIX 현물과 선물지수의 괴리(contango 드래그)가 전달력의 가장 큰 구조 요인이라는 점은
금융투자협회 위험고지서도 명시한다("2017년 1년간 변동성지수 -x% 하락 동안 변동성 ETN -70%
락" 등).

## 6. 파일 구조 제안 (생성 안 함 — 제안만)

research/strategy-lab/data/vix-products/ 아래 제안안은 적절하다고 판단한다. 다만 두 가지 보강:

```
universe.parquet            # code, name, issuer, type(ETN), basis_index, leverage_sign,
                            # listing_date, delisting_date, status, source_refs
daily_prices.parquet        # code × date OHLCV(+등락률), pykrx/naver 원본 그대로
product_metadata.parquet    # 만기, 보수, 환헤지 여부, LP 조건 — 발행사 페이지 캡처 원본
delisted_products.parquet   # universe의 status=DELISTED 부분집합 + 근거 공시 링크
iv_history.parquet          # (신규 제안) 지표가치 일별 — D+1 고시 규칙 메타 포함
_manifest.json              # BF-1.1 스타일: sourceUrl, rowCounts, fetchedAt, policyHash
```

이유: IV는 가격과 고시 시점(PIT 규칙)이 달라 파일을 분리해야 asOf join이 깔끔하다.
manifest에는 "naver 경로 = 거래대금 없음" 제약을 명시할 것.

## 9. 최종 판정

**B. 데이터는 확보 가능하지만, 수집 파이프라인 구축 후 시작한다.**

가격 자체는 무료로 전 생애 확보됨을 실증했지만, 연구 등급(universe 완전성 + 거래대금 +
IV/괴리율 + survivorship 목록)을 갖추려면 ①KRX 로그인 계정 확보(무료 — 별도 승인 대상) 또는
DART+발행사 공시 기반 유니버스 구축 ②IV 일별 수집 경로 결정 ③거래대금 경로 결정이 선행된다.

**질문 답변**

① **국내 VIX ETF/ETN의 2016~현재 역사 가격을 무료로 확보 가능한가?**
→ "2016~"이라는 전제 자체가 성립하지 않는다 — **국내 VIX 상품 시장은 2018-05-09 개장**.
   2018-05~현재 구간은: 개별 코드가 있으면 **무료로 전 생애 확보 가능(실증)**. 다만
   2018~2022년 상품들의 전체 코드 목록은 현재 차단된 KRX 목록 경로 없이는 미확보(UNKNOWN).

② **상장폐지/상환 상품까지 survivorship bias를 통제할 수 있는가?**
→ **통제 가능성 확인됨** — 폐지 3종의 전 기간 가격이 무료 조회됨을 실증. 체계적 통제에는
   폐지 목록이 필요하고, 그 원천은 DART 공시(가용)+발행사 공시+KRX 로그인 목록(미검증)이다.
   KIND 상장폐지목록은 기존 문서대로 경로 없음.

③ **VIXCLS와 국내 상품 가격을 PIT 정합적으로 연결할 수 있는가?**
→ **가능**. 상품 D종가→D+1 거래, VIXCLS는 미국 D−1 세션 종가→한국 D일 아침(기존 asOf
   원칙), ETN IV(D)는 D+1 오전 고시(투자설명서 문구 확인) — 세 규칙을 분리 명시하면 된다.
   단 "VIXCLS=현물, 상품=선물지수 연계"라는 구조 차이는 PIT가 아니라 **경제적 전달력** 문제로
   남고(§5), 그 분해엔 선물지수 데이터가 추가 필요하다.

④ **VIX 급등 → 국내 인버스/레버리지 상품 수익률 백테스트 데이터가 있는가?**
→ **1차 검증은 있다**(상품 일별 OHLCV 4종 + VIXCLS). 인버스 −0.5x는 2종 확보, +레버리지는
   관측된 바 없다. 다만 롤비용·contango 분해까지 하려면 VIX 선물지수 데이터가 빠져 있다(UNKNOWN).

⑤ **가장 먼저 어떤 상품 1개로 검증해야 하는가?**
→ **500077(신한 인버스0.5X S&P500 VIX S/T선물 ETN)**. 이유: ①전 생애(2023-03-30~2026-03-18)
   가격이 무료로 조회됨을 이미 실증 ②만기 상환까지 완결된 라이프사이클로 survivorship 처리
   절차를 end-to-end 테스트 가능 ③인버스라 "VIX 급등 → 상품 음(-)의 전달" 구조 확인에
   가장 민감한 검증체 ④환노출 없이 순수 전달력 측정 가능. 다음으로 570088(롱 H형, 폐지)
   에서 동일 검증을 반복해 방향 대칭성을 본다.

- **데이터 확보 가능성:** 가격(OHLCV+거래량)은 무료로 가능 — 폐지 상품 포함 실증 완료(500095/570088/500077/520063). 거래대금·NAV/IV·괴리율·유니버스 열거는 추가 경로(KRX 로그인/KIS/발행사) 필요.
