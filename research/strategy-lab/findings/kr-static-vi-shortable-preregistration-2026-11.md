# 정적 VI 근사 VU — 공매도 가능 종목 한정 (대차 실행 가능성 1단계) 사전등록 (2026-11-01)

> **동결.** 이 문서를 커밋한 뒤 SH 규칙(5거래일·거래량>0)·셀·문턱·비용·구간을 바꾸지 않는다. 통과해도 매매 반영은 🔴 별도 GO.

## 0. 지금 아는 것

- 모 연구·유동 대형주 후속: VU 는 숏 방향 ROBUST(전 종목 TEST −209bp, 상위 200 TEST −268bp). 둘 다 **그 종목을 실제로 공매도할 수 있었는지**는 모른다.
- 국내 공매도는 2025-03-31 재개 이후 코스피200·코스닥150 편입 종목에 한정된다고 알려져 있다(이 문서는 그 규칙을 믿지 않고 **관측**으로 대신한다 — A8 의 종목별 일 공매도 거래량). 시장조성자 예외 거래가 섞일 수 있어 '거래량>0' 은 허용의 근사다.
- 차입 수수료·대차 가능 물량은 비공개라 잴 수 없다. 개인 대주(신용 대주 종목·90일 제한)도 이 자료로는 모른다.
- 급등 종목이 코스피200·코스닥150 밖이면 SH 사건이 매우 적을 것이다(예상 하루 0~3건). **현실적 기대는 '판정불가' 또는 '표본 얇음'이다.**

## 1. 정의

- 사건 = 모 연구 VU 사건 전체(`kr_static_vi_liquid.py --events-out` 로 뽑은 목록, tier 칸 포함). 사건일 > A8 마지막 날이면 제외.
- SH = 사건일 직전 5거래일(A8 달력 기준) 중 하루라도 shortVolume > 0 인 종목. A8 에 그 종목 행이 없으면 NS. 사건일 당일 값은 쓰지 않는다(사전에 알 수 없음).
- 판정 = 모 연구 `judge_cell` 그대로(방향 = TRAIN 부호, INFORMATION → ECONOMIC(33.5·67bp) → ROBUST(net t ≥ 2), TEST 관측일 20 미만이면 판정불가), 바닥선만 1셀(SH).

## 2. 기록(판정 불사용)

- SH 비율: 전체 VU 사건 · VU_L 사건 중 SH 의 비율, SH 하루 평균 사건 수·SH 가 있는 날의 비율(전략을 돌릴 수 있는 날이 며칠인가).
- NS 같은 표(비교용). SH∩VU_L.
- 사건일 당일 shortVolume > 0 비율과 shortVolume ÷ (분봉 합 거래량) 중앙값 — 그날 실제로 공매도가 얼마나 있었나.
- 15:19 청산, 반도체 제외 한 줄, 시기 칸(데이터가 1년 남짓이라 구간 표 하나로 대신).
- 차입 비용 시나리오: SH 의 net33.5 에서 하루 1·3·12bp 를 더 뺀 값.

## 3. 하지 않는 것

규칙 변경(3·10일, 거래대금 문턱, 코스피200 편입 이력)·SH 판정 후 컷 탐색·롱 뒤집기·A8 이후 기간 외삽(A8 가 갱신되면 같은 규칙으로 forward 확장은 새 사전등록).

## 판정 해석 (결과 전 고정)

| 결과 | 읽기 |
|---|---|
| SH ROBUST ∧ SH 일평균 ≥ 1건 | 신호는 공매도 가능 종목에서도 남는다 — 실행 가능성 2단계(체결·업틱 룰·대차 수수료)는 🔴 GO 후 별도 |
| SH ROBUST ∧ SH 일평균 < 1건 | 신호는 남으나 쓸 수 있는 날이 드물다 — 용량 부족, 매매 논의 보류 |
| ECONOMIC·INFORMATION | 방향은 같으나 약함 — 매매 보류, 기록 |
| REJECT | 신호는 공매도 불가능 종목에서만 — 숏 실행 라인 종결 |
| 판정불가 | SH 표본 부족(TEST 관측일 < 20) — A8 갱신 뒤 같은 규칙으로 새 사전등록 |

## 동결

이 커밋 뒤 문턱·창·셀·비용·SH 규칙·판정 규칙을 바꾸지 않는다.
