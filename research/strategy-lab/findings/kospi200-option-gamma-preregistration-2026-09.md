- **만기일**: 종목명에서 읽는다. 월물 `YYYYMM` = 그 달 둘째 목요일 · 위클리(목) `YYMMW#` = 그 달 #번째 목요일 ·
  위클리(월) `YYMMW#` = #번째 월요일. 그날이 휴장이면 직전 거래일(거래일 = 옵션 자료가 있는 날). 읽히지 않는 종목은 빼고 수를 센다.
- **잔존기간** T = (만기일 − t) 달력일 / 365. **T = 0(그날 종가에 만기)은 뺀다** — 다음 날 남아 있지 않다.
- **감마**(한 계약, 지수 1% 움직임당 원화 감마): `G = γ_BS(S, K, T, σ=IMP_VOLT/100, r=0) × OI × m × S² × 0.01`,
  m = 1(정규·위클리), **0.2(미니)**. 승수 절대값(2012·2017 변경)은 아래 두 신호가 **비율이라 상쇄된다** — 쓰지 않는다.
- IMP_VOLT 가 비었거나 0 이하, OI 가 0 인 종목은 뺀다. **그날 OI 가중 IV 커버리지가 80% 미만이면 그날은 표본에서 뺀다**(게이트).

## 2. 신호 (두 셀 가족)

- **셀 G — 부호 감마 비율**: `SG_t = (Σ_콜 G − Σ_풋 G) / (Σ_콜 G + Σ_풋 G)` ∈ [−1, 1].
  부호 가정 = 미국 관례(딜러는 콜 매수·풋 매도 쪽 — 고객이 콜을 팔고 풋을 산다). 작을수록 딜러 음(−)감마 = '휘발유'.
  신호 `X_G = 1[SG_t 의 rolling252 percentile < 0.2]`. **예측 방향: 양(+)** — 다음 날 변동폭이 커진다(한쪽 방향 검정).
- **셀 T — 현재가 근처 감마 집중도(부호 없음)**: `CT_t = Σ_{|K/S−1| ≤ 2%} G / Σ G`. 신호 `X_T = CT_t 의 rolling252 percentile`(연속값).
  딜러 부호를 몰라도 되는 대조 셀. **방향을 정하지 않는다(양방향)** — 피닝(작아짐)과 증폭(커짐) 둘 다 이론이 있다.
- percentile 은 과거 252 거래일 유효값 기준(당일 포함), 유효값 252 개 전은 결측. RV20 percentile 과 같은 방식.

## 3. 판정

**표본**: 세 percentile(SG·CT·RV20)과 다음 날 결과가 모두 있는 날, 2011 년 초 ~ 수집 마지막 날. 두 반기 = 2011~2017 · 2018~끝.

- **INFORMATION**: 회귀 `|r_{t+1}| = a + b·RV20pct_t + c·X_t` 에서 c 의 Newey-West(lag 5) t 가
  - 셀 G: `t_c ≥ max(2.0, 바닥선)` (양의 방향만) · 셀 T: `|t_c| ≥ max(2.0, 바닥선)`
  - **그리고 두 반기 각각에서 c 의 부호가 같다.**
  - **바닥선**: X_G·X_T 시계열을 같은 무작위 거리만큼 원형 이동(252 ~ N−252 거래일, 1,000회, seed 20260928)해 두 셀의 |t_c| 중
    큰 값을 모은 분포의 95번째 백분위. (변동성 뭉침·자기상관이 만드는 가짜 t 를 잡는다.)
- **ECONOMIC**: INFORMATION ∧ **덧씌우기 규칙**의 net Sharpe 가 RV20 Rule B 단독보다 전 기간 **그리고** 두 반기 모두 높다.
  - Rule B(동결본 정의 그대로): 선물 1계약 매수 노출 1.0, RV20pct ≥ 0.8 이면 0.
  - 덧씌우기: '위험 큼' 신호인 날 노출 × 0.5. 셀 G = `X_G = 1` 인 날. 셀 T = 전 기간 c 의 부호가 가리키는 쪽 끝 20%
    (c > 0 이면 CT 상위 20%, c < 0 이면 하위 20%) — **방향은 INFORMATION 회귀가 정하고, 문턱 20% 는 여기서 고정**.
  - 수익 = 노출_t × r_{t+1}. **비용 = 노출 변화량 1.0 당 왕복 1.4bp**(선물, 결과 전 고정). 롤 날은 0 수익.
- **ROBUST**: ECONOMIC ∧ 결과를 **다음 5 거래일 실현변동성**(같은 계약 구간)으로 바꿔도 c 가 같은 부호 · t ≥ 2.0.
- 두 셀 다 INFORMATION 미달이면 **REJECT**. 게이트로 빠진 날이 표본의 20% 를 넘으면 INCONCLUSIVE.
