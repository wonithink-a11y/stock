# KOSPI200 선물 분봉 데이터 경로 — Phase 0 실측

선물이 현물보다 선행한다는 가설(사용자 제안, KAIST 실증연구 인용)을 이 저장소의
주식 분봉 패널(261거래일)과 붙여 검증할 수 있는지 **데이터 경로만** 확인한 기록이다.
가설 검증 자체(IC·구간분해·난수 바닥선·비용)는 아직 하지 않았다.

## 1. 판정

**가능하다.** 주식 분봉 패널 261일 중 **249일**에 대해 KOSPI200 선물 30초봉을 받을 수 있다.

## 2. 계약코드 — 이게 유일한 블로커였다

KIS 분봉 API는 계약 단축코드를 요구하는데, **추측으로는 못 찾는다.** 후보 41개 +
전수 스윕 144개(`101`+[A-Z0-9]+{03,06,09,12})를 돌려 걸린 건 2025년물 둘뿐이었다.

원인: **2026년물부터 KRX 코드 체계가 바뀌었다.**

```
101L3000 (2016-03)  101N9000 (2018-09)  101Q9000 (2020-09)
101S9000 (2022-09)  101V9000 (2024-09)  101W9000 (2025-09)
A0169000 (2026-09)  ← 접두가 101 -> A016
```

연도 문자(L·N·Q·S·V·W…)를 외삽하면 틀린다. **그날 코드는 KRX에서 읽어야 한다.**

변환 규칙(실측 확정):

```
KRX ISU_CD (8자리)  ->  KIS FID_INPUT_ISCD (6자리)
앞 4자 + 5번째 문자(월: 1~9 -> 01~09, A/B/C -> 10/11/12)

101W9000 -> 101W09      A0169000 -> A01609      A016C000 -> A01612
```

두 경로가 독립적으로 같은 답을 냈다(교차검증):

- **KRX** `drv/fut_bydd_trd` → `A0169000` → 변환 → `A01609`
- **KIS** `display-board-futures` / `FHPIF05030200` / `FID_COND_MRKT_CLS_CODE=K2I`
  → `A01609` · `A01612` · `A01703`

★ `MKI`는 **미니선물**이다(`A05609` 미니F 202609). 정규 코스피200은 **`K2I`**.
KIS 공식 예제가 `MKI`만 예시로 들고 있어 그대로 쓰면 다른 상품을 받는다.

## 3. 해상도별 과거 조회 가능 범위

`inquire-time-fuopchartprice` / TR `FHKIF03020200` / `FID_COND_MRKT_DIV_CODE=F` /
`FID_PW_DATA_INCU_YN=Y`, `FID_HOUR_CLS_CODE` 별 실측:

| 값 | 간격 | 과거 조회 | 확인 |
|---|---|---|---|
| `1` / `5` / `10` | 1·5·10초 | **당일만** | 20260701 요청 → 0행 |
| **`30`** | **30초** | **가능** | 20260701 → 102행, `152930`·`152900` |
| `60` / `120` / `300` / `600` | 1·2·5·10분 | 가능 | — |

**30초가 과거로 갈 수 있는 최소 해상도다.**

## 4. 보존창 — 매일 앞이 잘린다

| 요청일 | 결과 |
|---|---|
| 2025-08-29 | 102행 정상 |
| 2025-08-25 | **빈 응답** |

주식 분봉(`kis-minute-history-api.py`, 2026-09-01 실측 "오늘−약 1년")과 같은
**롤링 윈도우**다. 30초·1분 경계가 동일하다.

→ 우리 주식 분봉 패널(2025-08-08~2026-09-03, 261일) 중 **앞 12일은 선물이 없다.**
→ **지금 안 받으면 하루에 하루씩 영구히 사라진다.**

## 5. 콜당 분량 / 수집 비용

- 콜당 **102건 고정**. 페이지네이션 필요.
- 1분봉 하루 **408개**(08:48~15:45) = 4콜. 30초봉 하루 약 **821개** = 8콜.
- 근월+차근월 249일 ≈ **4,200콜**(KRX 249콜 포함), 초당 1콜로 약 90분.
- 차근월은 체결이 드물어 하루 **115~124봉**뿐이다 — 초단기 분석엔 사실상 못 쓰고
  롤오버·베이시스 참고용이다.

## 6. output2에 없는 것

`output1`에 `basis`·`kospi200_nmix`·`hts_otst_stpl_qty`(미결제약정)가 있지만
**현재 시점 스냅샷**이다(과거 분단위 아님). `output2`는 순수 OHLCV+체결량.

→ **분단위 베이시스는 현물 분봉과 페어링해 직접 계산해야 한다.**
→ 미결제약정은 KRX 일별만 가능.

## 7. 교훈81 재현 — 이번에도 걸렸다

만기된 계약에 미래 날짜를 요청하면 `rt_cd=0` + 102행이 오는데, 실제 내용은
**그 계약 만기일 데이터**다.

```
101W09 @ 요청 20260903  ->  rt_cd=0, 102행, stck_bsop_date=20250911 (2025-09 만기일)
101W12 @ 요청 20260903  ->  rt_cd=0, 102행, stck_bsop_date=20251211
```

성공코드·행수만 보면 "과거 데이터 있음"으로 오판한다.
**게이트는 `stck_bsop_date == 요청일`이어야 한다.**

비거래일 요청은 직전 영업일을 돌려주는데 이건 정상이다(실측 3건 전부 이 경우:
2026-08-01 토 → 07-31 · 2026-05-01 근로자의날 → 04-30 · 2025-11-01 토 → 10-31).

## 8. 막힌 경로 (재론 금지)

- **pykrx 선물** — `get_future_ohlcv_by_ticker()` 빈 응답. Actions 실 러너에서
  자격증명 있는 상태로도 `EMPTY_ALL`(`data/backfill/_probe-future-krx.json`, 2026-08-27).
- **KIS 마스터파일** — `new.real.download.dev.kis.co.kr/data/fo_idx_code*.mst.zip`
  전부 nginx 406. UA·Accept 바꿔도 동일.
- **모의투자(VTS) 도메인** — 선물 시세 TR이 `rt_cd=0`인데 `output1`이 항상 빈 dict.
  선물 전용 앱키(`KIS_VTS_FUTURES_*`)로도 동일. **시세는 실전 도메인으로 받는다.**
- **네이버** — KOSPI200 **지수**(`KPI200`)는 주지만 선물은 없다.

## 10. 야간장 — `FID_COND_MRKT_DIV_CODE=CM`

주간/야간이 **같은 ISU_CD를 쓴다**(`A0169000`이 주간·야간 양쪽). 계약이 다른 게
아니라 세션이 다르고, KIS는 시장구분 코드로 가른다.

- `CM`으로 부르면 `stck_cntg_hour`가 **18:00~300000**(30시 = 익일 06:00)로 온다.
- 과거 깊이는 주간과 같다 — 2025-11-03·2026-02-02·2026-05-04 전부 정상.
- 1일치 실측(2026-09-03): 코스피200 **1,344봉** · 미국달러 905 · 코스닥150 426 ·
  3년국채 29 · **10년국채 5**. 국채 야간은 사실상 안 돈다.
- KRX 야간 거래대금: 코스피200 58,679억(주간의 14%) · 달러 3,808 · 3년국채 1,065.

이 저장소가 **어떤 해상도로도 가져본 적 없는 데이터**다. "밤사이 정보 → 다음날
09:00 갭 → 개별주"라는 사슬을 처음으로 볼 수 있다.

★ 미해결: 야간 D가 주간 D의 **뒤인지 앞인지**. `stck_bsop_date=D` + `hour 18:00~30:00`
이므로 문자 그대로면 D 당일 18시부터 D+1 06시다. 수집기는 지어내지 않고 원본 그대로
저장한다(교훈75) — Phase 2에서 주간 D 15:45 종가와 야간 D 18:00 시가의 연속성으로
판정한다.

## 12. 아직 안 한 것

- 가설 검증 자체 — IC·TRAIN/VALID/TEST 구간분해·**난수 바닥선**·비용 차감.
- 현물(KOSPI200 지수) 분봉. `inquire-time-indexchartprice`(`FHKUP03500200`)는
  **쓸 수 없다** — `FID_ETC_CLS_CODE`를 0/1/3/4로 다 넣어도 `FID_INPUT_DATE_1`을
  **완전히 무시하고**(20260903과 20260701 응답이 동일) 분봉이 아니라 **일별**을
  돌려준다(`stck_cntg_hour`가 `999999`·`888888` 같은 집계 마커). 또 하나의 교훈81
  사례다. → 구성종목 시총가중 **합성**으로 간다(새 수집 0). G1(선물→개별주)에는
  현물이 필요 없고, 베이시스·잔차 통제에만 쓰인다.
- 08:48 이전 봉의 존재 여부(페이지네이션을 거기서 끊어 미확인).
- 야간 세션의 날짜 귀속(§10 미해결).

★ 이 저장소의 주식 분봉 창이 261거래일뿐이라는 제약은 그대로다. 60/15/25로 가르면
TEST가 65거래일인데, **Opening Fade가 정확히 그 규모(63거래일)에서 부호가 완전히
반전한 전례**가 있다(`opening-fade-longonly-walkforward-2026-08.md`). 판정 기준을
