## 4. PIT / Look-ahead 통제

- 이벤트 feature는 **판단 시각까지의 데이터만** 사용. 이후 데이터는 forward return 계산에만 사용.
- 상대거래량 baseline: **직전 세션까지의 expanding 평균(shift 1)** — 당일 값이 자기 baseline에 들어가지 않음.
- 레벨(지지/저항): **직전 세션 shift(1) rolling 고저**.
- 초과수익 벤치마크: 같은 날짜×시장구분 동일가중(동시횡단면) — 미래 정보 불필요.
- 파라미터 선택은 TRAIN 구간 한정(아래 16절), test는 최종 63세션.
- 발견·수정한 구현 버그 4건(factorize 언팩 교차, groupby-shift/to_numpy 정렬 불일치,
  GRID_MARKS HHMM-arange 가짜스탬프, 세그먼트 벤치마크 오염) — 전부 수정 후 재실행했으며
  과정 중 서로 모순된 두 결과(sns H4 vs 심화연구)는 제3 스크립트로 중재해 정찰했다.
