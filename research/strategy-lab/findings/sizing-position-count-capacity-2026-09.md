# 사이징 ① 종목 수 N — 수익으로는 못 고른다, 수용력으로 고른다

`maxPositions=30` 은 `build_selection.py` 의 `TOP_N=30` 상수일 뿐 이 저장소
어디에도 실측 근거가 없었다. 계좌가 1,000만원에서 5억으로 바뀌면서 이 값이
처음으로 실제 제약이 됐기에 쟀다.

## 방법

selection.json 에 `rank`(그 달 PBR 오름차순 순위)를 저장하도록 한 줄 고치고,
`rank < N` 으로 잘라 넣으며 `maxPositions` 를 맞췄다. 엔진의 maxPositions 만
줄이면 `tie_break=ticker_ascending` 이라 **알파벳순으로 잘려** 팩터와 무관한
포트폴리오가 된다 - 그래서 순위 절단이 필요했다.

청산·비용·리밸런싱·가중(균등금액)은 전부 고정. **바뀌는 것은 N 하나뿐이다.**
검증: 재생성한 selection.json 이 기존과 멤버십·holdSessions·메타 전부 동일
(rank 필드만 추가), top-100 판의 top-30 부분집합도 라이브와 완전 일치.

## ★ N 에는 안정적 최적값이 없다

- **세 구간이 각각 다른 N 을 고른다** — TRAIN N=100(0.757) · VALID N=10(0.726) ·
  TEST N=50(0.852). 이 프로젝트 표준 게이트("TRAIN 최선이 VALID·TEST 에서도
  상위 유지")를 어느 N 도 통과하지 못한다.
- **전체기간 Sharpe 가 U 자다** — 양 끝(N=10 0.6593, N=100 0.6136)이 높고
  중간(N=20 0.4915)이 최악. "팩터가 랭킹 상단에서 강하다"는 이야기가 맞다면
  단조 감소해야 하는데 그렇지 않다.
- **유일하게 일관된 축은 VALID 하나뿐이다** — N 이 커질수록 거의 단조 감소
  (0.726→0.384→0.190→0.062→0.091→0.111→-0.008→-0.098→-0.149). VALID
  (2022-05~2023-12)는 128개월 중 19개월(15%)이고, N=10 의 전체기간 우위는
  사실상 이 구간에서 나온다(TRAIN 은 0.623 vs 0.607 로 거의 동률).
  **구조적 효과가 아니라 국면 효과로 읽는다.**

연도별로도 N=10 이 N=30 을 11년 중 7년 이겼으나(한 해 몰림 아님) 2016년에는
-2.2% vs +9.0% 로 11%p 역전 — 집중도가 만드는 연도 편차가 크다.

## 그러므로 N 은 기계적으로 확정되는 축으로 정한다

수익으로 못 고르는 대신, N 에 **선형·확정적으로** 달린 두 가지가 있다.

### 수용력 (실측)

선택 종목의 20일 평균 거래대금: p05 1.14억 · p25 1.91억 · p50 3.56억 · p75 9.14억.
균등금액이므로 **가장 얇은 종목이 전체를 묶는다**. 유동성 기준(`MIN_TURNOVER`
= 1억원)이 하한을 만들므로:

```
전략 수용력 = MIN_TURNOVER(1억) x 참여율상한 x N
```

실측 검증(128개월, 그 달 최저유동성 종목 x N): 참여율 5% 에서 중앙값 1.60억 ·
하위 5% 달 1.50억 (N=30). 공식과 일치한다.

슬롯이 일 거래대금에서 차지하는 비율(N=30):

| 계좌 | 슬롯 | 중앙값 | p95 | 10% 초과 종목 |
|---|---|---|---|---|
| 1,000만 | 33만 | 0.09% | 0.29% | 0.0% |
| 1억 | 333만 | 0.94% | 2.93% | 0.0% |
| **5억** | 1,666만 | 4.68% | 14.65% | **19.6%** |

5억을 N=30 에 넣으면 다섯 종목 중 하나를 하루 거래대금의 10% 넘게 사야 한다 -
백테스트의 30bps 고정비용 가정이 성립하지 않는 영역이다.

### 집중도 (실측)

MDD 는 N 이 커질수록 대체로 개선된다(N=30 -21.09% -> N=100 **-15.34%**,
전 구간 중 최저). 수용력을 사는 대가로 위험이 늘지 않는다.

## 판정

**N 을 백테스트로 고르지 않는다. 수용력에서 역산한다.**

```
N = 배정자본 / (MIN_TURNOVER x 참여율상한)
```

5억 · 참여율 5% -> **N = 100**. 그 지점의 실측치는 N=30 대비 네 지표 전부
동등하거나 낫다(CAGR 6.05 vs 5.49% · MDD -15.34 vs -21.09% · Sharpe 0.6136 vs
0.5189 · Calmar 0.394 vs 0.260). **수용력을 사는 데 측정 가능한 성과 비용이
없다.**

단 N=100 을 "최선"이라 부르지 않는다 - 그 VALID(-0.149)는 전 구간 최악이고,
전체기간 우위는 위에서 말한 것과 같은 종류의 국면 산물일 수 있다. 주장하는
것은 "N=100 이 N=30 보다 나쁘지 않다"까지다.

## 수용력은 전략을 늘린다고 더해지지 않는다 (실측)

같은 종목을 두 전략이 사면 유동성 제약은 합쳐서 걸린다. 후보 간 월별 겹침:

| 쌍 | 겹침 |
|---|---|
| pbr_value_v1 x factor_earnings_yield_v1 | **49.1%** |
| pbr_value_v1 x pbr_value_v1_combined | **89.4%** |
| pbr_value_v1 x lowmom60_v1 | 0.6% |
| factor_earnings_yield_v1 x lowmom60_v1 | 1.2% |

**pbr 계열과 earnings_yield 를 독립된 두 슬리브로 세면 안 된다**(절반이 같은
종목). 진짜로 독립인 것은 lowmom60 뿐인데 그 전략은 같은 날 TEST 구간
CAGR -3.20% 로 나왔다(`tier2-exit-policy-oos-2026-09.md`).

## 한계

- N 당 1회 실행, 난수 바닥선 없음. 9점 격자에서 고른 값이 아니라 **"고를 수
  없다"가 결론**이므로 다중검정 문제가 결론을 뒤집지는 않는다.
- 수용력 공식은 `MIN_TURNOVER=1억` 유동성 필터가 만드는 하한에 의존한다. 이
  필터를 올리면 수용력은 오르지만 유니버스가 바뀐다 - 2026-08-21 에 확인된
  "유동성 통제변수가 팩터보다 강한 신호였다" 함정과 같은 영역이라 손대지 않았다.
- 참여율 상한 5% 는 관례이고 이 저장소가 실측한 값이 아니다. 실제 체결
  슬리피지로 재려면 분봉 체결 데이터가 필요하다(별도).
- lowmom60_v1 은 N 을 안 쟀다. TEST 마이너스 문제가 먼저다.
