# DMA + Stochastic 50선 (영상 유래) — 일봉 proxy SMOKE

## 0. 이 문서가 주장하지 않는 것

**Claude 는 원본 영상(`Screen_Recording_20260908_221933_Instagram.mp4`)을 보지
못했다.** 입력은 사용자가 옮겨 적은 규칙뿐이다. 따라서 "영상 전략을 검증했다"가
아니라 **"옮겨 적힌 규칙을 일봉에서 검증했다"** 이다.

**일봉이다.** 저장소의 분봉 미러는 `research/strategy-lab/.cache/minute_raw`
(2025-08-08 ~ 2026-08-21, 253 거래일)뿐이라 2016년부터의 분봉 검증은 원리적으로
불가능하다. 영상의 단타 체결구조(장중 진입·청산, 호가 슬리피지)는 여기서
재현되지 않았다.

## 1. 미확정 사항 (영상이 정하지 않은 것 — 임의 확정하지 않음)

| 항목 | 영상 | 이 실험이 한 것 |
|---|---|---|
| DMA 산식 | 미공개 ("일반 이평보다 빠르다") | EMA(n) · SMA(n) · displaced SMA(n, +3bar) 3종 병렬 |
| DMA 기간 | 미공개 | 5 · 10 · 20 |
| Stochastic 파라미터 | 미공개 | (5,3,3) · (14,3,3) |
| "smoothing line" | 미공개 | %K-slow 1순위, %D 는 절제로 별도 |
| 손절/익절 | 언급 없음 | 넣지 않음 (규칙에 없는 것을 만들지 않는다) |
| 포지션 상한 | 언급 없음 | 상한 없음 (capacity 미검증) |

★ **"앞쪽으로 변위된 DMA"는 검증 불가능하다.** displacement 를 음(-k, 미래로
당김)으로 두면 bar t 에서 SMA(t+k) 를 읽는 것이라 정의상 lookahead 다. 인과적인
방향(+k, 뒤로 밀기)만 넣었고, 그건 일반 이평보다 **느리다** — 영상 주장과 반대다.

## 2. 규칙 (구현된 형태)

```
Entry  close[t] > MA[t] AND close[t-1] <= MA[t-1]        (DMA 상향돌파)
   AND line[t] > 50    AND line[t-1] <= 50               (같은 bar, 50선 상향)
Exit   close[t] < MA[t] AND close[t-1] >= MA[t-1]
   AND line[t] < 50    AND line[t-1] >= 50               (같은 bar, 50선 하향)
체결   신호는 t 종가 확정 -> next session OPEN 체결
```

- 롱온리. 숏은 별도 variant 로 분리(미실행 — 아래 §6).
- PIT: A1a `listedAt` 이전 신호 폐기.
- 데이터 끝에서 열려 있는 포지션은 마지막 bar open 강제청산(`forcedExits` 로 보고).

## 3. 실행 검증 (오류 없음 확인)

| 검사 | 결과 |
|---|---|
| same-bar 체결 | **0건** (전 22변형) |
| 신호일 < 체결일 | selftest 가 assert (`entry_date > signal_date`) |
| 회계 항등 | 일별 분해의 곱 == 트레이드 net 수익 (1e-12 이내, selftest) |

| 지표 lookahead | MA·Stochastic 모두 t 이전만 사용. displaced 는 +방향만 |

## 5. 난수 바닥선 (최고 변형 sma5_st5, 20회)

심볼별로 신호 배열을 원형이동(circular shift)해 신호 **개수·간격 분포는 그대로**
두고 가격과의 시점관계만 깼다.

```
난수    CAGR  중앙값 6.83%  최대 8.45%     t vs EW  중앙값 -1.26  최대 -0.04
실제    CAGR        7.52%                 t vs EW        -0.70
```

실제 최고 변형이 **난수 분포의 중앙값 부근**이다. 신호 시점의 기여가 0 에 가깝다.
(combo-sweep 2026-09-02 의 교훈 — 난수 팩터 4,845조합 최고가 t=3.21 이었다.)

## 6. 판정과 그 근거

**REJECT (일봉 proxy 한정).** 재현 가능한 정량 전략으로 만드는 것은 됐지만
한국주식 일봉에서 유효한 신호가 아니다. 세 가지가 서로 독립적으로 같은 결론을 낸다.

1. **코어 18변형 전부가 벤치마크 미달.** 초과 t 가 -0.70 ~ -2.89 로 전부 음이고
   세 구간 어디에도 양의 유의값이 없다. 파라미터를 바꿔도 부호가 안 바뀐다 —
   과최적화 문제가 아니라 신호가 없는 것이다.
2. **최고 변형이 난수 바닥선 중앙값이다.**
3. **노출 0.999.** 같은-bar AND 청산이 거의 발화하지 않아 평균 보유가 26~117 bar 다.
   **일봉에서 이 규칙은 단타가 아니다** — 성과의 대부분이 신호가 아니라 상시 롱
   베타이고, 연도별 수익이 EW 를 거의 그대로 복제한다.
4. 청산을 실제로 단타답게 만들면(절제 3종, 보유 4~6 bar) **gross 부터 음이다.**
   비용 탓이 아니라 진입 후 우위가 없다.

### 이 판정이 닫지 않는 것

- **분봉 검증.** 253거래일(2025-08 ~ 2026-08) 미러로는 가능하나, 표본이
  `rule_discovery_criteria` 의 TRAIN 최소 100 을 만족하더라도 단일 국면
  (2025-2026 상승장) 이라 부호 안정성을 못 잰다. 위 §6-4(짧은 보유의 gross 가
  음)가 분봉에서도 같은 방향이면 재개할 이유가 없다.
- **숏 variant.** 롱 결과가 신호 부재이므로 대칭 규칙의 숏도 같은 결론일 가능성이
  높지만 **재지 않았다.** 재고 싶으면 같은 스크립트에 side 플래그 하나다.
- **capacity.** 슬롯 상한 없는 동일가중이라 실집행 슬롯예산·유동성은 안 봤다.
  벤치마크도 같은 규약이라 비교 자체는 편향되지 않는다.
