# 뉴스·공시 오버레이 — 0~3단계 (정의 고정 · 분류표 · 상식 필터 중복 확인 · 노출 점검)

배경: 절대 규칙 1(뉴스·추정치·공시 해독은 점수·매매에 쓰지 않는다)을 유지한 채, **검증을 통과한 공시 신호만** 모의 전략에 반영할 통로를
만들 수 있는지 본다(2026-09-30 대화). 순서는 사건 연구 → 전략 추가효과 → forward 그림자 → 별도 GO 이며, 그 앞에 **노출 점검**을 둔다.
이 문서는 그 앞단(0~3단계)만 다룬다. 규칙 1 문구는 바꾸지 않았다(변경은 🔴).

## 0단계 — 결과를 보기 전에 고정하는 것

| 항목 | 고정값 |
|---|---|
| 대상 전략 | `pbr_value_v1_combined` (모의투자 운영 슬리브) |
| 슬롯 | selection.json 의 (종목, 리밸런싱일) — 3,402개 |
| 걸림 | 공시 접수일이 슬롯 날짜 기준 0~30일 전. **공시 시각은 DART 목록 API 에 없다(접수일만)** → 지난 기업행사 시험과 같이 공시일 다음 거래일부터 반영 |
| "충분"(사건 연구로 넘어가는 최소 노출) | 유형별 걸린 슬롯 **≥ 100개** 그리고 서로 다른 종목 **≥ 30개** |
| 미달 시 | 그 유형은 사전등록 없이 종결(2026-09-21 유상증자 점검과 같은 처리) |
| 금지 | 수익률·승률·샤프 계산, LLM 의 호재/악재 판단, 결과를 본 뒤 기준 변경 |
| 통계 검증 대상 유형 수 | 최대 3~4개로 고정(다중검정 방지) |

기준 100/30 은 사전 판단값이다 — 유상증자 실측(4개)에서 보듯 이 전략의 노출은 자릿수가 다르므로, 기준을 조금 바꿔도 결론이 뒤집히지 않는다.

## 1단계 — 분류표 (공시 유형, 보고서명 규칙 기반)

분류는 DART 보고서명(`report_nm`)의 정규식만 쓴다. 기존 `scripts/build-stock-events.py` 의 `EVENT_RULES` 와 같은 방식이다.

| 구분 | 유형 | 데이터 | 처리 |
|---|---|---|---|
| **상식 필터** | 거래정지 | A4 일봉 거래량 0 (공시 아님) | 통계 검증 없이 "신규 진입 안 함". 아래 2단계에서 중복 확인 |
| 상식 필터 | 감사의견 거절·한정 | **미수집**(정기보고서 감사의견 항목 API 는 있으나 저장 안 함) | 미측정 — 필요하면 별도 수집 결정 |
| 통계 후보 | 유상증자 | A3d | **기존 점검(2026-09-21)으로 종결**: E2 4건·E3 0건(0.1%) |
| 통계 후보 | 계약 해지(단일판매·공급계약 해지) | DART 목록(거래소공시 I 유형) — 제목만 | 3단계 필요. ★**금액·매출비중은 목록 API 에 없다** — 제목만으로 건수는 셀 수 있으나 "매출 비중별 분류"는 문서 파싱이 필요 |
| 통계 후보 | 횡령·배임 혐의 발생 | DART 목록(거래소공시) — 제목만 | 3단계 필요. 제목에 규모 정보 없음 |
| 후순위(C) | 단일판매·공급계약 체결, 자사주 취득·소각 | 목록 제목 | 호재 가점은 별도 사전등록으로 분리 — 이번 범위 아님 |

정정: 앞선 대화에서 "계약 해지는 매출 비중 구조화 필드로 나눌 수 있다"고 했으나, **DART 목록 API 는 제목·접수일뿐이다.** 구조화 필드(금액)는
공시 본문 파싱이 필요해 1차 범위에서 뺀다 — 유형 존재 여부(제목)로만 시작한다.

## 2단계 — 상식 필터(거래정지)가 이미 걸러지는가

### 코드 확인
- 유니버스(A1a) 제외 사유는 **KONEX 109 · SPAC 71 뿐**이다(`data/backfill/universe/a1a/excluded.jsonl`). 거래정지·관리종목·감사의견 필터는 유니버스에 없다.
- 선정 스크립트(`build_composite_selection.py`)는 `dv20`(20거래일 거래대금 평균) ≥ 1억 원 게이트를 쓴다. 정지 종목은 거래대금이 0 이라 평균이 깎인다.
- 백테스트 엔진은 `open=high=low=0` 인 정지 잔재 행만 제거한다(`engine/runner.py:_drop_suspension_rows`) — 거래량 0 전부가 아니다.

### 실측 (A4 일봉, 건수만)
슬롯 3,402개 중 진입일 행이 있는 3,397개:

| 신호 | 슬롯 |
|---|---:|
| 진입일 거래량 0 | **0** (0.00%) |
| 진입 전 5거래일 중 거래량 0 있음 | **0** |
| 보유 기간 중 거래량 0인 날 있음 | **0** |
| 보유 중 연속 3일 이상 거래량 0 | **0** |

비교: A4 전체에는 거래량 0 인 행이 8,980개(5.39M 행 중 0.17%) 있다 — 측정이 눈이 먼 것이 아니다. PBR 결합 슬롯만 하나도 걸리지 않는다.
**결론: 거래정지 상식 필터는 이 전략에서 유동성 게이트가 이미 대신한다. 새 필터가 필요 없다.**

### 남은 의문 (해석하지 않음)
보유 창 안에 A4 행이 통째로 빠진 거래일이 있는 슬롯이 **18개(0.5%, 15종목)** 있다(데이터 끝에 걸린 6개 제외).
정지일 수도, 수집 공백일 수도 있다. 4월 진입 슬롯이 8개로 몰려 있어(2016·2022~2025) 감사 시즌 정지와 겹칠 가능성이 있으나 **확인하지 않았다.**
0.5% 는 기준(≥100)에 한참 못 미치므로 이 전략에서는 시험 대상이 아니다.

## 3단계 — 계약 해지·횡령배임 노출 점검 (2026-09-30 실행)

실행: `research/strategy-lab/event_overlay_exposure_step3.py`. 선정 150종목의 DART 목록(거래소공시 I 유형, 2015-12~2026-08) 제목·접수일만 받았다.
호출 **377회**(사전 추정 350회, 한도 20,000). 거래소공시 31,248건. corp_code 없는 종목 0. 정정 공시(`[기재정정]` 등)는 원공시와 중복이라 뺐다.
걸림 = 접수일이 슬롯 날짜 0~30일 전(슬롯 당일 접수분 제외 — 공시일 다음 거래일부터 반영).

| 유형 | 공시 건수(종목) | 걸린 슬롯 / 3,402 | 걸린 종목 | 기준(≥100·≥30) |
|---|---:|---:|---:|---|
| **계약 해지** | 67 (21) | **6** (0.18%) | 3 | 미달 → 종결 |
| **횡령·배임** | 39 (13) | **5** (0.15%) | 4 | 미달 → 종결 |
| 매매거래정지(기록 전용) | 88 (48) | 9 (0.26%) | 8 | 미달 |
| 관리종목(지정 우려 예고 포함, 기록 전용) | 13 (9) | 1 (0.03%) | 1 | 미달 |

### 분류 검증과 정정 (결과 확정 전)
- 첫 집계에서 계약 해지가 119건·28슬롯으로 나왔는데, **자기주식취득신탁계약해지 50건이 섞여** 있었다(고객 계약이 아니다). 규칙을 `(단일판매|공급계약).*해지` 로 좁혀 재집계했다(캐시 재사용, 호출 0회). 위 표는 좁힌 뒤 값이다. 좁히기 전 값도 기준 미달이라 결론은 같다.
- 정정 공시를 뺀 것은 의도다. 다만 원공시가 정정으로만 남은 경우는 놓칠 수 있다(미분류 변형 목록에서 정정 표기 횡령배임 4건 확인) — 건수가 기준의 1/20 수준이라 결론에 영향 없다.
- 거래정지 제목에는 정지 해제, 무상증자 관련 정지(기업행사에 따른 통상 정지)가 섞여 있다. 2단계의 거래량 0 대용치(0건)와 어긋나 보이지만, 여기 9슬롯은 슬롯 **전** 30일 안의 공시이고 정지가 이미 풀린 뒤 선정된 경우다.

### 결론
- 계약 해지·횡령배임 모두 이 전략에서 **시험할 대상이 없다.** 유상증자(0.1%)와 같은 결론이다. 사건 연구 사전등록은 쓰지 않는다.
- PBR 결합 전략은 저PBR 30 + 유동성 하한 + MAX 제외 + dropout 이 위험 이벤트를 가진 종목을 이미 거의 걸러낸다(지난 점검의 해석과 같은 방향, 검증은 안 함).
- 노출이 실제로 있는 전략은 lowmom60_v1(유상증자 4.6%) 계열이다. 오버레이 후보를 이어가려면 **전략을 그쪽으로 바꿔서** 같은 3단계를 다시 하는 것이 유일한 길이다 — 새 사전 판단이 필요하다.

## 결론과 다음 (0~2단계 시점 기록)

1. 상식 필터(거래정지): **추가 조치 없음.** 감사의견 거절은 데이터가 없어 판단 보류.
2. 유상증자: 종결 유지(0.1%).
3. 새로 잴 것은 **계약 해지·횡령배임** 둘. 방법: 이 전략이 실제로 한 번이라도 담은 **150종목만** DART 목록(거래소공시 유형)에서 2016~2026 제목을 받아 슬롯과 교집합을 센다(호출 수백 회 규모, 한도 2만). 기준 미달이면 종결.
4. 이 결과와 관계없이 사건 연구·추가효과·forward 그림자 단계는 **사전등록 후**에만 진행한다. 노출 통과는 수익성을 뜻하지 않는다.
