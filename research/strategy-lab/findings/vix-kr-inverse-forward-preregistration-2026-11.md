# VIX 한국 지수 R1 · 인버스 B — forward 사전등록 (2026-11-17)

> **동결.** 이 문서를 커밋한 뒤 규칙·문턱·체결·비용·판정 시점·판정 규칙을 바꾸지 않는다. 판정 시점 전 `--judge` 는 코드가 거부한다(건수만).
> **기록 전용 — 매매·알림 없음. CONFIRMED 여도 매매 반영은 🔴 별도 GO.** 코드: `run_vix_kr_inv_forward.py`. 두 갈래는 **독립으로** 판정한다.

## 0. 왜 forward 인가

- KR-R1: vix-fng-rsi-sector-kr 는 한국 R1 3셀 INCONCLUSIVE(타이밍 p 0.049~0.10 > 0.00125, 구간이 0 포함, 2025~ 에서 −20~−33%p 로 뒤집힘). 후속 '한국 VIX forward 사전등록으로만'.
- INV-B: vix-level-product-era 의 인버스 레그 B 는 선택 셀 [20,16] 이 TRAIN·VALID·TEST 모두 양이었지만 TEST 순열 p 0.071 로 OOS 실패, 수익의 상당 부분이 인버스의 구조적 보유 수익. 후속 '인버스 forward 사전등록으로만'.
- 같은 표본 재절단 금지. 남은 길은 아직 없는 자료다. 기존 forward #30(VIX·실현변동성 사다리 — 나스닥·반도체 3배·코스닥 2배)과 규칙이 다르다.

## 1. 갈래 KR-R1 (고정)

- 자료: yfinance `^KS11`·`^KQ11` 시가·종가(`auto_adjust=True`), `^VIX` 종가. VIX 는 대상 달력일에 맞춰 직전 값을 이어 붙인다(미국 종가는 한국 시간 다음 날 새벽이라 **다음 한국 거래일 시가 체결과 겹치지 않는다**).
- 규칙: VIX ≤ 14 이면 현금, VIX ≥ 20 이면 매수, 사이는 직전 상태 유지. 상태는 **2011-01-03 직전 봉을 매수로** 시작해 지금까지 재생한다(원 연구와 같은 시작).
- 체결: 봉 t 종가 뒤 목표 포지션 T[t] → 봉 t+1 시가에 전환, 시가 이전(밤사이)은 T[t−1]. 편도 5bp. 보유 비교 = 늘 매수(비용 0).
- 한계: `^KS11`·`^KQ11` 은 직접 거래 불가 지수다. 신호 검증용으로만 쓰고 현실성은 ETF 로 근사된다.

## 2. 갈래 INV-B (고정)

- 자료: yfinance `SVXY` 시가·종가(`auto_adjust=True`, 2018-03 이후 −0.5x), `^VIX` 종가. SVXY 상장 첫 봉부터 **현금으로 시작**해 상태를 재생한다.
- 규칙: 현금 상태에서 VIX ≥ 20 이면 매수, 매수 상태에서 VIX ≤ 16 이면 현금. 신호 종가의 다음 봉 시가에 체결(밤사이는 이전 포지션), 편도 5bp. 보유 비교 = SVXY 늘 보유(비용 0).
- 한계: 인버스 변동성 상품은 하루 급등 때 한 번에 큰 손실이 날 수 있고(2018-02 SVXY −1x→−0.5x 개편 사례), 일 재조정 괴리가 있다. 이것은 매매 권유가 아니다.

## 3. 관측 기록

- 관측 행 = 신호일 ≥ 2026-11-18 인 봉. 행마다 `date · mk · s1(봉 t 시가 이후 포지션) · s2(밤사이 포지션) · gon(밤사이 수익) · gid(장중 수익)` 을 `observations.jsonl` 에 **한 번만** 쓴다. 다음 실행에서 같은 날짜를 다시 계산한 값이 다르면(수정가 정정) 고쳐 쓰지 않고 `drift.jsonl` 에 남긴다. 실행 당일(KST) 봉은 버린다.
- 판정에 쓰는 수익은 관측 행에서만 다시 계산한다: 규칙 = (1+s2·gon)(1+s1·gid) − 1 − 0.0005·|s1−s2|, 보유 = (1+gon)(1+gid) − 1.

## 4. 판정 (성숙 250거래일 ∧ 첫 관측 뒤 12개월, 1회)

- 연율 샤프(√252). ΔSharpe = 규칙 샤프 − 보유 샤프(KR-R1 은 두 지수 평균).
- **타이밍 순열 p**: 관측 창의 포지션 열(s1·s2)을 같은 폭으로 원형 이동(이동 폭 21 이상, 4,000회, seed 20261117) → 규칙 샤프(KR-R1 은 두 지수 평균)가 이동본보다 큰 비율(+1 보정). α = 0.05 / 4 = **0.0125**(오늘 등록한 forward 4갈래 공동).
- **판정 불가**: KR-R1 은 현금 날(s1=0)이 두 지수 합쳐 10일 미만 / INV-B 는 진입(s1−s2 > 0)이 3회 미만 → 규칙이 거의 작동하지 않은 구간이라 연장 시점까지 기다린다.
- **KR-R1**: CONFIRMED = ΔSharpe(평균) > 0 ∧ 두 지수 모두 규칙 MDD 가 보유보다 얕음 ∧ p ≤ 0.0125 · REJECT = ΔSharpe(평균) ≤ 0 · 그 밖 INCONCLUSIVE.
- **INV-B**: CONFIRMED = ΔSharpe > 0 ∧ 규칙 총수익 > 0 ∧ p ≤ 0.0125 · REJECT = ΔSharpe ≤ 0 ∧ 규칙 총수익 ≤ 0 · 그 밖 INCONCLUSIVE.
- INCONCLUSIVE 는 500거래일 ∧ 24개월에서 1회 연장, 같은 규칙. 연장 뒤에도 INCONCLUSIVE 면 종결(기록만).
- 기록(판정 불사용): CAGR · 노출 · 전환 수 · 현금 날 다음 수익 평균 · 시기 구분(2025~).
