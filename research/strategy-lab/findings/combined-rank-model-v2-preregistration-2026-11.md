# 결합 순위 모델 v2 — 결함 보정 재실행 — 사전등록

## 1. 질문과 배경

원 실험(`combined-rank-model-results-2026-10.md`, ECONOMIC: h1 TEST net23.54 +8.5bp · h5 TEST +27.2bp, 33.5bp 비용에서 h1 TEST −1.5bp)은 사전등록에 "거래정지는 재개 첫 종가"라고 적었다.
감사(2026-11-13, Fable 5.2 서브에이전트, 관점 하나이며 승인 아님)는 구현이 이를 지키지 못한다고 보고했다:

1. **정지일 행**: A2a 의 거래정지일 행은 시가 0 · 종가는 직전가로 채워져 있다(예: 005930 2018-04-30 시가 0 · 종가 53,000). `combined_rank_model.py` 는 종가만 보고 행을 유효로 세므로(`bad = isnan(C)`)
   정지 중 묵은 종가로 청산한다. 감사 측정: h5 진입의 0.19%, 재개 때 평균 −14.6%, 유니버스 평균을 +2.3~5.2bp 부풀림. 초과에 미치는 영향은 모델 재실행 없이는 모름.
2. **거래량**: 가격은 수정주가인데 거래량은 원값이라(삼성 분할 전 24만 주 → 분할 뒤 3,950만 주) `value = C * V`(적격 필터와 `tv20` 특징)가 미래 분할·감자를 품는다. 수정계수 자료가 없어 직접 고치지 못한다.
   `tv20` 중요도는 상위 10 밖이라 영향은 작다고 추정(감사 미측정).

## 2. 고정 사항

- **자료·모델**: 원과 동일 — `combined_rank_model.py` 의 가격 적재, 특징 30개, LightGBM 연 1회 재학습, 매일 상위 20, t+1 시가 → t+h 종가(h=1·5), TRAIN-WF ≤2020 · VALID 2021~22 · TEST 2023~, 비용 23.54bp(스트레스 33.5bp), 바닥선 방식과 시드 모두 원 그대로.
  원 모듈을 import 해서 쓰고 아래 두 곳만 바꾼다. 원 파일은 수정하지 않는다.
- **V1 (정지일 행 무효화)**: 적재 직후 시가가 결측(≤0 → 결측 처리됨)인 행은 거래정지 행으로 보고 **종가·고가·저가·거래량도 결측**으로 만든다. 그러면 원 코드의 `next_valid_index` 가 재개 첫 종가를 쓴다(사전등록 원문 규칙의 실현).
  그 밖의 규칙(폐지 = 마지막 종가, 상장 종목 데이터 끝 초과는 미결, 상한가 시가 제외)은 원 그대로.
- **V2 (V1 + tv20 제거)**: V1 에 더해 특징 목록에서 `tv20` 만 뺀다(29개). 적격 필터의 거래대금 문턱은 원 그대로(거래량 영향이 남는다 — 한계).
- **비용·시장**: KR 연속 시장 23.54(단일가 가정)·33.5 스트레스를 원과 같이 보고한다. 결과를 보고 바꾸지 않는다.
