# 계약부채 증가 → 공시 뒤 주가 (2단계) — 사전등록 (2026-10-19, 결과 전)

## 1. 질문과 기대

1단계는 재무끼리였다(주가 없음). 여기서는 **사업보고서가 공개된 다음 날 산 사람**이 이기는지 잰다.
사업보고서는 결산 뒤 약 90일에 나오고 그 전에 잠정실적·분기 보고서가 나온다 — 계약부채 증가의 일부는 이미 알려져 있을 수 있다.
기존 증거: 정기보고서 접수일 프리미엄 없음(earnings-announcement-premium REJECT) · 업종 실적 확산 REJECT('정기보고서는 늦다') · 공시 '수주' 제목 사건은 20일 −63bp(반대 방향).
**현실적 기대: INCONCLUSIVE 또는 REJECT.**

## 2. 고정 정의

| 항목 | 값 |
|---|---|
| 재료 | `data/fundamentals-full/annual-full.jsonl`(DART 전체 재무제표 원문, 2026-10-19 수집) · A3 매출·KSIC · A2a+A2b 수정주가(폐지 종목 포함, 같은 날 중복은 A2a 우선) |
| 계약부채 CL | 1단계 `contract_liab_revenue.cl_amount` 그대로(재무상태표 계약부채·선수금·선수수익·초과청구공사, 확정계약·상위 합계 제외, 없으면 결측) |
| 사건 | 회계연도 t 의 사업보고서, CL_t·CL_t−1 둘 다 있음, 매출_t−1·매출_t ≥ 10억, 금융업(KSIC 64~66) 제외 |
| 신호일 | 그 보고서 응답 rcept_no 앞 8자리(접수일). 최신본이 정정이면 늦게 잡혀 보수적 |
| 신호 | dCL_t = (CL_t − CL_t−1) / 매출_t−1 |
| 분위 기준(PIT) | **직전 회계연도(t−1) 사건 전체**의 dCL 80·20 백분위 — 같은 해 늦게 공시한 회사로 기준을 정하지 않는다. 그래서 첫 사건 연도는 t = 2017(기준 t = 2016) |

| 진입 · 보유 | 신호일 **다음** 거래일 종가 → 126거래일(주) / 252거래일(기록) 뒤 종가. 그 전 가격이 끊기면 마지막 종가(폐지 포함). 창이 자료 끝을 넘으면 미성숙으로 뺀다 |
| 적격 | 진입일 가격 있음 ∧ 직전 20거래일 평균 거래대금 ≥ 10억 ∧ 금융업 아님 |
| 대조 | 같은 진입일 적격 종목 중 같은 KSIC 2자리 ∧ 같은 거래대금 3분위(그날 적격 전체 기준) 종목 등가중(자기 제외). 5종목 미만이면 같은 거래대금 3분위 전체 |
| 사건 값 | 초과 = 사건 수익 − 대조 수익. 회계연도 코호트별 평균 → 코호트 평균의 평균 |
| 귀무 | 같은 회계연도의 **모든 사건**(dCL 있는 회사)에서 Q5 와 같은 개수를 무작위로 뽑아 같은 통계 — 10,000회(seed 20261019). '계약부채 공시 회사·3월 공시 시점' 효과를 뺀다 |

## 3. 판정 (주 셀 = Q5 · 126거래일)

| 판정 | 조건 |
|---|---|
| **REJECT** | TRAIN 초과 평균 ≤ 0 · 또는 TRAIN p ≥ 0.05 이면서 VALID·TEST 중 하나라도 ≤ 0 |
| **INCONCLUSIVE** | TRAIN p ≥ 0.05 이고 세 구간 초과 모두 > 0 |
| **INFORMATION** | TRAIN 초과 > 0 ∧ p < 0.05 ∧ VALID·TEST 초과 모두 > 0 |
| **ECONOMIC** | INFORMATION ∧ 세 구간 모두 비용 후(−33.5bp) > 0 |
| (INFORMATION 이 아닌데 TRAIN p < 0.05) | VALID·TEST 중 ≤ 0 이 있으면 REJECT(부호 반전) |

셀은 하나 — 다중검정 바닥선 없음. 결과를 보고 백분위·보유 기간·대조를 바꾸지 않는다.
INFORMATION 이상이어도 매매·점수 채택이 아니다 — forward 사전등록 + 🔴 별도 GO.
