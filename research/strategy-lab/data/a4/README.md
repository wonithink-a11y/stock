# A4 수급 연구 데이터셋 (research/strategy-lab/data/a4/)

A4(종목별 일별 수급, KRX/pykrx, SD-1.0) 원자료를 Strategy Lab 연구용으로 가공한
데이터셋. **연구 전용** — production(scoringEngine·resolver·backtester)과 무관,
`config/policies/*` 무변경.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `a4-research-dataset.parquet` | (ticker, date)별 수급 파생 feature + forward return. 5,348,454행 · 2,558종목 · 2016-01-04~2026-08-03 |
| `a4-feature-summary.json` | 컬럼 정의·계산식·기술통계·결측률·계산 불가 항목 |
| `a4-data-quality.json` | 원자료 재검증(항등식·키집합·조인·커버리지)·제외 규칙 |
| `a4-analysis-results.json` | IC/Rank IC·decile·연도별·규모별·조합 분석 결과 |
| `A4-RESEARCH-HANDOFF.md` | 다음 세션용 인수인계(조사·결론·가설·한계·확인 사항) |
| `../build_a4_research_dataset.py` | 원자료→parquet 구축 스크립트 (streaming, PIT) |
| `../analyze_a4_research.py` | 분석 스크립트 (cross-sectional) |

## 원자료 출처와 기간

- **A4 원자료**: `data/backfill/supplyDemand/a4/{2016..2026}.jsonl.gz`
  - 수집: KRX via pykrx (`get_market_trading_value_by_date/_volume_by_date`), SD-1.0
  - 5,409,687행, 2,578종목, 2016-01-04~2026-08-14
  - 매수/매도·금액/수량 × 12 카테고리(개인·금융투자·기타금융·기타법인·기타외국인·보험·사모·연기금·외국인·은행·투신·전체)
  - 순매수는 조회 시 매수-매도로 유도 (원자료에 순매수 컬럼 없음)
- **가격**: `data/backfill/price/a2a/*.jsonl.gz` — **adjusted(수정주가)**. PR-1.5/1.6,
  액면분할·배당 보정. **unadjusted는 사용하지 않음.**

## PIT 규칙

- 모든 파생 feature(rolling netbuy 1/5/20d, 거래대금 비율, log거래대금)는 **date t까지의
  정보만** 사용 (ticker별 날짜 오름차순 rolling). look-ahead 없음.
- forward return: `t+20/+60/+120 거래일 close / t close - 1` (adjusted 기준).
  미래 데이터가 feature 계산에 섞이지 않음.
- 미래 부재(기간 말)는 NaN으로 남김 — 보간/대체 없음.

## 핵심 분석 결과 요약 (a4-analysis-results.json)

**방향성 확인용 잠정치다 — threshold/가중치는 이 데이터셋에서 확정하지 않는다.**
cross-sectional Spearman(날짜별 종목 간 순위), 일별 IC의 평균.

### IC / Rank IC (전체 기간)

| feature | d20 | d60 | d120 |
|---|---|---|---|
| 외국인 20d 순매수 | +0.004 | +0.009 | +0.012 |
| **기관 20d 순매수** | +0.004 | +0.011 | **+0.022** |
| 개인 20d 순매수 | -0.002 | -0.010 | **-0.022** |
| 외국인 20d 순매수/거래대금 | -0.012 | -0.013 | -0.010 |

- 기관·외국인 순매수는 **긴 지평에서 양의 IC**(t값 10~25, nDays 2,475~2,575).
- 개인 순매수는 **뚜렷한 음의 IC** — 개인이 많이 사는 종목의 장기 수익률이 낮다.
- 거래대금 비율은 부호가 뒤집힘(순매수 금액 자체와 반대) — 소형·저유동성 종목의
  극단값 영향 의심. **비율 feature는 추가 검증 필요, 운영 후보 아님.**

### 연도별 (20d feature vs d60)

| 연도 | 외국인 20d | 기관 20d | 개인 20d |
|---|---|---|---|
| 2016 | -0.005 | +0.011 | +0.003 |
| 2017 | +0.003 | -0.023 | +0.024 |
| 2019 | +0.009 | +0.018 | -0.013 |
| 2022 | +0.007 | +0.015 | -0.012 |
| 2024 | +0.020 | +0.014 | -0.026 |
| 2026 | +0.033 | +0.058 | -0.068 |

- **관계가 연도별로 안정적이지 않다**: 개인은 2019년부터 지속 음수로 역전,
  외국인·기관은 최근연도로 갈수록 양의 IC가 강해짐. 2016~2018에는 기관이 음수였던
  연도도 있음. 고정 파라미터 운영 시 기간 의존 리스크.

### 규모별 (거래대금 3분위 proxy, d60)

| feature | 소형(T1) | 중형(T2) | 대형(T3) |
|---|---|---|---|
| 외국인 20d | -0.013 | -0.004 | +0.013 |
| 기관 20d | -0.008 | -0.006 | +0.010 |

- **대형주에서만 양의 IC** — 수급 순매수가 중·소형에서는 오히려 음수.
  시가총액 미매핑이라 거래대금 proxy 기준 잠정치.

### Decile (10=최다 순매수, d60)

- 외국인·기관·개인 모두 **D5(중앙)가 최고, 양극단(D1/D10)은 낮음** — 극단 순매수/매도
  모두 장기 수익률에 우호적이지 않은 뒤집힌 U.
- D10이 D1보다 크게 나은 패턴은 아님 → "순매수 상위를 사면 좋다"는 단순 규칙은
  실측으로 지지되지 않음.

| 조합 | n | meanD60 |
|---|---|---|
| 외국인&기관 동시 순매수 | 1,076,686 | +0.021 |
| 외국인&기관 동시 순매도 | 1,357,890 | +0.018 |
| 외국인만 매수 | 1,345,100 | +0.022 |
| 기관만 매수 | 1,357,681 | +0.019 |

- 두 축 동시 순매수/순매도의 구분력이 미미. 승률(mean>0 비율)은 양쪽 다 ~43%.

## 검증 상태 (a4-data-quality.json)

- **KRX 시장 청산 항등식 재검증**: `buyAmount['전체'] == sellAmount['전체']` — 전건 0 위반
  (원자료 finalize `_diagnostics.json: marketClearingViolations=0`과 일치).
- 카테고리 키 집합 변형 1종 (전체 레코드 동일 스키마).
- A2a 조인: A4 2,578종목 중 2,558종목 매핑 (20종목은 A2a close 부재 → 패널 제외).
- forward 커버리지: d20 99.1% / d60 97.3% / d120 94.5% (기간 말 미래 부재).
- A2a가 A4보다 11일 짧음(마지막 수집 2026-08-03) → 패널 기간 2026-08-04~14는
  forward NaN으로 남김.

## 계산하지 않은 것 (정당화 불가 또는 원자료 부재)

- 주당 수급량(A3c 발행주식수 미연결), 외국인 보유율(보유잔고 원자료 없음),
  공매도 잔고(KRX 공매도 차단, `docs/operations/data-source-availability.md`),
  시가총액(A1a 유니버스 미매핑 — 거래대금 proxy 사용).

## 제약과 한계

- 전량 A4 panel(상장 종목 전부) — **상장 편향 있음**: 현재 상장 종목 기준이므로
  중도 상장폐지 종목의 최근 이력은 부분 누락(A4는 2,578종목 전체 포함이지만
  A2a 미커버 20종목 제외). survivorship 확인은 A2b/A1b 병합이 필요 — 다음 단계.
- 2008~2015 부재 (A4 수집 시작 2016-01-04).
- 전량 패널이라 개별 종목 액션(불공정거래·외국인 보유 한도 초과) 미보정.
- cross-sectional IC는 날짜별 순위 기반 — 시장 전체 방향(베타)은 제거되지만
  종목 간 상관(산업·테마)은 미보정.
