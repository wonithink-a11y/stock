# Stock Terminal — 디자인 시스템

작성 2026-11-14 · 토큰 [`tokens.css`](tokens.css) · 시안 [`prototype-today.html`](prototype-today.html). 로컬 확인: `python scripts/serve-site-preview.py` → `http://localhost:8734/design/prototype-today.html` · `/paper-trading/` (배포 구조 docs=루트·ui=/paper-trading/ 를 흉내 낸다).
목적: 대시보드(`docs/index.html`)·모의투자 앱(`ui/`)·autotrader 웹(`autotrader/web.py`)이 **하나의 제품처럼** 보이게 하고, "AI 가 만든 단편 화면" 티를 없앤다.
이 문서는 시스템(원칙·토큰·구성요소·적용 순서)이고 화면 전환은 §8 순서로 한다. 코드·데이터·점수 로직은 바꾸지 않는다.

## 2. 참고한 방식 (무엇을 어디서 가져왔나)

직접 확인한 것(✔)과 일반 지식(△)을 구분한다. 화면 캡처를 가져온 것이 아니라 **원칙만** 가져왔다.
- ✔ **토스증권 웹**(2026-11-14 실측): 한 글꼴, 본문 12–13px · 600 굵기, 숫자 tabular, 이모지 0, 반투명 면(`rgba(214,224,239,0.09)`) 위에 패널을 쌓는 **면 기반 구획**, 한 가지 파란 강조, 필 형태(999px) 칩, 우측 고정 관심 종목 패널 + 하단 시세 바. 국내 사용자가 이미 익숙한 정보 배치(순위 표 · 우측 관심)다.
- △ **블룸버그 터미널 계열**: 정보 밀도가 높고 색을 거의 쓰지 않으며(검정 바탕 + 한 가지 강조) 색은 의미(오름·내림·경고)에만 쓴다. 키보드 중심 명령 입력. → 우리는 밀도와 "색은 의미에만" 규율을 가져온다.
- △ **트레이딩뷰·핀비즈**: 차트·히트맵이 화면의 주인이고 UI 크롬은 후퇴한다. 핀비즈 홈은 광고 팝업이 정보를 가렸다 — 반면교사: **데이터 화면에 마케팅 요소 금지**.
- △ **디자인 시스템 규율(IBM Carbon·Atlassian·Shopify Polaris 류)**: 토큰→구성요소→패턴 3층, 구성요소마다 상태(기본·호버·선택·비활성·로딩·빈·오류), 접근성 기준(대비 4.5:1, 포커스 링, 터치 40px).
- ✔ **차트 규칙**(이 환경의 `dataviz` 스킬 검증 규칙): 이중축 금지, 범주색 고정 순서, 단일 지표는 차트 말고 숫자 타일, 얇은 마크·헤어라인 격자, 모든 차트에 표 대안, 상태색은 아이콘+글자와 함께.
- 한국 시장 관례: 상승 빨강·하락 파랑, 원·억·조 단위 표기, KST, 장중/장마감 상태 칩.

## 3. 토큰 (`tokens.css` 가 단일 출처)

- **면**: `--bg` → `--surface-1`(패널) → `--surface-2`(호버·선택·입력) → `--surface-3`(눌림·트랙). 구획은 명도 차이와 `--line` 헤어라인 한 줄. 패널 그림자 없음(떠 있는 팝오버만 `--shadow-pop`).
- **글자**: `--text-1`(본문·값) · `--text-2`(라벨) · `--text-3`(보조·축). **`--text-3` 은 surface-3 위에 쓰지 않는다**(대비 4.3:1 — 그 면은 트랙·눌림 전용).
- **방향색**: `--up`(빨강) `--down`(파랑) + `-wash`. **방향은 색만으로 전하지 않는다** — `▲ 1.20%` `▼ 0.40%` `― 0.00%` 글리프와 부호를 같이 쓴다. 상승·하락 색은 명도가 거의 같아 색만으로는 약하기 때문이다.
- **강조**: `--accent`(보라 계열) — 선택·포커스·링크 전용. 방향색(빨강·파랑)과 계열이 달라 가격 방향으로 읽히지 않는다.
- **상태**: `--good` `--warn` `--crit` + wash. 항상 **아이콘 + 글자**를 붙인다. 한국에서는 가격 상승이 빨강이라 `--crit` 와 `--up` 이 같은 계열이다 → 구분은 **위치와 모양**으로 한다(가격 열에는 ▲▼, 상태 칩에는 ⚠ 아이콘+글자).
- **대비(WCAG, 계산값)**: 다크 — text-1 14.7 · text-2 7.6 · text-3 5.0(surface-2 위) · up 5.9 · down 6.6 · accent 5.8. 라이트 — text-1 17.7 · text-2 7.6 · text-3 4.7 · up 4.5 · down 4.8 · accent 5.9. 값을 바꾸면 다시 계산하고 4.5:1 미만이면 반려한다.
- **글꼴**: `Pretendard Variable`(OFL, jsDelivr 서브셋) → Segoe UI → system-ui → 맑은 고딕. 전 요소에 상속(`button,input{font:inherit}`). 숫자는 `.num`(tabular).
- **크기**: 11 캡션 · 12 메타 · **13 본문** · 16 제목 · 20 페이지 제목 · 28 큰 숫자. 굵기는 400/500/600/700 만. 큰 숫자는 비례 폭(`tabular-nums` 금지), 표·목록의 숫자만 tabular.
- **간격** 4px 격자(4·8·12·16·24·32). **반경** 4(칩·입력) · 8(패널) · 999(필). **모션** 120ms, `prefers-reduced-motion` 에서 0.
- **테마**: 라이트 기본, 다크는 OS 설정 또는 `html[data-theme="dark"]`(라이트 강제도 가능). 둘 다 같은 토큰 이름의 값만 바뀐다.

## 4. 구성요소 (시안에 구현된 것 ✔ / 명세만 ○)

- ✔ **앱 셸**: 상단바(브랜드·검색·장 상태 칩·테마) · 좌측 메뉴(그룹 라벨·선택 시 `inset 2px accent`) · 작업영역 · 우측 관심 패널. 1180px 이하 우측 패널 숨김, 760px 이하 메뉴가 하단 탭 바로 변환.
- ✔ **지표 타일**: 라벨(12) · 큰 숫자(28, 비례 폭) · 변동(글리프+부호) · 스파크라인(선 1.5px + 마지막 점만 방향색). 지표 하나는 차트가 아니라 타일이다.
- ✔ **패널**: 헤더(제목 13/600 + 우측 메타) + 본문. 패널 안에서 목록·표는 가장자리까지 붙인다(안쪽 상자 금지).
- ✔ **목록 행**: 아이콘 칩 · 제목+보조 · 우측 태그. 행 사이는 헤어라인.
- ✔ **표**: 헤더 고정, 숫자 열 오른쪽 정렬·tabular, 행 높이 44, 선택 행 `accent-wash` + 좌측 표시, 점수는 막대(얇은 4px, 중립색 — 점수는 방향이 아니다). 좁은 화면에서는 보조 열 숨김(`.hide-sm`).
- ✔ **태그/필**: 중립 기본, `warn`·`crit`·`good` 은 아이콘과 함께. 색 배지를 새로 만들지 않는다.
- ✔ **데이터 기준 패널**: 데이터마다 기준일과 신선도(최신/지연)를 항상 보인다 — "정직한 점수" 원칙의 화면판. 시안 "종목별 수급(A4) 10.30 지연" 처럼 낡은 것을 숨기지 않는다.
- ○ **명령 팔레트**(Ctrl K): 종목·메뉴·행동 검색. ○ **상태 3종**: 로딩(이전 내용을 흐리게 유지, 레이아웃 점프 금지) · 빈 상태(이유+다음 행동 한 줄) · 오류(원인+재시도). ○ **토스트**, **팝오버/툴팁**(차트 호버, 값은 표 대안에도 존재).
- 아이콘: 24px 격자 선 아이콘, 굵기 1.75 단일. 시안은 자체 경로 SVG 스프라이트를 인라인한다(외부 라이선스 없음).

## 5. 화면 구조 — 정보 구조를 질문으로 짠다

메뉴는 파이프라인 구성 요소와 맞춘다(별도 문서: `docs/control/멀티에이전트-파이프라인-현황조사-2026-11-14.md`).

| 메뉴 | 답하는 질문 | 파이프라인 팀 | 현재 화면에서 올 것 |
|---|---|---|---|
| 오늘 | 지금 무엇을 확인하나 | 1 수집·이벤트 | 대시보드 "오늘 확인할 것·시장 수급·공시·일정" |
| 후보 | 어떤 종목이 걸러졌나 | 2 스코어링 | 스코어링·추천 이력·랭킹 |
| 종목 | 이 종목의 근거와 반증은 | 3 논리·반증(맥락 전용) | 종목 카드·공시·뉴스 |
| 계획·실행 | 무엇을 얼마에 하나 | 4 리스크·실행 | autotrader 계획 카드·모의 포지션·킬 스위치 |
| 성과 | 맞았나 | 5 사후 평가 | 성과·forward 그림자·R 배수 |
| 연구실 | 어떤 규칙이 검증됐나 | (연구) | 연구실·findings |

- 마스터-디테일: 표에서 행을 고르면 우측에 상세(종목)가 열린다. 목록과 상세가 한 화면에 있어 탭 이동이 없다.
- 점수·신뢰도·논리는 **맥락 전용**임을 화면에서도 구분한다(점수 영역과 맥락 영역을 섞지 않는다 — 절대 규칙 1).
- 어느 화면이든 첫 줄에 **데이터 기준일과 장 상태**가 보인다.

## 6. 데이터 시각화 규칙 (차트를 새로 만들 때)

1. 먼저 형태를 고른다: 지표 하나 = 타일, 비교 = 순위 막대, 시계열 = 선(축 1개), 구성 = 6조각 이하 누적 막대. 이중축·원형 비교·3D 금지.
2. 범주색은 고정 순서로, 8개를 넘기지 않는다(넘으면 "기타"). 필터를 바꿔도 남은 항목의 색은 바뀌지 않는다.
3. 마크는 얇게(선 2px, 막대 끝 4px 반올림), 격자는 실선 헤어라인 한 톤, 값 표기는 극값·끝점만. 크로스헤어+툴팁 기본 제공, 모든 차트에 표 보기.
4. 방향(오름·내림)이 의미인 값은 `--up/--down`, 범주 구분은 방향색을 쓰지 않는다(예: 코스피=파랑으로 그리면 하락으로 읽힌다 → 범주 팔레트는 방향색을 제외하고 `dataviz` 스킬의 검증 팔레트에서 고른다).
5. 색 팔레트를 새로 정하면 `dataviz` 스킬의 `scripts/validate_palette.js` 로 다크·라이트를 각각 검증한다.

## 7. 문구·콘텐츠 규칙 (AI 말투 제거)

- 설명 문단·면책 문구를 화면에 늘어놓지 않는다(메모리 규칙: 안내 문구 최소화). 필요한 한 줄만, 근거와 날짜를 붙여서.
- 느낌표·이모지·"~해 보세요" 투 금지. 숫자와 상태를 먼저, 해석은 한 줄.
- 단위: 지수·가격은 천 단위 쉼표, 금액은 억/조, 비율은 소수 2자리, 날짜는 `11.13`(같은 해) 또는 `2026-11-13`, 시각은 항상 KST 표기.
- 추천·권유 표현 금지: "매수 후보"가 아니라 "후보", 등급은 점수 구간의 이름일 뿐이다(투자자문 아님).

## 9. 수락 기준 (화면 하나가 "끝났다"의 정의)

- 글꼴 계열 1개, 글자 크기 6단계 이내, 반경 3종 이내, 색은 토큰만(하드코딩 16진수 0개).
- 이모지 0개, 아이콘은 SVG 스프라이트 하나로.
- 숫자 열은 tabular·우측 정렬, 방향 값은 글리프+부호, 상태는 아이콘+글자.
- 대비 4.5:1 이상(본문), 포커스 링 보임, 터치 대상 40px 이상(모바일).
- 데스크톱(1440)·태블릿(860)·모바일(375)에서 가로 스크롤 없음, 다크·라이트 둘 다 확인.
- 데이터 기준일·장 상태가 첫 줄에 보임.
- 시안과의 차이가 의도된 것이면 이 문서에 이유를 적는다.

## 10. 한계·미확인

- 토스증권 외의 참고(블룸버그·트레이딩뷰·핀비즈)는 일반 지식·부분 관찰이다. 상세 수치는 확인하지 않았다.
- Pretendard 는 외부 CDN 로딩이다(오프라인이면 Segoe UI 로 대체). 필요하면 저장소에 woff2 를 두는 것은 라이선스(OFL) 상 가능하나 용량이 커서 보류.
- 시안의 종목 표·일정·공시 행과 관심 종목 값은 예시다(지수·외국인 수급은 2026-11-13 실제 값).
- 접근성은 대비·포커스·터치 크기까지만 점검했다(스크린리더 시험 미실시).

## 11. v2 시안이 v1 과 다른 점 (2026-11-14)

v1 은 위생(글꼴·색·아이콘) 정리였고 화면 구성은 "큰 숫자 카드 + 스파크라인"이라는 기본 처방 그대로였다. v2 는 구성을 바꾼다.
- **한 줄 시황**: 숫자에서 규칙으로 만든 문장(LLM 아님) — 지수 등락·고점 대비·외국인 순매수 5일 합. 어제 연구(외국인 매도와 하락은 동행)가 화면에 처음 나온다.
- **연동 차트**: 코스피 캔들 + 외국인 순매수 막대를 한 시간축에 동기(TradingView lightweight-charts 4.2.0, CDN). 크로스헤어를 따라 시고저종·순매수 값이 바뀐다.
- **업종 지도**: 352종목 시총×수익률 트리맵(직접 그린 SVG squarified). 업종 머리글, 1일·1주·1개월 전환, 면적은 시총의 **제곱근**(삼성전자·SK하이닉스가 면적의 절반을 먹는 쏠림 완화 — 화면에 명시). ECharts 는 업종 머리글이 안 그려져 버렸다(원인 미조사).
- **후보 표 + 점수 구성**: 점수와 재무·가치·기술 구성 막대를 한 행에. 신뢰도·1일 수익률·상태.
- **연동 서랍**: 표 행·지도 칸·검색 어디서 골라도 같은 우측 서랍이 열린다(점수 구성, 수익률 5개 기간, 맥락 자리). 맥락(논리·반증·공시·뉴스)은 **비어 있고** "점수에 반영되지 않음"을 명시 — 파이프라인 3번 설계 전.
- **명령 팔레트** Ctrl K: 종목명·코드·업종·메뉴 검색, 방향키·Enter.
- 데이터는 2026-11-13 스냅샷 **실제 값**(캔들 야후, 코스피 외국인 순매수 KRX 일별 110일, 업종 `sector-strength.json`, 후보 `latest-v2.json`). 반응형(1180 이하 서랍이 하단 시트, 760 이하 하단 탭), 라이트·다크.
- 한계: 캔들 시가는 야후 값이라 전일 종가 대비 갭이 중앙값 1.6%로 커 보인다(미검증). 시안은 정적이라 데이터 갱신·가상화(수천 종목)·접근성 키보드 탐색은 안 했다. 지도·서랍의 스크린리더 대체(표 보기)가 없다.
- 이식 경로: 정적 사이트(빌드 없음) 유지 시 lightweight-charts + 자체 SVG. React·shadcn/ui 경로는 빌드 단계가 필요해 프로젝트 전제("npm 프로젝트 아님")를 바꾸므로 v2 를 본 뒤 사용자가 정한다.
