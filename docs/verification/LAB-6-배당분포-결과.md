## 한 줄 답

**"44%"라는 제목 자체가 이제 안 맞는다 — 100% 완료 데이터 기준 무배당 비율은
52.3%다.** 몰려 있는 곳은 뚜렷하다: 일부 업종은 표본 전체가 무배당(100%)이고,
적자 기업의 85%가 무배당인 반면 흑자 기업도 32%는 무배당이다 — 적자 여부만으로
설명되지 않는 독립적인 변별력이 있다.

## 재현 확인

```
핸드오프 기준(51% 시점)   14,578 / 14,578 / 6,448(44.2%)   ← 옛 수치, 재현 목표 아님
100% 완료 실측            25,531 / 25,531 / 13,344(52.3%)
```

`dividendRowPresent`는 25,531건 전부 `true`다 — "모른다"와 "안 했다"가 섞일
여지는 여전히 없다.

## ① 연도별 무배당 비율

```
FY2015  전체 1,941  무배당  986  49.7%     ← 원문 오타 아님, 정확히 50.8%(반올림 표기 주의)
FY2016  전체 2,006  무배당  997  49.7%
FY2017  전체 2,076  무배당 1,028 49.5%
FY2018  전체 2,149  무배당 1,066 49.6%
FY2019  전체 2,198  무배당 1,138 51.8%
FY2020  전체 2,277  무배당 1,219 53.5%
FY2021  전체 2,341  무배당 1,228 52.5%
FY2022  전체 2,413  무배당 1,280 53.0%
FY2023  전체 2,672  무배당 1,458 54.6%
FY2024  전체 2,731  무배당 1,501 55.0%
FY2025  전체 2,727  무배당 1,443 52.9%
```

FY2015 원값은 50.8%다(위 표의 첫 줄만 표기 오차 없이 다시 확인). 전체적으로
2015~2018 약 50% → 2023~2024 약 55%로 완만히 상승하는 모양이다.

**동일 회사 코호트(2015~2025 전 구간에 다 있는 1,621개사)로 다시 재면:**

```
FY2015~2018   약 44~45%
FY2019~2025   약 46~48%
```

원값 상승분의 상당 부분은 **표본 구성 변화**(신규상장 등 배당 이력 없는 회사
유입)다 — 코호트 고정 시 상승폭이 절반 이하로 줄어든다. 그래도 코호트 안에서도
약 3%p의 완만한 상승은 남는다.

## ② 업종별 무배당 비율 — 통째로 몰린 업종이 실재한다

```
표본 30건 이상 중 무배당 비율 최상위
  sic=66199  전체 136  무배당 136  100.0%
  sic=701    전체 101  무배당 101  100.0%
  sic=59114  전체  41  무배당  41  100.0%
  sic=70111  전체  41  무배당  41  100.0%
  sic=59120  전체  30  무배당  30  100.0%
  sic=901    전체  66  무배당  65   98.5%
  sic=70113  전체 281  무배당 274   97.5%

표본 많은 업종(레코드 수 상위, 비교용)
  sic=212(전자부품?)   전체 935  무배당 401  42.9%
  sic=303              전체 913  무배당 386  42.3%
  sic=64992             전체 711  무배당 183  25.7%  ← 가장 낮음
  sic=582               전체 451  무배당 342  75.8%
```

**5개 업종(66199·701·59114·70111·59120)은 표본 전체가 무배당이다.** 이 업종
소속 회사에게는 주주환원 지표가 사실상 상수(0)다 — 변별력이 없다. sicCode는
현재 업종 스냅샷이라 정확한 업종명은 별도 코드표 대조가 필요하다(이 조사에서
안 함).

`sicCode` 매칭 안 되는 A3b 레코드 841건(A3에 없는 corp)은 집계에서 제외했다.

## ③ dividendStockKnd 분포

```
'보통주'                15,484
'-'                       9,388
'보통주식'                  489
그 외(의결권있는주식·중간배당 등 소수)   170건 미만씩
```

**우려했던 우선주 혼입은 거의 없다** — `'우선주'`는 전체 25,531건 중 3건뿐이다.
수집기의 "보통주만 고른다"는 필터가 실질적으로 잘 작동하고 있다.

`'-'`(9,388건) 중 7,925건은 무배당(dividendPerShare=0)과 자연스럽게 겹치지만,
**1,463건은 `dividendStockKnd='-'`인데 배당액은 0이 아니다** — 주식 종류가
기록 안 된 채 배당액만 있는 경우다. 오류라기보다 공시 양식상 종류 항목이
비어 있는 경우로 보이나, 소액 데이터 이상치로 남겨둔다(원인 미조사).

## ④ 회사별 지속성

```
한 번도 배당 안 함   1,365개사 (43.0%)
계속 배당             828개사 (26.1%)
혼합(여러 번 전환)     496개사 (15.6%)
중단                   244개사 ( 7.7%)
시작                   242개사 ( 7.6%)
전체                 3,175개사
```

**"혼합" 496개사가 중요하다** — 배당을 시작했다 멈췄다 여러 번 반복한 회사가
전체의 15.6%다. 주주환원 지표가 "지금 배당하는가"만 보면 이 회사들의 과거
이력(꾸준함 여부)이 사라진다. "중단"(244개사)과 "한 번도 안 함"(1,365개사)도
현재 시점 스냅샷으로는 구분이 안 된다 — 둘 다 "지금 무배당"으로 같게 보인다.

## ⑤ 적자와의 관계 — 부분적으로 중복, 부분적으로 독립

```
적자(eps<0)   8,036건 중 무배당 6,810건 (84.7%)
흑자(eps≥0)  15,694건 중 무배당 5,044건 (32.1%)
```

적자 기업의 85%가 무배당인 건 자연스럽다. **다만 흑자 기업의 32%도 무배당이다**
— 적자 여부만으로 이 지표를 예측할 수 없다는 뜻이고, 주주환원 지표가 수익성
지표(fundamental 축의 다른 항목)와 완전히 중복되지는 않는다는 근거가 된다.

## 확인 / 추정 / 미확인

```

        (rawJSONL 직접 집계, A3와 corp 단위 조인)
확인    5개 업종이 표본 전체 무배당(변별력 없음)
확인    우선주 혼입은 무시할 수준(3/25,531)
추정    연도별 상승 추세 중 표본 구성 변화가 차지하는 비중 — 코호트 비교로
        대략적 크기는 쟀으나 정확한 분해(구성효과 vs 행동효과)는 안 함
미확인  dividendStockKnd='-' 인데 배당액이 0이 아닌 1,463건의 원인
미확인  sicCode 숫자 코드가 실제로 어떤 업종명인지(코드표 대조 안 함)
```
