## 013이 2015~2017에 몰리는 이유

```
2015  OK 1,941 · 013   697 · EARLY_STOP     0
2016  OK 2,006 · 013   659 · EARLY_STOP     0
2017  OK 2,076 · 013   670 · EARLY_STOP     0
2018  OK 2,149 · 013    74 · EARLY_STOP   623
2019  OK 2,198 · 013    78 · EARLY_STOP   641
...
2025  OK 2,727 · 013    20 · EARLY_STOP   754
```

**공시 제도 변화가 아니라 스캔 순서의 기계적 결과다.** 조기 종료 규칙이 "연속
3년 013이면 중단"이고 스캔이 2015년부터 오래된 순으로 진행되므로, **013을
관측할 수 있는 창 자체가 2015~2017(첫 3년) 뿐이다** — 그 뒤로는 이미 중단됐거나
데이터가 있어서(OK) 013을 볼 기회 자체가 구조적으로 없다. 2018년부터 013이 급감하고
EARLY_STOP이 그 자리를 채우는 게 그 증거다.
