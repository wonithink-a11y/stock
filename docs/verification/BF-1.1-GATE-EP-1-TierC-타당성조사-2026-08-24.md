# GATE-EP-1 Tier C 타당성 조사 (2026-08-24)

## 결론부터

**Tier C를 만들지 않는다.** 975건(UNKNOWN)의 구성을 이미 커밋된 데이터만으로
분해한 결과, Tier C가 아무리 잘 만들어져도 GATE-EP-1(5% 임계, 전체 1223건
기준)을 통과시킬 수 없다는 게 산수로 확정된다 — 추가 DART 호출 없이도
답이 나온다.

## 975건의 구성 (이미 커밋된 A1b·A2b·EO 산출물만으로 재구성, 신규 조회 0건)

```
A1b DELISTED 전체                                    1,223
├─ exitAtConfirmed 있음(Group A, 가격 흔적 O)           508
│   ├─ EO Tier A+B로 분류됨                             248  (커버리지 통과)
│   └─ 분류 실패(UNKNOWN 유지)                           260
│       ├─ noSignal(5개 카테고리 어디에도 안 걸림)         204
│       └─ ambiguousAuditCapital(의견부적정+자본잠식 동시)   56
├─ 품질 게이트 제외(raw는 있었으나 필터링됨)                122
│   (UNADJUSTED_CORPORATE_ACTION 107 · TRANSIENT_PRICE_SPIKE 15)
└─ 가격 흔적 자체가 없음(exitAtConfirmed 원리적으로 불가)     593
    ├─ dartModifyDate≈2017 배치값 몰림(선행 세션이 이미 확인)  474 (80.0%)
    │   → 수집 캘린더(2014-01) 이전 폐지로 추정, 오래됨
    └─ dartModifyDate 2018~2026(상대적으로 최근인데도 가격 0)  119 (20.0%)
        → 상장 직후 즉시 폐지·이례적 기업행위 등 추정, 원인 미확인
```

508+122+593 = 1223, 260+122+593 = 975(UNKNOWN 전건) — 정확히 일치.

## 산수: Tier C가 최선을 다해도 임계를 못 넘는다

GATE-EP-1 임계는 **UNKNOWN ≤ 전체의 5% = 61건**이다(1223×0.05=61.15).
현재 UNKNOWN 975건 중 914건(93.7%)을 추가로 분류해야 통과한다 — 즉 **전체
1223건의 95.0%를 분류해야 한다.** 지금까지 실제로 도달한 커버리지는
248/1223 = 20.3%다.

Tier C가 도달 가능한 최대 인구(reachable population)는 두 갈래뿐이다:

1. **260(Group A 미분류)** — exitAtConfirmed는 있으니 DART 조회 자체는
   가능하다. 다만 Tier B가 이미 같은 종목에 같은 카테고리로 한 번 조회해서
   실패한 것들이다 — 창을 넓히거나(365일→730일, 이미 후속1이 "근거가
   오히려 약해진다"고 판단한 바 있다) 본문(document.json)까지 읽어야
   ambiguous 56건 정도는 더 갈릴 수 있다. **낙관적 상한 260건.**
2. **122(품질 게이트 제외)** — anchor 자체(exitAtConfirmed)가 없어서
   Tier A/B를 못 붙인다. anchor를 복구하려면 A2b 수집을 완화된 게이트로
   재실행해야 한다(신규 데이터 재수집, 이 프로젝트의 "raw 행 자체가
   로컬에 없다" 문제). **낙관적 상한 122건.**
3. **593(가격 흔적 없음) 중 119(최근 dartModifyDate)** — anchor는 없지만
   비교적 최근이라 DART가 그 시절 공시를 갖고 있을 가능성은 있다. 다만
   이건 "가능성"이지 실측이 아니다. **낙관적 상한 119건(미검증).**
4. **593 중 474(2017 배치값 몰림)** — 캘린더 시작(2014-01) 이전 폐지로
   추정된다는 게 선행 세션(2026-08-24 후속3)의 이미 확정된 결론이다.
   DART API 자체도 오래된 공시는 보관 범위 밖일 가능성이 높고, 설사
   있어도 anchor 없이 검색 창을 잡을 방법이 없다(전체 역사를 훑어야
   하는데 그러면 오탐률이 급증한다 — 결정된 사건만 anchor로 쓴다는
   이 프로젝트의 원칙과 충돌). **사실상 도달 불가능.**

**1+2+3을 전부 낙관적으로 100% 성공한다고 가정해도**(260+122+119=501건
추가 분류, 현실적으로는 절대 100%가 안 나온다 — Tier B 자체가 같은 유형
329건 중 69건, 21.0%만 분류했다) 총 분류 749/1223(61.2%), **UNKNOWN은
여전히 474/1223 = 38.8%** — 임계 5%의 7.8배다. 4번(474건)을 건드리지
않는 한 GATE-EP-1은 원리적으로 못 넘는다. 그런데 4번은 이 프로젝트가
가진 어떤 방법론으로도 접근 경로가 없다(anchor 없음·DART 보관범위
불확실·이미 재정의 시도도 survivorship bias 위험으로 기각됨, 2026-08-24
후속3).

## 권고

**Tier C는 만들지 않는다.** 260건·122건 각각을 붙잡고 정교화해도 GATE-EP-1
통과에는 산수로 기여할 수 없다(위 계산) — 만들면 "죽은 코드"가 아니라
"통과에 기여 못 하는 코드"가 된다. exitReasonCoverage 리포트의 소수점을
조금 더 채우는 것 이상의 가치가 없다.

A6 Primary는 **이 EP-1.0/GATE-EP-1 프레임워크 위에서는 무기한 HOLD로
남는다** — 이것도 정직한 결론이다(GATE 자체가 "사유 미상 상태에서 결론을
내지 않는다"는 게 원래 목적이었다). exitPrice(정리매매가·공개매수가)
수집도 지금 시작할 이유가 없다(HOLD 상태에서는 어차피 Primary를 못 낸다).

열려 있는 갈래는 하나뿐이다 — **474건(pre-2014 추정 폐지)에 대해 DART가
아닌 다른 원천(KRX 자체 상장폐지 공고 아카이브 등)이 존재하는지**를 아주
좁게 정찰하는 것. 이것도 "Tier C를 만든다"가 아니라 "그런 원천이 존재
자체 하는지"를 묻는 훨씬 앞 단계의 질문이고, 존재해도 신규 데이터 소스
통합이라 별도 🔴 결정이다. 지금 당장 착수할 필요는 없다고 본다 — 지난
세션들이 이미 이 트랙에 상당한 시간을 썼고, Strategy Lab(PBR 등)이나
BF-1.1 10년 백필처럼 GATE와 무관하게 진행 가능한 다른 트랙이 있다.
