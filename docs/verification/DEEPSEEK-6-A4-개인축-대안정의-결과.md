```
과제   docs/control/handoff/DEEPSEEK-6-A4-개인축-대안정의-완전공선성.md
실행   DeepSeek (읽기 전용 — 임시 스크립트·산출물은 저장소 밖(%TEMP%\opencode\)에만
       뒀다. 저장소에 쓰기 0건)
배경   DEEPSEEK-2(docs/verification/DEEPSEEK-2-A4-marginal-IC-결과.md)가 확정한
       "개인축(절대금액) = 외국인+기관의 완전한 선형결합(항등식)"의 미확인 항목 —
       비율/부호로 바꾸면 이 공선성이 깨지는지
```

## 결론 한 줄

**비율로 바꾸면 안 깨진다(rank=2 유지) — 방향(sign)으로 바꾸면 깨진다(rank=3).**
단 sign은 새 독립 정보가 아니라 외국인+기관 합의 **비선형(방향) 성분**을 선형
모델이 잡게 된 것이다.

## 정의·방법

```
비율   indiv_ratio_20d = indiv_nb_20d / (buy+sell 거래대금 20일 누적)
       = indiv_nb_20d / (2 × rolling20(total_amount))  — 외국인·기관도 동일 공식,
       세 축이 공통 분모를 공유
부호   indiv_sign_20d = sign(indiv_nb_20d) ∈ {-1, 0, +1}
marginal IC   DEEPSEEK-2와 동일한 Fama-MacBeth 일별 cross-sectional OLS
```

## 수치 (5,348,454행, 2,558종목, 2,595일)

| 정의 | 풀링 rank(상관행렬) | 일별 rank(전 2,595일) | 공선성 |
|---|---|---|---|
| amount(원본) | 2 (고유값 0, 0.933, 2.067) | 전부 2 | 유지 |
| ratio | 2 (고유값 0, 1.177, 1.823) | 전부 2 | **안 깨짐** |
| sign | 3 (고유값 0.299, 1.055, 1.646) | 전부 3 | **깨짐** |

**비율이 안 깨지는 이유(수식+실측)**: 공통 분모 D로 나누면
`F_r+I_r+V_r = (F+I+V)/D = 0/D = 0` — 실측 `max|F_r+I_r+V_r| = 5.6e-17`(부동소수점
0). 동일 스칼라 나눗셈은 선형의존성(항등식)을 그대로 보존한다. DEEPSEEK-2가
추정으로 남겼던 "분모가 같으면 항등식이 남는다"가 이번에 확인으로 승격됐다.
sign은 비선형·비단사 변환이라 항등식이 전이되지 않는다.

**d120 개인축 marginal이 원본에서는 유의하지 않았는데(t=0.94) sign 정의에서는
유의해진다(t=10.98).**

## 해석 경계 — 중요

`sign(indiv) = -sign(foreign+inst)`이므로 정보론적으로 진짜 "새 정보원"은 아니다.
외국인·기관 두 축에 이미 있던 신호의 **비선형(방향) 성분**을 선형 marginal-IC
모델이 이제 감지할 수 있게 된 것뿐이다 — 공선성(식별 가능 여부)은 깨졌지만 독립
정보가 원천적으로 생긴 건 아니다.

## KR-2.3 반영 판단

KR-2.3(supplyDemand 축 재정의) 설계안은 현재 보류 상태다(Codex slot-marginal
발견 때문). 이번 결과는 그 보류를 풀지 않는다 — 오히려 "개인축을 4번째 지표로
추가"하는 안이 여전히 취약하다는 걸 다른 각도(정의를 바꿔도 진짜 새 정보는 아님)
에서 재확인한다. 다만 "방향성(sign) 정보를 기존 supplyDemand 슬롯 정의에
비선형 항으로 반영할 수 있는가"는 KR-2.3 재설계 시 참고할 만한 새 아이디어다 —
채택 여부는 별도 판단.
