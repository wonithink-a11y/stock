## 재현 여부: 일치 (+ 구조적 원인 규명)

세 결과(marginal IC·개인축 상관관계·개인축 규모별 IC) 전부 독립 구현으로 정확히
재현됐다. 그 위에 DeepSeek가 **"왜 d120에서 개인축 marginal 기여가 사라지는가"의
구조적 원인**을 추가로 찾아냈다 — Claude의 원 과제 지시에는 없던 발견이다.

## 핵심 발견 — 개인축은 독립 정보가 아니라 항등식이다

```
foreign_nb_20d + inst_nb_20d + indiv_nb_20d = 0   (5,348,454행 전부, max abs = 0.0)
```

**Claude가 직접 대조 검증함** — `research/strategy-lab/build_a4_research_dataset.py:35-37`:
```python
INSTITUTION_CATEGORIES = ["금융투자","보험","투신","사모","은행","기타금융","연기금","기타법인"]  # 8개
FOREIGN_CATEGORIES = ["외국인", "기타외국인"]                                                    # 2개
ALL_CATEGORIES = INSTITUTION_CATEGORIES + ["개인"] + FOREIGN_CATEGORIES                          # 11개
```
A4 원자료의 투자자구분 12개(전체 포함) 중 "전체"를 뺀 11개 전부가 정확히
외국인(2)+기관(8)+개인(1)으로 빠짐없이 나뉜다. 여기에 시장청산 항등식(전체
매수=전체 매도, A4 finalize `_diagnostics.json`에서 0 위반 확인된 사실)을 더하면:

```
Σ(11개 카테고리 net-buy) = 전체매수 - 전체매도 = 0
→ foreign_net + inst_net + indiv_net = 0  (우연이 아니라 구조적으로 필연)
```

**결론**: 개인축은 외국인·기관 축의 완전한 선형결합(음)이다. "4번째 supplyDemand
지표로 추가"는 정의상 불가능한 요청이었다 — 데이터가 부족해서가 아니라, 이미
있는 두 축의 정보를 이름만 바꿔 다시 넣는 것이기 때문이다.

## 방법론 코멘트 (DeepSeek 추가 검증)

- raw/z-score 회귀는 완전공선성(raw 공간 rank(X)=2)이라 식별 불가 — 순위 변환만이
  유일하게 작동하는 접근이었다(원본의 선택이 사후에 정당화됨)
- 순위 공간 VIF 2.1~3.1(낮음) — "상관 -0.5대가 다중공선성을 만드는가"라는 우려는
  순위 변환 후엔 성립하지 않는다. 진짜 문제는 높은 상관이 아니라 완전공선성 자체
- FWL 부분상관(독립 방법)으로도 d120 ≈ 0 재확인(-0.00085, t=-1.71, 유의하지 않음)
- d20/d60의 양(+) marginal은 순위 변환의 비선형성이 만드는 잔여 성분으로 추정 —
  직접 증명은 아님(미확인으로 남김)
