## ★ OpenCode 원본 결과의 오류 — 정정 기록

CLAUDE.md 원칙("OpenCode 결과는 관점 하나다, Claude 의 판단과 동일시하지
않는다")대로 검증한 결과 **두 가지가 틀렸다.**

**① 요청한 분류 축을 안 썼다.** A(수정됨)/B(A·B비교)/C(절대수치 인용)로
나누라고 했는데 *적립 단위*(건별/월별/일별)로 나눴다. 그건 결함의 심각도와
무관한 축이다. 다만 말미에 파일 자기주석 기준 3묶음을 덧붙여 그건 쓸 수 있었다.

**② "마커 없음" 6건 판정이 6건 모두 틀렸다.**

```
OpenCode:  "마커 없음(참고·대조용, resultTable 미사용)"
           pbr_oos_pooled_2023_2026_vs_ew · run_dd252_v1 · run_foreign_flow5d_v1
           run_lowmom60_v1 · run_pbr_value_v1 · run_pbr_value_v1_oos

실측:      6개 전부 MTM import O · deprecated 마커 O · resultTable = MTM
           → "마커 없음"이 아니라 "이미 수정됨"이다
```

이 오판을 그대로 받았으면 **이미 고쳐진 6개를 다시 고치는 작업**을 했을 것이다.
