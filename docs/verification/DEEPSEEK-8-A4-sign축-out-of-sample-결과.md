# DEEPSEEK-8 — 개인축 sign 정의의 out-of-sample 예측력 (결과)

```
과제   docs/control/handoff/DEEPSEEK-8-A4-sign축-out-of-sample.md
실행   DeepSeek (읽기 전용 — 스크립트·산출물 %TEMP%\opencode\에만. 저장소 쓰기 0건)
배경   DEEPSEEK-6(docs/verification/DEEPSEEK-6-A4-개인축-대안정의-결과.md)이
       indiv_sign_20d(방향 정의)로 개인축 완전공선성을 깨면 d120 marginal IC가
       유의(+0.015, t=11)해진다고 확인했다. 단 sign(indiv)=-sign(foreign+inst)라
       "새 정보원이 아니라 외국인+기관 합의 비선형 성분"이라는 해석을 달았다 —
       이 해석이 out-of-sample(미래 구간)에서도 버티는지 확인
```

## 결론 한 줄

**버틴다 — 단 "B≈A"가 아니라 "B(sign 포함 3축)는 A(2축) 대비 일관된 이득이
없다"는 방향으로.** d120(DEEPSEEK-6에서 in-sample 유의가 가장 강했던 구간)에서
오히려 OOS 성능이 **유의하게 악화**된다 — 전형적 과최적합 지문이다.

## 방법

```
분할   날짜 기준. train = 2016-01-04~2022-12-29(1,721일·3,285,103행)
       test = 2023-01-02~2026-08-03(874일·2,063,351행, 완전 미래 구간)
방법   DEEPSEEK-2/6과 동일한 Fama-MacBeth(일별 cross-sectional OLS, 순위 정규화).
       train 계수 평균을 train에서만 산출해 test에 그대로 적용 — ML 아님
모델   A(2축) = foreign_nb_20d + inst_nb_20d
       B(3축) = A + indiv_sign_20d
```

## 수치

| horizon | A test-IC(t_NW) | B test-IC(t_NW) | B−A | 판정 |
|---|---|---|---|---|
| d20 | −0.01148 (−3.25) | +0.00034 (0.13) | +0.01182(t=3.99) | B 유의 우위 — 그러나 §해석 참고 |
| d60 | +0.01106 (3.41) | +0.01209 (6.64) | +0.00104 | 유의차 없음 |
| d120 | +0.03476 (8.46) | +0.02873 (11.38) | **−0.00603(t=−2.27)** | **B 유의 열위** |

| 모델 | in-sample 모델IC | test-IC | 비고 |
|---|---|---|---|
| A d120 | +0.02213 | +0.03476 | test가 오히려 높음(과최적합 아님) |
| B d120 | +0.02419 | +0.02873 | **in-sample 우위가 test에서 거의 소멸** |

## 해석

- **d20의 "B 우위"는 새 정보가 아니라 상쇄 효과다.** A의 d20 test 신호가
  2023~2026에서 부호 반전(−0.0115)됐는데, sign축이 `≈ -sign(foreign+inst)`라
  train에서 학습한 양(+) 계수가 이 잘못된 노출을 부분 상쇄해 B의 IC를
  "-에서 0"으로 만든 것뿐 — B 자체에 예측력이 생긴 게 아니다.
- **d120에서 B가 유의하게 악화된 것이 DEEPSEEK-6 해석과 정확히 정합적이다** —
  기존 두 축의 비선형 함수를 억지로 독립 축처럼 넣으면, 표본 밖에서는 계수
  재분배가 잡음에 반응해 오히려 손해를 준다.
- B가 확실히 더 나은 구간은 하나도 없다.

## KR-2.3 반영 판단

DEEPSEEK-6이 열어둔 "sign 정의를 KR-2.3 재설계에 쓸 수 있는가"라는 질문에
**부정적 답**이 나왔다 — in-sample 유의성은 out-of-sample 예측력으로 이어지지
않는다. KR-2.3 보류를 풀 근거가 되지 않는다(오히려 개인축 관련 어떤 재정의도
신중해야 한다는 쪽으로 무게가 실린다).

## 확인 / 추정 / 미확인

- **확인**: train/test 계수 적용 test-IC 3구간 전부 산출 · B의 in-sample 우위가
  OOS에서 소멸 · d120 유의 악화(t_NW −2.27) · d20에서 A 신호 부호 반전
- **추정**: d20 "개선"이 잘못된 신호의 상쇄 효과라는 해석 — 직접 인과 실험은
  아님
- **미확인**: sign축을 실전 슬롯으로 채택하는 안의 가치 — 이번 결과는 근거를
  주지 않음(채택하지 말라는 신호에 가까움)
