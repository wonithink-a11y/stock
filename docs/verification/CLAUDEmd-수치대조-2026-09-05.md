## ★ 확인된 불일치 1 — findings 문서 자기 내부의 본문·표 모순

`findings/pbr-dropout-maxexcl-t1t3-decomposition-2026-08.md`

표(라인 34~37):

```
| | baseline T1 | baseline T3 | 변형 T1 | 변형 T3 |
| maxexcl 승률 | 48.6% | 50.8% | 49.2% | 52.4% |
```

Claude 재계산:

```
T1  49.2 − 48.6 = +0.6%p     본문과 일치
T3  52.4 − 50.8 = +1.6%p     본문은 +1.9%p ← 어긋난다
```

본문(라인 49~50)은 `승률 개선(T1 +0.6%p, T3 +1.9%p, 둘 다 방향 일치)`이라고
쓴다. **표에서 나오는 값은 +1.6%p 다.** CLAUDE.md 는 본문을 정확히 복사했으므로
CLAUDE.md 의 잘못이 아니다 — 원문 자체가 자기 표와 어긋난다.

방향(승률 개선)과 결론(개선이 평균수익 상승이 아니라 승률에서 온다)은 안 바뀐다.
같은 문서의 `dropout 평균수익률` 은 재계산해도 본문과 정확히 맞는다
(T3 5.43→13.06 = +7.63%p · T1 3.09→6.92 = +3.83%p).

**권고**: 원문 본문의 `+1.9%p` 를 `+1.6%p` 로 정정하고, CLAUDE.md 인용도 같이
고친다. 판정 변경은 없다.
