## 한 줄 답

**원래 질문("업종별로 얼마나 섞였는가")보다 더 근본적인 문제를 찾았다.** 별도
기준(1,972건, 7.7%)의 압도적 다수가 실제 회계 기준 차이가 아니라 **FY2015
공시 양식의 라벨링 공백**으로 보인다. FY2015는 별도 99.7%인데 FY2017부터는
전체 기간·전 업종에서 별도가 **0건**이다 — 업종별 섞임 자체가 "작은 회사가
별도로 보고한다"는 원래 가설이 아니라 이 한 시점의 데이터 특성이었다.

## 재현 확인

```
전체(51% 시점, 핸드오프 기준)   14,578 / 연결 13,237 / 별도 1,341   ← 옛 수치, 안 맞춤
전체(100% 완료, 실측)           25,531 / 연결 23,559(92.3%) / 별도 1,972(7.7%)
```

옛 수치는 A3b 51% 시점 것이라 재현 목표로 삼지 않았다 — 100% 완료된 지금 수치로
새로 쟀다.

## ★ 핵심 발견 — 별도 라벨은 FY2015~2016 초입에 몰려 있고 FY2017부터는 전무하다

```
FY2015   전체 1,941   연결     6( 0.3%)   별도 1,935(99.7%)
FY2016   전체 2,006   연결 1,969(98.2%)   별도    37( 1.8%)
FY2017   전체 2,076   연결 2,076(100%)    별도     0( 0.0%)
FY2018~2025                               별도     0( 0.0%)  ← 전 연도 0건
```

**A3의 독립적인 `fsDiv`(연결/별도 실제 재무제표 기준)와 대조하면 이게 회계
기준 변화가 아니라는 게 드러난다.** `fsDiv`는 FY2015~2025 전 구간에서 CFS
75~85% 대로 일정하다(FY2015도 CFS 1,389/OFS 451 = 75.5%, 다른 해와 다르지
않다). **같은 해에 A3는 "대부분 연결"이라고 말하는데 A3b는 "거의 전부
별도"라고 말한다** — 두 소스가 같은 회사·같은 해를 가리키는데 정반대다.

### 원인 — 수집기 코드 확인 (고치지 않음, 사실 확인만)

`scripts/build-fundamentals-a3b.py`의 `pick_row()`가 `config/policies/
fundamentals.v1.json`의 `epsPreference` 3단계를 순서대로 찾는다:

```
1순위  "(연결)주당순이익"
2순위  "(별도)주당순이익"   ← 정책 자체에 "아직 관측되지 않았다"고 적혀 있음
3순위  "주당순이익"         (괄호 접두어 없는 바닥 라벨)
```

FY2015~2016 초 응답에서 다수 기업의 `se` 필드가 "(연결)"/"(별도)" 접두어
없이 그냥 "주당순이익"으로만 왔고, 그래서 3순위로 떨어졌다. `fsDiv`가 그 해도
정상적으로 CFS 우세를 보이므로, **회사들이 실제로 별도로 전환한 게 아니라
DART 쪽 공시 양식이 그 시점에 "(연결)" 접두어를 안 붙였을 가능성이 높다.**

FY2016의 잔여 37건도 같은 패턴(연도 전체가 아니라 그 회사의 FY2016 건만
"주당순이익"이고 FY2017부터는 전부 "(연결)주당순이익")이라 전환기가 회사마다
접수 시점 차이로 한 해 정도씩 걸쳐 있는 것으로 보인다.

**★ 이건 강한 정황 증거이지 확정이 아니다.** 원본 공시 텍스트를 직접 못
봤다 — DART 뷰어가 프레임 구조라 본문(재무제표 원문)까지 못 들어갔다. 대신
샘플 하나(00100601, rcpNo 20160330001333)의 문서 목록에 "연결감사보고서"가
첨부돼 있는 걸 확인했다 — 이 회사가 자회사 없는 소규모 회사라서 별도로만
보고했을 가능성은 낮다는 정황 근거다.

## ① 업종별 섞임 (전체 기간 기준 — 위 발견을 감안해서 읽을 것)

```
sicCode 매칭 안 되는 A3b 레코드   841건 (A3에 corp 자체가 없음 — 폐지 종목 등)
섞이는 업종(0<별도비율<1)         457 / 전체 561
```

이 숫자 자체는 크지만, **FY2016+만 다시 재면 26/557로 확 줄어든다** — 즉
"업종 안에서 연결·별도가 섞인다"는 현상의 대부분은 FY2015 라벨링 문제
때문이고, 실제 지속적인 회사 단위 별도 보고는 훨씬 드물다.

## ② 별도로 내려간 회사의 성격 — 원래 가설(작은 회사·지주회사)은 기각

핸드오프 문서의 가설("별도는 작은 회사이거나 자회사가 없는 회사일 것")은
FY2016+ 데이터로 보면 **성립하지 않는다.**

```
전체 기간(FY2015 포함) 별도 corp 1,971개 — 자본·매출 분위가 Q1~Q4에 고르게
  퍼져 있다(Q1 334 · Q2 407 · Q3 529 · Q4 557) — "작은 회사에 몰린다"는
  패턴이 아니다. FY2015 라벨링 문제가 회사 크기와 무관하게 전방위로
  발생했다는 뜻이다

FY2016+ 만 보면 별도 corp 37개뿐이고, 20개 샘플 전부 "그 해만 별도, 앞뒤
  연도는 연결"인 전환기 패턴이다 — 지속적으로 별도만 보고하는 회사(진짜
  자회사 없는 소규모 상장사)는 이 데이터에서 사실상 관측되지 않는다
```

## Claude 재검증 (2026-08-12) — ★ 인과 설명을 일부 수정한다


**원래 인과 설명("그 시점 공시 양식이 라벨을 안 줬다")이 이 데이터와 안 맞는다.**

— 만약 라벨이 **접수 시점의 양식**을 따랐다면, 2023년에 접수된 건은 FY2017+
레코드처럼 전부 "(연결)"이어야 한다(그쪽은 100%였다). 그런데 안 그렇다.

**더 맞는 설명으로 보이는 것**: 라벨은 접수 시점이 아니라 **그 공시가 다루는
사업연도(FY2015)** 에 매여 있다 — 정정 공시라도 원본 FY2015 disclosure의 항목
구성을 그대로 이어받는 것으로 보인다. 이건 "언젠가 자연히 없어질 과도기적
문제"가 아니라 **FY2015라는 사업연도 자체에 영구히 붙어 있는 특성**이라는 뜻이라,
원래 결론(FY2015 EPS 라벨 신뢰 못 함)은 그대로이거나 오히려 더 강해지지만
"왜 그런가"의 설명은 수정이 필요하다.

**이것도 정황 증거다** — 원본 공시 텍스트를 여전히 못 봐서 확정은 아니다.
