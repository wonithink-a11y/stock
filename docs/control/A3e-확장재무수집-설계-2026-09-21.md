# A3e — 확장 연간 재무 수집 설계 (2026-09-21)

사용자 승인(2026-09-21): "가격 밖 데이터" 라인에서 EV/EBITDA·FCF·품질 계열을 열기 위해 확장 재무를 수집한다.
**연구 전용 패널**이다(production A-series 가 아님). 정식화(정책·워크플로·manifest)는 채택이 결정된 뒤 — `build_quarterly_earnings_panel.py` 선례와 같은 원칙.

## 1. 왜 확장이 필요한가

A3 는 `fnlttSinglAcnt`(주요계정)에서 **7개 계정**(매출·순이익·자본·영업이익·유동자산·유동부채·부채총계)만 저장한다. 그래서:

| 하고 싶은 것 | 필요한 계정 | A3 |
|---|---|---|
| EV/EBITDA·EV/EBIT | 차입금, 현금, 영업이익, (감가상각비) | 차입금·현금·감가상각 없음 |
| FCF 수익률 | 영업활동현금흐름, 유형자산 취득 | 현금흐름표 자체가 없음 |
| 매출총이익/자산(gross profitability) | 매출총이익, 총자산 | 둘 다 없음 |
| 발생액(accruals) | 순이익, 영업활동현금흐름 | CFO 없음 |
| 레버리지·이자보상 | 차입금, 이자비용/금융비용 | 없음 |
| 자산성장(투자) | 총자산(연도별) | 총자산 없음 |

## 2. 프로브 실측 (2026-09-21, DART `fnlttSinglAcntAll`, 삼성전자·SK하이닉스 + 무작위 110개 법인 FY2023)

- 응답은 **전체 재무제표**(BS·IS/CIS·CF·SCE, 삼성전자 연결 176행)이고 **표준계정코드(`account_id`)** 가 붙어 있다. 연결(CFS)과 별도(OFS)가 따로 있다.
- 자료가 있는 101개 중 **연결 82 · 별도만 19**. 9개는 조회 자료 없음(013).
- **계정 커버리지(FY2023, 101개)**:

| 계정 | 커버리지 | 비고 |
|---|---|---|
| 매출액·영업이익·현금성자산·자산총계 | 100% | |
| 영업활동현금흐름 | 98% | |
| 이자비용/금융비용 | 99% | |
| 매출총이익 | 89% | 계정 미표시 기업 있음 |
| 차입금(단기·장기·사채) | 89% | 표준코드가 없는 행이 있어 **이름 매칭**이 필요 |
| 유형자산 취득(capex) | 81% | |
| **감가상각비(주요 재무제표 안)** | **27%** | 대부분 기업은 **주석에만** 있다 — 삼성전자 CF 는 조정항목을 합산 표기 |

- **결론 하나**: `EV/EBITDA` 는 감가상각비 커버리지가 27%라 **전면 적용이 안 된다.** 현실적인 대안은 EV/EBIT(영업이익 100%)·EV/FCF·EV/매출총이익이다. 감가상각비가 있는 27% 는 부분 표본 검증으로만 쓴다.
- 속도: 호출당 약 0.3~0.7초. 20 corp-year 를 6.5초(호출 23)에 받았다.

## 4. 분석 계획 (수집 뒤 — 각각 별도 사전등록)

1. **계정 매핑 감사**: 행 이름·표준코드별 분포로 차입금·감가상각·capex 정의를 결과 전에 고정(연결/별도 혼합 영향 포함).
2. **가치 계열**: EV/EBIT, EV/FCF, EV/매출총이익 — **PBR 로 잔차화한 뒤의 추가 정보**로 판정한다(EY 가 PBR 로 잔차화하면 알파가 1/3 로 줄었던 전례).
3. **품질 계열**: 매출총이익/자산(gross profitability), 발생액, 영업이익률 변화, 자산성장률, 레버리지. 가치와 독립인지가 관건.
4. 모든 결과는 가족 단위 난수 바닥선 + TRAIN/VALID/TEST + gross/손익분기/net 표준 열(CLAUDE.md 규칙).
5. 이후: 분기 확장(매출·영업이익 분기 시계열, Q4 파생) — 이 패널의 계정 커버리지를 확인한 뒤 결정.

## 5. 알려진 한계

- 연결/별도 혼합(약 80/20)과 회계기준 변화(IFRS 계정 코드가 연도별로 다를 수 있음)가 표본 이질성을 만든다 — `fsDiv` 와 계정코드 분포로 점검한다.
- A3 격자는 **생존 종목 + 상장폐지 종목(A1b)** 이며 DART 법인코드가 있는 범위다. 비결산월 법인·신규 상장은 일부 연도가 비어 있다(013).
- 감가상각비는 주석에만 있는 기업이 대부분이라 EBITDA 는 부분 커버리지다.
