## 1. 이전에 막혔을 가능성이 큰 것 — 올리지 않는다
종료 사유는 모른다. 후보(11-13 인수인계 §3): 외부 콘텐츠 대량 수집(네이버·야후·텔레그램·유튜브) · 인터넷에 열린 서버(law VM·nginx) · 결제 정보. 그래서:

| 올린다 | 안 올린다(PC·Workers·Actions 로) |
|---|---|
| autotrader 엔진(실매매 프로필 1개) | 분봉·호가 수집, 연구 데이터 |
| 하트비트 + 텔레그램 발송(알림 전송만) | 뉴스·유튜브·네이버·야후 수집 |
| 사설 접속(Tailscale) | nginx·duckdns·법령 MCP 등 **인터넷에 여는 것 전부** |
| | 모의 슬리브 다수, rv20·크립토 모의 |

- **인바운드 전부 닫기**(보안 목록에 인바운드 규칙 없음) — ssh 도 Tailscale 안에서만. 아웃바운드는 KIS·업비트·텔레그램·Tailscale·OS 패키지로 한정.
- 한 계정에 인스턴스 하나, 사양은 최소(아래 §2).

## 2. 사양과 유휴 회수 (공식 문서 확인 11-14)
- 무료 한도(문서): Micro(AMD) 1/8 OCPU·1GB 최대 2개 · A1(Arm) 월 1,500 OCPU시간·9,000 GB시간. 1 CPU·1GB 급이면 실매매 엔진엔 충분(이전 10GB 서버가 717MB 만 썼다). **자동매매 프로세스의 실제 메모리는 아직 안 쟀다** — 설치 전 PC 에서 RSS 측정.
- ★ **유휴 회수**: Always Free 인스턴스는 **7일 동안 CPU 95분위 20% 미만 · 네트워크 20% 미만 · (A1 만) 메모리 20% 미만** 이 모두 참이면 Oracle 이 회수할 수 있다. 실매매 서버는 원래 한가하므로 정확히 이 조건이다. **종량제(PAYG)로 올리면 면제되는지는 이 문서에 없다 — 미확인.** 인위적으로 부하를 만들지 않는다(우회로 읽힘).
- 대응: **회수·정지돼도 돈이 새지 않는 설계** — ① 실매매 한도를 아주 작게 ② 하트비트(아래 §3)로 멈춤을 즉시 알림 ③ 손절을 거래소 쪽 조건주문으로 둘 수 있는지 확인(미확인) ④ 회수 시 포기 기준(§5).

## 3. 데드맨 스위치(무료)
- 서버가 5~10분마다 Workers(`stock-alerts`, KV)에 하트비트를 보낸다. Workers cron 이 마지막 하트비트가 N분 넘게 없으면 텔레그램으로 "실매매 서버 멈춤" 알림. Workers 무료 한도 안(cron 5개 중 4개 사용 중 — 기존 cron 에 합친다).
- 서버 쪽은 `curl` 한 줄 타이머. 구현은 설치 단계에서(🟡).

## 4. 설치 순서 (Claude 가 돕는 부분)
1. **(사용자)** 아내 본인 폰·메일·카드로 가입, 홈 리전 선택(서울 우선), 인증코드·비밀번호는 본인이 입력. 가입이 막히면 **즉시 포기**.
2. **(사용자)** 인스턴스 1개 생성(A1 1 OCPU 또는 Micro), 보안 목록 인바운드 비움, ssh 공개키 등록(키는 새로 만든다 — 옛 `ssh-key-*.key` 재사용 금지).
3. **(Claude)** 서버에 접속해 패키지·Python·Tailscale 설치, 스왑 1~2GB, 저장소는 **읽기 전용 clone**(VM 에 GitHub 자격증명 넣지 않음 — AI 협업 규칙), `.env` 권한 600.
4. **(Claude)** 기존 유닛 재사용: `deploy/autotrader.service`·`.timer`, 하트비트 유닛 신규(🟡). `install-vm.sh`·`install-unit.sh` 는 옛 수집 VM 가정이 많아 **읽고 필요한 것만** 쓴다.
5. **모의(VTS) 프로필로 며칠 관찰** — 신호·계획·알림·하트비트 확인.
6. **(사용자)** 실전 KIS 앱키(주문 권한만·IP 제한)·업비트 키(자산·주문조회·주문하기만, **허용 IP = 새 서버 공인 IP**, 출금 권한 금지) 발급. 키는 서버 `.env` 에만, 저장소·대화에 안 붙임. 한도 아주 작게 → README §4 체크리스트 전부.
7. 이상 없으면 사용자가 실매매를 켠다.

## 5. 포기·중단 기준
- 가입 거절, 인스턴스 생성 불가, 경고·정지 메일, 회수 → **OCI 포기**하고 다른 업체를 월 정확한 금액으로 비교해 사용자 확인(규칙 9). 이때 계정 정리(결제수단 삭제 등)는 아내분 몫.
- 포기해도 PC·Workers·Actions 구성은 그대로 살아 있다.
