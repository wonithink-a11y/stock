매핑 = `research/strategy-lab/a3e_account_map.py`(`a3e-map-1.1`), 감사 = `audit_a3e_mapping.py`(재현: `python research/strategy-lab/audit_a3e_mapping.py`).

## 발견 → 동결한 결정

| 발견 | 결정 |
|---|---|
| **표준코드 접두어가 연도별로 다르다** — 2015~2018 `ifrs_`, 이후 `ifrs-full_`. 접두어를 무시하면 자산 커버리지가 69%로 보인다(실제 99.9%) | `norm_id` 로 정규화 |
| **손익계산서가 `CIS`/`IS` 둘로 갈린다**(IS 약 8%) | 두 sj 모두 허용, 한 레코드에서 첫 매치 사용. 같은 코드 중복 0건 |
| **CF 취득·감가상각은 유출이 양수**(99~100%) | FCF = CFO − capex_ppe(− capex_intang 는 별도 개념, 결측이면 0 취급 안 함) |
| **차입금은 표준코드가 `dart_` 확장으로 파편화** — 이름 매칭 필요 | BS 행 이름이 차입금·사채·전환사채·교환사채·신주인수권부사채, 제외어(할인·할증·조정·상환·상각·손실·이익·이자·평가·자본·배당·미지급·선급·리스). **리스부채 제외**(2019 IFRS16 공시 방식 변화로 연도 간 비교가 깨짐) |
| 같은 이름 행 중복 7.4% — 조사 결과 **대부분 정상**(단기·장기가 같은 '차입금' 라벨, 유동성 부분+순액) | 합산 유지. 이름 중복은 이중계상 지표로 부적합 |
| **`총액`·`유동성 대체 부분` 행**은 부호가 일정하지 않다(대체 행 697개 중 97개 음수) — 규칙으로 이중/과소계상을 못 가른다 | 추측하지 않고 `debt_ambiguous` 표시, **주 분석에서 제외**(1,087행, 4.4%) |
| 재무상태표에 차입 행이 없는 레코드 17.3% — 무차입인지 미보고인지 못 가린다 | `debt_zero_assumed` 표시 + `debt_eff=0`. **사전등록에서 '실제 잡힌 표본만'의 민감도 결과를 함께 내도록 의무화**(교훈57) |
| 현금은 `현금및현금성자산`만 — 단기금융상품 미포함 | 순차입금이 과대. 한계로 명시 |
| `finance_cost` 는 이자비용이 아니라 **금융원가**(외환손실 등 포함) | 이자보상 용도로 쓰지 않고 레버리지 보조로만 |
| debt>자산 68건(0.3%) 중 일부는 단위 이상 의심(015110 2015 등) | 삭제하지 않는다. 신호는 순위 기반이고 극단값은 백분위로 흡수 |
