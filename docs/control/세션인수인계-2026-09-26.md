## 4. 실수·함정

1. SEC `-r 0-400` 범위 요청이 무시돼 38MB 가 출력으로 쏟아졌다(컨텍스트엔 안 들어감). 큰 파일은 `-o` 로 받는다.
2. 사용자 이메일을 묻기 전에 sec.gov 헤더로 1회 보냈다 — 사후 고지, 사용자 승인 받음. 외부로 개인정보를 보낼 땐 먼저 묻는다.
3. 네이버 호출량을 160콜로 가정했다가 실측 900콜(관심종목 872) — 간격은 실측 후 정한다.
4. Python `open(..., 'w')` 기본은 Windows 에서 CRLF — 커밋 시 경고(내용은 LF 로 정규화됨). 편집 스크립트는 `newline=''`/`'\n'`.
5. 세션 알림을 피하려고 추적 백그라운드 작업을 `TaskStop` 후 `Start-Process` 분리 실행으로 바꿨다 — 캐시 기반이라 손실 없음(깨진 캐시 0 확인).
6. 위키 S&P500 페이지에 **편출 이력 표가 더는 없다**(표 2개뿐) — 편출 종목 이름은 Tiingo 메타에서 얻는다.
