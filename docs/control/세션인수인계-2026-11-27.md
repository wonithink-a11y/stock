## 2. 태블릿 복귀 후 할 일 (Termux)
1. `cd ~/stock && git pull`
2. `nohup bash autotrader/termux/run-loop.sh > /dev/null 2>&1 &` — `--execute` 없음(주문 없는 기본 모드)
3. `pgrep -af run-loop.sh` 로 확인 → 5분 안에 하트비트 재개(Claude 가 `/stops` 로 확인 가능)
4. `python -m autotrader --config autotrader/autotrader.local.json status` — 킬 ON 이면 `resume-all` 은 **사용자 몫**
5. **자동 시작(미설정)**: 저장소에 부팅 자동 시작 설정이 없다. Termux:Boot(무료, Termux 와 **같은 출처**에서 설치 — F-Droid/GitHub 와 구글 플레이는 서명이 다르다, 사용자가 어느 쪽인지 모름) 설치 → 한 번 실행 → 배터리 "제한 없음" → `~/.termux/boot/start-loop.sh` 생성(`termux-wake-lock` + `pgrep -f run-loop.sh || nohup bash $HOME/stock/autotrader/termux/run-loop.sh &`) → `chmod +x`. 재부팅 후 **잠금을 한 번 풀어야** 시작된다(안드로이드 제약).
