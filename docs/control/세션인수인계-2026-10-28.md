## 6. 함정

- **auto 모드 권한 검사가 외부 코드 `git clone`·`pip install` 실행을 두 번 거부했다.** 우회하지 않고 사용자에게 받게 했다 — 외부 저장소는 사용자가 직접 받는 흐름이 맞다. 이미 설치된 패키지(OpenCV, imageio-ffmpeg 0.6.0)는 `pip list` 로 먼저 확인.
- 영상 음성은 못 듣는다(음성→글자 도구 없음). 주장 검증은 화면 글자·저장소 코드로만 했다 — 음성에만 나온 주장은 미확인.
- `committed_clean` 패턴: 사전등록과 코드가 둘 다 커밋돼 있어야 결과 계산이 돈다. 코드를 고치면 다시 커밋해야 결과를 만들 수 있다.
- 벡터 구현을 스캐너 원본과 대조할 때 **유동성 바닥이 먼저 걸린다** — 대조용 합성 가격이 1,000원·거래대금 20억 바닥 아래로 내려가면 가짜 불일치가 난다(이번에 한 번 겪음, 가격을 1e6 에서 시작해 해결).
- 국내 일봉 시가→종가 gross 는 대조(전 종목 평균)조차 음수다 — "장중 롱은 손실"이라는 기존 기록과 같은 방향. 초과(대조 차)와 net(비용 후 절대)을 섞어 읽지 말 것.
