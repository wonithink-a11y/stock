## 2. 진행 중 만난 문제 (같은 길 다시 가지 않기)

- 부팅 직후 자동 업데이트가 apt 잠금을 잡는다 — `pgrep -a apt` 가 비면 부트스트랩 재실행.
- **전체 `git clone` 은 1GB VM 에서 15분+ 걸렸다**(이력이 크다). 얕은 복제도 약 1GB 내려받는다. `deploy/gcp-bootstrap.sh` 를 `--depth 1` 로 고쳐 push(a2981b4b).
- **`curl | bash` 안의 `sudo -u ubuntu … <<EOF` 가 멈췄다**(자식 프로세스 없이 sudo 만 남음). 스크립트를 쓰지 말고 **단계별로 직접 실행**하니 통과 — 스크립트의 그 구간은 안정적이지 않다(원인 미확정).
- `install-unit.sh` 는 이름에 `@` 가 있으면 거부, `collector-pull` 은 `@USER@` 치환이 필요 → 수동 설치(부트스트랩 끝 안내문에 명령 있음).
