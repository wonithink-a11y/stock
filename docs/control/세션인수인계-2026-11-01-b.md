## 3. 함정 (이 세션에서 새로 확인)

- **클라우드 세션은 ssh(22) 불가** — 443 만 나간다(github.com:22 도 막힘). VM 은 `research-data.py status` 로 읽고, 쓰기는 사용자 Cloud Shell/PC.
- **PowerShell 은 ssh '…' 안의 큰따옴표를 지운다** — 사용자에게 줄 VM 명령에 큰따옴표·heredoc 을 쓰지 않는다.
- **VM `~/minute-raw` 는 최근 42거래일만**(OCI 업로드 뒤 정리, 수집은 정상). 전 기간 분봉 연구는 캐시(cache-minute_raw, ~10-12) + VM `--events-out` 합치기.
- 네이버 차트 API 는 **ETF 분배금만 수정**·주식 현금배당 미수정. `fchart` 실시간 봉은 장 뒤 통합(NXT) 가격.
- `create_trigger` 로 만든 예약 작업은 저장소가 안 붙는다 → 지시문 0단계에서 clone(공개 저장소라 됨). push 는 12-02 첫 실행에서 처음 확인.
- squash 병합 뒤 같은 브랜치에서 계속 일하면 main 과 add/add 충돌이 난다 → `git merge origin/main` 후 `--ours`(브랜치가 상위 집합일 때만), force push 금지.
