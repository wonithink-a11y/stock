# KIS 종목투자의견(invest-opinion) 커버리지 프로브 — 2026-09-21

소스 조사(`애널리스트-추정치-소스조사-2026-09-21.md` §3)의 권고 실행. **읽기 전용 조회 145콜, 수익률 미계산.** 스크립트 `research/strategy-lab/probe_kis_invest_opinion_coverage.py`(시크릿 없음, 원행 JSON 은 `reports/` gitignore).

## 결론

**PBR 슬리브 보유 종목의 커버율은 9%(6/69)로, 사전에 고정한 접는 기준(50% 미만)을 크게 밑돈다. 이 경로(KIS 목표가를 추정치 리비전의 대리 지표로)는 접는다 — 옵션 D.**
유동 유니버스 표본도 40%뿐이고 중앙 증권사 수가 1곳이라 "컨센서스"라 부를 수 없다. 이 결과로 인수인계 ①(KIS 목표가 수집 설계)도 종결한다.

## 사전 고정한 기준 (결과 전)

- '커버됨' = 최근 12개월(2025-09-22~2026-09-21) 창에서 **의견 행 ≥ 1건 ∧ 서로 다른 증권사 ≥ 2곳**.
- PBR 슬리브 보유 종목의 '커버됨' 비율 **< 50% → 접는다**, ≥ 50% → 목표가 대리 지표 설계로.
- 응답 일자가 요청 창 밖이면 '창 위반'으로 기록(교훈 81).

## API 아티팩트가 아닌지 확인

최근 12개월에 0건이던 슬리브 종목 3개를 창 10년(2016~2026-09)으로 재조회했다:
- 000140: 4건(2곳, 2016-02~08) · 000540: 7건(1곳, 2018-03~2019-12) · 000670: 42건(5곳, 2016-01~2023-07).

즉 **소형 가치주는 커버리지가 있다가 사라지는 종목이 많다**(API 가 소형주를 못 주는 게 아니라 애널리스트가 쓰지 않는다). PBR 하위 종목을 담는 슬리브의 성격상 커버리지가 낮은 것은 구조적이다 — 저PBR 은 소외주와 겹친다.

## 해석과 한계

1. **결측이 편향이다.** 목표가·의견이 있는 종목은 대체로 대·중형이고 없는 종목은 소외 소형주다. 이 축을 쓰면 "커버리지 유무" 자체가 크기·소외 팩터가 된다 — 추정치 효과와 구분이 안 된다.
2. 슬리브에 붙일 오버레이·필터로는 **보유 종목의 91% 가 결측**이라 작동하지 않는다(결측을 0 으로 채우지 않는다 — 규칙 1·교훈 57).
3. 유동 유니버스 전체를 대상으로 한 **독립 팩터**(대·중형 한정 목표가 상향 등)는 이번 프로브의 질문이 아니다. 표본 40개·중앙 증권사 1곳이라 그 방향의 근거도 약하다. 필요하면 별도 사전등록이지만 **지금 착수를 권하지 않는다**(같은 종류의 가격 추종 지표이고, PIT 추정치가 없어 리비전 본래 신호가 아니다).
4. 창은 최근 12개월 하나다. 커버리지가 과거에 더 좋았는지(2016~2019)는 재지 않았다 — 2020 표본 30개에서 7% 라 개선 근거는 없었다.
5. 이 프로브는 KIS 회원사 의견만 본 것이다. FnGuide 컨센서스는 더 많은 기관을 모으지만 로컬 DB 로 쓸 수 없다(소스 조사 §1). DataGuide 답변은 별도(문의는 사용자 몫).

- 남은 항목: DataGuide 문의(사용자, 초안은 소스 조사 §4). 답변이 컨센서스 이력·PIT·로컬 저장 허용을 확인해 주면 그때 다시 연다.
