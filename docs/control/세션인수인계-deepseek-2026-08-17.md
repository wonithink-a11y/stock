## 3. survivorship 귀인 실험 — 설계 완료, 실행 대기

### 질문

"-9.81% CAGR / -75% MDD가 ① 전략 구조 문제인지, ② A1A_ONLY 표본(생존자만) 때문인지"
를 분리한다.

### 실측으로 확정된 사실 (이 세션, 새 발견)

```
A1b(상장폐지) 1,223종목 — 전부 exitAt=null, exitReason=UNKNOWN,
                dartModifyDate는 폐지일이 아님(DART 레코드 최종 수정일).
                → 폐지 시점을 데이터로 특정 불가, 실험에서 별도 처리 필요
A2a(가격) 2,559종목 = A1a 2,558 + A1b 1(043090) → 사실상 생존자 전용
A1a 2,578 중 A2a 누락 20종목 = price-quality-excluded 20종목과 정확히 일치
                (UNADJUSTED_CORPORATE_ACTION 18 · TRANSIENT_PRICE_SPIKE 2)
post-fix 거래 심볼 864개 전부 A1a (A1b 0건)
A2b 정찰: 데이터 확보 631 / 분석구간(2016-01-01) 내 폐지 572
                → 병합 시 유니버스 약 +22% 증가 예상
```

### 결론 (방향성)

LONG_ONLY 전략에서 상장폐지(=성과부진) 종목 제외는 성과를 **부풀리는(낙관적)**
방향이다. 즉 "-9.81%가 표본 때문에 나빠 보인다"는 **방향상 기각** —
A1A_ONLY의 -9.81%는 전체 유니버스(폐지 포함) 결과의 **상한**일 가능성이 높다.
정량 확인은 A2b 완료 후 병합 실행으로만 가능하다.

### 실험 설계 (DESIGN.md)

- **고정**: 전략 파라미터·engine(c140c26+)·calendar·기간(2014-05-13~2026-08-03)·
  비용·portfolio·지표·A1a 가격은 A2a 유지
- **변경**: universeMode `A1A_ONLY` → `A1A_A1B_MERGED`, 가격 A2a+A2b, 폐지
  종목 거래 가능 구간 [firstTraded, exitAt]
- **판정**: ΔCAGR / ΔMDD / ΔtradeCount — MDD가 크게 개선되고 거래 수가 늘면
  survivorship 영향, 그렇지 않으면 구조 문제
- **사전 결정 4건**: ① exitAt 도달 시 청산·재진입 금지 ② exitAt 이후 신호 제외
  ③ stillTradingSuspect(최근까지 거래 지속)는 생존자로 취급
  ④ 043090(A1b 소속이나 A2a에 전체 가격 존재)은 A1b 처리하되 소스 우선 규칙 명시
- **실행 전 확인**: `config/policies/universe.v1.json` 확장(🔴, 병합 모드),
  runner.py의 `A1A_ONLY` assert 완화 — **모두 사용자 승인 대상**

상세: `research/strategy-lab/reports/2026-08-17-survivorship-attribution-design/DESIGN.md`
