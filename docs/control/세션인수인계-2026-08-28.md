### 확정된 정책 (다음 세션이 재현할 때 그대로 따를 것)

   넘으면 이상치로 제외 - A3 원본에서 실제로 물리적으로 불가능한 값

## 9. PER(저PER) 팩터 - 신규 착수, 1차 정찰만 (연구 계속 중)

### 배경

성장주 스크리닝 타당성 조사 중 "PER도 KRX API로 계산 가능하지 않냐"는
사용자 질문에서 시작. 확인 결과 **PER은 이미 2026-08-21에 production
연결까지 끝난 기능**(`lib/a5/resolver.js`, A2a가격+A3순이익+A3c
발행주식수) - 새 데이터 불필요. 사용자가 "완전히 별개 연구로" 진행
결정(PBR 연구선과 독립).

### 방법론

기존 PBR 연구(`a5_valuation_factor_precheck_v2_absolute.py`)와 완전히
같은 방법론 재사용 - 상대 tercile 대신 절대 유동성 임계값(turnover20≥
1억원), 저PER=밸류 오름차순 top30, 30bps 비용. 이미 계산된
`reports/2026-08-21-a5-valuation-precheck/valuation-panel.jsonl`
(pbr·**per**·epsGrowthRate·debtRatio 다 있음, 173,630행)를 그대로
재사용 - 새 계산 불필요.

### 결과 (1차 정찰, 결론 미확정)

- 저PER Top30, 필터없음: CAGR +5.11%, MDD -43.3%
- 고유동성 필터: CAGR +4.80%, MDD -42.6%
- 저유동성 대조군: CAGR +3.78%, MDD -37.0% (PBR과 달리 반전 없음 -
  고유동성이 저유동성보다 계속 낫다)
- **Decile IC(D1저PER-D10고PER): t=1.90** - PBR의 t=6.30보다 뚜렷이
  약함, 통상 유의성 기준(t≈2) 근처/미달

### 연도별 안정성 확인 (사용자 지시로 추가 진행)

11년 중 8년 양(+)·3년 음(-)(2017·2018·2020) - **PBR이 겪은 "2022년
한 해가 초과수익 98.6%" 같은 몰림 문제는 없음.** 특정 연도 착시가
아니라 **전 기간에 걸쳐 고르게 약한 신호**라는 게 확인됨. 개별 연도로
t≥2 넘긴 건 2022(t=2.22) 하나뿐 - PBR도 강했던 해(2022 금리인상기
가치주 강세, 매크로 레짐 연구가 이미 지목한 패턴)와 겹침.

### 상태

**결론 미확정 - 세션이 여기서 끝났다.** 다음 단계 후보(PBR이 거친
경로와 동일): decile 전체 스프레드 세분화 검증, T1/T3 유동성
분해(PBR에서 "대형주 반전" 문제가 있었으니 PER도 확인 필요), TRAIN/
TEST 분할. 아직 어느 것도 안 함 - 사용자 판단 대기.

## 10. Ollama 로컬 모델 연결 - 보류

사용자가 Claude Code 설정/플러그인 마켓에서 Ollama 관련 항목을 보고
문의. ChatGPT가 제안한 3단 구조(Claude Code=메인, Ollama=로컬 보조
worker, OpenCode=독립 검증자)를 검토했으나 **Claude가 핵심 결함을
지적**:

- Ollama를 MCP로 연결해도 **텍스트 생성기 하나가 추가될 뿐** - 파일
  읽기/셸 실행/반복 같은 에이전트 능력이 없다. "반복 코드·데이터
  전처리를 Ollama에 맡긴다"는 제안은 별도 에이전트 인프라를 새로
  만들어야 성립하는데, 그 비용이 컸다.
- "로컬이라 504 타임아웃을 피한다"는 것도 확정 아님(MCP 프로토콜
  자체 타임아웃 가능성 미검증).
- PC 사양(GPU/RAM) 확인 안 됨 - 모델 크기 추천이 전부 추측.
- 오늘 실제로 겪은 문제(OpenCode 504)는 이미 더 싼 방법(Claude 직접
  구현)으로 풀렸다 - Ollama가 필요했던 게 아니었음.

**결론: 지금 당장 설치 안 함.** 나중에 "로컬 프라이버시가 꼭 필요하다"
같은 구체적 이유가 생기면 재검토.
