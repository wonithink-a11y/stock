## 3. 이 세션에서 배운 함정

1. **로컬 상태 파일을 정본으로 읽지 않는다.** `data/paper/*.json`은 gitignore 대상이고
   실제 운용 상태는 VM에 있다. 로컬만 보고 "아직 한 주도 안 샀다"고 말했다가 VM에서
   18건 OPEN을 확인하고 정정했다 — 결론이 "빼면 끝"에서 "청산 계획이 필요"로 바뀌었다.
2. **정책 파일이 자기 상태를 잘못 적고 있을 수 있다.** PF-1.1이 "아무 코드도 이 파일을
   읽지 않는다"고 선언했는데 grep 한 번에 소비자가 나왔다. 정책의 자기 서술도 검증 대상이다.
3. **"발효"가 무엇을 바꾸는지 먼저 센다.** 등록해도 화면에 아무것도 안 나타나는 상태였고,
   registry 네임스페이스 의미도 "배선 안 된 스크립트 하나"뿐이라 빈약했다. 순서를 뒤집어
   소비 경로부터 살리니 네임스페이스의 뜻도 같이 정해진다.
4. **버전을 문장에 하드코딩하면 버전을 올리는 순간 본문이 낡는다.** `provisionalNote`가
   PF-1.2 산출물에서 "PF-1.1 은…"이라고 말했다 — 화면 제목과 나란히 떠서 바로 보였다.
   정책이 스스로 말하는 값을 읽게 한다.
5. **표본이 0건인 경로는 합성으로 밟는다.** `sectorCaution`이 오늘 0건이라 내가 고친
   가드 분기가 실행되지 않았다. 합성 데이터를 넣어 한 번 밟고 확인했다.
6. **게이트를 만들 때 적용 범위를 같이 적는다.** `allocation.gate`에 범위가 없어 모의
   관측 슬리브까지 걸렸고, 그대로 발효하면 자기 정책 위반 상태가 됐다.
