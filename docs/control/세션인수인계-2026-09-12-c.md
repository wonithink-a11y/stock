## 2. 리버스모드 해석 민감도 (④, `infinite-buying-reverse-mode-sensitivity-2026-09-12.md`)

`bottomup32/infinite-buying-bot`(원저작 파생 스펙, GitHub raw 로 직접 열람)의 §14가
"언이 계산기 변형판이 라오어 순정과 다른 지점"으로 명시한 것 중 리버스 관련 둘:

```
리버스 기준선 = 5일평균(sma5)                    (순정은 별지점 — 평단 기반)
리버스 T 갱신식(매수 +=(N-T)*0.25, 매도 ×(1-2/N))   (순정은 T 동결 가능성)
```

**현재 엔진은 "변형판" 쪽(5일평균 + T계속갱신)을 구현하고 있다.** 대안 해석
(별지점 + T동결, 후보B)으로 2022위기를 다시 돌리면 TQQQ -25%→-61%, SOXL
-41%→-54% 로 절대치가 크게 흔들리지만, **"V4.0이 2022에 취약하다"는 방향
자체는 안 바뀐다.** 원저작물 대조가 없어(로컬 규칙 스펙 §1) 어느 쪽이 맞는지는
성과로 안 정한다 — 후보A(현재 구현)가 나은 성과를 냈다고 그게 순정이라는
근거로 삼지 않는다. `infinite_buying_reverse_sensitivity.py` 에 후보B 를
"해석 민감도 기준선"으로 보관, selftest 7/7(원본 엔진과 회귀 대조 포함).

**★ 이후 모든 V4.0 수치는 이 조건부(후보A 전제)를 달고 다닌다.**

## 3. Crisis Path Decomposition — window 절단이 만든 착시 (⑤)

`infinite_buying_engine.py`의 `backtest()`에 `trace` 파라미터 추가(daybook 경유,
기본 None 이면 기존 동작 완전 동일 — CAGR/MDD 안 바뀜을 직접 확인). 2022위기를
날짜별로 재생한 1차 결론("TQQQ 후반전이 window 끝까지 이어져 회복할 시간이
없었다")은 **§5 (3B 재실행)에서 정정됐다** — 실제 episode 전체(2024-12-11 회복)로
보면 TQQQ 도 그 안에서 결국 회복한다. **관측 구간을 어디서 자르느냐가 결론을
바꾼다**는 게 이 세션 전체에서 반복 확인된 함정이었다(교훈으로 §7 참고).

검증 — 상관계수가 pooled·TQQQ·SOXL 전부 0 근처거나 가설과 반대 부호. 저/고
현금비중 그룹 비교도 지지 안 함. 사전고정 252거래일 보조분석도 같은 결론.**

판정: **NOT SUPPORTED.** 원 관찰 2건은 표본에서 가장 깊은 두 크래시(낙폭
82%·91%)였을 뿐 일반화되지 않는다. 극단크래시(낙폭70%+, 표본 n=3~4)에서만

맞는 자리를 찾는 사후탐색 함정을 피하려고 의도적으로 안 쫓았다).

이걸로 **하이브리드 v1 라인(파라미터 튜닝)을 종료**했다 — 3D·3E 로 새 가설을
계속 만들어 쫓지 않는다.
