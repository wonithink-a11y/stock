## 1. A5 파일럿 완전 검증 (설계안 §4~§5)

`docs/A5-파일럿-exit-overlay-설계안.md`가 고정한 검증 항목 전부 통과했다.

### 1.1 Claude 구현·실행

`scripts/build-a5-pilot.js` — 20종목×52주(1,040격자), resolve()+score()
(probe-v7-vertical-slice.js와 동일 호출)·priceSource.js(A2a 우선·A2b
폴백)·fwd/fwdStatus(FUTURE>EXIT>MISSING>HALTED>OK)를 그대로 잇는다. 결과

실측표와 **정확히 일치**.

실행 중 버그 2건 발견·수정(둘 다 이 세션에서 처음 발견):
1. `createWriteStream`+`process.exit()`가 버퍼 flush 전에 종료해 "기록했다"는
   진단과 달리 실제 파일이 비어 있었다 → `appendFileSync`(동기 쓰기)로 교체.
2. `noPriceAtAsOf` 스킵 분기가 상태 파일 쓰기를 건너뛰어 재개 시 마지막
   종목의 후행 스킵 구간이 "미완료"로 재처리됐다(데이터 유실은 아님) →
   done.add+상태쓰기를 분기 공통 경로로 통합.

selftest는 `scripts/test-a5-pilot.js`로 분리(회귀 발견 관례 `scripts/test-*.js`).

### 2.2 로컬 검증 (모두 통과, 산출물은 되돌림)

`--universeLimit N`(전체 유니버스를 자르되 모든 샤드가 같은 축소
유니버스에 합의 — `--limit`과 다르다, 후자는 샤드 담당분만 자른다)로
20종목 전체를 4샤드로 나눠 진짜 accept 경로를 실제로 통과시켜 검증:
corpsIncomplete=0·manifest 작성 성공(accept), 부분 실행 시 게이트 발동
(reject), `SCORES_FAIL_INJECTION` 강제 실패(exit 2), `verify-diagnostics.js`가
smokeTest 플래그를 올바르게 거부(A2a/A3d와 동일 원칙) — 전부 확인.
기존 JS 회귀 전체(`scripts/test-*.js`) 재통과.

### 2.3 실제 트리거 — 1차 실패 → 원인 수정 → 재트리거 성공

**1차 트리거(run `32710516850`)**: 8샤드 수집 전부 성공, `--finalize`도
성공(1,254,759행 정상 계산) — 그런데 `verify-diagnostics.js` 단계에서
거부돼 manifest 작성·commit이 스킵됐다. **원인**: `verify-diagnostics.js`의
`forbidden` 체크가 `k in d`(키 존재 여부)로 판정하는데, 스크립트가
`smokeTest:false`를 **항상** 채워 넣어서 실제 본수집(smokeTest가 아닌)도
"플래그가 있다"고 오탐했다. A2a·A3d 등 기존 단계는 이미 "참일 때만
키를 넣는다"는 관례를 쓰고 있었는데 이 스크립트만 그 관례를 안 따랐다.

**수정**(커밋 `e0195c0`): `smokeTest`를 조건부 스프레드로 바꿔 참일 때만
키가 존재하도록 함. 로컬에서 스모크는 여전히 올바르게 거부되고, 실제
본수집 모양(키 없음)은 정상 통과함을 확인 후 push.

**2차 트리거(run `32711717340`)**: **완전 성공**. 8샤드 병렬 벽시계
약 4~5분(각 샤드 3분47초~4분15초) + finalize 1분9초. `data/backfill/scores/
{2016~2026}.jsonl.gz`(11개 연도) + `data/backfill/manifest/A5.json` 커밋
`8226a58`(GH Actions 자동 커밋).
