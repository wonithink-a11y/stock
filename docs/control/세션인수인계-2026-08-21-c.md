# 세션 인수인계 — 2026-08-21-c — 투자대가 방법론 타당성 조사, 유동성 프리미엄 메타패턴 확정으로 종결

이 문서는 정본이 아니다 — 정본은 GitHub `main`의 실제 파일이다. `세션인수인계-
2026-08-21-b.md`("다음 방향은 A5-3 밸류에이션(peg/pbr)을 Strategy Lab에
결합" — §3)의 다음 세션이다. GPT가 제안한 "검증된 투자대가 방법론(버핏·린치·
그린블라트·오닐)을 한국시장 데이터로 정량화 → precheck → 후보 선별" 방향을
그대로 착수했으나, 세 번째 팩터(ROE/Buffett Quality)까지 돌린 뒤 **팩터
자체가 아니라 이 백테스트 인프라의 유동성 tercile 버킷이 수익을 만들고
있었다는 걸 플라시보 테스트로 확정**하고 이 라인 전체를 종료했다.

## 새 세션은 여기부터

1. **결론: PBR·PEG·ROE 세 팩터(가치·성장·품질, 서로 다른 경제적 근거) 전부가
   "팩터 알파"가 아니라 "T1(저유동성 tercile) 버킷에 들어간 것 자체"였다.**
   무작위로 T1에서 30종목을 뽑아도(20회 평균) CAGR +10.26%가 나왔는데, 이건
   PEG로 고른 T1(+4.08%)이나 ROE로 고른 T1(+8.68%)보다 오히려 높다 — 팩터
   기반 선별이 무작위 선별보다 못했다(§3 참고).
2. **이 유동성 프리미엄은 이미 죽은 것으로 확인된 바 있다.** 2026-08-18
   REV20 검증(`research/strategy-lab/reports/2026-08-18-strategy-candidates/
   README.md` §11)이 비용·유동성·가격 필터를 동시에(현실적으로) 걸자 같은
   종류의 저유동성 알파가 완전히 손실로 뒤집힌다는 걸 이미 보였다. 오늘의
   메타패턴 확정은 이걸 "REV20만의 특이 현상"에서 "이 프로젝트의 모든 가격
   기반·팩터 기반 전략 탐색이 반복적으로 부딪히는 구조적 벽"으로 일반화했다.
3. **CAN SLIM(오닐, 4번째 방법론)은 시도하지 않았다** — 같은 벽에 부딪힐
   가능성이 매우 높다고 판단해 사용자 승인 하에 이 라인 전체를 종료했다
   (§2 타당성 조사에서 CAN SLIM은 C(분기 EPS 성장) 원천 데이터 자체가 없고
   L(상대강도) 코드도 없어 어차피 절반만 구현 가능하다는 게 이미 확인된
   상태였다).
4. **다음 세션이 고를 두 방향**(순위 없음, 둘 다 사용자 승인 필요):
   - **(A) T3(고유동성/대형주) 전용으로 전략 탐색 범위를 좁힌다.** 유동성
     프리미엄이 없는 구간에서 PBR·PEG·ROE 중 하나라도 진짜 의미 있는 차이를
     만드는지 더 정밀하게(더 큰 top N, 다른 리밸런싱 주기, 팩터 조합) 재검토.
     지금까지 T3 결과는 전부 마이너스였지만(PEG -2.02%, ROE -7.66%), top 30·
     단일 팩터·월별 리밸런싱이라는 좁은 설정에서만 봤다 — 설정을 넓히면
     달라질 수 있는지는 미확인.
   - **(B) 비용·집행 모델 자체를 재검토한다.** 30bps 왕복비용이 실제 저유동성
     종목 슬리피지를 과소평가하고 있을 가능성이 있다 — 이게 맞다면 지금까지
     "유동성 프리미엄"으로 부른 것 자체가 백테스트 아티팩트다. 현실적 비용
     모델을 먼저 정하고 그 아래서 모든 팩터를 다시 재는 게 순서상 맞을 수
     있다. 단, REV20이 이미 현실적 비용 하에서 이 알파가 죽는다는 걸 보였으므로
     (§2) 이 방향의 정보가치는 낮을 수 있다 — 우선순위는 사용자 판단.
5. `git log --oneline -20`·`git status --short`로 이 문서 이후 변경이 있었는지
   먼저 확인한다.

## 1. GPT 제안 — 투자대가 방법론 타당성 조사부터 시작

사용자가 GPT의 제안("버핏/린치/그린블라트/오닐 방법론을 한국시장 데이터로
정량화")을 전달, "타당성 조사후 실행하자"로 착수 승인. 토큰 절감을 위해
데이터 필드 매핑 조사는 Explore 서브에이전트 2개(Quality/Value 계열,
Technical/모멘텀 계열)에 병렬 위임.

### 타당성 조사 결과 요약

| 방법론 | 상태 | 핵심 이유 |
|---|---|---|
| Lynch GARP/PEG | ✅ 즉시 가능 | peg·epsGrowthRate·debtRatio 전부 `available:true`(2026-08-21 A5-3 D4), 패널 생성 스크립트 재사용 가능 |
| Buffett Quality | ✅ 즉시 가능 (FCF 없는 축소판) | roe·roeConsistency(min 5y)·debtRatio·operatingMarginTrend 전부 available. FCF는 A3가 현금흐름표를 안 모아 미구현 |
| CAN SLIM(O'Neil) | 🟡 절반만 가능 | S(거래량급증)·I(기관수급)·M(시장국면 proxy)·N(52주신고가)은 기존 코드 재사용 가능. **C(분기 EPS 성장)는 DART가 연간만 수집해 구조적으로 불가능**, **L(상대강도 지수화)은 코드 자체가 없음** |
| Greenblatt Magic Formula | ❌ 사실상 불가 | ROIC·EV/EBITDA·Earnings Yield 전부 미구현 — A3 스키마에 현금흐름표·EV 계산 원재료가 없음 |

## 2. Lynch GARP/PEG precheck

`scripts/build-a5-valuation-panel.js`(2026-08-21-b가 만든 pbr precheck 패널
빌더)를 확장 — `epsGrowthRate`·`debtRatio` 필드 추가(하위 호환, pbr precheck는
기존 필드만 읽음). mergerSpinoff 이력 종목 제외는 그대로 유지(D4 우회식이
같은 상류를 씀).

`research/strategy-lab/lynch_garp_factor_precheck.py` 신설 — peg =
per/epsGrowthRate(epsGrowthRate<=0이면 PEG 정의 불가로 제외, `lib/
scoringEngine.js:162-177` 운영 정의와 동일 조건). **구현 중 버그**: `df.set_
index([...])[["peg","debtRatio"]]`로 DataFrame을 만들면 `.get((ticker,date))`가
인덱스가 아니라 컬럼명을 찾아 전부 `None`이 되는 걸 발견(pbr precheck는
Series라 문제없었다) — `to_dict("index")`로 수정.

**결과** (2016-01~2026-08, 월별 리밸런싱, top 30, 30bps 왕복비용):

| 시나리오 | CAGR |
|---|---|
| 저PEG 매수, 필터 없음 | +2.77% |
| 고PEG 대조군 | -3.86% |
| 저PEG + 유동성 상위 tercile(대형주) | **-2.02%** |
| 저PEG + 유동성 하위 tercile(소형주) | +4.08% |
| 저PEG + 부채비율 중앙값 이하 품질필터 | +2.63%(필터 없음과 거의 동일) |
| 저PEG + 품질필터 + 대형주 | -0.04%(거의 0) |

PBR·REV20·LOWMOM60+수급에 이어 **네 번째로 같은 유동성 함정 재현**. 부채비율
품질 필터를 얹어도 대형주 구간에서 살아나지 않았다.

## 3. Buffett Quality precheck — 메타패턴 발견

가격(밸류에이션) 축을 아예 안 보는 순수 품질 가설이라 다른 팩터와 경제적
근거가 완전히 다르다는 점에서 별도로 의미 있는 테스트였다.

`scripts/build-a5-quality-panel.js` 신설 — A3(fundamentals)만으로 나오는 축
(roe·roeConsistency=min(roeHistory5y)·debtRatio·operatingMarginTrend)이라
A3c/corporateActions(D4 파이프라인)를 안 거친다 — mergerSpinoff 제외 불필요,
전체 유니버스(2578종목) 사용.

`research/strategy-lab/buffett_quality_factor_precheck.py` 신설.

**결과**:

| 시나리오 | CAGR |
|---|---|
| 고ROE 매수, 필터 없음 | -0.64% |
| 저ROE 대조군 | -1.45%(고ROE와 거의 구별 안 됨) |
| 고ROE + 대형주(T3) | **-7.66%** |
| 고ROE + 소형주(T1) | **+8.68%** |
| 고ROE + eligibility(5년무적자·부채비율≤200%) | -1.42%(개선 없음) |
| 고ROE + eligibility + 대형주 | -4.39% |

고ROE와 저ROE가 거의 구별력이 없다(둘 다 마이너스, 차이 0.8%p) — ROE 자체의
설명력이 PBR/PEG보다도 약하고, 오직 소형주 구간에서만 강한 플러스가 나왔다.
**세 번째로 같은 패턴**(PBR·PEG·ROE 전부 "소형주에서만 플러스").

## 4. 메타패턴 확정 — 플라시보 테스트

사용자 승인 후 "이게 팩터 알파인지, 유동성 버킷 자체의 프리미엄인지"를
가르는 테스트를 설계·실행.

`research/strategy-lab/meta_pattern_liquidity_check.py` 신설 — 팩터 순위를
아예 안 쓰고 같은 유니버스(2578종목)·기간·turnover20 tercile 정의·30bps
비용·월별 리밸런싱으로 (a) T1/T3 버킷을 통째로 동일가중 매수하거나 (b) 버킷
안에서 무작위로 30종목을 뽑는(20개 시드 반복) 플라시보 백테스트.

**결과**:

| 시나리오 | CAGR |
|---|---|
| T1 버킷 전체, 동일가중(팩터 없음) | +11.97% |
| T3 버킷 전체, 동일가중(팩터 없음) | -5.74% |
| T1에서 무작위 30종목(20회 평균) | **+10.26%** (범위 +4.69%~+16.18%) |
| T3에서 무작위 30종목(20회 평균) | -6.86% (범위 -12.88%~-1.90%) |

**무작위로 뽑은 T1 30종목(+10.26%)이 PEG로 고른 T1(+4.08%)이나 ROE로 고른
T1(+8.68%)보다 높다.** 즉 팩터 기반 선별이 순수 무작위보다 나은 게 없었다
— 세 팩터가 측정한 건 팩터 알파가 아니라 T1 버킷 소속 여부 그 자체였다.

이 T1 프리미엄이 실제로 거래 가능한지는 §1 4번(A)(B)에 이미 정리한 대로
2026-08-18 REV20 검증이 부정적 근거를 이미 갖고 있다 — 현실적 비용 하에서
소멸을 확인한 바 있다.
