## 다섯 가지 공통 규칙

**① 분포를 내되 정책을 제안하지 않습니다.**
`"PBR weight 10~20%에서 차이가 작다"` 까지가 실험실의 산출입니다. 그것을 가중치 파일에
반영하는 것은 실험이 아니라 정책 변경이고, 사용자 승인 사안입니다.

**② 재현 확인을 먼저 통과하세요.**
각 인계서 끝에 **제가 이미 잰 숫자**가 있습니다. 그걸 먼저 재현하세요. 안 맞으면 로직이
다른 것이므로, 결과를 내기 전에 거기서 멈추면 시간을 아낍니다.

**③ 지금 데이터는 절반입니다.**
A3b는 3,801법인 중 1,944법인(51.1%)만 수집됐습니다. 모든 비율은 **하한**입니다.
`"조인율 X%"` 가 아니라 `"완료분 1,944법인 기준 X%"` 로 적어 주세요.

**④ 업종 코드는 시점 정보가 아닙니다.**
`sicCode`는 **현재 업종**이라 2015년 레코드에도 지금 업종이 붙어 있습니다. 업종별 집계를
낼 때 이 한계를 결과에 함께 적어 주세요. 업종이 바뀐 회사의 과거 집계는 그 시점 업종이
아닙니다.

**⑤ 확인한 것과 추정한 것을 갈라 적으세요.**

```
확인   epsSource 별도 비율 9.2% (14,578건 중 1,341건)
추정   d20 표본 30 돌파는 수일 내 (누적 속도 기준)
미확인 남은 1,857법인의 분포
```

이 프로젝트에서 2026-08-11 하루에 두 번, 확인하지 않은 것을 사실로 말해 잘못된 결론이
나왔습니다. 그래서 이 규칙이 생겼습니다.
