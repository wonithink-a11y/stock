> **이 과제는 재정의됐다.** `TASKS.md`의 원래 LAB-2는 "diagnostics 실패 원인 분류"였는데
> **재료가 없다** — 8샤드 전부 `rejected: {}` 이고 기각 0건이다. 재료가 있는 질문으로
> 바꾼다. 기각이 0이라는 사실 자체는 이미 확인됐으므로 다시 세지 않는다.

## 목적

**EPS 출처가 두 종류로 섞여 있다.**

```
(연결)주당순이익   13,237건   90.8%
주당순이익          1,341건    9.2%
                 ─────────
합계               14,578건   (완료분)
```

`perRelative`는 **업종 중앙값 대비 배율**이다(`A5-1.0` §3.3). 같은 업종 안에 연결 기준과
별도 기준 EPS가 섞이면 그 배율이 **회사 차이가 아니라 출처 차이를 잰다.** 지주회사처럼
연결과 별도의 순이익이 크게 다른 곳에서 특히 그렇다.

`perRelative`는 valuation 축에서 가중 0.30으로 가장 크고, valuation 축이 죽으면 그 종목의
basis가 바뀐다(SB-1.0). 그래서 이 혼재는 점수 하나가 아니라 **모집단**에 닿는다.

## 현재 상태

```
A3b collect  51.1% (1,944 / 3,801법인) · commit 02f183d
운영 수집기의 폴백  epsRow = bySe('(연결)주당순이익') || bySe('주당순이익')
                  → 연결이 없을 때만 별도로 내려간다 (A5-1.0 §1.1)
```

## 입력

```
data/backfill/fundamentals/_shards_a3b/shard-*.jsonl
  필드  corp · fiscalYear · eps · epsSource

업종 조인
data/backfill/fundamentals/a3/*.jsonl.gz
  필드  corp · fiscalYear · sicCode · equity · netIncome
```

## 기대 출력

```
1  업종(sicCode)별 · 연도별 epsSource 분포
2  한 업종 안에 두 출처가 섞이는 정도
   → 업종별로 "별도 비율"을 내고, 0 도 1 도 아닌 업종이 몇 개인가
3  별도로 내려간 1,341건이 특정 군에 쏠리는가   금융업 · 지주회사 · 소규모 법인
4  같은 법인이 연도에 따라 출처가 바뀌는 경우가 있는가
   → 있으면 그 법인의 EPS 시계열은 중간에 기준이 바뀐 값이다
```

4번이 가장 중요하다. 횡단면 혼재는 업종 집계로 완화할 수 있지만, **시계열 안에서
기준이 바뀌면 `peg`(EPS 성장률 기반)가 성장이 아니라 회계 기준 변경을 잰다.**

## 제약

```
EPS 를 보정하거나 통일하지 않는다. 분포만 낸다
수집기의 폴백 순서를 바꾸자고 제안하지 않는다 — 계약 변경(🔴)이다
'연결이 옳다/별도가 옳다'를 판정하지 않는다. 섞임의 크기와 위치만 잰다
```
