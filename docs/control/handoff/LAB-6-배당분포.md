# LAB-6 — 무배당 44%가 어디에 몰려 있나

```
발행   2026-08-11 · Claude
순서   4순위 — 급하지 않다
분량   두세 시간
```

## 한 줄

**수집한 배당 데이터의 44%가 0원이다. 그것이 어느 업종·어느 연도·어떤 회사에 몰려
있는지 센다.**

## 왜 이걸 하나

점수 체계에 **주주환원**이라는 지표가 있고, 배당 이력을 씁니다. fundamental 축 안에서
비중 0.15로, 그 축의 지표 중 두 번째로 큽니다. A3b가 열어 주는 지표이기도 합니다.

이 지표가 실제로 어떤 분포 위에서 작동하는지 아무도 본 적이 없습니다. 44%가 0원이면
그 지표는 **절반 가까운 회사를 같은 값으로 밀어 넣습니다.** 변별력이 있는지, 아니면
특정 업종을 통째로 깎는지 보는 것이 이 과제입니다.

## 배경 — 여기서 중요한 구분 하나

```
"배당 항목 자체가 공시에 없다"       → 모르는 상태
"배당 항목이 있고 값이 0원이다"      → 배당을 안 했다는 사실
```

**지금 데이터는 전부 후자입니다.** 14,578건 모두 `dividendRowPresent`가 `true`입니다.
공시가 배당 항목은 항상 주고, 무배당이면 0을 준다는 뜻입니다.

이 둘을 같게 다루면 "모른다"와 "안 했다"가 섞입니다. 다행히 지금은 섞일 여지가
없지만, **결과에 그 사실을 적어 두면** 나중에 다른 데이터가 들어왔을 때 구분이 살아
있습니다.

## 입력

```
data/backfill/fundamentals/_shards_a3b/shard-*.jsonl
  corp · fiscalYear · eps ·
  dividendPerShare       주당 배당금 (원). 0 이면 무배당
  dividendStockKnd       주식 종류 (보통주 / 우선주 / "-" 등)
  dividendRowPresent     배당 항목이 공시에 있었는가

data/backfill/fundamentals/a3/*.jsonl.gz        업종·규모 조인용
  corp · fiscalYear · sicCode · equity · revenue · netIncome
```

## 재현 확인 — 먼저 이 숫자를 맞추세요

```
전체 레코드                 14,578
dividendRowPresent = true   14,578   (전부)
dividendPerShare = 0         6,448   (44.2%)
```

## 작업 단계

**① 연도별 무배당 비율**

2015~2025. 경기 국면을 타는 지표라 연도별로 움직입니다.

**⚠ 연도별 비교 시 표본 구성이 바뀐다는 점을 함께 보세요.** 2015년 표본과 2024년
표본은 같은 회사 집합이 아닙니다. 비율이 움직인 것이 회사들의 행동 변화인지 표본
변화인지 구분이 필요합니다. 같은 회사만 골라 비교하는 방법이 있습니다.

**② 업종별 무배당 비율**

`sicCode`로 묶습니다. 무배당이 통째로 몰리는 업종이 있는지 봅니다.

**③ `dividendStockKnd` 값의 분포** ← 놓치기 쉬운 항목

수집기는 **보통주** 행만 골라 오도록 돼 있습니다. 그런데 실제 데이터에는 `"-"` 같은
값이 섞여 있습니다. 그 필터를 통과한 뒤에도 어떤 값들이 남아 있는지 세어 주세요.

우선주 배당이 섞여 있으면 그 값은 보통주 주주환원이 아닙니다.

**④ 회사별 지속성**

```
한 번도 배당한 적 없는 회사
계속 배당하는 회사
중간에 중단한 회사
중간에 시작한 회사
```

각 유형의 회사 수를 냅니다. 주주환원 지표가 "지금 배당하는가"를 보는지 "꾸준히
배당했는가"를 보는지에 따라 이 분포가 다르게 작동합니다.

**⑤ 적자와의 관계**

`eps < 0`인 회사의 무배당 비율을 따로 냅니다. 적자면 배당을 안 하는 것이 자연스러우므로,
이 지표가 적자 여부를 중복해서 재고 있는지 볼 수 있습니다.
