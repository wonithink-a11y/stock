아니다** — 상태의 정본은 언제나 `CLAUDE.md`와 `docs/control/TASKS.md`다. 이 문서가

## 알아두면 좋은 것 (운영상 함정)

- 로컬에 `DART_API_KEY` 환경변수 없음 — 실제 API 호출이 필요한 검증은 매번
  WebFetch로 DART 공시 원문에 직접 접근하거나(LAB-8처럼), 저장소 안 raw 데이터

  방식으로 진행했다.
