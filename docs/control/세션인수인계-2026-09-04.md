## 2. 페이퍼 트레이딩 상태 VM → OCI → Actions 자동 릴레이

사용자가 "깃허브 자동화가 안 되는 이유"를 물어본 데서 시작. VM은
"정본을 쓰는 주체는 하나다" 원칙상 GitHub에 못 쓴다(CLAUDE.md) - 분봉
승격 파이프라인(VM→OCI Object Storage→Actions→commit)과 **완전히 같은
원칙, 같은 버킷**(`stock-minute-manifest`, IAM이 버킷명 기준이라 새
prefix에 콘솔 작업 불필요 - 실측 확인)을 재사용해 구현.

- `scripts/upload-paper-state-oci.py`(VM, instance principal) -
  `paper-state/{strategy}/{timestamp}.json`로 매 폴링마다 업로드(IAM이
  OVERWRITE를 안 줘서 매번 새 키). `run_paper_trading_daily.py`가 매
  실행 끝에 호출하도록 배선.
- `scripts/sync-paper-state-oci.py`(Actions, API key) - 전략별 최신
  객체만 다운로드. sha256 검증 없음(몇 KB짜리 단일 전송이라 잴 게
  없다는 판단, 교훈50) - JSON 파싱 실패만 거부.
- `.github/workflows/paper-trading-ui.yml` 신규 - sync →
  `build_ui_feed.py`(KIS_VTS 시크릿으로 계좌 잔고 직접 실시간 조회) →
  commit, 평일 09:05~15:35 KST 30분 간격.
- 실제 종단간 검증 완료(VM 실업로드→Actions 실행→커밋→deploy-pages
  자동 발동→라이브 사이트 확인) - pyarrow 의존성 누락 1건 발견·즉시 수정.

**한계**: OCI 객체 정리 없음(IAM이 DELETE 안 줌) - 장기적으로 계속
쌓인다. 문제되면 OCI 콘솔 lifecycle 정책 필요(사용자 작업, Claude가
못 함).

## 4. KR 프로덕션 채점(KR-2.3) — valuation·fundamental 축 최근 역방향 조사

사용자가 대시보드 백테스트 탭에서 "A등급 승률 0%·마이너스, 등급
낮을수록 이익률 높음"을 재차 보고("초반에 잡은 계획과 실제 가격변동이
다른 것 같다"). 문서: **`research/strategy-lab/findings/
kr-production-valuation-fundamental-inversion-2026-09.md`**(verdict
UNCLASSIFIED, 이번 세션 안에서 4차례 갱신됨 - 아래는 최종 상태).

### 조사 순서와 결과 (전부 기각/축소되며 문제가 계속 좁혀졌다)

1. **41일 운영 이력(`docs/data/history/`, 41일·1,404건) 축별 분해** -
   `backtest-report.js`가 매번 현재 criteria(KR-2.3 포함)로 원본을
   재채점한다는 걸 코드로 확인. technical 축은 오늘 승격한 MA크로스
   반전(§본문 위쪽 CLAUDE.md 참고)으로 IC가 거의 0으로 정상화됐지만,
   **valuation IC=-0.191·fundamental IC=-0.139**가 역방향으로 남음.
2. **미국 10년물 국면 가설(126거래일 trailing, 기존 PBR 연구 정의
   재사용) - 기각.** 이 41일 전체가 "가치주에 유리해야 할" rising
   국면 하나뿐인데도 valuation이 역방향.
3. **"2025·26년 호황이 신호를 희석한다"는 사용자 가설(A5 10년 백필로
   검증) - 기각.** 2025·26 제외해도 IC 거의 안 바뀜(valuation
   +0.0619→+0.0588). valuation은 11개년 중 사실상 전 구간 양(+).
   **★ 그런데 A5의 유효기간(~2026-07-03)과 41일 구간(07-12~09-03)이
   하루도 안 겹친다는 걸 발견** - "10년 문제가 가려짐"이 아니라 "7월
   중순 이후 새로 튄 사건"으로 질문이 좁혀짐.
4. **코스피 급등장 가설 - 최초 오독, 정정.** "+22%"는 41일 구간이
   아니라 매크로 위젯의 1년치 변화율이었다. 실제 일별 데이터(두 독립
   파이프라인 교차검증)는 **7월 한 달 -30.8% 급락 후 8~9월 불안정
   반등**이었다.
5. **급락국면 일반화 가설(2020 코로나 급락, A5로 대조) - 기각.**
   규모가 비슷한 2020-02-17~04-14(-35.7%) 구간의 valuation IC는
   **+0.1335**로 연평균보다 오히려 강했다. "급락장이면 밸류가 깨진다"는
   일반 법칙이 아니다.
6. **A2a를 09-03까지 새로고침 후 A5 재백필(GH Actions
   `33778683774`)로 2026-07 급락 자체를 직접 실측.** fwdStatus.d20
   유효구간이 07-03→**07-31**로 확장 - **valuation IC=-0.0301(n=5,302)**.
   방향은 진짜 역방향(2020년과 다른 성격)이나 **크기가 41일 운영패널
   측정치(-0.191)의 약 1/6뿐**.
