## 함정

- **Yahoo `.KS` 개별 종목 일봉은 애프터마켓을 섞는다**(10-30 삼성전자 225,000 vs 정규장 220,500, regularMarketTime 이 16시대). 국내 종목 정규장은 네이버 차트 API 또는 KIS.
- **네이버 `m.stock.naver.com` 의 `fluctuationsRatio`·`closePrice` 는 통합(NXT 포함)**이다 — 정규장 등락이 응답에 아예 없다. 같은 네이버라도 `api.stock.naver.com/chart/…/day` 는 KRX 단독(거래량이 KRX 단독 19,485,781 vs 통합 30,703,210).
- 대시보드 공용 컴포넌트를 고치면 여러 탭이 같이 바뀐다: `.mrep-chip`(영상 요약·종목 리포트), `marketHeatmap`(홈·섹터강도·마감 리포트), 종목 상세 창(어디서 열어도 같은 창), 폰 표 이름 칸 고정 규칙(새 표가 이름이 아닌 첫 칸이면 제외 클래스 필요).
- 마감 리포트 같은 날 = `sector-strength.json` asOf 비교 — 히트맵 기본 기간이 '장중'이라 리포트 안에서는 `fixWin='1d'` 로 고정해야 지난 장에 오늘 시세가 안 섞인다.
