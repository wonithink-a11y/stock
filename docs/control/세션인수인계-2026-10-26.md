## 3. 히트맵(시장·섹터 > 섹터강도, 홈)
- **업종 확대·탭 확인**: 업종 이름·'업종 크게 보기'로 한 업종만 크게(금융 48종목 중 35개 이름 표시, 전체 화면은 352개 중 8개), 종목 칸 첫 탭 = 아래 정보 막대(이름·업종·등락·시총), 같은 칸 두 번째 탭 = 상세. 폰은 호버가 없어 누르기 전에 알 방법이 없었다.
- **지주회사 분리(B안, 표시 전용)**: KSIC '기타 금융업'에 섞인 지주회사 64개를 `config/sectorGroups.json` 새 키 `heatmapGroupOverrides` → `build-sector-strength.py` 가 `stocks[].hg` 로만 내보낸다. 1개월 금융 −16.4% → 순수 금융 −12.5%, 지주회사 −22.1%.
  - **`g`·`tickerOverrides` 는 절대 바꾸지 않는다**: 급등 군집 forward(`append-cluster-shadow.py`, 동결 정의)·업종별 A5 IC forward(`run_sector_ic_forward.py` 가 tickerOverrides 를 직접 읽음)·업종 표·급등 비율이 `g` 로 정의돼 사전등록이 깨진다.
  - `docs/data/sector-strength.json` 의 writer 는 daily-analysis(평일 16:40 KST). 그 실행 뒤에야 `hg` 가 생기고, 그 전엔 프런트가 `g` 로 폴백.
  - 금융에 남긴 것: 금융지주 9·창투/벤처/IB/캐피탈/카드/결제 16·해외상장 지배회사 11(사업 불명)·LS에코에너지(사업회사인데 KSIC 가 지주로 잡힘, 판단 보류).
  - 업종 옆 수익률은 이제 보이는 종목의 시총가중(업종 표 capRet 과 가중 시점이 달라 소수점이 다를 수 있음).

## 4. 증권사 의견 탭
- 의견 표기를 매수/중립/매도/미제시로 정규화(원문은 칩 툴팁 — 폰은 호버 없음), 증권사 약칭, 3열 압축(종목·의견+증권사·목표가+변경률+직전 목표가)으로 폰 가로 스크롤 제거.
- 날짜: 달력 입력(의견 없는 날은 가까운 이전 날짜로 이동 안내)·최근 10거래일 칩(건수)·기간(하루/5/20거래일/전체)·증권사·의견 필터·요약줄. 예: 최근 5거래일 209건 중 목표가 상향 36·하향 122.
- 직전 목표가: 처음 개편에서 폰에서 숨겼다가 사용자 요청으로 목표가 칸 아랫줄에 복원(`직전 330,000`, 같으면 '직전과 같음').

## 함정
- 종목 리포트는 남의 콘텐츠라 **저장소에 넣지 않는다**(VM 에만). 점수·매매 불사용(절대 규칙 1), 리포트 의견·목표가는 판단 근거 아님.
- Windows Git Bash 에서 Python 이 한글을 stdout/heredoc 으로 다루면 cp949 로 깨진다 — 한글 문자열 치환은 UTF-8 파일(Write)로 스크립트를 만들거나 바이트로 읽어 쓴다. DART 계정명이 깨져 일부(상반기 영업외 등)는 값의 구조로 해석했고 `reports.json` 에 '내 계산·추정'으로 표시했다.
- 업종 분류를 바꾸려면 먼저 그 업종 `g` 를 읽는 forward·표를 확인(위 3절).
- CIS 인스타 글의 '459억 원'은 출처 못 찾음(블룸버그 일본어판 40억 엔, 주간포스트 37억 엔) — 무시.
