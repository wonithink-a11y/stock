## 2. sessionBounds — 조용한 잘림을 관측 가능한 사실로

갭도 아니라 인수 조건이 그대로 통과한다. 새 회귀가 그 사실을 직접 고정한다 —

그리고 manifest 의 `observations` 는 **여태 빈 객체였다**(2026-09-09 실측).

```json

                  "distinctMinutes":381,"policySessionMinutes":381}
```

**판정하지 않는다 — 세어서 남기기만 한다.** 무엇이 정상인지는 제도가 정하고
그건 수집기가 알 수 있는 것이 아니다. 인수 조건 목록을 늘리지 않는 것도
회귀가 고정한다.

이월 조각도 포함한다(`validate_rows`·`revalidate_carried` 양쪽에
`minutes_seen` 통과). `minutes_seen` 은 선택 인자라 안 주면 결과가 이전과

### ★ ChatGPT 초안 지시문에서 바꾼 것 셋 (다음 세션이 반드시 읽을 것)

| | 지시문 | 실제 |

**세 번째가 제일 중요하다.** 2년 프로브에서 신호 25,187건에 포트폴리오

포트폴리오 수치는 현실성 참고로 병기한다.

### ★★ LWTI 에는 정본이 없다 — 지어내지 않았다

Loxx Pine 참조식 `(close - close[n]) / ATR(n) * 50 + 50` 만 옮겼다.
**"빨강→녹색"의 수치 정의는 공개 정의에 없다.** 둘 다 실제로 쓰인다:

```
slope     lwti[t] > lwti[t-1]      지표선이 돌아섰다
midline   lwti[t] > 50             기준선을 넘었다
```

지어내지 않고 **둘 다 구현해 정책에 어느 쪽을 썼는지 적고 둘 다 돌린다**
(교훈50). Loxx 원본의 스무딩 선택지는 **미검증으로 남겼다** — 검증하지 않은
자유도를 늘리지 않기 위해서다.

판독 하나 더: 원문 "3가지가 동시에 일치하는 순간"은 LWTI 를 **당일 전환**으로
읽을 수도 있다. baseline 은 `state`(돌파일에 녹색이면 통과)로 뒀고 —
차트 트레이더의 실제 판독은 "돌파가 사건이고 나머지 둘은 그 시점의 확인"이다 —
`transition` 도 변형으로 돌려 거래 수 차이를 **주장이 아니라 숫자로** 남긴다.

`intraday/forward.py` 가 이미 "이벤트 시점 → 이후 N분 수익"을 한다.
