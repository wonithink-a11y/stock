## 1. Ox Alpha(OpenCode) 협업 — 확정 + 실전 검증 2건

### 1.1 정체 확정 (이전 세션에서 시작, 이번에 완결)

```
"Ox Alpha" = opencode/x-preview-f-free 모델 + --variant max(추론노력 최대)
실행 커맨드: opencode.cmd run "<지시문>" -m opencode/x-preview-f-free --variant max
```
`AGENTS.md` §5(작업 분담 기준·충돌 방지 프로토콜)와
`docs/control/opencode-model-fallback-order.md`(메모리)에 반영 완료 —
전 세션에서 끝난 항목, 이번 세션은 그대로 적용만 했다.

### 1.2 실전 적용 1 — GitHub 전략 저장소 활용성 조사

사용자가 Freqtrade·Qlib·Backtrader·hftbacktest 등 10개 저장소를 Ox
Alpha에 조사시킨 결과를 Claude가 `gh api`로 star/활동상태 전수
재검증 — **전부 정확했다**, 심지어 `mementum/backtrader`의 "마지막 의미
있는 커밋 2023-04" 같은 세부 주장까지 실제 커밋 로그로 재확인해 맞았고,
`cryptofish7/jesse`(원 분석이 링크한 것)가 0스타 비공식 포크라는 것까지
정확히 잡아냈다. Qlib `TopkDropoutStrategy`의 `topk=50, n_drop=5` 코드도
직접 열어 일치 확인.

**결론(findings/github-strategy-sources-usability-2026-08.md)**: 대부분
저장소는 "이미 우리가 검증해서 기각한 계열"(V3·TREND-BREAKOUT과 같은
기술적 조합)이거나 데이터가 없어서(hftbacktest 호가창) 못 쓴다. 유일하게
새로운 축은 Qlib의 dropout(회전율 제한) 메커니즘 — `strategies/
pbr_value_v1/build_selection.py`가 매달 top-30을 완전히 새로 뽑아 전월
보유를 전혀 안 본다는 걸 코드로 확인해 실제 새 실험으로 이어졌다(§2.1).

### 1.3 실전 적용 2 — 학술 문헌 기반 신규 팩터 후보 조사

Ox Alpha가 MAX효과·PEAD·업종모멘텀·A4수급결합 4개 후보를 제시, Claude가
WebSearch로 논문 원문을 직접 대조:

```
✅ MAX효과(Nartea·Wu·Liu 2014) — 논문 실존, 핵심 주장 정확
   (저널명만 오탈자: Applied Economics Letters → 실제 Applied Financial
   Economics 24(6) 425-435로 정정)
✅ PEAD(Eom·Hahn·Sohn 2019, Goh·Jeon 2017) — 둘 다 정확, 핵심 결과까지 일치
🔴 업종모멘텀("Kang & Ryu 계열") — 인용 자체가 저자/연도/저널 없이
   검증 불가능한 형태였는데, 실제 가장 관련성 높은 최신 논문
   (Doojin Ryu 2024, Investment Analysts Journal 54(4), 한국 1983-2023
   데이터)은 정반대 결론("업종모멘텀 유의한 효과 없음") - 기각
```

**교훈**: Ox Alpha의 산출물 품질은 전반적으로 높지만(내부 프로젝트 인용은
100% 정확했다), **외부 학술 인용은 구체적 서지사항(저자·연도·저널)이
없는 항목을 특히 의심해야 한다** — 이번에 유일하게 틀린 게 정확히 그런
형태의 인용이었다. `findings/github-literature-return-enhancement-
candidates-2026-08.md`에 전체 대조표 있음.

## 2. PBR 신규 실험 2건 — 둘 다 개선 확인 (채택 판단은 보류)

### 2.1 회전율 제한(dropout) — `findings/pbr-dropout-turnover-limit-2026-08.md`

`strategies/pbr_value_v1_dropout/`(로컬 전용, 아래 §3 참고) - 매달 top-30
전체 재선정 대신 **전월 보유 중 순위 최하위 3개(nDrop=3)만 교체**.

| | baseline | dropout | 차이 |
|---|---|---|---|
| CAGR | 4.72% | 5.36% | +0.64%p |
| MDD | -21.70% | -21.42% | 개선 |
| Sharpe | 0.4556 | 0.4901 | +0.0345 |
| 청산거래 | 756건 | 449건 | -40.6% |

월평균 신규진입 종목수 6.08→3.65(-40%), 회전율 감소가 비용 절감으로
직결돼 net 개선. 11개 연도 중 7개 우위(특정 연도 몰림 없음).

### 2.2 MAX(복권효과) 제외 — `findings/pbr-max-exclusion-2026-08.md`

`strategies/pbr_value_v1_maxexcl/`(로컬 전용) - baseline이 뽑은 top-30
중 그 달 적격 유니버스 내 MAX5(최근 21거래일 상위5일 평균수익) 상위
20%를 **대체 없이 제외**(카운터팩추얼 - "이 종목들을 안 샀으면").

기존 프로젝트의 "노출 오버레이"(exposure_frac 스칼라) 방식은 시장전체
타이밍 신호용이라 종목별 특성인 MAX에는 안 맞는다고 판단해, 구성 자체를
바꾸는 새 방법론을 썼다(재사용 아님 - 첫 시도).

| | baseline | MAX제외 | 차이 |
|---|---|---|---|
| CAGR | 4.72% | 5.67% | **+0.95%p** |
| MDD | -21.70% | -20.80% | 개선 |
| Sharpe | 0.4556 | 0.5814 | **+0.1258** |
| 청산거래 | 756건 | 882건 | +16.7%(경계선 종목 반복 진입청산) |

거래건수가 늘었는데도 net이 개선됐다는 게 "회전율 감소 효과"가 아니라
"MAX 상위 종목 자체가 나쁜 편입이었다"는 방향을 시사 - dropout 실험보다
개선폭이 크다. 11개 연도 중 8개 우위.

### 2.3 두 실험 다 아직 채택 근거 아님 — 공통 한계

- 각각 **1회 실행, 파라미터 값 하나만** 테스트(nDrop=3 하나, exclusion
  20% 하나) - 스윕 안 함
- **T1/T3(대형주) 분해 안 함** - 특히 MAX효과는 한국에서 소형주 표본
  에서만 유의했다는 문헌 경고가 있는데 확인 안 됨. 이 프로젝트가 3~4번
  재현한 "T3 대형주 반전" 패턴과 겹치는지 미확인
- Out-of-sample(TRAIN/VALID/TEST) 분할 검증 안 함 - Opening Fade·REV20이
  겪은 "OOS 반전" 위험이 여기서도 있는지 모른다
- **두 실험의 결합**(dropout + MAX제외 동시 적용)도 안 해봄
- 방법론은 견고함(baseline 재현치가 CLAUDE.md 최종본과 정확히 일치하는
  걸 먼저 확인한 뒤 비교, realized-pnl 방식의 함정을 피해 처음부터 MTM
  방법론 사용, 기존 회귀 143건 통과 확인)
