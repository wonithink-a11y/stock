## 2. 규칙 (설계 §3 에서 옮김 — 구현에 들어 있다)

- TTM = 공시된 **연속 4개 분기** 합, 하나라도 없으면 None. 4분기 = 사업보고서 EPS − 3분기 누적. 가용일 = `rcept_no` 앞 8자리.
- 기본 EPS = 계속영업(총 EPS 가 2% 넘게 다르면 따로 표시). 정정 재공시(접수일−기간말 > 200일)는 `restated` 로 표시하고 그 4분기가 빈 구간은 TTM 결측.
- 분할 기준: A3c 분기 발행주식 수 정수배 점프 + 같은 해 누적 항등식. 판정이 약하면 `split_uncertain`.
- **EPS 가 주가의 1% 미만이면 PER 을 안 낸다**(`EPS_TINY`, 내가 정한 표시 기준 — 검증 안 됨. 두산 TTM PER 284배 같은 값). EPS ≤ 0 도 PER 없음.
- 12월 결산만(351종목, 2종목은 결산월 미상). 비12월 결산은 "분기 라벨을 다루지 않는다"로 표시.

## 3. 함정

- **웹 유닛에는 DART 키가 없다** — 즉석 조회는 불가능했다. 그래서 Actions 수집 → `docs/data` 파일 → 카드 구조다. 웹 유닛은 저장소(`~/collector`)를 통째로 읽기 전용 마운트하므로 새 파일에 유닛 변경은 필요 없다.
- DART 응답이 가끔 **분 단위로 멈춘다**(로컬 직렬 150콜이 32초·122초, 4스레드가 10초·285초로 들쭉날쭉) — 그래서 병렬로 바꿨다(8스레드 150콜 6초·오류 0, 결과는 직렬과 동일). 단일 요청 타임아웃 25초·3회 재시도. 020 은 새 제출을 멈추고 정상 종료.
- 로컬에서 캐시를 시험할 땐 반드시 `--cache`·`--out` 을 임시 경로로(저장소 파일은 Actions 만 쓴다). `--no-fetch` 는 네트워크 없이 계산만.
- 주당이익 행 이름이 제각각이다(`계송영업순이익` 오타 포함) — 파서는 `parse_eps` 한 곳. 새 이름이 나오면 그곳에 케이스와 회귀를 같이 추가한다.
- 정정 재공시로 원본이 없는 종목(카카오 FY2020~22, 두산 FY2017~20)은 4분기가 비어 그 구간 TTM 이 결측이다 — 정상이고 화면에 표시된다.
- 이 세션의 스크래치 스크립트(`dart_q_fetch.py`·`ttm_series2.py` 등)는 임시 폴더라 사라질 수 있다 — 같은 로직이 `build-eps-ttm.py` 에 들어 있다.
