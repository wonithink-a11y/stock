전환사채 정형 API(`cvbdIsDecsn`) = 전환가·전환 주식 수·총주식 대비 %·**전환청구 시작일**. 수주를 고른 이유: 공시 A/B(1ee09ba7) 결과 문서가 "금액·매출 비중이 없어 큰/작은 수주를 못 갈랐다"를 한계로 적었다.

- 사전등록 핵심: 주 셀 = 매출 대비 % ≥ 직전 연도 80백분위, 다음 날 시가 → 60거래일, 정보 = 공시 A/B 와 같은 매칭 대조 대비, 귀무 = 같은 진입 연도 모든 수주에서 같은 개수 무작위 10,000회(크기만 잰다). 현실적 기대 REJECT/INCONCLUSIVE.
- **다음**: 수집 완료 확인(`python research/strategy-lab/order_contract_size.py --coverage` 첫 줄이 '수집 완료') → 커버리지 다시 → 사용자 동결 GO → `verdict: PREREGISTERED` 커밋 → 1회 실행.
