## 6. 알게 된 것

- KIS 모의 체결가 ≠ 시초 단일가(1건) — 모의로 동시호가 전략을 검증할 수 없다.
- 동기화 패스키는 서명 카운트가 항상 0 — 복제 탐지 대신 구글 계정 2단계 인증이 방어선.
- 텔레그램 봇은 자기가 보낸 메시지 기록을 조회할 수 없다 — 화면에 넣으려면 보낼 때 기록해야 한다. 공개 채널은 `t.me/s/<채널>` 미리보기로 읽을 수 있다(주인이 끄면 불가).
- KRX Open API 는 휴장일에도 요청 날짜 그대로 빈 가격 행을 준다(교훈 81 의 변형) — 거래일 판정은 거래량으로.
- ETF 호가단위는 2023-12-11 전후로 다르다(전 5원 일괄, 후 2천원 미만 1원).
- Windows 파이썬 `write_text` 치환 중 `\n` 이 실제 줄바꿈으로 들어가는 사고 3회 — 문자열 치환은 Edit 도구나 `chr(10)` 로.
- 1분봉으로 체결 이후 수익을 잴 때 **그 분의 종가에서 재면 지정가 체결 쪽이 부풀려진다**(떨어지는 분에 산 체결은 종가가 체결가보다 낮다, 평균 7bp) — 체결가 기준으로 잰다.
- BitMEX 체결기록의 Funding 행 `commission` 은 펀딩비 자체가 아니라 '낸 쪽이면 +' 다 — 실제 펀딩비 = commission x 포지션 부호.
- 저장소에 제가 만들지 않은 로컬 변경(`research/strategy-lab/data/market-regime/_manifest_fred_extended.json`)이 있다 — 손대지 않았다(`Crypto_won/` 은 §4-c 에서 gitignore).
  `ui/data/macro.json` 로컬 변경은 rebase 충돌로 원격본을 쓰고 원래 변경은 `git stash` 보관함(autostash)에 남겼다.
