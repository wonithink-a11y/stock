# 세션 인수인계 — 2026-11-16-b 태블릿 원격 킬 · 웹 화면 정리 (Sonnet 5.5)

## 한 장 요약
- **구멍 발견**: PC 웹의 킬 버튼은 PC 상태 폴더에 쓰고, 태블릿 엔진(Termux)은 자기 상태 폴더의 `KILL` 만 본다 → 웹에서 눌러도 태블릿에 안 닿는다. 모의·dry-run 이라 지금은 무해, **실매매 전 필수 해결 항목이었다.**
- **해결(PR #116, Workers 배포 완료 11-16)**: Workers 에 요청(`POST /kill` 관리 키, 또는 서명 링크 `/k`)을 남기면 태블릿 `run-loop.sh` 가 **매분** 가져가 `kill-all`(기본+모든 프로필) → `/kill/ack`(요청 삭제) → 매매방에 "요청"·"적용" 알림. **켜기 전용** — 해제는 태블릿에서 `resume-all`. PC 에서는 `scripts\kill-tablet.ps1`.
- 폰용 정지 링크는 `C:\Users\User\stock-backup\kill-link.txt`(저장소 밖). 즐겨찾기로 두면 VPN 없이 한 번에 정지(GET=버튼만, POST=요청). 새도 거래가 멈출 뿐이다.
- 웹 화면(PR #115): 카드 테두리 · 홈 맨 위 매매 계획 바로가기. PC 웹은 `stock-autotrader-web` 작업으로 켬(8787, Tailscale serve `/autotrader`).

## 아직 안 한 것 (사용자 몫·미확인)
1. **태블릿 `git pull` + `run-loop.sh` 재시작** — 이걸 해야 원격 킬이 동작한다. 재시작은 하트비트를 몇 분 끊는다(3일 시험 11-16~18 구간에 끊김 기록 필요).
2. 재시작 뒤 **킬 실물 시험**: `scripts\kill-tablet.ps1` → 1~2분 안에 매매방 "적용" 알림 → 태블릿 `status` 에서 킬 ON → `resume-all` 로 해제. (모의·dry-run 이라 안전)
3. 폰 Tailscale: 은행 앱이 VPN 때문에 막힘 → 앱별 제외(App-based split tunneling)를 하거나 평소엔 꺼 둔다. 알림·엔진과 무관.
4. 실매매 전 남은 것: 웹 킬이 태블릿에 닿지 않는 것은 위로 해소했지만, 웹의 "주문 켜기·끄기"(auto) 도 같은 구조(PC 상태 폴더)다 — 태블릿 엔진의 auto 는 프로필 파일 + 태블릿에서 직접. 필요하면 같은 방식으로 설계.

## 함정
- Bash heredoc 안 파이썬 문자열의 `\n` 이 실제 줄바꿈으로 바뀐다(`run-loop.sh` 의 printf 가 깨졌다가 고침). 쉘 스크립트 편집은 Edit 도구로.
- 데모 서버 종료를 PowerShell `CommandLine -match` 로 하면 그 명령 자신이 걸린다 — `autotrader-web-dem[o]` 식으로 쓴다.
