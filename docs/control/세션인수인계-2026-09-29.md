- **허용목록 방식 설정 로더는 새 키를 조용히 버린다**(8a6d22b1) — 기능을 만들 때 테스트가 env dict 를 직접 넣으면 로더를 안 거쳐 통과한다. 로더를 거치는 회귀를 넣었다.
- 권한 자동 확인(auto mode) 서버가 '판정 없음'을 연속으로 내면 편집·명령이 다 막힌다 — 사용자가 권한 모드를 수동으로 바꾸면 풀린다(이번 세션 여러 번).
- ★ 넓게 걸리는 프로세스 종료 명령(`taskkill /IM python.exe`)을 잘못 쳤다 — 아무것도 안 죽었지만, **프로세스는 명령줄로 PID 를 확인한 뒤 그것만 멈춘다.**
- 연구 스크립트 두 번이 **판정 계산 뒤 저장 단계**에서 죽었다(배열 길이·numpy int64 JSON) — 판정 숫자를 보기 전/후를 결과 문서에 적고 '저장만 고쳐 재실행'으로 기록했다.
- in-sample 최적값 요청(무한매수 %·배수)엔 표는 보이되 **고르지 않고**, 규칙을 고정한 재현(다른 종목)·forward 로 넘겼다 — 사용자에게 이유(다중검정) 설명함.
