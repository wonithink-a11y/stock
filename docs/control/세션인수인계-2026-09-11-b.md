## 2. 모의투자 UI — 사용자 요청 4건을 순서대로

### 2.1 전략별 매수금액·평가손익 (`9861459`)

도넛 범례와 전략별 표 머리에 매수금액(원가)·평가금액·평가손익(원/%)을 붙였고,
종목 행에 매수금액·평가금액 칼럼을 더했다. `strategyTotals()` 하나를 둘이 같이
쓴다 - 두 벌로 계산하면 언젠가 갈리고 갈린 쪽이 맞는지 화면으로는 못 가린다.

평가액 기준을 마지막 일봉 종가 → **현재가**로 바꿨다(일봉은 `historyAsOf` 라
며칠 낡는다). 도넛의 예수금이 그만큼 움직인다.

### 2.2 ★ 주문 원장 — 전략 귀속을 제출 시점에 남긴다 (`3aaceb1`, 🟡 GO 받고 진행)

**"전략별로 못 가른다"는 첫 답이 틀렸다.** 정보가 없는 게 아니라 10분 만에
버려지고 있었다.

```
paperEngine.py:474  매수 제출 → state[symbol]["order_no"] = ...
paperEngine.py:554  매도 제출 → state[symbol]["order_no"] = ...
paperEngine.py:507  매수 체결 → order_no 를 pop
paperEngine.py:580  매도 체결 → del state[symbol]      ← 포지션이 통째로 사라진다
```

귀속 정보의 수명이 폴링 한 사이클(10분)이고 UI 는 하루 3번 빌드한다. 교훈75 -
그 자리에서 안 남기면 영영 못 얻는다.

```
positionStore.record_order()   주문번호 → {날짜, 종목, side, 수량, 사유}
  ↓ paper-orders/{전략}/{ts}.json — positions 와 같은 OCI 경로
build_ui_feed                  체결내역(odno) ⋈ 원장 → trades.byStrategy
```

지어내지 않는 자리 둘:
- 원장에 없는 주문은 **날짜별 잔차**(계좌 − 귀속분)로 "기록없음" 행이 된다.
  뺄셈이라 짐작이 아니다. 종목·수량으로 되짚는 건 겹쳐 든 종목(pbr_value_v1
  29종목 중 25종목이 combined 와 겹친다)에서 짐작이 된다.
- 과거분은 소급 안 된다.

원장 쓰기가 매매를 못 막는다 - `record_order` 가 예외를 삼키고 False 를 낸다.
회귀가 **진짜 쓰기 실패**(부모가 파일인 경로)로 확인한다. 함수를 통째로
바꿔치기하면 그 방어를 건너뛰어 없는 실패를 시험하게 된다(교훈72).

### 2.3 전략별 실현손익 (`02232b4`)

새 쓰기 지점을 안 늘렸다. `entry_price` 는 **매도를 제출하는 순간** state 에

갈린다(교훈72).

아니라 "기록없음". 수수료·세금 전이다.

## 4. ★★ macro 코스피가 하루 밀려 보이던 것 (`47cb218`) — 고칠 자리가 달랐다

사용자 요청은 "생산자 날짜 밀림도 고쳐줘"였는데 **생산자는 안 틀렸다.**

```python
# macro_common.py:235  asof_join_kr()
pd.merge_asof(..., direction="backward", allow_exact_matches=False)
```

docstring 이 "date < D 인 가장 최근 관측치"라고 적었고 `selftest_asof_join()` 이
"D당일 관측치를 쓰지 않는다(등호 배제)"로 핀까지 박아 뒀다. **의도된 PIT 다.**
여기를 고쳤으면 `*_macro_regime_check.py` · `build_regime_features_backfill.py`
가 쓰는 시리즈에 **lookahead 를 넣는 것**이었다. parquet 은 손대지 않았다.

진짜 결함: parquet 은 날짜를 둘 들고 있는데(`date` = 쓸 수 있게 된 거래일,
`<col>AsOfDate` = 실제 관측일) `build_ui_macro._series_from()` 이 뒤엣것을
버려서 소비자가 "그날 종가"로 읽을 수밖에 없었다. **값이 틀린 게 아니라
라벨이 사라진 것이다.**

```
date 로 읽으면   41일 중 39일 한 행 밀림 · 같은 날 일치  0건
asOf 로 읽으면   겹치는 22일 전부 일치   · 불일치        0건
```

(먼저 `docs/data/history` 의 날짜 라벨이 옳음을 KIS 일봉으로 확인했다 -
`000080` 2026-09-10 종가 15,300 일치.)

이게 조용히 틀리고 있던 것: 벤치마크 비교가 하루 어긋났고, **Beta 가 하루 밀린
두 계열의 상관이라 전부 0 근처**(-0.04 · 0.01 · -0.06)로 나왔다. 한국 주식
베타가 0 일 리 없는데 표가 그렇게 말하고 있었다. 보정 후 0.09 · 0.16 · 0.37.

**연구 산출물은 아무것도 안 바뀐다.** 레짐 findings 를 다시 볼 필요 없다.

`macro.json` 에 `asOf` 가 실제로 붙는 것은 `macro-regime-ui.yml`(16:55 KST)이
다시 돌고 나서다. 그 전까지 `chart.js` 는 "한 행 밀기" 폴백을 쓴다(같은 값).
**생산자를 고쳤으니 폴백은 나중에 지워도 된다.**
