# 미국 개별주 유니버스·PIT 데이터 확보 조사 (2026-09-21)

방식 B(미국 개별주 횡단면)를 열 수 있는지 소스를 조사했다. 수집은 하지 않았고 페이지·저장소를 읽어 확인했다.
`확인` = 이번 세션에서 직접 열어 봄, `미확인` = 기억·2차 정보(ChatGPT 요약 포함).

## 0. 결론

**Sharadar(개인 라이선스)가 유일하게 현실적인 경로다.** 삭제 종목·PIT S&P500 구성·기업행동이 한 벤더에 있고 월 $9~29 다.
GitHub `tenicho/data-cleaning` 은 **데이터가 아니라 Sharadar 원자료를 정리하는 코드**다 — 그 저장소에서 parquet 을 내려받을 수는 없다.
구독·키 입력·결제는 사용자가 해야 하고, 데이터는 **로컬 전용**이다(Sharadar 재배포 금지 + 이 저장소는 PUBLIC).

## 2. `tenicho/data-cleaning` (확인)

- 저장소에 있는 것: `scripts/sharadar/`(파이프라인 코드), 노트북, 문서. **`data/` 는 gitignore — 데이터 파일 없음.** LICENSE 파일도 루트 목록에 없다.
- 하는 일: Sharadar `SEP`(가격)·`tickers`·`actions`·`sp500` 을 받아 `sh_panel.parquet`(1998-01-02~2026-07-31, 41.8M 봉, 19,023 종목, 삭제 13,288)을 조립. **본인 API 키 필요**, 전체 빌드는 952MB 다운로드, 벌크는 "entitled plan" 이 필요(없으면 느린 페이지 조회로 폴백).
- 저장소 제목/설명은 "FMP + SEC EDGAR, 2003~"으로 낡았고 README 본문은 Sharadar 1998~ 이다 — **본문이 현재판**이다.
- 유용한 함정 기록: 수정주가는 **수준(level)에 쓰면 미래정보 누출**(1998 AAPL 이 $0.122) · 분할 계수는 3자리 반올림 잡음이라 단계함수로 복원 · `sp500` 표는 삭제 종목을 `LEHMQ`·`BSC1` 식 접미 심볼로 씀 · 500%↑ 일변동 종목 639개를 격리했는데 **실제 붕괴 종목을 지웠을 수 있다(측정 안 됨)** — 생존편향이 뒷문으로 돌아올 수 있는 자리.
- 한계: 발행주식수 없음(시총 계산 불가) · 재무 미사용 · 호가 없음 · `exchange` 는 현재 속성.
- 검증 사례: 2008-09-12 기준 S&P500 로스터가 500명이고 LEHMQ 가 종가 $3.65 로 실제 봉을 가짐. 멤버십 쌍의 99.83% 가 가격에 조인.
  (전부 저장소 자체 주장이며 우리가 재현한 것은 아니다.)

## 3. 라이선스 (확인 — Sharadar 개인 라이선스)

- **개인·비전문 용도만**. 기관·법인·전문적 연구·"publication" 금지. 이 프로젝트가 개인 연구인 한 해당하나, 결과를 남에게 팔거나 게시하는 방향으로 가면 위반이다.
- **재배포 금지**: 데이터 또는 "역공학을 허용하는 파생 데이터" 공유 불가. 접근 권한 공유도 불가.
- 공개 표시 시 "Data from Sharadar.com" 표기 필요.
- 이 프로젝트 함의: 저장소가 **PUBLIC** 이므로 원자료·패널 parquet 은 커밋하지 않는다(무한매수 규칙 값과 같은 방식 — gitignore, 로컬 전용).
  요약 통계(t 값·구간별 수익 등)를 findings 에 싣는 것은 파생 데이터 재구성이 불가능한 수준이면 무방해 보이나 **경계는 Sharadar 해석에 달렸다 — 종목 단위 표는 싣지 않는다.**
- GitHub Actions 는 이 데이터를 못 읽는다(키·데이터가 로컬). 모든 실행은 로컬 수동.

## 4. 우리 규칙과의 충돌 점검

- 규칙 2(시크릿): 키는 `.env`(`SHARADAR_API_KEY`) 에만. **Claude 는 키·결제 정보를 입력하지 않는다** — 사용자가 직접.
- 규칙 4(`data/backfill` 로컬 커밋 금지): 무관 — 미국 패널은 `research/strategy-lab/data/` 아래 gitignore 로 둔다.
- A6 Primary HOLD: 무관 — Strategy Lab 은 그 GATE 와 별개 시스템(CLAUDE.md).
- 새 외부 데이터 소스 통합은 "확인받는다" 범주다 — 이 문서가 그 확인 요청이다.
- `tenicho` 코드는 **그대로 실행하지 않는다.** 라이선스 불명 + 외부 코드가 API 키를 다룬다. 접근법만 참고해 우리가 필요한 부분만 새로 짠다.

## 5. 최소 진행 순서

1. (사용자) Sharadar 가입 — **무료 플랜(다우 30종)으로 스키마·키 먼저 확인**. 무료 키로는 벌크 불가.
2. (사용자) 어느 표가 어느 플랜에 들어 있는지 가입 화면에서 확인. **미확인**: `sp500`·`tickers` 가 Prices($9) 에 포함되는지. 포함 안 되면 Bundle $29.
   한 달만 받고 해지해도 로컬 parquet 은 남지만 **해지 후 보유·사용 조건은 약관 전문을 확인**해야 한다(이번엔 앞부분만 읽음).
3. (사용자) 키를 `.env` 에 `SHARADAR_API_KEY=` 로 저장.
4. (Claude) 작은 pull 스크립트 신설 — `tickers`+`sp500` 로 **S&P500 PIT 유니버스만** 먼저, 그 종목의 `SEP` 가격만 받는다(전체 2만 종목·952MB 는 나중).
5. (Claude) 사전등록 → S&P500 PIT 횡단면에서 30주선 기울기 가설 1개 검증. 전체 미국 종목으로 넓히는 것은 그 결과를 본 뒤.

## 6. 하지 않는 것

- 유료 구독·키 입력·가입을 Claude 가 대신하지 않는다.
- ChatGPT 요약의 "GitHub 에서 데이터 다운로드" 는 사실이 아니었다(코드만 있음) — 다운로드 경로로 계획하지 않는다.
- 이 조사로 방식 B 의 결과가 미리 나온 것은 없다. 데이터가 생기기 전에는 미국 개별주에 대한 판단을 하지 않는다.

## 7. 추가 조사 — MarketParquet · S&P500 구성 명단 저장소 (2026-09-21, 확인)

ChatGPT 요약("무료 샘플 + 전체 archive", "무료 데이터로 방식 B 검증 가능")을 원문 페이지와 대조했다.

### MarketParquet (marketparquet.com)
- **무료가 아니다**: 무료 샘플은 **최근 1년 일봉만**(API 60 req/min). 2000년부터의 이력·삭제 종목·분봉은 **Complete Archive $79 일회성**, 환불 없음. Keep Current $15/월은 선택.
  → "무료 샘플로 삭제 종목 포함 여부를 검증"은 불가능하다(삭제 종목은 과거 파일에만 있다).
- 주장: 23,000+ 종목(누적)·삭제 종목 포함·2000-01-03~2026-09-18, 종목 전부가 날짜별 파일 하나에 들어 있음.
- **스키마 한계**: `symbol` 문자열뿐 — 영구 식별자(permaticker 류)·상장폐지일·사유·발행주식수 **없음**. 티커 재사용 처리 방식은 **문서에 없다**(미확인).
  가격은 **분할조정만, 배당 미반영**(총수익 아님). 2026-03-27 이전 일봉은 `date` 대신 `timestamp` 열.
- **출처 불명·신생**: GitHub 계정이 2026-09-04 생성, 기여 7건. 데이터 원천(어느 벤더에서 왔는지) 언급 없음 — provenance 를 우리가 검증할 수 없다.
- **라이선스는 Sharadar 보다 관대**: 개인·내부 연구·상업 백테스트 허용, 파생 통계·차트·논문 게시 허용("원자료 재구성 불가한 집계"), 원자료 재배포·공개 호스팅 금지.
  → PUBLIC 저장소에도 요약 통계는 실을 수 있다(원자료·종목별 봉은 여전히 로컬 전용).

### S&P500 구성 명단 (확인)
- `fja05680/sp500` — **MIT**. 1996~2019 는 Clenow 책 부속 파일, 이후는 위키를 보고 **수동 갱신**. 티커만 있음. 유지자 본인이 "위키의 변경 목록은 불완전해 과거를 위키만으로 복원할 수 없다"고 적고, 삭제·변경 심볼용 가격은 **유료 데이터가 필요**하다고 명시.
- `chinobing/historical_sp500_constituents` — 자동 갱신(스크랩). 최근 이력에 **번복 흔적**이 있다(COIN 2025-05-13 편입→05-14 편출→05-17 편입, HOOD·EME·APP 09-06 편입→09-09 편출→09-23 편입). 자동 수집 노이즈로 보이며, 이걸 정본으로 쓰기엔 검증이 필요하다.
- 공통 한계: **티커 키만** 있어 삭제·개명 종목을 가격과 이을 때 (LEH→LEHMQ, BSC→BSC1 같은) 심볼 불일치가 난다. Sharadar `sp500` 표가 가격과 같은 심볼 체계라는 점이 그 자리를 푼다.

### 판단
- ChatGPT 의 단계 2("무료 가격 + 구성 명단으로 먼저") 는 **삭제 종목 가격이 없으면 결론을 못 낸다** — 생존자만으로 잰 30주선 효과는 편향 방향이 불분명해 통과해도 실패해도 근거가 안 된다. 파이프라인 예행연습 용도로만 가치가 있다.
- 비용 대비: MarketParquet $79 일회성 vs Sharadar Bundle $29/월. 라이선스는 MarketParquet 이 낫고, **식별자·PIT 구성·기업행동은 Sharadar 가 낫다.** 방식 B 가 PIT S&P500 을 요구하면 MarketParquet 은 명단(fja05680)과 티커로만 이어져 재사용·개명 검증이 우리 몫이다.
- 구매는 사용자만 한다(Claude 는 결제·가입·키 입력을 하지 않는다).
