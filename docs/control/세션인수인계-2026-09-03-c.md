## 2. ★ UI 경로 — 실험실 데이터는 **다른 페이지**다

사용자 질문("실험실 데이터가 UI에 추가된 게 따로 없나")으로 확인한 것.
한 번의 Pages 배포에 **두 사이트**가 들어간다(`deploy-pages.yml` 이 조립):

| 경로 | 소스 | 내용 |
|---|---|---|
| `.../stock/` (루트) | `docs/` | 운영 대시보드 — 종목점수·백테스트·ETF·공시·뉴스·시장수급·실시간·섹터강도 |
| `.../stock/paper-trading/` | `ui/` | Paper Trading Engine — **"리서치랩" 탭이 실험실 findings** |

실험실 데이터는 따로 추가하는 게 아니라 **자동으로 들어간다**:

```
research/strategy-lab/findings/*.md
  → research-lab-ui.yml (push 시 findings/** 구독 + 평일 17:00 KST 안전망)
  → build_ui_findings.py → ui/data/findings.json → /paper-trading/ "리서치랩" 탭
```

macro 도 같은 패턴(`macro-regime-ui.yml` → `ui/data/macro.json`). 둘 다
`deploy-pages.yml` 의 `workflow_run` 구독 목록에 있어 갱신되면 재배포까지 붙는다.

**커밋만 하고 push 를 안 하면 UI 에 안 뜬다** — 트리거가 `push` 다. 실제로
확인 시점에 `ui/data/findings.json` 이 263건인데 저장소 findings 는 264건이었다
(이번 세션 커밋이 아직 로컬에만 있던 상태). push 후 워크플로 자동 발동 확인.

참고: `docs/` 의 **섹터강도** 탭은 이 경로가 아니다 — `docs/data/prices.json`
을 읽는 관찰용 지표이고 findings 판정과 분리해 만든 것이다.
