## 2. Tier 1.5 (거래 단위) — 초안 기각

`findings/portfolio-exit-policy-validation-2026-09.md`

기존 `simulate_exits.py`(엔진 `executor.py` 청산규칙을 옮겨온 도구)에 **무작위
진입 대조군**(`--random-entries`)만 추가해 격자를 돌렸다. 진입 5종(무작위
seed 0·1·2 + pbr + earnings_yield) × TRAIN/VALID/TEST = 15셀, 셀당 60점.

- 초안(2×ATR/RR3.0/21일)은 15셀 평균 **21.3위 / 60점**
- **TRAIN 최선을 들고 나가면 VALID 에서 60/60·58/60·53/60위.** 무작위 진입에서
  TRAIN→OOS 순위상관 -0.117 / +0.234 / +0.004 — 종목선택을 빼면 TRAIN 은 청산
  파라미터를 예측하지 못한다
- 격자를 넓히면 ATR 배수 2.0→9.0 으로 단조 개선 = **"손절 없음"으로 수렴**
- 정면비교(42일): 무손절 +0.739% vs 손절2×ATR+RR3 +0.387%, 평균손실은
  -11.25%→-7.87%. **기대값 절반을 팔아 꼬리 30% 를 산다**

당시 결론: "손절의 근거는 수익이 아니라 꼬리 축소뿐이다."
**그리고 스스로 한계를 적었다 — 거래 단위로는 포트폴리오 MDD 를 못 잰다.**

## 3. Tier 2 (실제 엔진) — 앞 결론이 뒤집혔다

`findings/portfolio-tier2-exit-sizing-2026-09.md`

(CAGR / MDD / Sharpe)

### ★ 두 계층이 반대인 이유는 슬롯이다

Tier 1.5 는 손절이 기대값을 **절반**으로 깎는다고 했는데 Tier 2 에서는 CAGR 을
**올린다**(5.49→9.14%). 모순이 아니다 — 거래 단위 통계에는 **자본 재투입이 없다**.
실제 엔진에서는 손절이 슬롯을 비우고 다음 후보가 들어간다(pbr 청산 777→2,079건).

5DC VIX 정제필터에서 겪은 "슬롯 경쟁이 오프라인 결론을 뒤집는다"의 **반대 방향
사례**다. 그때는 오프라인이 과대평가했고 이번엔 과소평가했다.

### 두 계층이 유일하게 일치하는 항목
**손절만 걸고 목표를 안 걸면 최악**(D). 세 전략 모두 무손절 A 보다 나쁘고
Tier 1.5 에서도 최악이었다. 목표가는 장식이 아니다.

### 격자 경계를 이번엔 닫았다 (pbr)

손절 축(RR1.5 고정): 3×ATR Calmar **0.714** > 4×ATR 0.640 > 6×ATR 0.491.
CAGR·Sharpe 는 4×ATR 에서 꺾이고 MDD 는 넓힐수록 단조 악화.

손익비 축(3×ATR 고정): RR 0.5 → 0.75 → **1.0** → 1.5 → ∞ 에서
Calmar 0.160 → 0.484 → **0.735** → 0.714 → 0.395.
**두 축 모두 내부 최적점** — CAGR·Sharpe 는 RR1.5, MDD·Calmar 는 RR1.0.

### 사이징 — 기각
균등위험 사이징은 수학적으로 **역변동성(1/ATR%) 가중**이다(수량 ∝ 1/손절폭 →
금액 ∝ 진입가/손절폭). 청산을 C 로 고정하고 비중만 바꾸니:

| pbr | CAGR | MDD | Sharpe | Calmar |
|---|---|---|---|---|
| 균등금액 | **9.14%** | **-12.80%** | **0.7318** | **0.714** |
| 균등위험 | 7.35% | -14.07% | 0.6473 | 0.522 |

네 지표 전부 악화. 2026-08-26 역변동성 실험("사실상 무승부")과 방향 일치.

## 4. ★ 다음 세션의 1순위 — OOS 검증

**Tier 2 는 전 구간(2016~2026)을 한 번씩만 돌렸다.** Tier 1.5 가 보여준 가장 강한
결과가 "TRAIN 최선이 VALID 60/60위"였다는 걸 기억할 것 — **구간을 쪼개 같은
순서가 유지되는지 보기 전에는 채택 근거가 아니다.**

방법은 이미 준비돼 있다: `tier2_exit_policy.py --start/--end` 로 구간을 잘라
A·C·(3.0:1.0) 세 점만 TRAIN/VALID/TEST 로 돌리면 된다. 실행당 약 8~14분,
9회면 끝난다. 판정 기준은 이 프로젝트 표준 — **부호 반전 0건 + TRAIN 최선이
VALID·TEST 에서도 상위 유지**.

그게 통과하면 그때 PF-1.1 로 값을 확정하고 registry 등록(🔴 사용자 GO 필요).
통과 못 하면 Tier 1.5 결론("손절은 선언적 위험 상한일 뿐")으로 돌아간다.

## 8. 사용자가 원래 물은 것에 대한 현재 답

> "종목별로 얼마면 사도 되고 얼마면 팔아야 하나, 손절가는 얼마고 얼마나 오르면 파나"

- **손절가·목표가**: 규칙으로 낼 수 있고 실제로 냈다(`trade-levels.json`).
  단 **어느 배수가 맞는지는 OOS 검증 전까지 확정 못 한다.**
- **얼마나 살까**: 균등위험 사이징은 **기각**됐다. 균등금액이 낫다.
- **얼마면 사도 되나(진입가)**: `entryZone: null` 로 남겼다. 손절·목표가 ATR 비례라
  R:R 이 진입가와 무관하게 일정해서 산술적으로 진입 상한이 안 나오고, 진입 타이밍
  규칙은 이 프로젝트가 5개 후보에서 이미 다 닫았다. **지어내지 않았다.**
