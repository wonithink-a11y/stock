# 데이터 인벤토리 — 실험실/OpenCode 위임용 (2026-09-12)

★ **대부분 로컬 전용이다.** `research/strategy-lab/data/**/*.parquet` ·
`data/**/*.pkl` · `research/strategy-lab/.cache/` 전부 gitignore 대상이라
**GitHub에는 없고 이 로컬 저장소에만 있다**(`research/strategy-lab/.gitignore`
확인). OpenCode를 이 로컬 머신에서 돌리면(`opencode.cmd run`, 프로젝트 루트
기준) 그대로 보이지만, 다른 환경(클론·새 워크트리·클라우드 실행)에는
아무것도 없다 — 필요하면 각 항목의 "재현 스크립트"로 다시 받아야 한다.
`data/backfill/`(KR 메인 스코어링)만 예외로 GitHub Actions가 커밋해 저장소에
실제로 들어있다.

각 항목: **경로 · 커버리지(종목/기간) · 형식 · 출처 · 재생성 스크립트(있으면)**.

## 사용 시 주의

1. **위 목록 대부분이 로컬 전용**(§ 서두 참고) — OpenCode를 이 머신이 아닌
   곳에서 돌리면 못 본다.
2. **선물 lead-lag(§2 KR 선물)와 VAA/GEM류 국면필터(§5 VIX)는 이미 이 프로젝트가
   시도해서 기각한 라인과 겹친다** — 새로 실험을 맡기기 전에 관련 findings
   부터 훑는 걸 권한다(중복 재탐색 방지).
3. 크립토·미국ETF는 전부 무료 소스(업비트·바이낸스·yfinance)라 재수집
   비용이 낮다. KR 메인 파이프라인(§3 data/backfill)은 DART·KIS 호출량 제한이
   걸려 있어(절대 규칙과 무관하게) 대량 재수집 전 확인이 필요하다.
