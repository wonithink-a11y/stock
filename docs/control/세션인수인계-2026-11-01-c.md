## 4. 함정 (이번에 물린 것)

- **실데이터 dry-run 이 단위 테스트가 못 잡은 버그 3개를 잡았다**: 매수 수량 8자리 미반올림(테스트 시세가 round 라 숨음) · 밴드 고정 5%p 라 목표 5% 미만 코인은 영영 안 삼 · 한 글자 코인(`KRW-G`) 정규식 거부. 새 전략·거래소는 반드시 공개 API 실데이터로 dry-run 해 본다.
- **24시간 거래대금 순위는 그날 급등 코인과 USDT 가 지배**(BTC 5~8%). 스테이블 제외·N일(30일) 평균·코인별 상한이 필요했다.
- 업비트 공개 시세 `ticker?markets=` 를 코인 수백 개로 부르면 **414(URI too long)** — 100개씩 나눈다. 일봉은 코인마다 1회 호출(월 1회 선정 때만, 0.12초 간격).
- `SameSite=Strict` 쿠키는 다른 사이트 링크로 들어올 때 빠져 세션이 살아 있어도 로그인 화면이 뜬다 → Lax.
- 이름의 극성: "킬 스위치 켜짐"=주문 멈춤이라 "자동주문 켜짐"과 반대 — 그래서 **긴급 정지 중 / 정상** + 자동주문 켜짐·꺼짐 칩으로 분리.
- **VM `.env` 키 이름**: 프로필은 주문 전용 `<접두사>_ACCESS_KEY` 만 읽고 조회용 이름은 못 고른다(`autotrader-web` 은 키 없음). 손으로 시험할 땐 `AUTOTRADER_ENV_FILE=~/collector-venv/.env` 를 붙인다.
- 도구: bash heredoc 에 한글·따옴표가 섞이면 "unexpected EOF" 가 난다 → 파일은 Write 로 쓰고 실행만 bash. `cd` 한 디렉터리가 다음 호출에 남는다(항상 저장소 루트로 `cd`). `gh pr merge` 는 사용자가 그 턴에 명시하지 않으면 자동 권한 확인이 막는다 — 사용자가 병합했는지 `gh pr view N --json state` 로 확인한다.
