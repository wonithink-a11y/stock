# 읽기 전용 검토 지시문 틀

출처: 주식 공동분석규격 v1 §9(2026-10-18). Claude·OpenCode 에 **읽기 전용 검토를 맡길 때만** 붙이는 작업 단위 틀이다.
프로젝트 기본값이 아니다 — 평소 변경·실행·커밋은 CLAUDE.md 승인 등급을 따른다.
증거 등급·출처 필드의 정의는 `docs/AI협업-업무분담.md` §4.3.
OpenCode 에 넘길 때는 opencode.cmd 가 첫 줄만 넘기므로 이 틀을 채운 파일을 만들고 한 줄로 가리킨다(`opencode-지시문-2026-09-05.md`).

```text
작업 모드: READ-ONLY REVIEW
저장소: wonithink-a11y/stock

목표:
[질문 한 문장]

범위:
[대상 경로·데이터·기간]

공통 분석 규격:
1. 먼저 실제 저장소의 지침과 관련 파일을 읽고, 확인한 경로와 근거를 보고하라.
2. 목표·기준일·기간·자료 출처·산출물·완료 기준을 먼저 명시하라. 모호한 핵심 조건은 추정하지 말고 질문하라.
3. 사실, 재현된 계산, 해석, 미확인 사항을 분리하라.
4. 수치마다 출처·기준일·단위·기간을 기록하고, 핵심 수치는 원천과 독립 대조하라.
5. 재무 데이터는 연결/별도, 분기/누적, 공개일/결산일, 단위, 정정 공시를 구분하라.
6. 과거 시점 분석은 point-in-time 기준을 지키고 미래정보 누출 여부를 확인하라.
7. 결측을 0으로 대체하지 말고, 접근 실패를 성공으로 보고하지 말라.
8. 반대 근거와 실패 시나리오를 확인하라.
9. 결과는 PASS / PASS WITH LIMITATIONS / BLOCKED / NOT RUN 중 하나로 판정하고, 통과하지 못한 항목을 명시하라.
10. 이 요청에서는 파일을 수정하지 말고, 데이터 쓰기·실행·커밋·푸시도 하지 말라. 변경안은 제안으로만 제출하라.

완료 보고:
- 확인한 파일과 근거
- 결론 및 확실성
- 수치/출처 대조표
- PIT·무결성·계산 검증 결과
- 미확인 항목과 위험
- 권장 다음 단계
```
