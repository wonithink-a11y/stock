이번 세션은 `lib/a5/`·`config/policies/fundamentals.v1.json`(a3d 블록 신설,
FN-1.7→FN-1.8)·`.github/workflows/fundamentals-a3d.yml`(신규)를 수정했다 —
전부 커밋·푸시 완료. **실제 DART API 실행(collect)은 사용자 사전 확인 후 총
7회**(스모크 5회 + finalize 시도 1회 + 전체 실행 1회) 진행했고 매번 결과를
`gh run view`/`gh run download`로 실측 확인했다. `data/backfill/`에 로컬
커밋은 없다(전부 GitHub Actions 산출물, 규칙 4 준수) — 단 각 스모크가 남긴
`_shards_a3d/` 진행 상태는 GitHub Actions 봇이 자동 커밋했고, 다음 재실행 전에
매번 삭제해 재실행이 옛 버그의 결과를 "완료됨"으로 건너뛰지 않게 했다.
VM(`ssh stock`)에는 서비스 정지(`systemctl stop`) 1건만 실행 — 사용자가
명시적으로 요청했다("할일없으면 정지해줘"). credential은 어디에도 노출되지
않았다(DART_API_KEY는 로컬 `.env`·GitHub Secrets에서만, OpenCode에 전달 안 함).
