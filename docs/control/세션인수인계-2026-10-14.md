## 5. 함정

- **폰 브라우저가 옛 CSS 를 계속 쓴다** — `ui/index.html` 의 `style.css?v=…`·`scoring.js?v=…` 버전을 **고칠 때마다 올린다**(현재 `20261014d`). 대시보드는 CSS 가 index.html 안이라 해당 없음.
- **같은 선택자의 기본 규칙이 미디어 쿼리보다 뒤에 있으면 덮어쓴다** — 이번에 세 번 물렸다(모의투자 `.sitenav`, 마감 리포트 `.mrep-head p`, 홈 표 `#content td`). 폰 규칙은 기본 규칙 **뒤에** 두거나 선택자를 더 구체적으로.
- 로컬 미리보기에서 홈 지표 띠·마감 리포트를 보려면 `docs/data/market-reports/` 를 임시로 만들어야 한다(배포 단계가 복사) — 보고 나서 **반드시 지운다**(`docs/data/` 는 Actions 몫).
- `deploy-pages` 배포 뒤 확인은 `curl …?t=$(date +%s) | grep -c <새 코드 조각>`.
- 매매 웹 데모 로그인은 `scripts/autotrader-web-demo.py` 의 가짜 세션(쿠키 `at_sess=demo`).
