# 전달 문서 — electric 앱에 전기 관련 법령 링크 넣기 (2026-11-13)

> 이 문서는 stock 프로젝트 세션에서 만들었다. **electric 저장소(`wonithink-a11y/electric`) 세션**에서 읽고 작업한다. stock 코드는 건드리지 않는다.

## 목표
electric 앱(전기설비 유지보수 달력·현안 앱, GitHub Pages)의 **법정검사·현안·점검 항목에서 관련 법령 조문으로 바로 이동하는 링크**를 단다.
대상 법령(사용자 지정, "등"이라 목록은 상수 하나로 늘릴 수 있게):
전기안전관리법 · 전기안전관리법 시행령 · 전기안전관리법 시행규칙 · 전기사업법 · 전기사업법 시행령 · 전기사업법 시행규칙

## 배경 — 왜 링크 방식인가
- 처음엔 한국 법령 MCP 커넥터를 앱에 붙이려 했다. **불가**: electric 은 서버·AI 가 없는 정적 PWA 라 MCP 를 붙일 곳이 없다.
- 앱 안 검색·요약(공개 MCP 서버를 브라우저에서 직접 호출)은 CORS 허용 여부를 **확인하지 못했고**, API 키를 코드에 넣으면 공개 저장소에 노출된다 — 이번 범위에서 제외.
- 그래서 **서버·키가 필요 없는 국가법령정보센터 링크**만 한다.

## 확인된 사실 (stock 세션에서 직접 열어 봄)
- `https://www.law.go.kr/법령/전기안전관리법시행규칙` → 정상 로드(페이지 제목 = 법령명).
- `https://www.law.go.kr/법령/전기사업법/제7조` → 정상 로드(제목 = 전기사업법).
- **법령명은 공백 없이** 붙인다(시행령·시행규칙도 `전기안전관리법시행령` 식). 주소의 한글은 브라우저가 알아서 인코딩하므로 `href` 에 한글을 그대로 써도 되지만, 코드에서 만들 땐 `encodeURIComponent` 를 쓴다.
- **미확인**: 조문 주소가 해당 조문 위치로 스크롤하는지(페이지 제목 로드만 봄) · 항·호 단위 이동 · 개정 이력 주소. `제N조` 까지만 쓰고, 항·호는 텍스트로 적는다.

## 요구사항
1. 법령 목록을 **상수 한 곳**에 둔다(이름 → 표시명). 새 법령 추가가 한 줄이어야 한다.
2. 항목(법정검사·현안·점검)에 **선택 입력 "관련 조문"** 칸: 법령 선택 + 조문 번호(예: `제7조`, 비워도 됨) → 저장하면 항목 카드에 링크가 보인다.
3. 링크는 **새 탭**으로 열고 `rel="noopener noreferrer"` 를 붙인다.
4. 폰 폭(375px)에서 가로 스크롤·글자 잘림이 없어야 한다(사용자는 폰으로 많이 본다).
5. 기존 데이터는 **그대로 동작**해야 한다 — 관련 조문이 없는 옛 항목이 깨지면 안 된다(필드가 없으면 링크를 그리지 않는다).

## 하지 말 것
- **서버·API 키·외부 호출을 넣지 않는다.** 링크만이다. 키가 필요하면 멈추고 사용자에게 묻는다.
- **저장 형식(브라우저 저장소 스키마)을 깨지 않는다.** 필드 추가만 하고, 기존 필드 이름·구조는 바꾸지 않는다. 사용자의 업무 데이터가 브라우저 안에만 있다 — 잃으면 복구가 어렵다. 스키마를 건드리는 변경은 먼저 사용자에게 말한다.
- **`index.html` 전체를 읽지 않는다**(약 600KB). `grep` 으로 구간만 본다.
- 법령 **본문을 앱에 복사해 넣지 않는다**(링크만).
- 회사 업무 데이터·내부 설비 정보를 커밋하거나 공개 저장소에 올리지 않는다(저장소가 공개다).

## 작업 순서 (권고)
1. 항목 데이터가 어떤 모양인지부터 본다(`grep` 으로 법정검사·현안 입력 폼과 저장 코드 위치 확인).
2. 법령 상수 + 링크 생성 함수(작게) → 입력 칸 → 카드 표시 순서로 넣는다.
3. 폰 폭에서 확인한다.
4. `service-worker.js` 의 캐시 이름(버전)을 올려야 설치된 앱이 새 버전을 받는지 확인한다(이미 쓰고 있으면 올린다).
5. 커밋 전에 **되돌리는 방법**을 한 줄로 적는다.

## 완료 기준
- 법정검사 항목 하나에 `전기안전관리법` + `제7조` 를 넣고 저장 → 카드의 링크가 `https://www.law.go.kr/법령/전기안전관리법/제7조` 로 새 탭에서 열린다.
- 관련 조문이 없는 기존 항목은 화면과 동작이 그대로다.
- 폰 폭에서 가로 스크롤이 생기지 않는다.

## 사용자에게 확인할 것
- 링크를 달 항목 종류: 법정검사만인지, 현안·점검도 포함할지.
- 대상 법령에 더 넣을 것이 있는지(예: 전기설비기술기준은 법이 아니라 고시라 주소 형식이 다를 수 있음 — 넣을 때 확인).
