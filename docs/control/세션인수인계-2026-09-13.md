## 4. 이번 세션에서 확인한 재사용 가능한 함정/사실

- **data.go.kr 서비스키는 이미 URL-인코딩돼 있다** — `urlencode()`에
  같이 넣으면 이중인코딩으로 깨지고, 그 결과가
  `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`로 오진되기 쉽다(활용신청은
  이미 승인 상태였음). serviceKey는 분리해서 raw로 붙인다.
- **관세청 품목별 수출입실적(GW) API는 조회기간 1년 제한**
  (`resultCode 99`) — 연도별로 쪼개 호출해야 한다.
- **HS 8542.32 하위 10자리**: 1010=디램, 1020=에스램, 1030=플래시메모리
  (NAND), 3000=복합구조집적회로(HBM 후보, 전용 코드 아님), 4000=MCOs.
  이 10자리 체계는 **2007-01 이전 데이터가 없다**(실측, 그 이전 연도는
  전부 0건).
- **한국은행 ECOS(생산자물가지수 404Y016)에는 "D램" 단독 품목이 없다**
  (플래시메모리만 있음) — 관세청 HS 분류와는 다른 얘기, 혼동 주의.
- **낮은 별점(0~1) + 커밋 공동저자 "claude" + llms.txt 포함 GitHub
  저장소는 데이터 소스로 반려한다** — AI가 인용하도록 설계된 콘텐츠일
  가능성이 있고 독립검증(peer review) 없음.
- **다중검정 보정은 가설을 정하기 전(오늘 안에 시험한 전체 조합 수)을
  family로 잡아야 정직하다** — "이 관계 하나에 대한 3개 로버스트니스
  체크"로 좁혀 잡으면(m=3) 전부 생존하지만, 실제로는 그날 돌린 162개
  조합 중 하나를 사후에 짚은 것이므로 m=162가 맞는 분모다.
