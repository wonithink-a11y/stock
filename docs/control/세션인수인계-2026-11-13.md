## 4. 결정
- **새 Oracle 계정·가족 명의 가입은 하지 않는다.** 근거: 1인 1무료 계정 규정·다중 계정 시도 금지 · 연락처·결제 정보는 정확해야 하고 본인 동의 아래 사용 · 종료 우회로 읽힐 위험 · 같은 IP·PC·카드 연결로 재종료 가능. (사용자가 두 번 물었고 두 번 같은 답.)
- **24시간 서버는 지금 만들지 않는다.** 규칙 9(무료 우선). 필요해지는 시점은 **실매매 직전**(주문 뒤 PC 가 꺼지면 손절·청산 불가) — 그때 새 업체를 월 정확한 금액으로 비교해 사용자 확인. 참고값: 구글 e2-micro 외부 IPv4 월 약 $3.6(11-07 공식 가격 확인, 재확인 필요).
- 지금 구성: 알림 = Workers(`stock-alerts`) · 자동매매 웹 = 이 PC · 백업 = `C:\Users\User\stock-backup\gcp\`. 분봉은 PC 를 켠 날 KIS 보관(~246영업일) 안에서 따라잡는다(11-11 인수인계 §3).
- 사용자가 안 보는 것: 뉴스·장중 알림은 많이 와서 안 보고, 회사 업무 중 텔레그램도 못 본다. 지키고 싶은 것은 **모의매매→실매매 연결**. 뉴스·장중 알림을 끌지 줄일지는 **미결정**(사용자: "나머지는 일단 그대로").
