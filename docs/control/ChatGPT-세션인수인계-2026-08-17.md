## 5. 현재 ChatGPT가 다음 세션에서 우선 할 일
1. 사용자가 묻는 현재 프로젝트 상태는 실제 저장소 기준으로 다시 확인.
2. A2b 임계값 문제와 5DC 연구는 별도 트랙으로 유지.
3. 5DC 결과를 추가 최적화하기 전에 데이터 표본·PIT·survivorship·거래 데이터 정합성을 우선 검토.
4. AI Lab에서 종가매매/다른 매매법을 연구할 경우 필요한 데이터와 수집 경로를 설계:
   - OHLCV/거래량
   - corporate action/adjustment
   - 상장·폐지 및 거래정지 이력
   - 재무/공시 PIT 데이터(재무 기반 전략인 경우)
   - 시장/지수/섹터 데이터
   - 수급 데이터(전략에서 사용하는 경우)
   - 비용·슬리피지·세금·체결 가정
   - 종목 유니버스의 historical reconstruction
   - 데이터 provenance와 관측일(as-of) 정보
5. 새로운 전략 연구는 먼저 연구용 데이터 계약과 백테스트 정의를 정한 뒤 실행. production 정책으로 자동 승격하지 않음.
