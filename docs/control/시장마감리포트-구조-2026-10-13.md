# 장 마감 리포트 — 현재 구조 한 장 (2026-10-13)

시각화 설계를 위한 현황표다. 설계안이 아니라 **지금 무엇이 있고 어디에 있는가**만 적는다.

## 1. 흐름

```
[코드] scripts/market-close-facts.py ──→ reports/market-daily/<날짜>-<kr|us>.facts.json   (구조화된 숫자 + 뉴스 후보)
                                              │
[Claude 루틴] 지시문을 읽고 해석 ──→ reports/market-daily/<날짜>-<kr|us>.md        (일반 텍스트 리포트)
                                              │ git push
                    ┌─────────────────────────┴─────────────────────────┐
     market-report-telegram.yml (1분 안)                        deploy-pages.yml (1~2분)
     → 텔레그램 1:1 방, md 원문 그대로                            → 대시보드 '오늘 > 마감 리포트' 탭, md 원문을 <pre> 로
```

| 종류 | 실행 | 다루는 장 | 지금 쌓인 것 |
|---|---|---|---|
| kr | 평일 18:10 KST | 오늘 한국 정규장 | 10-06·07·08·12 (백필) |
| us | 평일 07:00 KST | 직전 미국 정규장 + 오늘 한국장 체크 | 10-06·07·08·09·12 (백필) |

리포트 1편 = 2,600~3,100자, 섹션 7~8개.

## 3. facts.json 필드 (실제 키)

공통: `market` · `generatedAtKST` · `expectedSession` · `sessionOpen` · `regularSessionEnded` · `backfill` · `missing[]` · `repoData[]` · `news{window, items[]}`

```
series[] (kr 18개 · us 28개)
  {sym, name, group, kind(regular|around), close, prevClose, chgPct, chg5dPct, chgBp(금리만),
   barDate, lastTradeKST, fresh, source}
  group  kr: 지수 · 업종ETF(15) · 환율 · 미국선물
         us: 지수(5) · 시장폭(SPY,RSP) · 섹터(11) · 한국연결(EWY) · 위험(VIX) · 금리 · 환율 · 원자재 · 크립토 · 미국선물

kr.{KOSPI,KOSDAQ}      tradingValue조원 · breadth{상승,상한,보합,하락,하한} · flows억원{개인,외국인,기관}
                       · program억원{차익,비차익,합계} · topByMcap[{code,name,chgPct,mcap조원}] (10개) · marketStatus · fresh
us2y                   {date, value, chgBp}            (FRED, 하루 늦음)
afterHours[]           {sym, regularClose, regularChgPct, ahLast, ahTimeET, ahChgPct}   (대형 기술주 8 + 추가)
news.items[]           {pubKST, title, link, query}    (그날 00:00 ~ 리포트 시각, 최대 60)
```

## 5. 시각화해도 지켜야 할 규칙 (지시문에서)

- 숫자는 facts.json 것만. 새 비율·합계 금지(두 값의 차·순위 정렬만 허용)
- **종목별 지수 기여도 수치 금지**(비중 데이터 없음) — 시총·등락률만
- 정규장 등락과 시간외 등락을 더하지 않는다(따로 표시)
- `fresh: false` 값은 날짜를 붙이거나 빼고, `missing` 은 "수집 안 됨"으로 보인다
- 원인은 확신도(높음·중간·낮음)와 반대 증거를 같이. 근거가 부족하면 "원인 미확정"
- 가격 목표·확률 숫자·매수/매도 권유 금지. 백필은 사후 지식 금지

## 6. 시각화할 때 걸리는 지점 (사실)

1. **원인 절(4)은 글뿐이다** — 원인·확신도·근거 시각·반대 증거가 구조화된 필드로 저장되지 않는다. 카드·타임라인으로 그리려면 루틴이 별도 JSON 을 써야 한다.
2. **facts.json 이 대시보드에 배포되지 않는다** — 차트를 그리려면 deploy-pages 가 함께 복사해야 한다(한 줄 추가).
3. 시계열은 5일 등락 하나뿐 — 스크립트는 Yahoo 일봉 3개월을 받지만 저장하지 않는다.
4. 장중 흐름(분 단위 지수 경로)은 없다 — "뉴스 시각 vs 가격 움직임" 대조를 그림으로 보이려면 장중 지수 데이터가 새로 필요하다.
5. 텔레그램은 지금 글만 보낸다. 이미지(차트 PNG) 발송은 가능한 API 지만 구현돼 있지 않다.
