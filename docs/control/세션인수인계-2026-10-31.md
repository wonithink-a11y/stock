## 4. 함정

- **VM 명령은 반드시 `ssh -t stock-new "…"` 한 줄로 준다**(맨몸 `sudo` 를 3번 줘서 사용자가 PowerShell 에 붙였다 — 메모리 강화).

- Cloud Shell 은 FIPS 모드 — ed25519 키 생성 거부, RSA 4096 으로.
- 업비트 종료 주문 조회는 한 번에 최대 7일 — 어댑터가 나눠 부른다.
