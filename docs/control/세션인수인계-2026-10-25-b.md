## 5. 함정

- 지금 방들은 **일반 그룹**이다. 슈퍼그룹으로 업그레이드(토픽 켜기 포함)하면 방 ID 가 `-100...` 으로 바뀌어 알림이 끊긴다. 끊기면 `getUpdates` 로 ID 를 다시 확인해 `.env`·Secrets 갱신.
- 폴백 때문에 ID 를 빼먹어도 에러 없이 1:1 방으로 간다 — 조용히 틀린다. 안 나뉜 것 같으면 먼저 의심.
- 8-K 는 급등락 방으로 간다(급한 알림으로 분류). 이름이 어색하면 방 이름만 바꾼다(ID 불변).
- 봇 토큰·`getUpdates` URL 은 채팅·저장소에 붙이지 않는다.
- 영상 요약 방은 Actions 에 등록하지 않는다(VM 전용).
