## 함정
- 터미널 패널은 **탭마다 PowerShell 변수가 따로**다(`$t` 를 다른 탭에서 못 씀 → 텔레그램 404). 명령은 한 줄로 합쳐 한 탭에서.
- 텔레그램 봇은 그룹방에서 슬래시 명령(`/hello@봇이름`)만 받는 경우가 많아 `getUpdates` 가 비었다. 채널이면 `channel_post`.
- Termux 시간대가 한국이 아니라 로그가 12시간 어긋났다(`TZ=Asia/Seoul` 로 고침). `termux-setup-storage` 에서 y/n 질문 중 여러 줄 붙여넣기 금지.
- Git Bash 가 `/autotrader/` 같은 선행 슬래시 인자를 Windows 경로로 바꾼다 → sparse-checkout 시험은 `MSYS_NO_PATHCONV=1`. 파이썬 heredoc 안의 `C:\Users` 는 `\U` 유니코드 오류 — 긴 문서는 파일로 쓰고 읽어 붙인다.
- `test-glance-calc.js` 는 이 PC 작업 사본이 CRLF 라 정규식이 실패한다(저장소는 LF, LF 로 바꾸면 28/28) — 기존 현상.
- 테스트의 가짜 시각이 실제 `Date.now()` 보다 미래면 확인(ack) 시각 비교가 틀어진다 — `Date.now` 를 같이 가짜로.
- 업비트 약관: 허용 IP 에서만 사용, 위험 IP 는 등록 거부 가능. 해외 IP 금지 문구는 못 찾았고 KIS 해외 서버 정책은 공식 문서에서 못 찾았다(미확인).
