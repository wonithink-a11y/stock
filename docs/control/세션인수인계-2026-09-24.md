## 6. 실수·함정

1. **`python - <<'EOF' ... < /dev/null`** — heredoc 과 `< /dev/null` 이 충돌해 stdin 이 비고 Python 이 대화형 모드로 무한 대기
   (2회). 인라인 스크립트는 **파일로 쓰고 실행**한다.
2. **rebase `--autostash` 충돌** — 원격 자동 커밋이 사용자 로컬 변경 파일(`ui/data/macro.json`)을 같이 갱신해 UU. stash 원본으로
   복원 + `git hash-object` 대조로 원상 확인. 메모리 `feedback-no-git-commit-a` 에 예방 절차 추가. `stash@{0}` 에 보존본 남아 있음.
3. Git Bash `TZ=Asia/Seoul date -d` 는 시간대를 못 읽어 UTC 로 계산 — 시각은 `date -d '...+09:00'` 로 쓴다.
4. 로컬에서 만든 `docs/data/*.json` 은 커밋하지 않는다(쓰기 권한 = Actions). 로컬 검증 뒤 지웠다.
