## 4. 코인베이스 프리미엄 z — "한 시간에 한 번이어야 하나?" (사용자 질문, 답)

- 정의(동결 20401a4): P(T) = 정각 T 에 끝난 **1시간 봉** 종가 비(코인베이스 BTC-USD / 바이낸스 BTCUSDT), z = 직전 720시간(최소 360) 평균·표준편차 기준. 연구(C24 ECONOMIC·강건성 PASS)·모의 슬리브·실계좌 dry 가 전부 이 정의다.
- **같은 정의로 더 자주 돌려도 z 는 다음 정각까지 안 바뀐다** — 이득은 지연 단축뿐인데 지금도 :02(봉 마감 2분 뒤) 실행이다.
- **5분·1분 봉으로 z 를 다시 정의하는 것은 다른 신호**다(분포·창·잡음이 다름, 미검증). 판정 전(청산 40건) 동결 규칙을 바꾸면 모의 원장이 판정 정본 자격을 잃는다 → 하려면 새 사전등록·백테스트·별도 forward.
- 바꿀 만한 것은 하나: 코인베이스 봉이 늦게 와서 `T 의 P 가 아직 없으면` 다음 실행(1시간 뒤)으로 밀려 30분 한도로 '놓침'이 되는 경우 → **:12·:22 재시도 실행 추가**(정의 불변, 운영 변경). 먼저 VM `~/collector-venv/cbprem-paper/runs.jsonl` 에서 놓침·지연 건수를 보고 필요하면 한다(새 타이머 = 사용자 설치).
