실제 폐지 종목으로 시험했다. 동기: EDGAR(companyfacts·submissions)로 미국 PIT 재무·공시가 무료로 풀리는 것을 확인했고

## 0. 결론

**Tiingo 무료 계정이 2016년 이후 S&P500 PIT 가격의 현실적 경로다.** 2010~2015 는 구멍이 커서 쓰지 않는다.
단 (1) 실제 API 가 폐지 종목 이력을 무료로 주는지는 **키가 없어 미확인** — 가입은 사용자 몫,
(2) 개명 종목은 티커가 아니라 **EDGAR CIK 로 이어야** 하고, (3) 구성 명단(fja05680)은 위키 기반이라 검증이 필요하다.

## 3. 판단

- **2016~ 는 가능, 2010~2015 는 불가**(폐지 종목 약 40개 결손 = 생존편향이 그대로 남는다). 한국 연구 창과 비슷한 길이라 첫 검증 창으로 충분하다.
- 필요한 종목 수: 2016 이후 S&P500 에 있었던 종목 ≈ 현재 500 + 편출 약 300 → 무료 한도(월 500종목)로 **두 달**, 또는 유료 1개월.
- 티커 재사용(MON: 2000~2018 몬산토, 2021~ 다른 회사)·개명은 **EDGAR CIK** 로 잇는다 — 이번 조사로 EDGAR 가 재무뿐 아니라 식별자 문제도 푼다는 점이 확인됐다.
- Sharadar(월 $29, PIT 구성·영구 식별자 포함)와 비교: Tiingo 무료 + EDGAR + fja05680 은 돈이 안 드는 대신 **연결·검증이 우리 몫**이다.

## 4. 다음 단계 (사용자 결정)

1. (사용자) Tiingo 무료 가입 → 키를 `.env` 에 `TIINGO_API_KEY=`. Claude 는 가입·키 입력을 하지 않는다.
2. (Claude) 키로 10종목만 찔러 본다: SIVBQ·TWTR·BRCM·META(FB 이력 포함 여부)·MON(재사용) 등 — §2 의 미확인 두 가지(폐지 이력 무료 제공·개명 이력 위치) 확정.
3. 통과하면 새 외부 데이터 소스 통합(확인 대상) → 수집 설계 → 사전등록 → PBR 미국 재검증.

## 5. 무료 키 실측 (2026-09-26, 13개 종목 사용 — 월 500 한도)

| 종목 | 결과 |
|---|---|
| SIVBQ · BBBYQ | **파산 종목 전체 이력 받음**(2010~, 파산 후 장외 거래까지) |
| TWTR · CELG | **인수합병 폐지 종목 받음**(2013~2022 · 2010~2019) |
| META · RTX | **개명 종목은 새 티커 아래 옛 이력까지 있음**(META 2012-05-18 상장일부터 = FB 기간, RTX 1970~ = UTX 기간) |
| FB · UTX | 옛 티커로는 없음(UTX 404 · FB 는 지금 **다른 ETF** 를 가리킴) |
| MON(2015~2018 요청) | **빈 응답** — 티커가 재사용되면 API 는 최신 증권만 준다. 옛 몬산토에는 닿을 수 없다(목록엔 있는데) |
| BRCM | 2016-01-04~02-09 26봉뿐(§2 의 앞부분 잘림 그대로) |

**2016년 이후 S&P500 편출 250건 재분류**(목록의 최신 행 = API 가 주는 행):
- API 로 바로 받음 **188 (75%)**
- 목록 매칭 없음 **45 (18%)** — 대부분 개명(META·RTX 로 확인한 패턴). CIK → 현재 티커로 이어야 한다. 일부는 진짜 결손.
- **티커 재사용으로 API 불가 17 (7%)** — MON·옛 DOW·EMC·옛 SNDK·STI·CA·SPLS·ADT·APC·DNB·DO·FTR·INFO·NFX·POM·SE·CSRA.
  전부 **인수합병·분할로 사라진 회사**다(파산 없음). 원래 티커를 문의로 풀 수 있는지(permaTicker 접근)는 미확인.

판단: 2016~ 은 편출 종목의 약 90% 이상을 이을 수 있다(188 + 개명 대부분). 남는 구멍 ~7% 는 **피인수 기업**이라
결손의 방향이 알려져 있다 — 피인수 대상은 발표일 전후 프리미엄을 받으므로 빠지면 유니버스 수익률이 약간 낮게 잡힌다.
사전등록에 결손 명단과 이 방향을 적고 들어가면 된다. 식별자 조인은 티커가 아니라 **CIK** 가 정본이다(FB 가 ETF 로 재사용된 실례).
