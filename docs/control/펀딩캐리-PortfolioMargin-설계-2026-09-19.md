# BTC 펀딩 캐리(델타중립) — Portfolio Margin 경로 설계 (2026-09-19)

**성격**: 연구·엔지니어링 설계 문서다. **투자 조언이 아니다** — 실행 여부·자본 규모·거래소 선택은 사용자가
정한다. 실계좌 주문(계좌 개설·이체·주문·설정 변경)은 Claude 가 하지 않는다(프로젝트 원칙, 아래 §8).
근거 데이터는 로컬 실측(재현: `research/strategy-lab/crypto_funding_carry_pm_analysis.py`)과 Binance 공식
FAQ(2026-09-19 열람)다. 열람하지 못했거나 시점에 따라 바뀌는 값은 §10 에 "미확인"으로 모았다.

---

## 0. 한 장 결론

1. **구조적으로는 성립한다.** 통합 담보 계정(Portfolio Margin 또는 Multi-Assets Mode)에서는 현물 BTC 가
   USDT-M 숏의 손실을 상계하므로, 09-13 에 REJECT 한 "격리 마진 2% 상승에 청산" 문제는 없다.
   2019-12 진입·재조정 없음 가정에서도 uniMMR 최저가 **41**(청산선 1.05)이었다(§5).
2. **그러나 수익이 작아졌다.** 헤드라인 CAGR 12.5% 는 2020~2021(합 47.9%p)이 끌어올린 값이고,
   **최근 365일 연환산 3.34%, 2026 년(8개월) 1.65%** 다(§2). 수수료·이자·운영 위험을 빼면 무위험 대안과의
   차이가 남는지 지금은 불분명하다.
3. **정적 보유는 안 된다 — 재조정 규칙이 필수다.** BTC 가 오르면 숏 손실이 USDT 음수잔고로 쌓이고 그 이자가
   수익을 잠식한다(연 10% 가정 시 급등 구간 1년에 명목의 3~17%p, §5.2). 통합 담보를 써도 "붙여만 두는" 구조가 아니다.
4. **권고: 실계좌 실행은 지금 하지 않고 Stage 0(읽기 전용 모니터링)+Stage 1(모의 시뮬레이션)만 한다.**
   실행 재검토 게이트는 §8 에 있다. 이 권고는 조언이 아니라 "현재 근거로 뒷받침되는 수준"의 서술이다.

## 1. 전략 정의

BTC 현물 롱 1x + USDT-M 무기한 선물 숏 1x(수량 동일). 가격 손익은 상쇄되고(백테스트에서 가격 PnL ≈ +0.1%),
**수익은 펀딩(롱→숏 지급)에서 나온다.** 펀딩이 음수이면 숏이 지급한다. 자본은 현물 전액이 지배한다
(연구실 ROIC 11.7~12.3% 는 현물 전액 기준).

## 3. 09-13 REJECT 가 무엇이었고 무엇이 바뀌는가

09-13 검증의 결론은 "격리(isolated) 마진 1~2.5% 로는 BTC 2% 상승(진입 14일 후)에 청산"이었다. 현물이 다른 지갑에
있어 손실을 못 메꾸는 구조였다. 통합 담보 계정은 현물 담보가 같은 자본풀에서 숏 손실을 흡수하므로 그 결함이
**구조적으로 사라진다.** 단, 09-13 이 지적한 "이 저장소 데이터만으로는 그 모드의 담보율·헤어컷을 검증 못 한다"는
여전히 사실이라 §5 는 담보율·MMR 을 **스트레스 격자**로 처리했다.

## 4. 계정 구조 후보 (Binance 공식 FAQ 기준)

| | Portfolio Margin (PM) | Multi-Assets Mode (MAM) |
|---|---|---|
| 자격 | VIP 1~9 **또는 총자산 50,000 USDT 초과**(Cross Margin·선물 지갑 합). 법적 서명 불필요 | 별도 자격 언급 없음(VIP 등급별 **자산 최대 입금 한도**가 있음) |
| 담보 | 360여 종, 자산별 담보율(예시 BTC 95%) | BTC·ETH·BNB 등 **5% 가치 헤어컷**, USDS-M 지갑 안에서만 |
| 마진 판정 | 통합 uniMMR = 조정자산/유지증거금 | 교차 마진, 지갑 단위 |
| 청산 | uniMMR < **1.05** 전량 청산(콜 1.5, 신규 진입 제한 1.2) | USDⓈ-M 포지션·지갑 담보에 한정(다른 지갑은 영향 없음) |
| 음수잔고 | **이자 부과**, 같은 코인으로 자동상환 | 이자 여부 **미확인**. 자동 환전 기능이 있다는 것만 확인(BTC→USDT 충당은 추정) |
| 이동 제약 | 입출금은 Cross Margin 지갑 경유만 | 담보를 USDⓈ-M 지갑으로 이체해야 함 |

**추정(미확정)**: 소액이면 PM 자격(50,000 USDT)을 못 채우므로 MAM 이 유일한 후보가 된다. MAM 은 청산 범위가
좁아 유리하지만, **자동 환전이 현물 수량을 줄여 헤지가 어긋난다**(BTC 상승 → 숏 손실로 USDT 음수 → BTC 매도 충당 →
현물 감소·숏 유지 → 순 숏 노출). §6 의 델타 밴드 관리가 필요한 이유다.

## 5. 시뮬레이션 (재현: `crypto_funding_carry_pm_analysis.py`)

### 5.1 uniMMR 여유 — 재조정 없음, 2019-12 진입(BTC 7,554 → 최고 125,989)

현물 1 BTC(담보율 c)·숏 1 BTC, 펀딩은 USDT 로 누적. 최저 uniMMR(청산선 1.05):

| 담보율 c | MMR 0.5% | MMR 1% | MMR 2.5% |
|---|---:|---:|---:|
| 0.95 | 41.2 | 20.6 | 8.2 |
| 0.90 | 31.2 | 15.6 | 6.2 |
| 0.80 | 11.2 | 5.6 | 2.2 |
| 0.70 | **−8.9(붕괴)** | −4.4 | −1.8 |

- c ≥ 0.90 이면 어떤 MMR 에서도 6.2 이상, c=0.80 이어도 최저 2.2(청산선 1.05 위)다. **가격 방향 자체로는 청산이 안 난다** — BTC 가 16 배로 올라도.
- 취약점은 **담보율이 내려갈 때**다: 헤어컷 (1−c) 가 누적 상승분에 곱해져 순자산이 깎인다(c=0.70 에서 붕괴).
  담보율은 거래소가 바꿀 수 있는 값이므로 §7 의 모니터링 항목이다(현행 BTC 담보율은 §10 미확인).
- 이 격자는 **수량 고정·재조정 없음**이라 §5.2 의 이자 문제는 안 들어 있다.

### 5.2 정적 보유의 함정 — USDT 음수잔고와 이자

숏의 미실현 손실은 USDT 음수잔고다. 1년 정적 보유 시(명목 대비):

| 진입 | BTC 변화 | 펀딩 수취 | 최대 음수잔고 | 이자(연 10%) | 이자(연 20%) |
|---|---:|---:|---:|---:|---:|
| 2020-01 | +306% | 30.8% | 276% | 4.3%p | 8.6%p |
| 2020-07 | +281% | 140.2% | 494% | 17.5%p | 35.0%p |
| 2021-01 | +61% | 52.9% | 92% | 3.2%p | 6.4%p |
| 2023-01 | +157% | 15.0% | 158% | 6.9%p | 13.7%p |
| 2024-01 | +117% | 19.2% | 136% | 4.5%p | 9.0%p |
| 2025-01 | −7% | 5.7% | 29% | 0.8%p | 1.6%p |
| 2025-07 | −45% | 3.5% | 15% | 0.2%p | 0.4%p |

급등장에서는 **음수잔고 이자가 펀딩 수취의 상당 부분을 먹는다**(이자율은 미확인 — 10%/20% 는 가정). 급등장이 펀딩이
높은 국면이기도 해서 순효과는 국면별로 다르다. 다만 **최근처럼 펀딩이 낮은 장에서 상승이 오면 이자가 펀딩을 넘을 수
있다.** 그래서 정적 보유가 아니라 아래 재조정 규칙이 필요하다.

## 6. 운영 설계 (규칙 초안 — 실행 전 별도 검증 대상)

| 항목 | 규칙 초안 |
|---|---|
| 헤지 비율 | 델타 = 현물 BTC 수량 − 숏 수량. 밴드 ±2% 이탈 시 재헤지(수량 맞춤) |
| 음수잔고 관리 | USDT 음수잔고가 명목의 X% 를 넘기 전에 현물 일부를 USDT 로 환전하고 **숏도 같은 수량 축소**(수량 동시 감소). X 는 이자율·수수료 확인 후 정한다 |
| 완충 | 추가 USDT 버퍼(명목의 5~10%)는 uniMMR 여유가 아니라 **음수잔고 이자 회피용**이다(§5.1 에서 uniMMR 에는 영향 미미) |
| 펀딩 감시 | 롤링 7·30·90일 연환산이 임계 아래로 N 일 지속되면 **신규 진입 중단·청산 검토 알림**(자동 청산 아님) |
| 청산 트리거(수동) | 90일 연환산 < (수수료+이자+무위험대안 기준) 또는 uniMMR < 3 또는 담보율 인하 공지 |
| 재조정 비용 | 매 재조정 수수료·슬리피지를 실측해 §5.2 표를 재계산한다(현재 미반영) |

이 규칙은 09-13 의 "능동 재조정 −1.2%/yr" 결과(격리 지갑 구조)를 **그대로 승계하지 않는다** — 그 시뮬레이션은 통합
담보가 아닌 분리 지갑이었다. 그러나 통합 구조에서의 재조정 손익은 **아직 시뮬레이션하지 않았다**(Stage 1 과제).

## 8. 단계와 게이트 — 그리고 Claude 가 하는 일

| 단계 | 내용 | 누가 | 조건 |
|---|---|---|---|
| **Stage 0** | 읽기 전용 모니터링: 공개 API(키 없음)로 BTC 펀딩·프리미엄 일별 기록, 롤링 수익률·음수 비율 산출·알림 | **Claude** (조회 전용, 자격증명 불필요) | 바로 가능. 기존 크립토 수집 경로가 있으면 재사용 |
| **Stage 1** | 통합 담보 구조의 재조정 시뮬레이션: 델타 밴드·이자율 시나리오·수수료 반영, 실제 시계열로 순수익 재계산 | **Claude** | Stage 0 과 병행, §10 미확인 값을 사용자가 확인해 주면 정확도 상승 |
| **Stage 2** | 실계좌 소액 시험: 계정 개설, 자금 이체, 모드 전환, 주문 | **사용자 본인만** | 아래 게이트 충족 + 사용자 결정 |
| Stage 3 | 자동 주문 | **하지 않음** | 프로젝트 원칙상 Claude 는 실계좌 주문·자동매매 코드를 실행하지 않는다. 별도 결정 사항 |

**Stage 2 검토 게이트(제안)**: (a) 롤링 365일 순수익(수수료·이자 반영 시뮬레이션)이 사용자가 정한 무위험 대안 수익
을 넘는다, (b) 롤링 90일 연환산이 N 개월 연속 임계 위, (c) §10 미확인 항목 전부 확인, (d) 규제·과세 확인 완료.
임계값은 사용자가 정한다 — Claude 가 임의로 정하지 않는다.

## 9. 사용자가 정할 것

1. 이 전략을 계속 볼 것인가(Stage 0·1 만 진행할지). — **권고: 예**(비용 0, 부작용 0).
2. 자본 규모의 대략(PM 자격 50,000 USDT 이상인지, MAM 후보인지가 갈린다).
3. 규제·과세·거래소 이용 가능 여부(§7)는 사용자가 확인한다.
4. Stage 2 진입 시 자동화 여부는 그때 별도로 정한다(현재 기본값은 수동 실행).

## 10. 미확인 사항 (정직하게)

- **BTC 의 현행 담보율**(PM 은 "예시 95%"만 확인, 실제는 트레이딩 파라미터 페이지 값). MAM 은 5% 헤어컷이 문서에 명시.
- **MAM BTC 최대 입금 한도**(VIP 등급별). 소액이면 문제없을 가능성이 크나 확인 안 함.
- **음수잔고 이자율**(PM·MAM 공통 "부과됨"만 확인, 요율 미확인 → §5.2 는 10%/20% 가정).
- **거래 수수료율**(현물 마진·선물 테이커/메이커, BNB 할인). 재조정 비용 계산에 필요.
- **PM 자격 문턱 최신 여부**: FAQ 갱신일 2026-01-02, 50,000 USDT. 바뀌었을 수 있다.
- **MMR 구간표**(BTC 명목별): §5.1 은 0.5~2.5% 격자로 갈음.
- **한국 거주자의 Binance 이용 가능 여부·신고·과세**: 조사하지 않았다.
- 09-13 finding 의 격리 마진 청산 분석은 이 문서로 **무효화되지 않는다** — 격리 마진 경로는 여전히 REJECT 다.
