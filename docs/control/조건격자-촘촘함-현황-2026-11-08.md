### 1-3. 시장·지평·구간·대조·보정
- 시장 12곳: SPY · QQQ · ^SOX · 닛케이 · DAX · 항셍 · 코스피 · 코스닥 · 대만 가권 · 상해종합 · FTSE · CAC40 (거래량이 0 인 시장은 거래량 칸 제외).
- 지평 5·21·63일(주 지표 21일). 구간 TRAIN ~2009 / VALID 2010~19 / TEST 2020~ 의 합산 초과수익.
- 대조 두 가지: ① 그 시장의 **무조건(전 날) 평균** ② **같은 조건을 만족하는 모든 날 평균(matched)** — 국면 효과 분리.
- 순열 p: 순환 이동 1,000회(양측). 다중검정: 주 지표 전체 시험에 Benjamini–Hochberg FDR 5%.
- 칸 통과: BH 통과 시장 ≥ 보유 시장의 절반 ∧ VALID·TEST 합산 같은 부호 (+ 매칭 대조 부호 일치를 스킬이 요구).

### 1-4. 규모

## 3. 더 촘촘히 하는 방법과 그 비용
| 방법 | 효과 | 비용·위험 |
|---|---|---|
| 축마다 구간을 더 세분(예: VIX 10구간, RSI 8구간) | 국면별 형태를 더 정밀히 봄 | K 가 선형으로 늘어 BH 임계가 엄격해지고 칸당 건수가 줄어 검정력↓ (칸당 최소 5건 → 20건으로 올리는 것을 권장) |
| 2축·3축 조합을 전수로 | 상호작용 발견 | 조합 수가 폭증(49개의 2축 전수 = 1,176칸). **사전 지정 조합만** 허용하는 현재 규칙을 유지하고, 조합은 축 선택 단계(스크리닝)에서만 확장 |
| 미구현 축 추가(갭·20일 급락·매크로·수급 등) | 조건 폭 확대 | 엔진 코드 + 자료 시점(PIT) 확인 필요 |
| 사건 정의 변형(L·D 격자) | 사건 깊이별 효과 | 사건 간 중복이 커서 독립성↓ |
| 시장·자산 확대(개별 ETF·섹터·33종) | 표본↑, 거래량 자료 개선 | 생존편향(개별주), 비용 모델 필요 |
| **2단계 설계**(스크리닝 → 확증) | K 가 커도 정직함 유지 | 1단계(TRAIN·VALID)에서 칸을 거르고 2단계에서 **TEST·새 시장·forward** 로만 확인 — 같은 표본 재절단 방지 |
| 연속형 모형(회귀·로지스틱, 변수 16개를 한 번에) | 칸 수 없이 정보량을 살림 | 해석 어려움, 비선형 효과는 칸이 더 낫다 |
| 군집 보정(블록 부트스트랩·위기 구간 제외 민감도) | 사건 독립성 문제 완화 | 구현 필요 |

## 4. 권장 단계 (점진적으로 촘촘하게)
1. **L1(현재)**: 150칸·K≈1,200, 단일 축 구간 + 사전 조합 8개. ← 완료
2. **L2**: 미구현 축 6~8개 추가(갭·20일 급락·FOMC/CPI 거리·달러·금리 변화·수급 지수 연결), 칸당 최소 20건으로 상향, 위기 구간 제외 민감도 병기. 예상 K 2,000~3,000.
3. **L3**: 스크리닝(TRAIN·VALID) → 확증(TEST + 새 시장/forward) 2단계 + 54규칙의 일부를 사건 필터로. 최종 확증 단계는 통과 칸만 소수.
4. **L4**: 자산 33종·레버리지 상품 수익을 연결하고, 통과 칸의 단순 매매 시뮬레이션(분할·비용)까지 — 이 단계부터가 매매 근거 검토이며 🔴 승인 대상.
어떤 단계든 **조건 목록과 K·보정을 결과 전에 사전등록**하고, **통과를 상위만 골라 보고하지 않는다**.

## 5. 지금 알려진 결과의 의미 (촘촘함을 늘릴 때 유의)
- 12조건에서 49조건으로 늘려도 새 통과 칸이 없었다 — 촘촘함을 더한다고 신호가 저절로 나오지 않는다.
- 국면 변수(VIX·낙폭)는 매칭 대조 없이는 거의 항상 '통과'로 보인다. 모든 국면 칸에 매칭 대조를 붙이는 것이 L2 이상의 필수 조건이다.

## 6. 갱신 (2026-11-08 늦게) — L1.5·L2 실행 결과
