## 4. UI 3건 (`856415f` · `ccc8f30` · `4b2c883`)

### 4-1. 리서치랩 비교표 — frontmatter 유실

`build_ui_findings.py` 가 verdict **값**을 4종 화이트리스트로 검사해, 없으면
**frontmatter 를 통째로 버리고** 본문에서 verdict 를 추측했다. 실측 7건이
conditions·reason·수치를 전부 잃었고 **macross 는 원문 PASS 가 화면에서
KEEP 이 됐다**(지어낸 값). 추가로 줄 단위 정규식 파서라 `reason: >-`(블록
스칼라)는 값이 `">-"` 가 되고 `conditions: [a, b=1]`(flow 시퀀스)도 못 읽었다.
→ 이미 설치된 PyYAML(6.0.3)로 교체, verdict '존재'로 판단, 정규 4종이 아니면
원문을 `original_verdict` 로 보존. 나중에 **수치를 verdict 와도 분리**했다
(수치는 verdict 와 별개의 사실).

`conditions` 156→165 · `reason` 235→242 · `win_rate` 0→22 · `cagr` 51→53.

### 4-2. 칸 폭 — 5개 표시

데이터 칸을 190px 로 **고정**한 게 원인. `table-layout: fixed` 라서 고정폭을
빼면 남는 폭을 N개가 나눠 갖는다. 1,000px 화면에서 5개 선택 시 칸당 119px,
가로 스크롤 없음(실측). 제목도 고쳤다 — 1행만 보고 `# ` 헤딩을 찾는데
frontmatter 문서는 1행이 `---` 라 **전부 파일명으로 떨어지고 있었다.**

★ 그 과정에서 자기 버그 하나 — YAML 주석도 `# `로 시작해서 주석이 제목이 됐다.
공유 헬퍼 `strip_frontmatter()` 를 `build_findings_registry.py` 에 추가.

### 4-3. ★ 차트 탭 배포본 404 — 로컬 검증으로는 안 잡히는 종류

`chart.js` 가 `fetch("../data/positions.json")` 을 쓴다. 상대경로는 **문서
기준**이라 배포본(`/stock/paper-trading/`)에서 `/stock/data/` 로 빠져나간다.
**로컬은 문서가 서버 루트라 브라우저가 `..` 를 잘라 우연히 동작했다** — 그래서
지금까지 로컬 검증을 통과해 왔다. `data/...` 로 통일.

**교훈: `ui/` 를 검증할 때는 배포 레이아웃(`_site/paper-trading/`)을 그대로
만들어서 봐야 한다.** 이번엔 그렇게 재현해 확인했다(별도 포트로 서빙).
