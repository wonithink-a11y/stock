## 3. 규칙이 된 것 (다음 세션이 어기지 않게)

- **실계좌 주문 켜기·실행·킬 해제는 패스키로만.** TOTP 로 내려가는 경로 없음. 패스키 등록은 서버 `passkey-enroll`(1회용 15분), 삭제는 `passkey-reset`(서버만).
  명령은 반드시 `cd ~/collector && ~/collector-venv/bin/python3 -m autotrader --config ~/collector-venv/autotrader/autotrader.local.json …`
  (`cd` 빠지면 `No module named autotrader` — 사용자 실측).
- **웹 유닛은 허용목록 격리**(`ProtectHome=tmpfs` + 바인드). 웹이 새 파일을 읽어야 하면 `deploy/autotrader-web.service` 의 `BindReadOnlyPaths` 에 추가해야 한다 — 안 하면 "파일 없음"으로 조용히 빈다.
- nginx 정본이 저장소에 있다: `deploy/nginx-wonithink-stock.conf` · `nginx-stock-ratelimit.conf` · `nginx-autotrader.location.example`. VM 에서 직접 고치지 말고 여기서 고쳐 복사(`nginx -t` 후 reload, 백업 `/etc/nginx/*.bak-*`).
- 공개 실시간 중계는 공개 목록만(`LIVE_RELAY_USE_HOLDINGS=1` 일 때만 보유 종목).
- 한 종목은 한 프로그램만 매매한다 — 실현손익(`fills.json`)이 우리 주문번호 기준이라 겹치면 계좌와 어긋난다.
- 모의투자는 LOC 불가 → 지정가. 모의 숫자는 전략 판정에 안 쓴다(기존 규칙 그대로).
- 화면 손익 색은 국내 관례(상승 `up` 빨강·하락 `dn` 파랑). `ok`/`bad` 는 상태(정상·오류) 전용 — 섞지 않는다.
- 공개 대시보드(GitHub Pages, `ui/`) 디자인은 **손대지 않았다** — 사용자가 말한 'UI'가 그쪽이었다면 별도 작업.
