## 5. 함정·교훈

- **KIS 모의 주문번호는 날마다 재사용된다** — 주문번호만으로 원장을 잇지 않는다(날짜 포함).
- **목록에 종목을 추가하는 코드가 '보유 중'인 경우를 지우는지 먼저 본다** — DROP 경로가 탑업 PENDING 을 통째로 삭제하는 구조였다.
- **Windows `opencode.cmd` 는 여러 줄 지시문 첫 줄만 넘긴다** — 지시는 파일, 한 줄로 가리키고 열지 말 경로 명시(메모리 `opencode-windows-multiline-prompt`). 첫 시도는 정답지 문서를 읽어 시험이 오염됐다.
- **OpenCode 가 결과 파일 없이 exit 0 으로 끝나는 경우가 있다**(지역난방공사) — 종료 코드가 아니라 출력 파일 존재로 확인.
- **A2a gz 한 줄의 티커 위치는 `line[12:18]`** — 한 칸 어긋나면 조용히 빈 결과(동종사·손절가가 비었다).
- **DART 반기 현금흐름표의 전년 동기는 `frmtrm_amount` 가 비고 add/q 칸에 오는 회사가 있다.**
- 모니터 알림을 촘촘히 받으면 대화 토큰이 계속 든다 — 긴 백그라운드는 완료 알림 하나로.
