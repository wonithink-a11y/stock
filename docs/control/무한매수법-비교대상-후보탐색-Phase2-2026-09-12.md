## 8. 최종 판정 (사용자 확정, 2026-09-12)

**Phase 3 = WAIT.** 지금 1a를 바로 백테스트하지 않는다. Phase 1(경로분해 →
B&H 성과분해 → **LOC 체결 현실성**)을 먼저 끝낸다. 이유: LOC 체결 모델이
바뀌면 V4.0 자체의 수치가 바뀌므로, 그 전에 1a를 재현해봐야 비교 기준이
다시 바뀔 수 있다 — 순서를 지키지 않으면 두 번 할 일이 된다.

**LOC 결과 이후 조건부 분기**

```
LOC 현실성 검증 결과
        │
        ├─ V4.0 성과를 크게 훼손하지 않음
        │     → 1a 재현 GO. 기존 episode 프레임(TQQQ 16·SOXL 12) 그대로 재사용
        │
        └─ V4.0 성과를 상당히 훼손함
              → 체결 모델부터 수정 → V4.0·1a를 같은 현실적 체결 모델로 동시 비교
                (V4.0만 새 체결모델로 바꾸고 1a는 옛 모델로 비교하면 공정하지 않다)
```

**1a 재현 시 비교축은 CAGR/MDD보다 recovery time·cash requirement를 주 지표로
삼는다.** 무한매수의 핵심 주장("버티면 회복 시 유리하다")과 1a의 철학("추세
깨지면 현금화 후 재진입")이 정확히 갈리는 지점이 거기다.

**HOLD 4건(1b·2a·2b·3a)은 폐기가 아니라 보류다.** 특히 3a(TQQQ/SOXL 상대모멘텀
로테이션)는 "TQQQ vs SOXL 중 무엇을 보유할까"라는 질문이 프로젝트에서 다시
나오면 가장 먼저 다시 볼 후보로 남겨둔다. REJECT는 3b 하나뿐(원문 확인 불가).

**"실제 운용 중"은 실행 가능성의 증거이지 성과의 증거가 아니다.** 1a가 Phase 3에
들어가도 "이미 좋은 전략"이라는 가정 없이 우리 데이터에서 처음부터 채점한다 —
Auto-Trade의 존재는 "규칙대로 자동매매가 가능하다"만 증명한다.

★ **Phase 2 후보 탐색은 여기서 종료한다(사용자 확정, 2026-09-12).** 후보를 더
찾지 않는다 — 지금 늘리면 "후보 탐색 → 파라미터 탐색 → 백테스트 확대"로
