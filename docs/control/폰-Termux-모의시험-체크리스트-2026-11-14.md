# 폰(Termux) 모의 시험 체크리스트 — 실매매 엔진을 폰에서 돌려 보기 (2026-11-14)

목적: 안드로이드 폰에서 autotrader 엔진이 **모의(VTS)** 로 며칠 멈춤 없이 도는지 본다. 쓰던 폰에서 시험하고 나중에 LG G7(집에 두는 전용 폰)로 옮긴다.
**비용 0원. 실계좌 키·업비트 키는 이 단계에서 폰에 넣지 않는다.** 실매매 전환은 사용자가 따로 결정(🔴).
Claude 가 직접 확인한 것: 최소 clone(약 15MB)에서 `python -m autotrader check-config` 가 PC 에서 돈다(키가 없으면 "막힘"을 정확히 보고). **폰에서의 설치·동작은 아직 미확인** — 이 시험이 그것을 확인한다.

## 0. 사전 확인 (2분)
- [ ] 안드로이드 폰이다(아이폰은 Termux 불가). 설정 → 휴대전화 정보에서 **안드로이드 버전**을 적는다: ______ (12 이상이면 §3 의 ★ 항목 필수)
- [ ] 저장 공간 여유 3GB 이상 · 모델명 ______
- [ ] 쓰는 폰이면 시험 중 배터리가 평소보다 빨리 닳을 수 있음을 안다.

## 1. Termux 설치 (5분)
- [ ] **구글 플레이 버전은 쓰지 않는다(오래됨).** 폰 브라우저에서 F-Droid(`f-droid.org/packages/com.termux/`)로 설치한다(Termux 공식 배포처로 알려짐 — 설치 파일은 출처를 눈으로 확인).
- [ ] (선택, 재부팅 자동 시작용) 같은 방식으로 `Termux:Boot` 도 설치. 처음 시험에는 없어도 된다.

## 2. 설치 스크립트 (5~10분, 와이파이)
Termux 를 열고:
```bash
curl -fsSLO https://raw.githubusercontent.com/wonithink-a11y/stock/main/autotrader/termux/setup.sh
cat setup.sh        # 받은 내용을 눈으로 한 번 읽는다(키·외부 전송 없음, 패키지 설치와 저장소 일부 받기만)
bash setup.sh
```
- [ ] 끝에 "설치 끝" 문구가 나온다. 오류가 나면 **마지막 10줄을 Claude 에게 붙여넣는다**(키가 들어 있지 않다).
- [ ] 저장소는 `~/stock`(약 15MB, 일부만 받음).

## 3. 폰 설정 — 안 하면 몇 시간 뒤 꺼진다
- [ ] 설정 → 앱 → Termux → 배터리 → **제한 없음/최적화 안 함**(삼성은 "사용하지 않는 앱 절전"·"자동 최적화"도 끄기, LG 는 배터리 최적화 제외)
- [ ] Wi-Fi 연결 유지(절전 중 Wi-Fi 끄기 옵션이 있으면 끈다)
- [ ] ★ 안드로이드 12 이상: 개발자 옵션의 "자식 프로세스 제한 해제"(14+) 또는 adb 로 phantom process 제한 해제 필요(기종별 방법은 미확인 — 막히면 버전을 알려 달라)
- [ ] 화면 잠금(PIN/지문) 설정 — 키 파일 보호
- [ ] 자동 시간(한국) 켜짐

## 4. 모의 키 입력 (직접)
- [ ] 한국투자증권 **모의투자** 앱키·앱시크릿·모의 계좌번호(`12345678-01` 형식)를 준비한다(실전 키 아님).
- [ ] `nano ~/stock/.env` → `KIS_VTS_APP_KEY=` 등 세 줄의 `=` 뒤를 채우고 저장(Ctrl+O, Enter, Ctrl+X). **키를 이 대화창·메신저·클라우드에 붙이지 않는다.**
- [ ] `ls -l ~/stock/.env` 가 `-rw-------` 로 시작한다(본인만 읽기).

## 5. 점검 → dry-run (주문 없음)
```bash
cd ~/stock
python -m autotrader check-config      # dry-run: 막힘 없음 이면 통과
python -m autotrader run               # 주문 없이 계획·위험 검사 결과만 출력
```
- [ ] `check-config` 에서 모의 키 관련 "막힘"이 없다(KIS 시세용 키 등 다른 항목은 별도 — 이 단계는 VTS 만).
- [ ] 오류가 나면 마지막 줄들을 알려 준다(키는 출력되지 않는다).

## 6. 반복 실행 (며칠)
```bash
cd ~/stock
nohup bash autotrader/termux/run-loop.sh > /dev/null 2>&1 &     # 5분마다 run-due, 기본 dry-run
tail -f logs/heartbeat.log                                      # 5분마다 한 줄이 쌓이면 정상 (Ctrl+C 로 보기만 끝냄)
```
- [ ] 멈추려면 `pkill -f run-loop.sh`. 모의 주문까지 켜려면 이 시험이 통과한 뒤 `bash autotrader/termux/run-loop.sh --execute`(프로필이 `"auto":"execute"` 인 것만 나간다).
- [ ] 기록표(멈춘 시각·원인 추정): 날짜 ____ 시각 ____ 원인 ____

## 7. 합격 기준 (이 기준을 시험 전에 고정한다)
1. **3일 연속** `logs/heartbeat.log` 가 5분(±1분) 간격으로 끊김 없이 쌓인다. 끊긴 구간이 있으면 원인이 폰 설정으로 설명되고 고쳐진 뒤 다시 3일.
2. `logs/autotrader.log` 에 오류 반복이 없다.
3. (선택) 모의 `--execute` 1회가 정상 체결/보고된다.
통과 → G7 이전. 3일 안에 설명 안 되는 멈춤이 반복되면 → 폰 방식은 접고 집 PC 24시간 또는 국내 VPS(월 금액 확인) 비교.

## 8. G7(전용 폰)로 옮기기
- [ ] G7: §0~§3 동일(안드로이드 10, 유심 없음/모바일 데이터 끔, 충전기 연결, 배터리 팽창 확인).
- [ ] §2 스크립트로 새로 설치. **키 파일은 옮기지 않고 G7 에서 `.env` 에 직접 새로 입력**(전송 경로 자체를 없앰). 상태(`autotrader/state/`)는 모의라 새로 시작해도 된다 — 옮기려면 USB 로 복사.
- [ ] 쓰던 폰: `rm ~/stock/.env` 로 키 파일 삭제.
- [ ] 실전 전환(업비트 허용 IP = G7 이 쓰는 집 공인 IP, KIS 실전 키)은 **별도 사용자 결정(🔴)** — 한도 아주 작게, README §4 체크리스트 전부.

## 9. 하지 않는 것
- 실계좌 키·업비트 키를 쓰던 폰에 넣지 않는다 · `AUTOTRADER_ALLOW_LIVE` 설정 금지 · 폰 모바일 데이터로 실매매 금지(IP 가 바뀜) · 키를 대화·메신저·클라우드로 전송 금지.

## 10. 미확인 (시험이 밝힌다)
- Termux 에서 `pip install requests tzdata` 성공 여부 · `pandas`/`yfinance` 쓰는 전략(코인베이스 프리미엄·무한매수)이 폰에서 설치되는지(엔진 코어는 표준 라이브러리만) · 안드로이드 버전별 백그라운드 설정 경로 · 쓰던 폰의 제조사 절전 기능이 얼마나 공격적인지.
