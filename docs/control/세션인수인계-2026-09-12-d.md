## 0. 다음 세션이 먼저 볼 것

### ① V4.0 비교 기준선이 바뀌었다

**앞으로 V4.0을 다른 후보와 비교할 때는 "이상적 체결"이 아니라 "실현10bp"
기준을 쓴다.** `research/strategy-lab/realistic_fill_model.py`의
`use_realistic_fill()`로 감싸면 된다. 엔진(`infinite_buying_engine.py`) 자체는
안 바꿨다 — 과거 findings(버전별 비교 등)는 여전히 이상적 체결 기준 숫자다.

```
              이상적(과거 findings)      실현10bp(신규 기준)
TQQQ 전체CAGR/MDD   19.17%/48.7%         18.92%/48.9%   (거의 안 흔들림)
SOXL 전체CAGR/MDD   27.11%/59.4%         23.41%/70.5%   (통상치에서도 흔들림)
```

### ② Phase 2 후보 중 유일한 REPRODUCE(1a)를 재현·확장까지 다 해봤다

1a(QQQ 50일SMA 추세필터)는 V4.0과 "정반대 철학"(추세 깨지면 현금화 vs
버티며 계속매수) 비교군으로 재현됐다. 결론은 단순한 우열이 아니라 **국면
의존적 상호보완**이다:

```
급락·V자반등(변동성 큰 구간)  -> V4.0 승
추세장(뚜렷한 상승)          -> 1a 압도적 승
장기횡보                    -> V4.0 승(1a는 휩쏘로 평균 손실)
장기하락(완만한 하락)         -> 관측 안 됨 — 이 두 종목 역사에 0건
```

**국면결합(하이브리드)을 실제로 시도했지만 "우월한 대체재"는 아니었다** —
1a의 2일 지연확인 비용 때문에 급락·장기횡보에서 V4.0 단독보다 오히려
나빠졌다. 전체 CAGR은 오르지만(18.9%→27.6%) MDD도 같이 오른다(48.9%→62.1%)
— 공짜 개선이 아니라 다른 위험/수익 지점으로 이동한 것. **여기서 멈췄다**
(사용자 지정 범위) — 지연확인 튜닝·VIX필터 추가 둘 다 반려했다(파라미터
튜닝 재개 + 검증 불가능한 예측모델이 되기 때문).

### ③ "완결실패 0/16"은 "반등을 다 탄다"는 뜻이 아니다

B&H 성과분해로 확인: V4.0은 평균 노출 30~32%뿐이고, 저점→회복 구간에서
**가격 반등의 32~39%만 계좌에 반영**한다(TQQQ 최극단 사례: 가격 452% 반등에
계좌 99.6%). "파산은 피한다"와 "반등을 다 탄다"는 다른 질문이라는 게
정량적으로 확인됐다 — `infinite-buying-tqqq-version-final-comparison`의
"0/16"을 과대해석하지 않는다.

## 1. 이 세션의 흐름

```
①  ChatGPT가 조사한 "무한매수와 비슷한 전략" 목록 검토 요청
    → Phase 2 read-only 후보 탐색(체크리스트만, 백테스트 안 함)
    → 3그룹 6후보 중 1a(QQQ 50SMA)만 REPRODUCE, 나머지 HOLD/REJECT
②  ChatGPT가 HOLD 후보(3a·2a) 재론 시도 → "새 정보 없이 별점만 올랐다"로 반려
③  Phase 1 — LOC 체결 현실성 검증(사용자가 최우선 지목)
    → 판정 "V4.0 훼손 큼"(SOXL은 현실적 수준에서도 흔들림)
④  합의한 조건부 분기 실행 — 체결모델 표준화(realistic_fill_model.py)
⑤  1a 실제 재현·비교 — 전체기간 대등하지만 MDD는 V4.0이 더 나음,
    episode 프레임(고점시작)이 추세추종에 불리하다는 편향 발견
⑥  가격 경로별 구조분해(캘린더 타일링) — 그 편향을 피해 재평가,
    국면 의존적 상호보완성 확인, "장기하락" 0건 발견
⑦  B&H 성과분해 — cash drag/averaging benefit/recovery capture로
    "왜" 그런 상호보완성이 나오는지 메커니즘 규명
⑧  커밋 1(93e5c38: ①~⑤ 관련), 커밋 2(d5ef8c9: ⑥⑦, 사용자 검토 후 진행)
⑨  국면결합 하이브리드 — 1a의 기존 시그널을 스위치로 V4.0/1a 연결,

⑫  장기하락 예측모델 가능성 질문 → 표본 0건이라 불가, PBR 라인의

    데이터로 레버리지 합성)은 별도 큰 프로젝트로 남김(미착수)
```

## 2. 남은 것 / 재개 조건

- **PBR 스타일 타이밍필터 재시도** — 안 함. 이미 PBR 라인에서 여러 축이
  같은 이유("상관관계 ≠ 타이밍가치")로 기각됐고, 이번 세션의 VIX필터
  제안도 같은 근거로 반려했다. 재개 조건: 새로운 메커니즘 가설(단순 상관
  관찰이 아닌).
- **장기하락 국면 대응** — 표본이 없어 미착수. 재개하려면 QQQ/SOXX 출시
  이전(1999~/1994~) 데이터로 3배 레버리지 수익률을 합성하는 별도 프로젝트가
  선행돼야 한다 — 이번 세션에서 그 스코프는 안 열었다.
- **하이브리드 v2(지연확인 개선·VIX필터)** — 안 함, 재개 조건 없음(파라미터
  튜닝 재개가 되므로 새 가설 없이 재론 안 함, 09-12-c의 종료 원칙과 동일).
- **1a의 SOXL 확장** — SOXX 데이터 없어 미착수, 필요해지면 §0⑤ 인벤토리에서
  확인 후 신규 수집.
