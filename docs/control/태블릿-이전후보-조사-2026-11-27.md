# OCI 유닛 → 태블릿(Termux) 이전 후보 조사 — 2026-11-27

조사 방식: `deploy/*.service` 30개를 서브에이전트가 읽기 전용으로 훑음(ExecStart·타이머·환경변수 이름은 전수 확인, 스크립트 본문은 키워드 위주로 읽었고 **전부 정독하지는 않음**). Claude 가 후보 3개의 유닛 정의와 스크립트(git·OCI·`/srv`·`/home/ubuntu` 하드코딩 없음, 표준 라이브러리만 사용)를 직접 재확인했다. 코드·설정 변경 없음.
태블릿 제약: systemd·sudo·인바운드 없음, 집 공용·주말 외출 시 단절, 안드로이드가 프로세스를 죽일 수 있음, 이중화 없음. 비용 0(이미 있는 기기, 규칙 9).
