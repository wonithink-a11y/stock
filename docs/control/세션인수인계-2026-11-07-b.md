## 6. 함정 (이번에 물린 것)

- **Git Bash(MSYS)가 `/autotrader` 같은 인자를 `C:/Program Files/Git/autotrader` 로 바꾼다** → `--base-path` 가 틀어져 404. PowerShell 로 실행.
- **PowerShell 실행 정책이 `npx.ps1` 을 막는다** → `npx.cmd`. `tailscale` 명령은 설치 직후엔 새 PowerShell 에서.
- **관리자 PowerShell 로 알림 테스트를 돌리면 `~\collector-venv\kakao\token.json` 이 관리자 소유로 바뀌어 일반 권한이 못 읽는다**(EPERM·액세스 거부, Python 3.13 의 Windows ACL 동작 추정) → 관리자 창에서 `takeown /f …; icacls … /grant 'namwon\user:F'`. 같은 이유로 `Disable-ScheduledTask`·`Register-ScheduledTask` 는 관리자 창이 필요. 터미널 창이 일반 권한인지 관리자인지 먼저 확인.
- 브라우저 SSH 에 여러 줄 코드를 붙이면 줄바꿈이 깨진다(서버를 이제 안 쓰지만 재가동 때 주의). GCP 서버는 `~/collector` 가 main 만 받은 얕은 복제.
- Cloudflare 시크릿은 PC `.env` 에서 파이프로 넣었다(값이 화면에 안 찍힘) — 끝에 개행이 붙을 수 있어 코드가 `trim()` 한다.
- 이 세션의 WebSearch 는 모델 오류로 죽어 있었다 — 브라우저 패널(`mcp__Claude_Browser__*`)로 공식 가격·한도 페이지를 읽었다(메모리 `websearch-dead-use-browser-pane`).
- 스크린샷에 비밀 값(카카오 시크릿 일부·TOTP 키)이 찍혀 대화에 남은 적이 있다 → TOTP 키는 `web-setup --reset` 으로 새로 받았고, 카카오 시크릿은 노출 가능성이 남음(걱정되면 카카오 콘솔에서 재발급 후 PC `.env`·`wrangler secret put KAKAO_CLIENT_SECRET`).
