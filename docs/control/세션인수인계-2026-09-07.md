### 절대 바꾸면 안 되는 결정 4가지

1. **가중치는 각 창의 시작 시점.** 종료 시점으로 잡으면 오른 종목에 오른 뒤의
   비중을 준다 — 실측으로 6개월 벤치마크가 +29.67%→**+47.32%**, 전자부품·
   디스플레이 RS 가 46%p→**127%p** 로 부풀었다.
2. **CAP 은 조정주가 × 현재 상장주식수.** raw 종가로 바꾸면 안 된다. 우리가
   가진 주식수는 **현재 시점 하나**뿐이고, 조정주가는 정의상 현재 주식수 기준
   으로 과거를 재작성한 것이라 둘을 짝지어야 분할이 상쇄된다. 검증: KRX 가
   함께 주는 시가총액과 재구성값이 **352종목 중앙값 비 1.0**(2% 초과 1건).
   `lib/a5/corporateActionAdjustment.js:2` 도 같은 말을 한다.
   ★ **운영에서도 확인됐다**(2026-09-07 daily-analysis):
   `krxMarketCapCheck = {n: 272, medianRatio: 1.0, maxAbsDeviation: 0.0,
   beyond2pct: 0}`. 재구성값과 KRX 시가총액이 272종목 전부 오차 0 이다.
3. **CAP·TV 에는 분면(주도/부상/둔화/약세) 라벨을 안 붙인다.** EW 전용이다 —
   "시총가중 주도"는 매매신호로 읽힌다.
4. **`capTop`/`capTopWeight` 는 장식이 아니다.** 19그룹 중 6개가 단일종목
   시총비중 >= 49%(반도체=SK하이닉스 99%, 통신·네트워크=삼성전자 95%). 이걸
   같이 안 보여주면 시총가중 값을 그룹 이야기로 오독한다.

### EW 완전 불변 — 이번 작업의 최우선 회귀 조건

주식수 출처가 KRX 든 A3c 든 없든 **EW 계열 필드는 한 값도 바뀌면 안 된다.**
변경 전 커밋 버전과 값 단위로 대조해 PASS 확인했고 selftest 에 고정했다.
앞으로 이 파일을 고칠 때 **이 assert 가 깨지면 그 시점에서 중단**한다.
