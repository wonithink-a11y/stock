## 2. 시가총액 공식 (분할·분사)

가격 패널은 조정 종가 `close_adj(t) = raw(t) / Π(t 이후 모든 계수)` 다. 공시 주식수는 **filed 시점 단위**다(filed 전 분할은
재무제표가 소급 반영 — ASC 260). 진짜 주식수 `shares(t) = shares_filed × Π(filed < d ≤ t 인 진짜 분할)` 이므로

```
시가총액(t) = close_adj(t) × shares_filed × Π(t 이후 모든 계수) × Π(filed < d ≤ t 인 진짜 분할)
```

계수가 전부 진짜 분할이면 `Π(filed 이후 분할)` 로 줄어든다. 분사 계수가 filed 와 t 사이에 끼면 옛 식은 다음 공시까지(≤ 3개월)
시가총액을 그 계수만큼 틀리게 냈다 — 새 식은 그 구간도 맞다.

## 4. 같은 감사에서 잡은 보안 마스터 오류 (가격 패널까지 번졌던 것)

- **PARA 2022-02~2025-08 이 다른 회사 가격이었다** — Tiingo PARA 는 2021-02 시작 $10 평탄 SPAC(7GC → Banzai) 시계열이고
  R3 가 이름으로 Banzai CIK 1826011 을 골랐다. 가격 구간 검사(공백·×3 급변)는 평탄한 가격을 못 잡는다. **V5(시총 < $1B)가 잡았다.**
- 고침: yfinance **PSKY 이력이 2005-12~ CBS → ViacomCBS → Paramount 를 이어 담는다**(2019-12 ≈$40·2022-02 ≈$35 확인) →
  `segments.csv` 로 CBS·VIAC·PARA 세 구간을 CIK 813828 · PSKY 가격으로. CBS·VIAC 는 UNREACHABLE 에서 되살아났다
  (가격 패널 커버리지 0.9892 → 0.9903).
- 교훈: 가격 검사는 '끊김'만 본다. **다른 회사의 매끄러운 가격**은 규모(시총) 점검에서만 드러난다 — 가격·재무를 합친 뒤에
  재는 검사가 따로 필요하다(교훈 73 — 병합에서만 잴 수 있는 것은 병합 자리에 둔다).
