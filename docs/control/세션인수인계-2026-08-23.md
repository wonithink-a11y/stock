## 2. 위 발견에 대한 후속 지시 2건 — 완료·검증

**V5b(연기금 제외/분리)** — `findings/v5b-expension/`. V4b의 발견을 바탕으로
"연기금 빼면 V5가 나아지지 않을까" 가설을 세웠는데 **틀렸다** — 반대로
악화됐다(divA T+20 +0.122→+0.079%p, 전 호른즈 감소). 재현 검증(V5_original이
기존 findings/v5-divergence 수치와 MATCH)도 통과. 해석: 연기금의 "매도"
쪽이 divA의 "기관 매도" 조건에 담는 정보가 실은 양(-) 기여였다는 뜻 —
V4b(연기금 "매수"가 강한 음수)와는 다른 축의 결과라 모순 아님. 채택 여부는
판단 대기.

**V6 엔진 스모크** — `findings/v6-engine-smoke/`. 30종목 소표본,
`strategies/v6_acc_price/`(pbr_value_v1 패턴 재사용, 엔진 코드 무변경),
continuousHoldOnRenewal=true 지시대로 적용(382체인 병합 확인 — 지시가
유효했음, PBR 재발 방지). 결과: signal study 절대평균 대비 거래별 평균이
약 31% 축소, 비용 반영 시 약 58% 축소 — **PBR과 동일한 패턴이 V6에서도
재현**. 오른꼬리 의존 구조(중앙값 음수·승률<50%)도 그대로 이전됨 — "전략이
사라진 게 아니라 마찰로 두께가 줄었다"는 관측.

이어서 낸 후속 지시(아직 결과 없음): ① 오프닝 페이드 상한가/하한가 제외
재검증, ② 월별/분기별 안정성(PBR 2022-집중 전례 재확인용), ③ 관측창(5분→
1분/15분) 민감도. ④ V6 daily-vs-minute 진입근사 오차 실측도 별도로 지시함.

## 3. 분봉(1분봉) 데이터 — 이번 세션에 처음 확보

### 3-1. VM 조사 + 실제 확보 (Claude 직접 수행, Ox Alpha 아님)

Oracle VM(`ssh stock`, `~/minute-raw`)은 매일 자동 수집 중이지만 저장소엔
전혀 반영 안 돼 있었다(승격 파이프라인 VM→Object Storage→Actions→commit이
미구현 상태 그대로). **이걸 Ox Alpha에게 시키면 안 된다** — VM SSH
자격증명은 이 프로젝트의 "절대 공유 금지" 목록에 해당하고, 로컬에서 bash
실행 권한이 있으면 사실상 그 키에 접근 가능해지기 때문이다. 그래서 직접
읽기 전용 조사(`findings/minute-vm-inventory-2026-08.md`) 후, 사용자 승인
받아 **전체 1.3GB를 로컬로 가져왔다**(tar 스트리밍, VM 원본 무변경).

- 저장 위치: `research/strategy-lab/.cache/minute_raw/date=YYYY-MM-DD/part-*.parquet`
  (`.gitignore`돼 있어 git에 안 들어감 — 확인됨)
- 로더: `research/strategy-lab/engine/data/minuteProvider.py` — 기존
  `PriceProvider` 추상 인터페이스(`load`/`coverage`/`manifest_hash`) 구현,
  `A2aProvider`와 같은 "전체 스캔" 패턴 재사용. 소표본 로드 테스트로 검증됨.
- 기간 2025-08-08~2026-08-21(252거래일), 종목 약 2,448~2,461/일, KST 1분봉
  09:00~15:30 확인.
- **정식 MN-1.0 승격이 아니다** — `data/backfill/`에 여전히 분봉 manifest
  없음. `manifest_hash`는 "로컬 미러가 어떤 날짜로 구성됐는지"만 나타낼 뿐
  재현성 보증이 아니다(코드 주석에 명시).

### 3-2. 사용자가 별도로 Ox Alpha에 직접 시킨 감사 4건 — 이번에 검토

사용자가 나를 거치지 않고 Ox Alpha에 직접 지시한 산출물이다. 이번 세션에서

JSON 대조 방식이 안 맞음).

   호환)이라고 확인. 즉 일봉↔분봉 가격을 직접 비교해도 조정 축 불일치 문제는

3. **`intraday-data-source-study-2026-08.md`** — **핵심 신규 사실**: KIS
   무료 분봉 보존기간이 **공식 최대 1년**(실측 246거래일과 부합) — 즉 지금

   짧다"가 아니라 **소스 자체의 구조적 한계**다. 2016년까지 소급은 무료
   경로로 불가능함을 확정(대안: 대신증권 CYBOS 2년설, 단 2026-03 축소
   보고 있어 재측정 필요/KRX 유료 견적 별도 트랙). **매일 적립을 지금
   시작 안 하면 그만큼 영구 손실**이라는 게 이 문서의 핵심 권고 — §"새 세션은
   여기부터" 3번 참고.
4. **`minute-data-quality-2026-08.md`**(내 분봉 확보 이후 작성) — 252일·

   0·KST위반 0·비단조 0·역전 0·음수 0·거래일 누락 0). MEDIUM 2건만: ①

   [low,high] 밖인 69건(시가단일가 체결 특성으로 추정) — 둘 다 정책 문서

  pbr_value_v1 패턴 재사용) (b) 외부 웹 자료 인용 조사(`intraday-data-source-
  study`, KIS/Creon/키움 공식문서·커뮤니티 실측 인용)까지 했다 - 둘 다
  `research/strategy-lab/` 안이고 커밋도 안 했다. 프로덕션 코드 위임은
  여전히 안 하는 걸로 유지 중.
- 이번 세션에서 발견한 절차적 허점: Ox Alpha가 낸 findings 폴더 중 **내가
  지시하지 않은 것(사용자가 직접 지시한 것)이 섞여 있었는데, 파일 타임스탬프로
  구분하기 전까지 몰랐다** — 다음 세션은 findings/ 아래 새 폴더가 보이면
  누가 지시했는지부터 사용자에게 확인하고 시작하는 게 안전하다.
- 이번 세션 코드 변경은 `minuteProvider.py` 신설 하나뿐(커밋 안 함, 순수
  추가 파일). `research/strategy-lab/engine/runner.py`의 기존 수정
  (V3 스모크 때 발견된 버그 수정, 이전 세션에 이미 diff 검토+회귀 115개로
  검증됨)은 여전히 미커밋 상태로 남아 있다 - 커밋 여부는 사람 판단.
