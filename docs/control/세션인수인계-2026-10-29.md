   ```bash
   # (a) PC 브라우저 → cloud.oracle.com → Cloud Shell(>_) 에서 — 새 열쇠 만들고 공개키 한 줄 출력
   ssh-keygen -t ed25519 -f ~/.ssh/vm_phone -N "" && cat ~/.ssh/vm_phone.pub
   # (b) 같은 날 PC 에서 ssh stock-new 로 VM 에 들어가 — (a) 의 'ssh-ed25519 AAAA…' 한 줄 등록
   echo "ssh-ed25519 AAAA…(복사한 한 줄)" >> ~/.ssh/authorized_keys
   # (c) 이후 폰 브라우저 → cloud.oracle.com → Cloud Shell 에서

   ```

   - 끊고 싶으면 VM `~/.ssh/authorized_keys` 에서 그 줄을 지운다.
   - 끝나면 위 1번의 "개인키를 Cloud Shell 에 먼저 올려 둬야 한다" 안내는 (c) 로 대체된다.
