## 3. Feature Gap 분석 (Book3 Ch9 vs `config/criteria/KR-2.2.json` + `lib/a5/featureRegistry.js`)

| 축 | 없는 것 (Book3 Ch9 후보 기준) |
|---|---|
| Fundamental | Net Margin(검증완료, 무신호), ROA, Equity Growth, OCF, FCF |
| Valuation | PSR, EV/EBITDA, Dividend Yield, FCF Yield — **전부 원천 데이터 없음(OCF·CapEx·EBITDA·총자산 미수집) 또는 A2a(수정주가)-A3c(비조정 발행주식수) 조정 불일치 재현(PSR/PBR류)** |
| Technical | Momentum(검증완료, 역전), MA Distance, Volatility, ATR, Turnover, Drawdown — 미검증 |
| SupplyDemand | Short Interest(의도적 배제, 절대규칙1), Credit Balance, Trading Value — 미검증 |

**다음에 검증 가능한 후보**: Volatility·Drawdown·ATR·Turnover·MA Distance(전부 A2a 가격만으로
계산, 새 블로커 없음) — 아직 미착수.

## 4. Book3 Ch13(Signal 구조) 결론

- Momentum은 이 설계에서 "단기 Feature"로 이미 분류돼 있음(§13.9) — Strategic Score(Fundamental/
  Valuation) 축이 아니다.
- Strategic Score를 직접 수정하거나 Signal로 즉시 변환하는 건 금지(§13.46).
- 의도된 결합: `Strategic Score(Context/필터) + Momentum·Trend·Volume·Regime → Short-Term
  Signal`. 단 이 Signal Layer 자체가 production에 없음(Book3 설계 문서일 뿐).

## 5. Strategy Lab 재사용성 + 데이터 공백 발견

- 5DC-v1A-P의 `engine/{signals,execution,portfolio,data}` 계약은 전략 로직과 분리돼 있어 새
  전략에 재사용 가능. 새 전략은 `strategies/<id>/{policy.json, rule.py}`만 구현하면 됨.
- **단, 이 엔진(`max_positions=10` 집중 슬롯)은 이산적 트레이드 신호 전략용이지,
  cross-sectional 필터(Momentum>0 같은) 검증에는 안 맞는 도구** — tie-break 규칙이 결과를
  지배해버림(`benchmarks/b0_buy_hold.py`의 기존 "contract mismatch" 회피 선례와 동일 이유).
  → Book3 Ch11 스타일 Decile/Forward-Return 분석으로 우회, 이번 세션에서 정착된 패턴.
- **★ 중요한 데이터 공백**: `data/backfill/scores/`가 존재하지 않는다. production `score()`는
  "오늘" 시점만 계산하는 라이브 엔진이고, 과거 PIT Score 재현(BF-1.1)은 원재료만 준비되고
  **미실행**(`CLAUDE.md` "언제든" 항목, 변화 없음). 원래 가설이었던 "Score 상위군 + Momentum"을
  그대로 검증하려면 이 백필부터 별도로 실행해야 한다 — 아직 그 결정은 안 내려짐.

## 안전 관련 메모

- 오늘 실행한 것은 로컬 Python 스크립트 2개(momentum/net_margin decile analysis)뿐 — GitHub
  Actions·VM·push 전부 안 건드림.
- **push 전 확인 필수**: 현재 로컬이 origin/main보다 **1 커밋 앞서 있고 2 커밋 뒤처져 있다**
  (`ahead 1, behind 2`, 이 세션이 끝난 시점 기준). 다음 세션이 push하기 전 반드시
  `git fetch origin` → `git log HEAD..origin/main`로 겹침 확인부터 할 것(CLAUDE.md Git 규칙).
- 로컬 uncommitted 상태(`.obsidian/`, `HANDOVER_2026-08-17.md`, 루트의 각종 `analyze_*.py`·
  `audit_*.py` 등, `graphify-out/`, `reports/`, `docs/control/ChatGPT-...`·`...-deepseek-...`)는
  **이 세션이 만든 게 아니다** — 손대지 않았다.
