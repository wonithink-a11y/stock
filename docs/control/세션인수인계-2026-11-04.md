## 함정
- 이 PC 의 bash 도구에서 python heredoc 안에 `'''` 가 들어가면 한 번 파싱 실패가 났다 — 긴 텍스트는 Write 로 파일에 쓰고 읽어 넣는다.

- 크립토 카드는 이제 홈의 **실계좌** 화면에만 나온다(기본 모의 화면엔 없음) — 테스트 passkey 의 홈 검사도 `/?a=live` 로 바꿨다.
- WebSearch 는 이 세션에서도 라우팅 오류 → 브라우저 패널(구글)로 조사. 네이버 검색은 패널에서 차단.
