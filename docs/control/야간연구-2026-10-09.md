## 규칙 (위임 아래에서도 바뀌지 않는 것)

- 연구 전용. 실주문·계좌·autotrader·VM 유닛·`config/policies`·`config/criteria` 는 건드리지 않는다. 점수·매매 연결은 아침에 사용자 GO.
- 연구마다 **사전등록 커밋 → 계산 코드(+selftest) 커밋 → 1회 실행 → 결과·해석 커밋**. 사용자 GO 자리는 "사용자 사전 위임(2026-10-09 밤)"으로 적는다.
- '최적화'는 TRAIN 안에서만 하고 VALID·TEST 는 고른 값으로 1회만 본다. 같은 표본에서 결과를 보고 칸을 다시 고르지 않는다.
- CLAUDE.md '안 한다' 라인(돌파·모멘텀 추격·거래량 급증 매수·Stine·스캘핑·지수 단기 10일 최저 규칙·팩터 조합 54축·PBR+가치 계열 등)은 재시험하지 않는다.
- 기록 규칙: 결과 표에 gross·비용 후 net·손익분기 비용, 머리말 `reason` 첫머리 "신호: … · 경제성: …".
- 데이터 수집은 허락 없이 해도 되지만 한도를 지킨다(DART 하루 2만 콜, KRX 는 기존 수집기 대기 간격 그대로). 키는 `.env` 에서만 읽는다.
