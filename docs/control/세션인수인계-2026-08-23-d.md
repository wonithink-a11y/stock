## 3. Macro Regime Layer — 소스확인 → 설계 → selftest → 실제 백필

**소스확인**(`findings/macro-regime-layer-data-source-check-2026-08.md`):
미국 금리(FRED DFF·DGS10, 무료무키)·미국시장(NASDAQCOM)·한국시장(네이버
KOSPI, count 확장)까지는 바로 백필 가능. 한국 물가·경기는 **FRED 경유
계열이 2023-11~2024-03에서 갱신 정지된 걸 실측 확인** — 못 채운다.

사용자가 한국은행 ECOS API 키를 발급받아 `.env`(`ECOS_API_KEY`)에 등록.
라이브 조회로 한국 금리(국고채3년·회사채AA-3년, 일별)·신용스프레드(파생)·
CPI·경기선행/동행순환변동치(월별)까지 전부 확인 — **ECOS 원천은 정상
최신 갱신 중**(FRED가 막혀 있었을 뿐, 한국이 통계를 안 내는 게 아니었다).

**설계**(`findings/macro-regime-layer-design-2026-08.md`, 사용자 지시
10항목): 새 join 로직 없이 기존 `macro_common.py::asof_join_kr()` 재사용,
월별 시리즈는 "참조월 말일+lag일"을 usableFromDate로 미리 계산해 같은
함수에 태움(CPI lag=5일, 경기종합지수 lag=60일 — 웹검색 기반 보수적
추정, 12월 예외를 균일 상수로 흡수). synthetic PIT selftest
(`test_macro_regime_layer_pit.py`) 12건 PASS.

**실제 백필**(`build_macro_layer_backfill.py`): 9 raw + 1 derived(신용
스프레드) 10개 컬럼, `market_regime_features.parquet` 25→**45컬럼**(행수
2,604 무변경). Audit 15건 PASS, **기존 25컬럼 diff=0**(백업본과 직접
대조 확인). 커밋 `4989745`.

## 6. PBR 진입 타이밍 필터 실전 backtest — 완전히 기각

`build_pbr_ratefilter_selection.py`(런 단위로 hiking 시작월만 남기는
selection.json 필터, 원본 `pbr_value_v1` 무변경) + `pbr_ratefilter_vs_
baseline_mtm.py`(동일 엔진 MTM 비교).

**결과**: CAGR +4.72%→+2.26%(-2.46%p), Sharpe 0.4556→0.3293, **Calmar도
악화**(0.2175→0.1836, 추가 backtest 없이 산술로 확인). **원인**: 2022년
PBR-EW 초과수익은 컸지만 PBR **자신의 절대수익은 그 해에도 -2.38%로
마이너스**였다 — EW가 더 나빴을 뿐. 2020·2025처럼 금리와 무관하게 PBR이
잘된 해를 필터가 걸러내는 손실이 2022년 방어 이득보다 컸다. **"상대적
우위를 설명하는 축"과 "타이밍 필터로 쓸 축"은 다른 질문**이라는 방법론적
교훈. findings: `pbr-ratefilter-backtest-2026-08.md`.

새 전략 디렉터리 `strategies/pbr_value_v1_ratefilter/`는 원본

미커밋)로 로컬에만 남기고 미커밋. 생성 스크립트·findings 문서만 커밋함.
